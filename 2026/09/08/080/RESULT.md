# Three binary cyclic symbol-pair codes meeting the b-symbol Griesmer bound outside the two known families

## Context

The b-symbol (for b=2, symbol-pair) metric models read channels whose outputs
are overlapping b-tuples, motivated by high-density storage (Cassuto–Blaum;
Yaakobi–Bruck–Siegel). Shi–Zhu–Helleseth (arXiv:2109.13764) conjectured a
b-symbol Griesmer bound for cyclic codes and connected the Hamming, b-symbol,
and generalized Hamming metrics. Luo–Ezerman–Güneri–Ling–Özbudak
(arXiv:2401.04941, Theorem 1) proved a b-symbol Griesmer bound for all linear
codes by simplex concatenation and gave two distance-optimal families.
At q=2, b=2 these are family A: (2^t−1, t, 3·2^{t−2}) and family B:
(2^t−1, t+1, 3·2^{t−2}−1), t ≥ 2. Singleton-attaining (MDS/AMDS) symbol-pair
work uses a disjoint optimality notion. Whether further cyclic codes meet the
b-symbol Griesmer bound outside families A/B was open at short lengths.

## Definitions

- Binary cyclic code of length n: ideal in GF(2)[x]/(x^n+1) generated by a
  monic divisor g | x^n+1; dimension k = n − deg g. Over GF(2) the only
  nonzero constacyclic constant is a=1, so constacyclic = cyclic.
- Symbol-pair (b=2) weight: wt_2(c) = #{i : (c_i, c_{i+1}) ≠ (0,0)}, indices
  mod n; equivalently popcount(c OR rotl(c)). Pair distance d_2 = minimum
  wt_2 over nonzero codewords. A (n,k,d_2)^2_2 code is binary linear of
  length n, dimension k, pair distance d_2.
- Luo b-symbol Griesmer bound (q=2, b=2): 3n ≥ Σ_{i=0}^{k−1} ⌈2d_2/2^i⌉.
  Griesmer value d_G(n,k) = max{d ≤ n : Σ ⌈2d/2^i⌉ ≤ 3n}; gap_G = d_G − d_2.
  A code meeting it (gap_G = 0) is Griesmer-optimal.
- Singleton bound (b=2): d_S = n − k + 2; gap_S = d_S − d_2.
- Generators written as hex bitmaps (LSB = constant term), e.g. 0x33 = x^5+x^4+1.

## Result (headline)

Exhaustive survey of **all** binary cyclic codes at 3 ≤ n ≤ 15 (every monic
divisor g | x^n+1, 135 codes with k ≥ 1, every codeword pair-tallied with two
independent tallies) yields **three** cyclic codes meeting the b-symbol
Griesmer bound with equality that lie **outside** both Luo families A and B,
each with Singleton gap 1 (Griesmer strictly stronger than Singleton):

| (n,k) | generator g | d_H | d_2 | d_G | gap_G | d_S | gap_S | pair spectrum A^2 |
|---|---|---|---|---|---|---|---|---|
| (8,3) | 0x33 = x^5+x^4+1 | 4 | 6 | 6 | 0 | 7 | 1 | A^2_6=4, A^2_8=3 |
| (12,5) | 0xbd = x^7+x^5+x^4+x^3+x^2+1 | 4 | 8 | 8 | 0 | 9 | 1 | A^2_8=9, A^2_9=16, A^2_12=6 |
| (14,3) | 0xb97 = x^11+x^9+x^8+x^6+x^4+x^2+1 | 8 | 12 | 12 | 0 | 13 | 1 | A^2_12=7 (constant pair-weight) |

Non-membership: families A/B both require n = 2^t−1; n = 8, 12, 14 are not
of that form (checked arithmetically). Boundary sums: S(8,3,6)=21 ≤ 24 <
S(8,3,7)=25; S(12,5,8)=31 ≤ 36 < S(12,5,9)=37; S(14,3,12)=42 ≤ 42 <
S(14,3,13)=46, where S = Σ_{i<k}⌈2d/2^i⌉.

Supporting census facts: family A re-found at (3,2,3), (7,3,6), (15,4,12);
family B at (3,3,2), (7,4,5), (15,5,11), and no others in range; the (31,5,24)
family-A reference reconstructed directly from h=x^5+x^2+1 via g=(x^31+1)/h
has d_H=16 and constant pair-weight 24 (A^2_24=31), d_G=24. Full 135-code
table with spectra and per-length records is committed in the artifacts.

## Proof / evidence

Computational proof by exhaustive enumeration (machine-certified, replayable),
not an analytic infinite-family proof:

1. `census.py`: enumerates all monic g | x^n+1 by GF(2) polynomial division
   for 3 ≤ n ≤ 15; for each code enumerates all 2^k codewords c = m·g,
   asserts window-count tally equals bitwise c|rotl(c) tally on every
   codeword (140,806 asserts = Σ 2^k), accumulates full spectrum, d_H, d_2,
   d_G, d_S, gaps, family flags; writes census_all.csv / best_per_length.json.
2. `verify.py` (independent path): string/bit-list tally with fresh
   long-division and Griesmer routines re-tallies the three headlines and
   builds the (31,5,24) reference directly (no divisor enumeration),
   ending VERIFY_OK; output verify.json.
3. The auditor independently recomputed divisibility, dimensions, d_H, d_2,
   spectra, codeword counts, Griesmer boundary sums, Singleton gaps, family
   non-membership, per-n divisor counts, and the (31,5,24) construction with
   separate code — all match.

Run: `python3 output/artifacts/census.py && python3 output/artifacts/verify.py`
prints tables and ends with VERIFY_OK (seconds-scale; stdlib only).

## Limitations

- Scope is binary cyclic codes at 3 ≤ n ≤ 15 (constacyclic coincides with
  cyclic over GF(2)). No infinite-family generalization is claimed.
- Equivalence/automorphism classification beyond the reciprocal-twin
  observation is not attempted; the CSV contains further Griesmer-meeting
  codes (e.g. a (14,5,10) pair) listed but not elevated to headline claims.
- Per-length record tie-break (larger k, then smaller generator) is a
  reporting convention; the full table is authoritative.
- DRAFT §3.3 per-length shorthand line is cryptically worded; authoritative
  values are in census_all.csv / best_per_length.json / verify.json.

## Reproducibility

Artifacts: output/artifacts/census.py, verify.py, census_all.csv,
best_per_length.json, verify.json. Stdlib-only Python 3. Fresh-machine replay
is the two-command run above. Deterministic; no randomness, no external data.
