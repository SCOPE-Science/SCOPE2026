# Replayable nilpotency/derived census and class-2-quotient extremals for the 51 groups of order 32

## Context and motivation

Groups of order 32 ($2^5$, 51 isomorphism classes) are the smallest 2-power
where nilpotency class, derived subgroup, center, Frattini subgroup, and
automorphism behavior diversify enough to calibrate general $p$-group bounds
(Burnside–Hall through Higman–Sims/coclass), isoclinism families, capability
criteria, and Noether rationality (Chu–Hu–Kang–Prokhorov: 2-groups of order
$\le 32$ have rational invariant fields; Chu–Hu–Kang–Kunyavskii and Hoshi for
orders 64/128). A closed, from-presentation, machine-checkable census with
witnesses gives later classifications a checkable base case.

## Definitions

Let $G$ have order 32, with multiplication table $T$, identity $e$, inverses
from $T$. All invariants are recomputed from $T$, not looked up:

- abelian: $T[a,b]=T[b,a]$ for all $a,b$.
- center $Z(G)=\{a: T[a,b]=T[b,a]\ \forall b\}$; record $|Z(G)|$.
- commutator $[a,b]=a^{-1}b^{-1}ab$ via $T$; derived subgroup
  $G'=\langle [a,b]:a,b\in G\rangle$; record $|G'|$.
- lower central series $\gamma_1=G$, $\gamma_{i+1}=[G,\gamma_i]$ (subgroup
  generated by $[a,h]$, $a\in G$, $h\in\gamma_i$, normally closed);
  nilpotency class $c$ with $\gamma_{c+1}=1$ ($c=1$ iff abelian).
- $\gamma_3(G)$: third term; record $|\gamma_3|$.
- class-2 quotient $Q=G/\gamma_3(G)$ with coset multiplication from $T$;
  record $|Q'|$ (derived order of $Q$). For abelian or class $\le 2$ groups,
  $|\gamma_3|=1$ and $|Q'|=|G'|$.
- Frattini subgroup $\Phi(G)=G^2[G,G]$ ($G^2=\langle a^2\rangle$); Frattini
  rank $d=\log_2|G/\Phi(G)|$; record $d$ and $|\Phi|$.
- conjugacy classes via $gag^{-1}$ orbits from $T$; record count $k(G)$ and
  check $\sum |{\rm cl}|=32$ with singletons $=|Z(G)|$.
- order profile: counts of elements of each order from $T$.
- Local indices g0..g50 are lane-internal representatives stored in
  `reps32.pkl`; they are NOT GAP `SmallGroup(32,i)` IDs.

## Result (certified headline)

Over the 51 committed representatives (g0..g50), verified by `verify.py`
(`VERIFY_OK`):

- abelian: 7; nonabelian: 44.
- nilpotency class: $1\times 7$, $2\times 26$, $3\times 15$, $4\times 3$.
- $|G'|$: $1\times 7$, $2\times 17$, $4\times 24$, $8\times 3$.
- $|Z(G)|$: $32\times 7$, $8\times 15$, $4\times 19$, $2\times 10$.
- Frattini rank: $1\times 1$, $2\times 19$, $3\times 24$, $4\times 6$,
  $5\times 1$.
- conjugacy-class counts: $32\times 7$, $20\times 15$, $17\times 2$,
  $14\times 19$, $11\times 8$.
- $|\gamma_3|$: $1\times 33$, $2\times 15$, $4\times 3$.
- class-2-quotient derived $|Q'|$: $1\times 7$ (abelian), and over the 44
  nonabelian groups $2\times 35$, $4\times 9$.
- Joint class/derived cells: $(1,1)\times 7$, $(2,2)\times 17$,
  $(2,4)\times 9$, $(3,4)\times 15$, $(4,8)\times 3$.
- The 7 abelian order profiles present are exactly the 7 abelian groups of
  order 32: C32; C16×C2; C8×C4; C8×C2×C2; C4×C4×C2; C4×C2³; C2⁵.
- Frattini-rank correlation (certified joint data): rank 5 once (C2⁵); rank 4
  six times (all class $\le 2$); the three class-4 groups all rank 2;
  rank 3 (24 groups) spans classes 1–3. Full joint table in
  `table.json`/`table.csv`.

**Extremal A (maximal class, verified).** Exactly 3 of the 51 groups have
class 4 (g48, g49, g50), each with $|G'|=8$, $|Z(G)|=2$, $|\gamma_3|=4$,
class-2-quotient derived order 2, class count 11, Frattini rank 2. No group of
order $2^5$ has class $\ge 5$. Hence the class-4 triple is the maximal-class
extremal set, with explicit witnesses in `reps32.pkl`.

**Extremal B (minimal class-2 derived quotient, verified).** For every
nonabelian group $G$ of order 32, $G/\gamma_3(G)$ has derived order $\ge 2$;
this bound is attained (35 witnesses, e.g. g2). Hence the minimal class-2
derived quotient over nonabelian groups is 2. (The only quotient-derived-1
cases are the 7 abelian groups, already class 1.)

## Proof / evidence (distinguish proof from computation)

- Construction: hand-built seeds for the 5 groups of order 8; central
  extensions via $H^2(Q,C_2)$ as an $\mathbf{F}_2$ nullspace of normalized
  2-cocycle equations modulo coboundaries, one representative per
  cohomology class, explicit extension tables; bootstrap $8\to 16$ (14
  classes) $\to 32$ (51 classes) with signature-binned exact backtracking.
  Every nonabelian 2-group has a central $C_2$ quotient, so central
  $C_2$-extensions of order-16 groups cover order 32; normalized cocycle /
  coboundary linear algebra is standard.
- Certification (`verify.py`, stdlib+numpy): (1) each of 51 tables is a group
  of order 32 (identity, inverses, full $32^3$ associativity, vectorized);
  (2) recomputed class/$|G'|/|Z|$/Frattini-rank match `table.json`; audit
  independently rechecked class counts, class equations, LCS lengths
  $=$ class$+1$, $\gamma_3$ sizes, quotient derived orders with quotient
  class $\le 2$; (3) pairwise distinctness: 41 signature bins
  (abelian, class, $|Z|$, $|G'|$, Frattini rank, order profile, class count,
  abelianized-quotient type) plus 11 within-bin exact-backtracking
  non-isomorphism checks. Backtracking pruning checks only already-assigned
  products, so a true isomorphism is never pruned: distinctness verdicts are
  sound. Completeness follows from 51 pairwise-distinct groups of order 32
  together with the established theorem that there are exactly 51 classes
  (GAP SmallGroups library); the $H^2$ route plus $5/14/51$ checkpoints
  corroborate it.
- Extremals A/B are direct readings of the certified table plus the general
  bound ${\rm class}\le 4$ for $|G|=2^5$; witnesses named above.
- Automorphism orders are NOT part of the certified headline: `autorders_partial.json`
  holds 38/51 computed orders by generator-tuple backtracking with full leaf
  verification; the 3 missing abelian orders (g0, g1, g27) are covered by the
  analytic abelian-Aut formulas, leaving 10 nonabelian orders (g28–g34,
  g48–g50) timed out and recorded unknown. Analytic
  abelian orders confirmed (C32: 16, C16×C2: 32, C8×C4: 128, C8×C2×C2: 384,
  C4×C4×C2: 1536, C4×C2³: 21504, C2⁵: 9999360 $=|GL(5,2)|$); global largest
  $|{\rm Aut}|$ is C2⁵ analytically, but no certified
  largest-nonabelian-$|{\rm Aut}|$ ranking is claimed.

## Limitations

- Local indices g0..g50; no mapping to GAP `SmallGroup(32,i)` provided.
- 10/51 nonabelian $|{\rm Aut}|$ values unfinished (g28–g34, g48–g50; plus 3
  abelian orders covered analytically); hence no certified
  largest-nonabelian-$|{\rm Aut}|$ claim and no Aut-orbit-count column.
- Isomorphism completeness evidence is the $H^2$-class enumeration plus
  textbook checkpoints 5/14/51 and the external $N(32)=51$ theorem; the
  verifier rechecks axioms, invariants, and pairwise distinctness but does
  not re-derive completeness from scratch.
- Abelian $|{\rm Aut}|$ analytic formulas cross-checked against backtracking
  but not independently re-derived in this audit.
