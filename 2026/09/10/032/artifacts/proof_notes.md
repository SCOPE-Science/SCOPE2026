# Proof notes (target-directed deepening)

## Setup
D_l: triangles TL={a1,a2,a3}, TR={b1,b2,b3}, bridge path a1=z0,z1,...,z_{l-1},z_l=b1
(l=1: edge a1b1, no interior vertices). Cover ideal J(D_l) = intersection over
edges e of P_e=(vars of e) (Alexander dual of edge ideal; J radical monomial).
J(D_l)^{(2)} = intersection over edges of P_e^2 (Herzog-Hibi-Trung: monomial
x^a in J^{(2)} iff a is a 2-cover: a_i+a_j >= 2 for every edge ij).
J(D_l) monomial-generated by (all) vertex covers; J(D_l)^2 monomial-generated by
pair-sums c1+c2 of covers; restricting to MINIMAL covers is enough (any cover
contains a minimal one, pair-sum only larger). Monomial m in J^2 iff some
minimal-cover pair-sum p <= m coordinatewise.

## Lemma A (tau). tau(D_l) = 4 + floor((l-1)/2).
Lower bound: any cover C has |C cap TL| >= 2 and |C cap TR| >= 2 (a triangle
needs 2 vertices; TL, TR, Z pairwise disjoint). For l >= 2, the interior edges
z_i z_{i+1} (1 <= i <= l-2) have both endpoints in Z, so C cap Z is a vertex
cover of the path on vertices z_1..z_{l-1} (l-1 vertices), hence
|C cap Z| >= floor((l-1)/2). Total |C| >= 4 + floor((l-1)/2) (for l=1, 2+2=4).
Upper bound: C* = {a1,a2,b1,b2} U {z_{2j} : 1 <= 2j <= l-1} is a cover of that
size: TL covered by {a1,a2}, TR by {b1,b2}; bridge-path edges a1z1 and
z_{l-1}b1 by endpoints a1,b1; each interior edge z_i z_{i+1} by z_i (i even)
or z_{i+1} (i odd). Machine cross-check l<=12 in verify_handproof.py.

## Lemma B (target part (a), all l). w_l = full vertex product.
Every edge-sum = 1+1 = 2, so w_l in J^{(2)}. deg(w_l) = l+5 < 2*tau(D_l):
even l=2k: 2tau = 6+2k > 2k+5; odd l=2k+1: 2tau = 8+2k > 2k+6. Every nonzero
monomial of J^2 has degree >= 2tau (sum of two covers), so no J^2 generator
divides w_l: w_l not in J^2. Hence w_l in J^{(2)} \ J^2 for ALL l >= 1.

## Lemma C (minimal 2-cover criterion). If a is a 2-cover and a_i >= 3 for some
i, then a - e_i is still a 2-cover (all sums through i stay >= 2). Hence every
MINIMAL 2-cover has entries in {0,1,2}: enumeration over {0,1,2}^n is complete.
Minimal 2-covers = minimal monomial generators of J^{(2)}.

## Lemma D (five universal gap patterns). For every l >= 1, with 1s on all
bridge-interior vertices, the patterns (TL|TR) =
W0=(111|111), M1=(111|202), M2=(111|220), M3=(202|111), M4=(220|111)
are minimal 2-covers outside J(D_l)^2. General hand proofs:
- 2-cover: triangle-internal sums >= 2 by inspection (111: all pairs 2;
  202: pairs 2+0=2,0+2=2,2+2=4); bridge-path sums: every endpoint/interior
  value is in {1,2} (a1,b1 in {1,2}, all z = 1), so every adjacent sum >= 2.
- Minimality: let m be such a pattern and decrement one positive entry.
  Triangle 1 with two neighboring 1s (111 side, or the 1-side of 202): the
  triangle edge to its neighboring 1 drops to 0+1 = 1. Triangle 2 on an edge
  with a 0 (202 side): that edge drops to 1+0 = 1. Interior z_k = 1:
  some adjacent bridge-path edge has both endpoints 1 (z_{k-1},z_{k+1} are 1
  or endpoints a1,b1 in {1,2}; if the only 1-neighbor... check: decrementing
  z_k to 0 gives neighbor-sum 0+1 = 1 on any edge to a 1-valued neighbor;
  every z_k has such an edge: for 1<k<l-1 use z_{k-1}z_k; for k=1 use a1z1
  unless a1 = 2 and... if a1 = 2 (M3/M4) use z1z2 (l>2) or z1b1 (l=2,
  b1 = 1): always some incident edge with other endpoint 1; symmetrically
  for z_{l-1}). Endpoint decrement (a1/b1 = 1 -> 0): bridge edge a1z1 resp.
  z_{l-1}b1 drops to 0+1 = 1 (l >= 2) or bridge edge a1b1 drops to 0+1
  (l = 1); endpoint 2 -> 1: the triangle edge to its 0-neighbor drops to
  1+0 = 1. So no single decrement is a 2-cover: m minimal.
- Outside J^2 (M1, hand counting, valid for every l): b2-exponent 0 forces
  b1,b3 in BOTH covers c1,c2 (edges b1b2,b2b3); each cj meets TL in >= 2
  vertices (restriction of a cover to TL covers the triangle, needs 2), so
  c1+c2 uses >= 4 slots on TL, but m|TL = (1,1,1) allows <= 3. Contradiction.
  M2 same with b3 = 0. M3/M4 mirror (a-zero forces two a-vertices in both
  covers; TR = (1,1,1) allows <= 3 < 4). W0 by Lemma B degree gap.
  Machine re-verified (no pair-sum below) l <= 12.

## Lemma E (forcing/sdefect identity). sdefect(J) = #{minimal 2-covers of J
outside J^2}, exactly, characteristic-free (all ideals monomial).
Proof: minimal monomial generators of J^{(2)} = minimal 2-covers (Lemma C).
Adding all outside ones gives J^{(2)} = J^2 + (outside ones) (upper bound).
For the lower bound, use graded Nakayama on M = J^{(2)}/J^2: minimal number of
S-generators of M = dim_k M/mM. Each minimal 2-cover m outside J^2 represents
a nonzero element of M/mM (m not in J^2 + mJ^{(2)}: m not in J^2 by hypothesis,
m not in mJ^{(2)} by minimality as an ideal generator), and distinct such m
are k-linearly independent in M/mM (distinct monomials, neither dividing the
other, no k-linear relation). Hence equality. Equivalently, in monomial terms:
any monomial f in J^{(2)} lying below a minimal 2-cover m (f|m) equals m, so
each outside minimal 2-cover must itself occur among any monomial generating
set over J^2.

## Consequences.
- Target (b) (defect exactly 1) is FALSE: sdefect(D_1) = 5 exactly (the 5
  patterns; complete enumeration: 15 minimal 2-covers, 10 in J^2).
- In fact sdefect(D_l) >= 5 for EVERY l >= 1 (Lemma D + E); exact computed
  values l=1..8: 5,7,13,20,29,47,70,110 (complete {0,1,2}^n enumeration +
  pair-sum test; l=7,8 via extended run).
- Target (a) TRUE for all l (Lemma B). The "mixed" witnesses M1..M4
  (single-triangle gap 111 on one side x ordinary doubled pattern 202/220 on
  the other, glued with 1s along the bridge) are the obstruction to defect-1.
