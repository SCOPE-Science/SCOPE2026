# Impossibility of short non-commuting 2-isogeny generators at j = 1728, p = 1031

## Context

The admitted target asked for two explicit non-backtracking 2-isogeny loops
C1, C2 based at j = 1728 at p = 1031, each of length at most 8, that do not
commute and generate an order of explicit discriminant and index in
End(j = 1728), each with a Velu-verified j-sequence and a quaternion
left-ideal word in a fixed maximal order of B_{1031,infty}.
This record resolves the target by rigorous disproof: the requested
conjunction is impossible.

## Definitions

Let p = 1031 (prime, p = 3 mod 4) and E0: y^2 = x^3 + x over Fp, so
j(E0) = 1728 = 697 mod p. Let i be the order-4 automorphism
i(x,y) = (-x, a y) with a^2 = -1 in Fp2, and let pi be p-Frobenius.
Then i^2 = -1, pi^2 = [-p], pi i = -i pi. Write k = i pi.
A 2-isogeny loop of length l based at j = 1728 is a chain of l
2-isogenies starting and ending at j = 1728; identifying the terminal
curve with E0 via a j-preserving isomorphism (degree 1) gives an
endomorphism of degree 2^l. Q(i) denotes the commutative quadratic
subfield generated by i.

## Result

End_{Fbar_p}(E0) = Z + Z i + Z (1+k)/2 + Z (i+j)/2, a maximal order of
discriminant p^2. With alpha = x1 + x2 i + x3 (1+k)/2 + x4 (i+j)/2,

  4 N(alpha) = (2x1+x3)^2 + (2x2+x4)^2 + p (x3^2+x4^2).

If alpha is outside Q(i), i.e. (x3,x4) != (0,0), then
N(alpha) >= ceil(p/4) = (1+p)/4 = 258, sharp (e.g. (i+j)/2 has norm 258).
Since every length-l <= 8 based 2-isogeny loop has degree 2^l <= 256 < 258,
every such loop defines an endomorphism in Q(i) cap End(E0).
Consequences: (1) any two such loops commute; (2) no set of such loops
generates an order (rank 4) in End(E0), a fortiori no maximal order
containing Frobenius from loops alone. The target conjunction (two
non-backtracking length-<=8 non-commuting generating loops with Velu
sequences and ideal words) is impossible. Context: short loops exist
(e.g. 1+i of norm 2 with kernel {O,(0,0)}; Phi_2(697,Y) has roots
{697,878}), but non-commutation at length <= 8 does not.

## Proof / evidence

E0 has #E0(Fp) = p+1 = 1032 (direct count), trace 0, hence supersingular.
On E0[2] = {O,(0,0),(a,0),(-a,0)}, both i and pi act as the transposition
(a,0) <-> (-a,0) (using a^p = -a), so (1+i pi) and (i+pi) kill E0[2].
Since [2] is separable and central with kernel E0[2] (char != 2),
(1+k)/2 and (i+j)/2 are endomorphisms. The order
O1 = Z + Z i + Z (1+k)/2 + Z (i+j)/2 has Gram transition determinant 1/4
from Z[i,pi] (discriminant 16p^2), hence discriminant p^2, maximal; by
Deuring, O1 = End(E0). The norm formula and gap above are exact integer
arithmetic. Replay: `python3 output/artifacts/verify_disproof.py`
(stdlib only) prints VERIFY_OK and writes output/artifacts/verify.log.

## Limitations

Disproof applies to the stated bound (each loop length <= 8) at p = 1031,
j = 1728. Longer loops (degree >= 512) leave Q(i) and the usual generation
phenomenon resumes. No claim is made about minimal generating lengths or
other primes/vertices.
