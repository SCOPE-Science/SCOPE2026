# One-step Pasch neighbourhood of the Pasch-containing cyclic STS(19)s takes exactly five joint Pasch–mitre values

## Context

Steiner triple system classification between orders 15 and 19 is a recognized
frontier. The full STS(19) census (Kaski–Östergård: 11,084,874,829 systems)
is stored as a ~39 GB compressed archive, unreachable for direct inspection
in a short session. A feasible natural subfamily is the symmetric tier: the
four cyclic STS(19)s, hand-typable from published difference triples in
Mathon–Phelps–Rosa notation, and their one-step Pasch-switch neighbourhoods.
The admitted target asked whether one Pasch surgery already diversifies the
classical configuration profile around symmetric seeds: with
J(S) = (p(S), m(S)) the joint Pasch/mitre count, does J take at least 10
distinct values over N = {two Pasch-containing cyclic seeds} ∪ {all
one-step Pasch-switch isomorphism classes}, including an
equal-automorphism-order separated pair?

## Definitions

- An STS(19) is a pair (V,B) with |V| = 19 and 57 triples such that every
  unordered point pair lies in exactly one triple.
- A cyclic STS(19) is generated by developing three base blocks
  {0,a},{0,b} modulo Z_19; each ordered difference triple (a,b) denotes the
  base block {0,a,b}.
- A Pasch configuration is four blocks on six points in quadrilateral form
  (each point in exactly two of the four blocks); equivalently a 6-point
  subset spanning exactly four blocks. A Pasch switch replaces the four
  blocks by the unique opposite Pasch on the same six points.
- A mitre configuration is the classical five-block seven-point
  configuration: one root point of degree 3, six arm points of degree 2;
  equivalently a 7-point subset spanning exactly five blocks with point
  degrees [3,2,2,2,2,2,2].
- C1 = [[1,4],[2,9],[5,11]] and C2 = [[1,8],[2,5],[4,10]] are the two
  Pasch-containing cyclic difference families on Z_19.
- N is {C1,C2} plus every STS(19) isomorphism class reachable by exactly
  one Pasch switch from C1 or C2. L is the labelled set: the two seed
  block-sets plus all 57 one-step switched block-sets on the fixed point
  set Z_19 with no quotient by isomorphism.

## Result

Let J(S) = (p(S), m(S)) be the joint Pasch count and mitre count. Then:

1. |{J(S) : S ∈ N}| ≤ 5 < 10. The target claim of at least 10 distinct
   joint values is false.
2. Exactly: the labelled switch ledger attains precisely the five values
   (19,57), (22,48), (29,16), (30,7), (38,0); the isomorphism-class set N
   cannot exceed this set. Seeds: J(C1) = (19,57), J(C2) = (38,0).
   Every C1 switch has J = (22,48); C2 switches split 19 with (29,16)
   and 19 with (30,7).
3. The equal-automorphism-order separation conjunct is moot because the
   10-value threshold already fails.
4. Supplementary isomorphism reduction: N has exactly 5 classes with
   (J,|Aut|) = ((19,57),38), ((38,0),114), ((22,48),2), ((29,16),6),
   ((30,7),6).

## Proof / evidence

J is an isomorphism invariant (configurations are defined by block
incidence, preserved by any point relabelling). Every class in N has a
labelled representative in L, so {J(S):S∈N} ⊆ {J(D):D∈L} and
|J(N)| ≤ |J(L)|. Computing |J(L)| = 5 therefore refutes the target with
zero reliance on canonical labelling or isomorphism decisions.

Computation (stdlib only, replayable):

1. Cyclic census. Difference-triple search over Z_19 yields 864 ordered
   families, all verified STS(19) by pairwise-balance check. Pasch census:
   486 with 19 Pasch, 216 with 0, 162 with 38. Hence exactly two
   Pasch-containing cyclic types, represented by C1 (19 Pasch, 57 mitre)
   and C2 (38 Pasch, 0 mitre). The other two cyclic types have
   J = (0,114) and (0,0).
2. Switch enumeration. Generic Pasch trade completion (recompute the unique
   opposite Pasch on the same six points): C1 yields 19 distinct labelled
   switched block-sets, C2 yields 38; all 57 are pairwise distinct as
   labelled sets, distinct from both seeds, with zero cross-seed overlap.
   So |L| = 2 + 19 + 38 = 59 labelled designs.
3. Dual independent counting with 0 mismatches on all 59 designs. Fast:
   shared-point-pair Pasch enumerator and root-plus-3-arms-plus-transversal
   mitre counter. Independent: 6-subset census (a Pasch iff a 6-set spans
   exactly 4 blocks, each verified a quadrilateral with all six points of
   degree 2) and 7-subset degree-sequence census (a mitre iff a 7-set spans
   exactly 5 blocks with degrees [3,2,2,2,2,2,2]). This audit independently
   replayed both paths on seeds and all 57 switches and confirmed agreement.
4. Isomorphism reduction (supplementary, not load-bearing): exact
   backtracking isomorphism test groups the 59 labelled designs into
   5 classes with automorphism orders 38, 114, 2, 6, 6.

## Limitations

- Seed identity rests on hand-typed difference triples, cross-checked by
  the exhaustive 864-family cyclic census (only Pasch numbers 19/0/38
  occur); a seed outside these types would fail the replay script's STS
  and Pasch checks.
- The ceiling argument uses labelled counting only and is therefore immune
  to isomorphism-test bugs; the 4-class cyclic grouping and the
  iso-class reduction are supplementary.
- Mitre definition is the classical 5-block/7-point configuration; both
  counters implement this definition and agree on all 59 designs.
- The result concerns the one-step Pasch ball only; it makes no claim
  about multi-step neighbourhoods or other configurations.

## Reproducibility

- `python3 output/artifacts/verify_final.py` (~1 s core ledger plus
  per-J-value independent recount): rebuilds seeds, all 57 switches,
  the labelled J ledger, and recounts one representative per J value
  with both independent counters; prints VERIFY_OK and writes
  `output/artifacts/ledger_labelled.json`.
- Full 59-design dual recount runs in seconds with stdlib only.
- Artifacts: `sts19_lib.py` (counters, switch, isomorphism routines),
  `verify_final.py` (bounded verifier), `ledger_labelled.json` (certified
  ledger with representative block lists), `neighbourhood.json`
  (5-class reduction with automorphism orders).
