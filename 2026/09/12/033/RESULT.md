# Countable path-swap coherence rank in Cat: strict countable presentability via per-index finite separators

## Context

Let Graph be the presheaf category Set^{E ⇉ V} and T the free-small-category monad with forgetful functor U : Cat → Graph and left adjoint F. Finitary monads preserve sifted colimits, in particular reflexive coequalizers, but need not preserve coequalizers of countably generated non-reflexive congruences. The admitted target asks for a decision for an explicit parametrized path-swap family: either the Graph comparison map is an isomorphism with a finite subfamily generating the full categorical congruence (finite presentability), or there is an explicit path-level mismatch and per-index separating functors showing strict countable presentability with a rank jump.

## Definitions

Let G be the finite graph with one vertex * and three loops a, b, c. Then F(G) is the free monoid M = {a,b,c}* viewed as a one-object category. For each integer n >= 2 define words p_n = a^n b c^n and q_n = c^n b a^n in M. Let R = {(p_n,q_n) : n >= 2}. Let S ⊂ M×M be the equivalence relation generated by R as plain pairs (the underlying Graph-level relation data), and let ≡ be the categorical (monoid) congruence generated by R, closing additionally under whiskering (left/right multiplication / composition contexts). Let Q = M/≡ = <a,b,c | a^n b c^n = c^n b a^n, n >= 2>, the Eilenberg–Moore coequalizer category (one-object quotient monoid). Let Q_N = M/<p_n = q_n : n ≠ N> for N >= 2. Let X_N be a set with N+3 states {s_0, x_1..x_N, y_N, z} and E_N = End(X_N) the full transformation monoid (a finite one-object category).

## Result

Theorem. Let Q = <a,b,c | a^n b c^n = c^n b a^n for all n >= 2>. Then:

(a) Q is nontrivial and infinite: each relation preserves the Parikh (abelianization-counting) vector, so length and total exponents of a, b, c descend to Q; no generator collapses.

(b) The canonical Graph comparison map coeq(S) → U(Q) is not an isomorphism. With r = a·p_2 = aaabcc and r' = a·q_2 = accbaa, [r]_S ≠ [r']_S but r ≡ r' in Q.

(c) For every N >= 2, (p_N,q_N) is independent of all other pairs: there is an explicit homomorphism φ_N : Q_N → E_N with φ_N(p_N) ≠ φ_N(q_N). Hence no finite subfamily of R generates ≡, and Q is strictly countably presentable (countably but not finitely presentable as a monoid, hence not finitely presentable in Cat): the presentability rank jumps from finite to countable.

## Proof / evidence

Pairwise disjointness: all p_n, q_n are pairwise distinct odd-length words 2n+1 with distinct first letters a vs c within a pair and distinct block lengths across n. For (b): [p_2]_S = {p_2,q_2} since no other pair contains those words. The whiskers r, r' have even length 6, hence occur in no pair, so [r]_S = {r}, [r']_S = {r'}, distinct. In Q, left-whiskering the relation (p_2,q_2) by a is legal, so r ≡ r'. Two distinct Graph-coequalizer classes fuse in U(Q); the comparison is not injective.

For (c), define actions on the right: B = constant map c_0 (all ↦ s_0); A: s_0 ↦ x_1, x_i ↦ x_{i+1} (1 ≤ i < N), x_N,y_N,z ↦ z; C: s_0 ↦ x_1, x_i ↦ x_{i+1} (1 ≤ i ≤ N-2; empty if N=2), x_{N-1} ↦ y_N, x_N,y_N,z ↦ z. Put φ_N(a,b,c) = (A,B,C). Since B is constant, φ_N(u b v) = const_{s_0·ṽ} where ṽ is the reverse-action evaluation of v from s_0; thus φ_N(p_n) = const_{s_0·C^n} and φ_N(q_n) = const_{s_0·A^n}. Orbit lemma: s_0·A^n = x_n for 1 ≤ n ≤ N, z for n ≥ N+1; s_0·C^n = x_n for 1 ≤ n ≤ N-1, y_N for n = N, z for n ≥ N+1, by direct chain inspection with z absorbing. Hence φ_N(p_n) = φ_N(q_n) (const_{x_n} for n < N, const_z for n > N) for all n ≥ 2 with n ≠ N, while φ_N(p_N) = const_{y_N} ≠ const_{x_N} = φ_N(q_N). So φ_N factors through Q_N and separates p_N, q_N. If finite F ⊂ {n ≥ 2} generated ≡, pick N ∉ F; cong(F) ⊆ cong(R∖{N}) gives Q_F ↠ Q_N carrying p_N = q_N to Q_N, contradicting separation. So ≡ is not finitely generated on {a,b,c}. If <a,b,c | E> = Q with E finite, each e ∈ E follows from some finite R_{F_e} by Birkhoff completeness; F = ∪ F_e gives R_F ⊢ E ⊢ R, contradicting independence. Tietze elimination extends this from {a,b,c} to any finite generating set. Filtered colimits of one-object categories in Cat stay one-object, so Mon ↪ Cat preserves filtered colimits and finite presentability of a one-object category in Cat implies finite presentability as a monoid. Hence Q is not finitely presentable in Cat; it is countably presentable by construction, i.e. strictly countably presentable.

## Limitations

The headline exact witnesses (mismatch words, per-N separators, strict countable presentability) are complete. No claim is made about decidability of the word problem of Q, coherence beyond this family, or a general criterion for finite presentability of path-swap monoids.
