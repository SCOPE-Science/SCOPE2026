# Countable Inequality Rank in OrdMon: Comparison Failure with Finite Presentability

## Context

Let Pos be the cartesian closed category of posets and monotone maps. Let T be the
free ordered-monoid monad on Pos: T(X) is the free monoid X* = coproduct_{k>=0} X^k
with pointwise order (tuples comparable only at equal length, coordinatewise).
T is finitary and in fact strongly finitary: it preserves filtered colimits and
reflexive (hence sifted) coinserters. The admitted target asks what happens for a
countably generated non-reflexive inequality diagram outside that theorem, and
whether the presented ordered monoid jumps in presentability rank.

## Definitions

- P = {a,b} discrete two-point poset; M = T(P) = {a,b}* with discrete (equality) order.
- For each integer n >= 2, lambda_n is the inequality a^n b <= b a^n in M.
- Diagram: S = {s_n : n >= 2} discrete; f,g : S -> M (rightwards) with
  f(s_n) = a^n b, g(s_n) = b a^n. The pair is non-reflexive with no common section.
- C := coinserter(f,g) in Pos: least preorder on M containing equality and all
  (a^n b, b a^n), then poset-reflected.
- T(f),T(g) : T(S) -> T(T(P)) rightwards; T(S) = finite tuples of indices,
  T(T(P)) = {a,b}** = finite tuples of words.
- D := coinserter(T(f),T(g)) in Pos, with generator set
  G = {(((a^{n1}b)...(a^{nk}b)), ((b a^{n1})...(b a^{nk}))) : k>=0, n_i>=2}.
- T(C): same underlying set {a,b}**, ordered componentwise by the C-order.
- Comparison c : D -> T(C): identity on underlying tuples, monotone.
- Q: Eilenberg-Moore coinserter ordered monoid = presented ordered monoid
  < a, b | lambda_n (n >= 2) >.

## Result (mixed TARGET resolution)

1. The canonical Pos comparison map c : coinserter(T) -> T(coinserter) for the
   family {lambda_n : n >= 2} is a bijective monotone map but NOT an
   order-isomorphism. Both orders equal diagonal plus generators exactly, and the
   explicit mismatch pair p = (a^2 b, a), q = (b a^2, a) satisfies p <= q in T(C)
   but p not<= q in D.
2. Simultaneously the ordered monoid Q presented by all lambda_n is finitely
   presentable: Q is isomorphic to < a, b | lambda_2, lambda_3 > as ordered
   monoids. Every lambda_n (n >= 2) follows from {lambda_2, lambda_3} by explicit
   ordered-monoid derivations, so no separating homomorphism and no rank jump exist.

The two pure branches of the target's "either...or" do not co-occur; this mixed
outcome decides every listed question.

## Proof / Evidence

First-letter barrier (global, exact, truncation-independent). Every bottom word
a^n b starts with letter 'a'; every top word b a^n starts with 'b'. Hence no top
equals a bottom.

- In C: no generator pair chains with another, and no cycles arise; the
  Egli-Milner collapse is trivial and C-order = diagonal UNION
  {(a^n b, b a^n) : n >= 2} exactly. Antisymmetry is direct.
- In D: every generator bottom-tuple consists solely of a-initial words, every
  generator top-tuple solely of b-initial words (nonempty case; the empty tuple
  contributes only the diagonal). A top-tuple can never be a bottom-tuple, so no
  D-generator chains with another: D-order = diagonal UNION G exactly.

Mismatch pair. p = (a^2 b, a), q = (b a^2, a), tuples of length 2 over M.
In T(C): a^2 b <=_C b a^2 is a generator and a <=_C a by reflexivity, hence
p <= q componentwise. In D: p differs from q; p is not a generator bottom because
its second component 'a' is never of the form a^n b (it does not end in 'b');
since D-order = diagonal UNION G with no chains, p not<= q in D. Thus c reflects
no order on (p,q) while c(p) <= c(q): c is bijective and monotone but not an
order-isomorphism. This exhibits failure of T to preserve this non-reflexive
(non-sifted) coinserter.

Additivity lemma (ordered-monoid derivation rule). For all m,n >= 2, lambda_{m+n}
derives from lambda_m and lambda_n in three primitive steps (context +
transitivity):
  a^{m+n} b = a^m (a^n b) <= a^m (b a^n) [lambda_n, left context a^m];
  = (a^m b) a^n <= (b a^m) a^n [lambda_m, right context a^n];
  = b a^{m+n} [equality].
Hence lambda_2, lambda_3 derive every lambda_n (n >= 2): even n = 2+...+2,
odd n = 3+2+...+2 (semigroup generated by 2,3 covers all n >= 2). Any derivation
using some lambda_n is rewritten by splicing in its {lambda_2,lambda_3}
derivation, so the canonical quotient maps factor both ways and
Q is isomorphic to < a, b | lambda_2, lambda_3 >, a finite presentation.
In particular the free model of {lambda_2,lambda_3} satisfies every lambda_n,
so no separating monotone homomorphism from a finite-subfamily quotient
violating some lambda_N exists.

Universal properties: C and D satisfy the coinserter universal properties for
their generator sets by the exact order descriptions; T(C) with concatenation is
the free ordered monoid on the poset C; Q = < a,b | lambda_2, lambda_3 > is
universal among ordered monoids with elements x,y with x^2 y <= y x^2 and
x^3 y <= y x^3, the isomorphisms both ways given by generators and well-defined
by the lemma.

Computation (bounded cross-check, not replacing the global proofs):
artifacts/verify.py machine-checks primitive-step derivation shapes for every
2 <= n <= 60 (each step exactly l . lambda_r . r with r in {2,3}), enumerates
C-order on all 255 words of length <= 7, and BFS-checks D-reachability for the
mismatch pair; artifacts/derivations_n2_n10.json lists steps for n = 2..10;
artifacts/verification_results.json records outcomes. Independent rerun confirms
all checks.

## Limitations

The target's two pure branches do not co-occur: comparison half negative (not an
order-isomorphism) while rank half finite (no jump). Computation is bounded
(derivations to n = 60, word enumeration to length 7, truncated D-BFS) and
supports but does not replace the global barrier and additivity proofs. The
D-order exactness statement is for the pairwise generator set G as defined; the
empty tuple contributes only diagonal. Glosses in draft prose about Q's
underlying poset coinciding with T(C) and about T failing strong finitariness
are imprecise and not needed: T is strongly finitary (preserves reflexive /
sifted coinserters) and the failure here is on a non-reflexive non-sifted
diagram, which is consistent with that.

## Reproducibility

Run `python3 artifacts/verify.py` from the record root with Python 3 and
standard library only (deterministic, string comparisons only, no floats). It
rebuilds derivations to n = 60 with exact context-shape assertions, checks the
first-letter invariant for n < 500, enumerates words to length 7, and BFS-checks
the mismatch pair. See artifacts/verification_results.json and
artifacts/derivations_n2_n10.json.
