# Non-formality of the unordered three-point configuration space C_3(S^2 x S^2) over Q

## Context

Let M = S^2 x S^2, a closed simply connected formal 4-manifold with
H*(M;Q) = Q[u,v]/(u^2,v^2), |u|=|v|=2, w = uv, |w|=4.
Let Conf_3^ord(M) = M^3 minus the fat diagonal and
C_3(M) = Conf_3^ord(M)/S_3 the unordered configuration space of 3 distinct
points. The admitted target asked for a two-sided rational-formality decision:
either (i) exhibit a defined nonzero triple Massey product with a full cocycle
ledger, hence non-formality, or (ii) prove formality by an explicit zigzag of
quasi-isomorphisms to the cohomology algebra with zero differential.

## Definitions

Ordered Totaro / Cohen-Taylor / Lambrechts-Stanley-Idrissi model:
G = H^{tensor 3} tensor exterior(e_12,e_13,e_23), |e_ij| = 3,
D|_H = 0, D(e_ij) = diagonal class at points i,j:
D(e_12) = 1xw + wx1 + uxv + vxu (and cyclic permutations), i.e.
Delta = 1xw + uxv + vxu + wx1.
Quotient by the ideal I generated by the Arnold relation
omega = -e_12 e_13 + e_12 e_23 - e_13 e_23 (with all CDGA multiples) and by
L = {(a_i - a_j) e_ij : a in {u,v}} (with all multiples).
Q = G/I models the ordered configuration; F = Q^{S_3}, S_3 permuting tensor
factors and relabelling e_ij, models the unordered configuration C_3(M).
Coefficients are Q throughout.

Named S_3-invariant cocycles (sym = symmetrisation, [a|b|c] = tensor positions):
H^2: A1 = sym(u), A2 = sym(v).
H^4: BUU = sym(uu), BUV = sym(uv), BVV = sym(vv).
H^6: CUUU = uxuxu, CVVV = vxvxv.
H^7, H^9: e-containing classes; H^9 is 2-dimensional.
Cohomology of F: H^0=Q, H^2=Q^2, H^4=Q^3, H^6=Q^2, H^7=Q^2, H^9=Q^2,
others 0; total dimension 12, Euler characteristic 4 = 24/6.
Cup data: H^2xH^2 -> H^4 all nonzero; H^4xH^4 -> H^8 all zero;
A1*BUU != 0, A2*BVV != 0; A1*BUV = A1*BVV = A2*BUU = A2*BUV = 0; H^5(F) = 0.

## Result

C_3(S^2 x S^2) is NOT formal over Q.
With a = [BUU] in H^4, b = [A2] in H^2, c = [BUV] in H^4,
[a][b] = 0 = [b][c], and the triple Massey product <a,b,c> is defined with
zero indeterminacy and equals the single nonzero class with coordinates
(4,0) in the computed basis of the 2-dimensional H^9(F).
The mirror triple <[BUV],[A2],[BUU]> = (-4,0). A nonzero Massey product
obstructs formality, so no zigzag of quasi-isomorphisms from any Sullivan
(minimal) model to (H*(C_3;Q),0) exists.

## Proof / evidence

Exact rational linear algebra over Q (Fractions), independently recomputed in
audit from scratch:
1. Full relation ideal (all monomial multiples of omega and L) gives
quotient dimensions with chi(ordered) = 24 = 4*3*2 and chi(unordered) = 4;
D(omega) lies in the degree-7 relation span and D(L) = 0, so D descends;
D^2 = 0 on Q and on F; S_3 commutes with D.
2. Restricted differentials FD on S_3-invariants give the cohomology above;
in particular FD_5 has rank 4 on a 4-dimensional domain, so H^5(F) = 0.
3. Explicit invariant bounding cochains:
x = 2[1|1|u]e_12 + 2[1|u|1]e_13 + 2[1|u|1]e_23
  + 2[u|1|1]e_12 + 2[u|1|1]e_13 + 2[u|1|1]e_23 (deg 5),
y = 2[1|1|v]e_12 + 2[1|v|1]e_13 + 2[v|1|1]e_23 (deg 5),
satisfy D(x) = BUU*A2 and D(y) = A2*BUV exactly at free level.
Hence the triple Massey product is defined; representative (all classes even)
m = BUU*y - x*BUV (21 terms, degree 9) satisfies D(m) = 0 at free level.
4. In H^9, incoming differential rank is 0 and [m] = (4,0) != 0; mirror is
(-4,0). Indeterminacy a*H^5 + H^5*c = 0 since H^5 = 0; bounding choices are
unique. Controls <BUV,A1,BUV>, <BVV,A1,BVV>, <BUU,A2,BUU> all vanish.
5. Transfer: the LS/Idrissi algebra F is a rational CDGA model of the
unordered configuration for this formal manifold (Totaro/Kriz collapse plus
characteristic-zero invariants; Idrissi proves the real-model statement), and
triple Massey sets are preserved under CDGA quasi-isomorphisms. A
quasi-isomorphism to (H*,0) would send the Massey set to {0}, impossible.
Hence every Sullivan model inherits the obstruction; no minimal model needs
to be printed.

## Limitations

The ledger is written in the LS/Idrissi CDGA F, not as explicit Sullivan
minimal-model generators and differential; transfer uses the cited model
theorem plus Massey invariance under quasi-isomorphism. Exact machine linear
algebra over Q (cross-checked mod p in research) on roughly 500-dimensional
free monomial spaces; no hand-check of relation matrices. Integral or other
coefficient formality is not addressed.

## Reproducibility

output/artifacts/betti.json, bounding_x.json, bounding_y.json,
massey_rep.json, massey_classes.json carry the exact ledger.
Recompute: build H, exterior generators, D(e_ij), Arnold plus L relations
with all monomial multiples, quotient by exact rref, restrict D to
S_3-invariants, compute cohomology, verify D(x), D(y), D(m), and H^9
coordinates as above. Audit recomputation used independent Python/Fractions
code following exactly these steps.
