# Disproof of the simple 1-2-3 dimension spectrum for the Kaad-Kyed t-deformed Dirac on quantum SU(2)

## Context

The Kaad-Kyed two-parameter family of Dirac operators D_{t,q}, with t,q in (0,1],
acts on the Peter-Weyl Hilbert space H = L^2(SU_q(2))^{oplus 2} with core
O(SU_q(2))^{oplus 2}. It decomposes as D_{t,q} = D^V_t + D^H_q, a vertical diagonal
part built from classical t-numbers and a horizontal off-diagonal part built from
twisted derivations, which anticommute on the core. The closure is selfadjoint.
The Kaad-Kyed memoir (arXiv:2205.06043) establishes twisted commutators, equivariance,
and compact quantum metric structures with quantum Gromov-Hausdorff continuity, but
contains no ordinary-trace dimension-spectrum, zeta-continuation, or compact-resolvent
claim. The admitted target asked whether, for every t != 1 and every b in the
commutator-enlarged algebra B, zeta_b(z) = Tr(b|D_{t,q}|^{-z}) extends meromorphically
to all of C with only simple poles in {1,2,3}.

## Definitions

- O(SU_q(2)): coordinate Hopf algebra with Peter-Weyl basis of matrix coefficients
  u^n_{ij}, n >= 0, 0 <= i,j <= n, with convention u^n_{ij} = 0 outside range.
- Left circle weight: sigma_L(z, u^n_{ij}) = z^{2j-n} u^n_{ij}; A^m_q is the weight-m
  subspace; u^n_{ij} has weight m = 2j - n.
- Classical t-number (t != 1): [a]_t = (t^a - t^{-a})/(t - t^{-1}); [a]_1 = a.
- Vertical Dirac: on xi in A^n_q, eta in A^m_q,
  D^V_t(xi,eta) = (t^{(-n+1)/2}[(n-1)/2]_t xi, -t^{(-m-1)/2}[(m+1)/2]_t eta).
- Horizontal Dirac: D^H_q = [[0, -q^{-1/2} d_{fk^{-1}}],[-q^{1/2} d_{ek^{-1}}, 0]]
  with d_e(A^n_q) subset A^{n-2}_q, d_f(A^m_q) subset A^{m+2}_q.
- Joint blocks: V^n_{ij} = {(lambda u^n_{ij}, mu u^n_{i,j-1})}.
- B: algebra generated by the unital smooth algebra A^{smooth} (so 1 in B) and
  iterated commutators with |D_{t,q}|.
- zeta_b(z) = Tr(b|D_{t,q}|^{-z}) for Re(z) large, with Tr the ordinary operator
  trace (sum over an orthonormal basis, value in [0,+infinity]).

## Result

Fix t0 = 1/2, q0 = 1/2 (so t0 != 1) and b = 1 in B. Then

  zeta_1(z) = Tr(|D_{t0,q0}|^{-z}) = +infinity for every z in C.

In particular there is no half-plane Re(z) > R on which zeta_1 is defined, so it
cannot extend to a meromorphic function on C with any pole set, let alone only
simple poles in {1,2,3}. The universal target claim is therefore false. This is a
complete TARGET resolution by rigorous disproof. The parameter q0 plays no role;
any q in (0,1] works. A mirror family covers t > 1.

## Proof / evidence

1. One-dimensional blocks. For n >= 1 and 0 <= i <= n, u^n_{i,-1} = 0, so
   V^n_{i0} = {(lambda u^n_{i0}, 0)} is one-dimensional. The vector u^n_{i0} has
   left weight m = 2*0 - n = -n.

2. Horizontal part vanishes on V^n_{i0}. Since D^H_q is off-diagonal,
   D^H_q(lambda u^n_{i0},0) = (0, -q^{1/2} lambda d_{ek^{-1}} u^n_{i0}).
   With d_{ek^{-1}} u^n_{i0} = sum_l u^n_{il} <ek^{-1}, u^n_{l0}> and
   <ek^{-1},u^n_{l0}> = sum_r <e,u^n_{lr}><k^{-1},u^n_{r0}>, the memoir pairing
   formulas give <e,u^n_{lr}> proportional to delta_{l,r-1} (forcing r = l+1)
   while grouplikeness gives <k^{-1},u^n_{r0}> proportional to delta_{r0}
   (forcing r = 0), impossible for l >= 0. Hence d_{ek^{-1}} u^n_{i0} = 0 and
   D^H_q = 0 on V^n_{i0}. The same delta-pattern with <f,.> gives the mirror
   vanishing d_{fk^{-1}} u^n_{in} = 0 for t > 1.

3. Vertical eigenvalue. On (lambda u^n_{i0}, 0) with m = -n,
   D^V_t acts as e_n = t^{(n+1)/2}[-(n+1)/2]_t = (t^{n+1}-1)/(t^{-1}-t).
   For t0 = 1/2: e_n = ((1/2)^{n+1}-1)/(3/2) in [-2/3,-1/2], e_n -> -2/3.
   In general for t in (0,1): |e_n| = (1-t^{n+1})/(t^{-1}-t) >= (1-t^2)/(t^{-1}-t)
   > 0 with limit 1/(t^{-1}-t) > 0. For t > 1 the mirror blocks V^n_{i,n+1}
   give f_n with |f_n| -> 1/(t-t^{-1}) > 0. At t = 1, e_n = -(n+1)/2 -> -infinity,
   so t = 1 is exactly the threshold where the obstruction disappears.

4. Orthonormal eigenvectors. psi_{n,i} = (u^n_{i0},0)/||u^n_{i0}||, n >= 1,
   i = 0..n, is orthonormal by Peter-Weyl/Schur orthogonality (Haar norms
   ||u^n_{ij}||^2 = q^{2(n-i)}/<<n+1>>_q > 0), with D psi_{n,i} = e_n psi_{n,i}
   and |D| psi_{n,i} = |e_n| psi_{n,i}. Each e_n has multiplicity n+1.

5. Everywhere divergence. For real x, Tr(|D|^{-x}) >= sum_{n<=N} (n+1)|e_n|^{-x}
   by trace monotonicity (partial orthonormal sum). Since |e_n| -> 2/3 at
   t0 = 1/2, the block summand (n+1)|e_n|^{-x} -> infinity for every fixed x
   (for x <= 0 use |e_n| >= 1/2), so the trace is +infinity for all real x,
   hence zeta_1(z) is infinite for every complex z. Numerically, partial sums
   at N = 2000 grow ~N^2, reaching 9e5 (x = -2) to 1.2e8 (x = 10).

6. Conclusion. b = 1 lies in B since A^{smooth} is unital. Empty domain implies
   no meromorphic extension. The obstruction (essential spectrum of |D_{t,q}|
   accumulating at 1/|t^{-1}-t| != 0; non-compact resolvent for every t != 1)
   is strictly stronger than one exotic pole, so no pole location z0 is needed.

## Limitations

The disproof uses b = 1 and one parameter pair (t0,q0) = (1/2,1/2); it does not
classify which other b or parameters admit partial zeta theory, nor compute any
meromorphic continuation, since none exists in this case. The argument concerns
the ordinary operator trace Tr, not semifinite or twisted traces (cf. Kaad-Senior
2011, whose meromorphic zeta uses a different trace and operator). Orthogonality
and norm facts are standard Peter-Weyl results cited via the memoir and Klimyk-Schmudgen.
