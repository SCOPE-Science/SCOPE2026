Verbatim formulas from Kaad-Kyed memoir source (arXiv:2205.06043, suq2-arxiv-v3 .tex).

[A] Vertical Dirac (eq:dirvert):
\C D^V_t \pma{\xi \\ \eta} :=
  \pma{ t^{\frac{-n + 1}{2}} [ \frac{n-1}{2} ]_t & 0 \\
        0 & - t^{\frac{-m - 1}{2}} [ \frac{m+1}{2} ]_t } \pma{\xi \\ \eta}
for all \xi \in \C A^n_q and \eta \in \C A^m_q.

[B] Horizontal Dirac (eq:dirhori):
\C D^H_q := \pma{ 0 & -q^{-1/2} \pa_{fk^{-1}} \\ -q^{1/2} \pa_{ek^{-1}} & 0 }.

[C] Weight shifts: \pa_e(\C A_q^n) \subseteq \C A_q^{n-2},
\pa_f(\C A_q^m) \subseteq \C A_q^{m+2}; \C D^V_t, \C D^H_q anticommute on the core
\C O(SU_q(2))^{\oplus 2}; closure D_{t,q}=D^V_t+D^H_q selfadjoint (Lemma l:sumdirac).

[D] Joint invariant blocks:
V^n_{ij} := { (la u^n_{ij}, mu u^n_{i,j-1}) : la,mu in C }, n>=0, 0<=i,j<=n;
convention u^n_{ij}=0 outside range.

[E] Pairings (eq:exppai), q!=1:
<k,u^n_{ij}> = de_{ij} q^{j-n/2};
<e,u^n_{ij}> = de_{i,j-1} q^{(1-n)/2} sqrt( <<n-j+1>>_q <<j>>_q );
<f,u^n_{ij}> = de_{i,j+1} q^{(1-n)/2} sqrt( <<n-j>>_q <<j+1>>_q ).
k grouplike => <k^{-1},u^n_{ij}> = de_{ij} q^{n/2-j} (matrix inverse of diagonal).

[F] Classical t-number: [a]_t = (t^a-t^{-a})/(t-t^{-1}), t in (0,1); [a]_1 = a.

[G] Circle action: si_L(z,u^n_{ij}) = z^{2j-n} u^n_{ij} (weight m=2j-n).

[H] Haar norms (eq:haarmatrix):
||u^n_{ij}||^2 = h((u^n_{ij})* u^n_{ij}) = q^{2(n-i)}/<<n+1>>_q > 0;
distinct (n,i,j) orthogonal (Schur orthogonality).

Consequence used (proved in DRAFT.md from [E] alone):
d_{ek^{-1}} u^n_{i0} = 0 since <e,.> forces r=l+1 while <k^{-1},u^n_{l+1,0}>=0;
likewise d_{fk^{-1}} u^n_{in} = 0. Hence D^H_q vanishes on V^n_{i0} (resp. V^n_{i,n+1}),
which are 1-dim with pure vertical eigenvalues e_n=(t^{n+1}-1)/(t^{-1}-t)
(resp. f_n), bounded away from 0 iff t!=1.
