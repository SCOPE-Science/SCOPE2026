# No extinction for the equivariantly deformed Ammann-Beenker first peak

## Context

The Ammann-Beenker (AB) vertex set is the primitive 8-fold quasicrystal obtained
from the Z^4 cut-and-project scheme with physical space R^2, internal space R^2,
and regular octagonal window. Deformed model sets (Hof; Kusters; Baake-Grimm-Moody)
replace each point x by x + theta(x*) with an equivariant internal displacement
theta, retaining pure-point diffraction for small C^1 equivariant displacements.
A natural question in this program, previously studied for distorted Penrose
tilings by Sing-Welberry (intensity transfer on Bragg peaks), is whether a Bragg
peak can be driven to extinction (intensity zero) by turning up a deformation
amplitude. This record resolves that question for the first observable 8-fold peak
of AB under the lowest odd-odd internal Fourier-mode deformation.

## Definitions

- Cut-and-project data: physical star e_j = CIS(j pi/4), internal star
  e_j* = CIS(3j pi/4), j = 0..3. Lattice L in R^2 x R^2 with row-generator matrix
  M = [e | e*]. Exactly MM^T = 2 I_4, so |det M| = 4, dens L = 1/4, dual lattice
  generated by rows of M/2.
- Fourier module: k(n) = (1/2) sum n_j e_j with conjugate
  k*(n) = (1/2) sum n_j e_j*, n in Z^4.
- Window: regular octagon O of edge 1, circumradius R = 1/sqrt(2 - sqrt2),
  area 2 sqrt2 R^2 = 4.828427124746191, vertices R CIS(pi/8 + m pi/4).
- Deformation: Lambda_a = {x + a u psi(x*)} with fixed unit u = (1,0),
  psi(y) = sin(2 pi y_1) sin(2 pi y_2), a in [0, 1/4].
- Deformed amplitude (Hof-Kusters window-F formula): for k = k(n),
  A_win(k;a) = int_O exp(2 pi i (k* . y + a beta psi(y))) dy with
  beta = k_parallel . u; Bragg intensity I(a) = (dens L)^2 |A_win|^2 = |A_win|^2/16.
- First observable 8-fold shell: 4|k|^2 = 17 - 12 sqrt2, |k| = 1 - sqrt2/2
  approximately 0.085786, realised by 8 integer vectors
  (3,-2,0,2), (-3,2,0,-2), (0,2,-3,2), (0,-2,3,-2),
  (2,-3,2,0), (-2,3,-2,0), (2,0,-2,3), (-2,0,2,-3).
  All share |k*| = 2 + sqrt2/2 approximately 2.91421356.
  The Fourier module is dense (Pell units P^2 - 2Q^2 = 1 give shells with
  4|k|^2 -> 0+), so "first" means first observable shell with visible window
  amplitude, the standard diffraction-literature convention.

## Result

There is no extinction amplitude a0 in (0, 1/4]. For every member of the
8-vector ring-1 shell and every a in [0, 1/4],

  Re[A_win(a)] <= -0.0075, hence |A_win(a)| >= 0.0075,

  I(a) = |A_win(a)|^2 / 16 >= 3.5 x 10^-6 > 0.

Pure-point diffraction holds on all of [0, 1/4] by deformed-model-set theory
(Kusters; Baake-Grimm-Moody torus parametrisation), so each Fourier-module k
carries a well-defined Bragg intensity and the vacuous reading (peak ceases to
exist) does not apply. This is the second complete answer allowed by the admitted
target (certified positive lower bound). The ring splits under u = (1,0) into two
axial members (beta = +-0.085786), two frozen members (beta = 0, amplitude
constant -0.011812), and four diagonal members (beta = +-0.060660).

## Proof / evidence

1. Exact algebra (proof_A_symbolic.py, exact Fractions in Q(sqrt2)): MM^T = 2I_4;
   quantization 4|k|^2 = P + Q sqrt2 with P, Q in Z; ring-1 and ring-2 data exact;
   shell completeness: boxes [-4,4]^4, [-6,6]^4, [-10,10]^4 contain exactly the 8
   listed vectors with (P,Q) = (17,-12).
2. Certified moments: psi^j expanded as an explicit trigonometric polynomial, so
   each M_j = int_O exp(2 pi i k* . y) psi^j dy is a finite sum of exact polygon
   plane-wave integrals F_0(Q) = int_O exp(2 pi i Q . y) evaluated by fan
   triangulation with elementary exponential antiderivatives and Taylor fallback
   with explicit Lagrange remainder at removable singularities, all in
   outward-rounded mpmath interval arithmetic. Axial member:
   M_0 = -0.01181160 +- 1e-14, M_1 = 0, M_2 = -0.00706642, M_3 = 0
   (odd-odd symmetry); diagonal members have real M_1 = 0.03743, M_2 = 0.26545
   with first-order term purely imaginary and second-order contribution negative
   real at small a.
3. Taylor in a at order J = 3 with rigorous remainder
   |R_3| <= vol(O) (2 pi |beta| a)^4 / 24 (<= 6.97e-05 axial, <= 1.74e-05
   diagonal) plus interval Lipschitz bound over 10 subintervals of [0, 1/4]
   gives sup Re[A] <= -0.011678 (axial), -0.011812 (frozen), -0.011607 (diagonal),
   all below -0.0075 (certify_ring1.py ALL PASS, log retained).
   Since |A| >= -Re[A], the intensity bound follows.
4. Direct high-order quadrature cross-checks agree to ~1e-8 (non-certifying).
5. Patch: the intensity is fed by pair correlations of the radius-1 eightfold
   vertex-star patch (central AB vertex with eight surrounding rhombi), whose
   window overlaps Fourier-transform to A_win.

## Limitations

- Certificate proved for fixed u = (1,0); the argument that any fixed unit u only
  changes the beta-splitting with worst case |beta| <= 0.0858 is stated, not
  separately interval-certified per angle.
- First-observable minimality against Pell-smaller shells (|k| -> 0) is numerically
  indicated (relative amplitudes < 1e-4) but not interval-certified; not needed for
  the lower bound on the named ring.
- Pure-point retention cites the Kusters / Baake-Grimm-Moody theorems.
- Interval engine correctness rests on code review, outward rounding, and
  quadrature agreement, not a separately proved engine theorem.
