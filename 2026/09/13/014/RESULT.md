# Improved MDADT Certificate for the Hou–Zong 2018 Switched Time-Delay Benchmark with Unstable Subsystem

## Context

The reference benchmark is Hou and Zong, "Stability of Switched Time-Delay Systems via Mode-Dependent Average Dwell Time Switching," IEEE Access, vol. 7, pp. 1174–1181, 2019 (DOI 10.1109/ACCESS.2018.2886381, submitted 2018). It studies continuous-time switched time-delay systems with both stable and unstable subsystems under mode-dependent average dwell time (MDADT) switching: slow switching (large dwell time) for stable modes and fast switching (small dwell time) for unstable modes. The delay-dependent criterion uses multiple Lyapunov–Krasovskii functionals with a Wirtinger-based integral inequality, yielding per-mode linear matrix inequalities (Proposition 1, equation (8)) plus jump coupling orders (equations (15)(16)), from which Theorem 1 derives the MDADT bounds tau_ia* = ln(mu_i)/alpha_i. The numerical example has two stable modes and one unstable mode, with delay bound h = 2 and delay signal d(t) = 0.2 sin(t) (hence delay-derivative bound tau = 0.2). The admitted audit target was the exact improvement-or-tightness question: keeping the paper's per-mode rates, chatter bounds, and LMI class fixed, either certify a strictly componentwise-smaller MDADT triple or prove a tightness barrier with a witness trajectory.

## Definitions

Modes: S = {1, 2} stable, U = {3} unstable. System matrices: A1 = [[-2.5,-0.5],[0.2,-1.5]], B1 = [[-0.1,0.1],[-0.1,0.2]]; A2 = [[-1.8,0.1],[0.1,-1.5]], B2 = [[-0.2,-0.1],[-0.4,-0.1]]; A3 = [[0.5,0.1],[-0.3,0.5]], B3 = [[0.1,-0.3],[-0.2,0.1]]. Fixed rates: alpha = (2, 2.6, -2), beta = (1, 1, 0). Delay data: h = 2, derivative bound tau_d = 0.2. Reported jump parameters: mu = (3.8, 1.7, 0.6), giving the reported triple tau* = (ln 3.8/2, ln 1.7/2.6, ln 0.6/(-2)) = (0.66750053, 0.20408779, 0.25541281). New jump parameters: mu' = (3.0, 1.6, 0.64), giving the improved triple tau*' = (ln 3.0/2, ln 1.6/2.6, ln 0.64/(-2)) = (0.54930614, 0.18077063, 0.22314355). Coupling constraints: P_i <= mu'_i P_j, Q_i <= mu'_i Q_j, R_i <= mu'_i R_j for i in {1,2} versus all j != i and i = 3 versus j in {1,2}, totaling 18 order constraints. Compatibility requires mu2' * mu3' = 1.024 >= 1 for the two-sided mode-2/mode-3 orders. The per-mode 8x8 LMI is the paper's Wirtinger-based Proposition-1 block with Psi(1,1) = A_i'P_i + P_i A_i + alpha_i P_i + Q_i - (4/h)e1 R_i, Psi(1,2) = P_i B_i - (2/h)e1 R_i, Psi(2,2) = -(4/h)e1 R_i - (1-tau_d)e2 Q_i, off-diagonal blocks (6/h)e1 R_i, -(6/h)e1 R_i, -(12/h)e1 R_i with e1 = exp(-alpha_i beta_i h), e2 = exp(alpha_i beta_i h), plus the Schur extension rows h A_i'R_i, h B_i'R_i, -h R_i.

## Result

For the Hou–Zong 2018 benchmark data above, the mode-dependent Lyapunov–Krasovskii LMI class of Proposition 1 with coupling (15)(16) certifies exponential stability under the strictly improved MDADT triple (0.54930614, 0.18077063, 0.22314355) from mu' = (3.0, 1.6, 0.64). This triple componentwise strictly dominates the reported (0.66750053, 0.20408779, 0.25541281) with differences (0.11819439, 0.02331716, 0.03226926), i.e. relative reductions of 17.7%, 11.4%, and 12.6%. Explicit symmetric positive-definite matrices P_i, Q_i, R_i (2x2, i = 1,2,3) are exhibited in output/artifacts/cert_matrices.npz: all three 8x8 LMIs are strictly negative with maximum eigenvalues -4.811874e-04, -9.722790e-05, -9.572105e-05, and all 18 coupling order constraints hold strictly with worst margin -2.714120e-05 (R3 - 0.64 R2). Rounded to 10 decimals: P1 = [[0.8385021523, 0.2478731468],[0.2478731468, 0.7442371386]]; P2 = [[0.5590014349, 0.1652487645],[0.1652487645, 0.4961580924]]; P3 = [[0.3556640220, 0.1051221877],[0.1051221877, 0.3123156504]]; Q1 = [[0.1052591649, -0.0722940914],[-0.0722940914, 0.1292637922]]; Q2 = [[0.0697794452, -0.0477305464],[-0.0477305464, 0.0853164696]]; Q3 = [[0.0440545569, -0.0303503900],[-0.0303503900, 0.0542816396]]; R1 = [[0.0282480300, 0.0201525673],[0.0201525673, 0.0213952583]]; R2 = [[0.0186679162, 0.0132777730],[0.0132777730, 0.0141500908]]; R3 = [[0.0118749013, 0.0084598052],[0.0084598052, 0.0089971785]]. By Theorem 1 with mu', the system is exponentially stable under tau_a1 >= 0.5493 (slow), tau_a2 >= 0.1808 (slow), tau_a3 <= 0.2231 (fast).

## Proof / Evidence

Verification is computational with numpy eigvalsh, independently recomputed by the auditor from the full-precision .npz file. Positive-definiteness holds via Cholesky with smallest eigenvalues P: 0.539/0.359/0.227, Q: 0.0440/0.0292/0.0184, R: 0.00438/0.00294/0.00185. The 8x8 LMI assembly above reproduces the reported maxima to about 1e-11, and the 18 coupling max-eigenvalues are all strictly negative with the stored worst margin reproduced exactly; matrix norms are 5.6468/12.3726/0.3984, so margins sit roughly 1e6x above double-precision eigenvalue noise. The search method (no SDP solver available) used numpy-only random search over 2x2 SPD parametrizations plus projected hill-climbing on the worst relative-then-absolute margin, exploiting that mu enters only the coupling plus the MDADT formula and not LMI (8), that mu2*mu3 >= 1 forces P3/Q3/R3 near 0.63 times P2/Q2/R2, and that the mode-2 LMI (alpha = 2.6) is the bottleneck. The tightness alternative was probed and disfavored by direct DDE simulation. The certificate satisfies exactly the stated LMI plus coupling hypotheses, so Theorem 1's conclusion follows from its hypotheses regardless of any gap in the paper's proof steps.

## Limitations

Margins are thin in absolute terms (LMI about 1e-4, tightest coupling about 2.7e-5); verification is computational (numpy eigvalsh), not interval-rigorous. The bound tau_d = 0.2 follows from the paper's simulation d(t) = 0.2 sin t and h = 2; the paper does not state tau_d explicitly, so reuse must preserve this bound. The improvement is within the fixed LMI class and fixed rates; it does not change the method or close the general MDADT optimality question.
