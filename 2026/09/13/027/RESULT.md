# Maximum Pasch Count over Cyclic STS(21): C_max = 63

## Context
A Steiner triple system of order 21 (STS(21)) is a pair (V,B) with |V|=21 and 70 triples such that every pair of points lies in exactly one triple. A Pasch configuration is four triples on six points isomorphic to {{a,b,c},{a,d,e},{b,d,f},{c,e,f}}; the Pasch count is the number of distinct 6-subsets supporting such a configuration. Cyclic STS(21)s are those admitting a point-regular cyclic automorphism group, equivalently Heffter difference families over Z_21. Pasch configurations are the smallest nontrivial (6,4) configurations; anti-Pasch (Pasch-free) and maxi-Pasch (Pasch-maximal) systems are a recognized research theme, and cyclic STS(21)s form a classical catalogued subclass (Mathon-Phelps-Rosa systems C1-C7).

## Definitions
- STS(21): 21 points, 70 triples, each pair in exactly one triple.
- Pasch count: number of 6-subsets containing exactly four blocks (verified that no 6-set contains more than four).
- Cyclic STS(21): admits translations of Z_21; block orbits are one short orbit {t,t+7,t+14} (7 distinct blocks) plus three full orbits of 21 blocks generated by base triples {0,x,y} (a Heffter difference family).

## Result
C_max = 63. Over all cyclic STS(21)s, the maximum Pasch count is 63. It is attained, for example, by the difference family with short orbit {0,7,14} and full-orbit base blocks {0,1,3}, {0,4,12}, {0,5,11}. Exhaustive enumeration gives exactly 7 cyclic isomorphism types with Pasch counts 63, 63, 63, 42, 42, 21, 0, so no cyclic STS(21) exceeds 63. In particular there are three non-isomorphic Pasch-maximal cyclic types and one Pasch-free (anti-Pasch) cyclic type ({0,1,3},{0,4,12},{0,5,15}).

## Proof / Evidence (exhaustive, machine-checkable)
1. Short orbit forced: a triple fixed setwise by a nontrivial translation of Z_21 must be a coset of {0,7,14}.
2. Candidate base blocks: of C(20,2)=190 pairs {0,x,y}, exactly 108 have six distinct differences avoiding {0,7,14}.
3. Exact cover: the three base-block difference sets must partition the 18 remaining nonzero residues; ordered backtracking yields 224 raw unordered families.
4. Multiplier quotient: quotienting by the 12 units mod 21 gives 7 multiplier-equivalence classes with normalized representatives in the certificate.
5. Design verification: expanding each representative gives 70 blocks; all 210 pairs occur exactly once in each of the 7 systems.
6. Pasch counts: all C(21,6)=54264 six-sets per system examined; a six-set is a Pasch iff it contains exactly four blocks (asserted none contains more); independent recount additionally verifies the degree-2 structure of each Pasch. Counts: 63,63,63,42,42,21,0.
7. Non-isomorphism: the 7 block sets are pairwise distinct and a complete backtracking isomorphism search over all 21 points found no isomorphism between any two; since every cyclic STS(21) arises from a difference family in exactly one multiplier class, enumeration is complete.
Scripts `artifacts/enumerate.py` and `artifacts/verify.py` reproduce everything; `artifacts/certificate.json` records representatives and counts. Independent audit re-ran both scripts with matching output and ran positive/negative isomorphism controls.

## Limitations
Scope is cyclic STS(21)s admitting the regular translation group of Z_21; non-cyclic STS(21)s (millions of types) are excluded. Isomorphism completeness and Pasch counts are established by exhaustive computation rather than closed-form theory.

## Reproducibility
Run `python3 artifacts/enumerate.py` (enumerates 108 candidates, 224 families, 7 classes; verifies each STS; prints Pasch counts and C_max=63) and `python3 artifacts/verify.py` (confirms 7 distinct block sets, pairwise non-isomorphic, independently recounts Pasch numbers).
