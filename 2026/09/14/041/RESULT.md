# Acylindrical hyperbolicity on Wiedmer's rigidified family Gamma'(Lambda): necessity for arbitrary Lambda and sufficiency for edgeless Lambda

## Context

Genevois asked when the outer automorphism group Out(A_Gamma) of a right-angled Artin group is acylindrically hyperbolic. Baik-Kim (arXiv:2405.19702v2) settle the no-SIL-pair case (Theorem A / Corollary 3.2) and the maximal-SIL-pair-system case (Theorems 4.1/4.9), but explicitly leave open graphs that possess SIL-pairs yet admit no maximal SIL-pair system, naming Wiedmer's constructions (arXiv:2209.02033v2) as the illuminating test family. Wiedmer shows every RAAG A_Lambda occurs as PSO(A_Gamma) with finite index in Out(A_Gamma) for suitable Gamma, with a rigidified Gamma'(Lambda) whose quotient is (Z/2)^N, but never studies acylindrical hyperbolicity of these Out groups.

## Definitions

Let Gamma be finite simplicial, lk(v)/st(v) link/star, v <= w iff lk(v) subset st(w). A nonedge pair (a,b) is a SIL-pair if Gamma minus (lk(a) intersect lk(b)) has a component containing neither a nor b. Let PSO(A_Gamma) be the pure symmetric outer automorphism group generated by partial conjugations. A_Lambda is acylindrically hyperbolic iff |V(Lambda)| >= 2 and Lambda is not a join (complement connected). A group is acylindrically hyperbolic if it admits a non-elementary acylindrical action on a hyperbolic space (Osin, Trans. AMS 368).

## Result

Let Gamma'(Lambda) be Wiedmer's rigidified graph (|V(Lambda)| >= 3; |V(Lambda)| < 3 conditional on Wiedmer Appendix A as cited). Then:

(a) Necessity for arbitrary Lambda: if Out(A_Gamma'(Lambda)) is acylindrically hyperbolic then A_Lambda is acylindrically hyperbolic, i.e. |V(Lambda)| >= 2 and Lambda is not a join.

(b) Sufficiency for edgeless Lambda: if Lambda is edgeless with |V(Lambda)| = n >= 2 (so A_Lambda = F_n), then Out(A_Gamma'(Lambda)) is virtually nonabelian free, hence non-elementary hyperbolic, hence acylindrically hyperbolic.

(c) SIL census on 12 machine-verified Lambda types (|V| <= 5: empty3, path3, complete3, empty4, cycle4, path4, complete4, disconn4, empty5, tree5, join2+2, joinK2_K1): on those types the SIL-pairs of Gamma'(Lambda) are exactly the nonedges of Lambda, each with the a-side witness component and joined outside its link-intersection (ncomp = 2 throughout); verified clique types have nsil = 0 and fall under Baik-Kim Corollary 3.2, agreeing with (a). General regime placement beyond verified types is cited to Baik-Kim Remark 3.7 and end of Section 3, not proved here.

(d) Sharp obstruction: for non-edgeless Lambda with A_Lambda acylindrically hyperbolic but non-hyperbolic (e.g. path on 4 vertices), Out(A_Gamma'(Lambda)) = A_Lambda semidirect (Z/2)^N with inversion action, so remaining sufficiency is an explicit finite-extension instance of the open ascent/quasi-isometry-invariance problem for acylindrical hyperbolicity; no WPD element or s-normal/product obstruction is available.

## Proof / evidence

Wiedmer Theorems 2.2/2.5 give PSO(A_Gamma') = A_Lambda with finite index (no transvections, forest supports). Corollary 3.8 gives Out/PSO = (Z/2)^N with N = |V(Gamma')| and Gamma' rigid, so PSO is normal of finite index. If Out is acylindrically hyperbolic it is infinite non-virtually-cyclic, so infinite PSO is s-normal and acylindrically hyperbolic by Osin Corollary 1.5; the RAAG criterion yields (a), uniformly covering finite/trivial/virtually-cyclic edge cases. For edgeless Lambda, PSO = F_n has finite index, so Out is virtually free non-virtually-cyclic, hence non-elementary hyperbolic, hence acylindrically hyperbolic, giving (b). For (c), independent pure-Python rebuilds reproduce nsil counts, ntrans = 0, joined-outside flags, SIL-equals-Lambda-nonedge matching with no non-vertex SILs, and star-complement 2-component splits on the archived types. The wildness probe (400 random graphs) shows generic in-regime graphs carry strict transvections outside Day-Wade/Baik-Kim hypotheses, supporting (d).

## Limitations

Items (a)-(b) hold generally via cited proofs; items (c) regime/census claims beyond the 12 verified types are cited placement, not new proof. Graphs with |V(Lambda)| < 3 rely on Wiedmer Appendix A as cited, not machine-verified here. The transcription of Figure 3.3 follows Wiedmer p.11 text; machine checks (ntrans = 0, forests, quotient shape) guard fidelity. Arbitrary-Lambda sufficiency remains open as diagnosed.
