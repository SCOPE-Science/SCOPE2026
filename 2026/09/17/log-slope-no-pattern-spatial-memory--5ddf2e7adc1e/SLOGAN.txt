For the no-growth spatial-memory PDE-ODE steady problem, the exact chemical-potential identity d log U + alpha V = constant converts the memory feedback into a covariance estimate. If phi(z)=h(e^z) has Lipschitz constant L, all positive stationary patterns are excluded whenever |alpha| L < d(1+R^2 lambda_1); for h(u)=u/(1+u) at mean density 1, this global uniqueness region reaches exactly the first local bifurcation threshold alpha=-4d(1+R^2).
