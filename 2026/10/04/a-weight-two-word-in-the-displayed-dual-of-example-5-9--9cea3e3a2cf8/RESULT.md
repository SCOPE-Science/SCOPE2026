# A weight-two word in the displayed dual of Example 5.9
## Finding

Example 5.9 of Shukla--Pandey--Mishra--Pathak--Upadhyay gives a non-separable \(\mathbb Z_2\mathbb Z_2[v]\)-cyclic code with block lengths \(31\) and \(9\). It reports that the binary Gray image of the displayed Euclidean dual has parameters
\[
[49,20,9]_2
\]
and uses that value in Theorem 5.4 to state an EAQECC with parameters
\[
[[49,19,9;28]]_2.
\]

For the dual generator printed in the example, the correct binary Gray parameters are
\[
[49,20,2]_2.
\]
The displayed dual contains an explicit word whose Gray image has Hamming weight \(2\). Exact reconstruction finds no weight-\(1\) word and exactly \(36\) weight-\(2\) words.

The same reconstruction gives binary dimensions \(29\) for the displayed original code and \(20\) for the displayed dual. The two Gray images are orthogonal and their dimensions sum to \(49\), so the displayed second code is exactly the ordinary binary dual of the first. Their intersection has dimension \(1\), agreeing with the hull dimension stated in the source.

Thus Theorem 5.4 applied to the displayed Example 5.9 data gives the dual-branch parameters
\[
[[49,19,2;28]]_2,
\]
not distance \(9\). This does not rule out a different construction of a \([[49,19,9;28]]_2\) code.

## Assumptions and scope

Work is over
\[
R=\mathbb Z_2+v\mathbb Z_2,\qquad v^2=v.
\]
The source uses
\[
\xi_1=v,\qquad \xi_2=1-v
\]
and
\[
\eta(\xi_1a_1+\xi_2a_2)=a_2.
\]
For \(p=2\), its Gray map is
\[
\phi(\xi_1a_1+\xi_2a_2)=(a_1,a_2).
\]

Let
\[
\begin{aligned}
B(x)={}&(x^5+x^3+x^2+x+1)(x^5+x^4+x^2+x+1)\\
&\cdot(x^5+x^4+x^3+x+1)(x^5+x^4+x^3+x^2+1).
\end{aligned}
\]
Since \(x-1=x+1\) over \(\mathbb F_2\), the displayed dual is generated by
\[
g_1=((1+x)B\mid0)
\]
and
\[
g_2=(B\mid\xi_1H+\xi_2),\qquad H=1+x+\cdots+x^8.
\]
The claim concerns exactly this displayed generator.

## Proof

Since \(\eta(\xi_2)=1\), the source module action gives
\[
\xi_2\star g_2=(B\mid\xi_2).
\]
Cyclicity gives
\[
x(\xi_2\star g_2)=(xB\mid\xi_2x).
\]
Therefore
\[
(\xi_2\star g_2)+x(\xi_2\star g_2)+g_1
=(0\mid\xi_2(1+x)).
\]
Because \(\phi(\xi_2)=(0,1)\), this word has exactly two nonzero binary Gray coordinates. Hence
\[
d^\perp\le2.
\]

For the reverse inequality, the verifier reconstructs the entire binary row space generated by all cyclic shifts of the printed module generators. Its rank is \(20\). None of the \(49\) binary unit vectors lies in that space, so
\[
d^\perp\ge2.
\]
Thus
\[
d^\perp=2.
\]

Independently, the displayed original reconstructs to a rank-\(29\) binary Gray image. Every reconstructed dual basis row is orthogonal to every reconstructed original basis row. Because \(29+20=49\), the displayed second code is exactly the binary dual of the first. Their combined rank is \(48\), so the hull dimension is
\[
29+20-48=1.
\]

The source's Theorem 5.4 takes \(d^\perp\) as the distance of its dual EAQECC branch. With
\[
n=49,\quad k_1=29,\quad k_2=20,\quad h=1,\quad d^\perp=2,
\]
that branch is
\[
[[49,19,2;28]]_2.
\]

## Verification

`artifacts/verify.py` uses only the Python standard library. It represents polynomials over \(\mathbb F_2\) as bit vectors, takes cyclic shifts modulo \(31\) and \(9\), and implements the source Gray-coordinate ordering.

The replay checks rank \(29\) for the original, rank \(20\) for the displayed dual, all cross inner products, membership of the explicit weight-\(2\) witness, absence of all \(49\) unit vectors, and hull dimension \(1\). It then exhausts all \(2^{20}\) dual words and finds exactly \(36\) of weight \(2\). Successful replay prints `VERIFY_OK`.

## Relationship to prior work

The primary article assigns \([49,20,9]_2\) to this displayed dual and then states \([[49,19,9;28]]_2\) from Theorem 5.4. It compares that claimed distance-\(9\) EAQECC with an earlier distance-\(9\) construction.

The explicit identity above contradicts the distance-\(9\) assertion for the printed generator. The rank and orthogonality checks also rule out an interpretation in which the reconstructed rank-\(20\) space is merely an unrelated subcode.

Focused searches using the article DOI and title, Example 5.9, \([49,20,9]\), \([[49,19,9;28]]\), corrected distance \(2\), and correction-or-erratum terminology did not locate a public correction or an earlier statement of this exact discrepancy. Related hull-based EAQECC papers concern different code families and do not determine this printed dual's minimum distance.

## Limitations

The result addresses Example 5.9 as printed. A typographical error in one displayed factor could mean that the authors intended a different dual code.

The result does not challenge the paper's general hull formulas or Theorem 5.4. It corrects the distance assigned to one explicit displayed dual and the downstream application to that displayed data.

No claim is made that \([[49,19,9;28]]_2\) is impossible by another construction.
