# Independent mathematical audit

## correctness

PASS

Local Z rotations change an edge phase by the sum of endpoint angles, so gauge classes are the cokernel of the unsigned incidence map. On an odd cycle that map is invertible over the real phase torus; on an even cycle its one-dimensional integer kernel is generated by the alternating sign vector, giving exactly the flux \(\Phi\). In the trace expansion, a phase-carrying monomial has signed edge-use vector in this kernel. A nonzero multiple requires at least one use of every edge, so moments of order below m are phase-free; at order m only the two alternating orientations occur, each with \(m!\) orderings and local trace one, yielding \(2m!s^m\cos\Phi\). Direct matrix reconstruction for \(C_4\), \(s=1/2\), gave fourth moments differing by exactly \(96s^4=6\) between flux 0 and \(\pi\), and the package verifier independently checks the triangle characteristic polynomial and square-cycle moment.

## originality

PASS

The source paper defines these phase-shifted Hamiltonians, proves phase removal on trees, and explicitly says cycles can retain magnetic-flux dependence, but does not classify a cycle’s gauge orbit, identify the odd/even dichotomy, or compute the first flux-sensitive spectral moment. It leaves the phase-shifted conjectures open. No prior exact cycle law was located.

PASS

The source itself identifies phase-shifted cycles as a qualitatively different regime. The audited theorem converts that observation into an exact gauge invariant and pinpoints the first spectral statistic that detects it, while the odd-cycle result shows complete cancellation. This is a natural structural answer, not merely a numerical example.
