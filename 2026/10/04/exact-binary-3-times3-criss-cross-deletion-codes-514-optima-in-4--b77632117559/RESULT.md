# Exact binary \(3\times3\) criss-cross deletion codes: 514 optima in 46 symmetry classes
## Finding
For binary \(3\times3\) arrays under one-row-and-one-column criss-cross deletion, the largest deletion-correcting code has cardinality exactly \(4\). There are exactly \(514\) labeled optimal four-array codes. Under the 16 channel symmetries generated by reversing row order, reversing column order, transposition, and global bit complementation, these \(514\) optima form exactly \(46\) equivalence classes, with orbit-size distribution one class of size \(2\), four of size \(4\), twenty of size \(8\), and twenty-one of size \(16\).

An explicit optimal code, writing each array as its three row strings, is
\[
\{(000,000,000),(000,011,101),(011,011,011),(110,101,000)\}.
\]
Its four deletion-ball sizes are \(1,6,2,6\), and the balls are pairwise disjoint.

## Assumptions and scope
For a binary array \(X\in\{0,1\}^{3\times3}\), let \(D(X)\) be the set of distinct \(2\times2\) arrays obtained by deleting exactly one row and exactly one column. A code \(C\) corrects this criss-cross deletion if and only if \(D(X)\cap D(Y)=\varnothing\) for every distinct \(X,Y\in C\). The statement is finite and specific to binary \(3\times3\) arrays; it makes no asymptotic claim and no claim for larger alphabets or larger arrays.

The equivalence relation used for the classification is generated only by genuine channel symmetries: reversal of row order, reversal of column order, transposition, and bit complementation. Arbitrary permutations of the three row or column positions are not used, because deletion preserves the relative order of the surviving rows and columns.

## Proof
There are \(2^9=512\) binary \(3\times3\) arrays and only \(2^4=16\) possible binary \(2\times2\) deletion outputs. For each of the 512 arrays, all nine row-column deletion choices are generated and duplicates are removed, producing an exact 16-bit mask for \(D(X)\). Two arrays are compatible exactly when their masks are disjoint.

The maximum cardinality is certified in a representation independent of the compatibility-graph enumeration. The \(512\) arrays yield \(470\) distinct deletion-ball masks. An exact memoized set-packing recurrence on the 16 possible outputs evaluates
\[
F(A)=\max\bigl(\{0\}\cup\{1+F(A\setminus B): B\subseteq A,\ B\text{ is one of the 470 deletion-ball masks}\}\bigr)
\]
for subsets \(A\) of the 16-output universe. It returns \(F(U)=4\). Every deletion-correcting code gives a packing of these masks, so no code has five words; conversely, the displayed four-word witness gives four disjoint masks. Hence the maximum is exactly \(4\).

For the classification, form the compatibility graph on all 512 arrays. An exhaustive increasing-index traversal lists every four-clique, and it finds exactly \(514\). Because the independent set-packing computation has already proved that no five-clique exists, these are exactly all labeled optimal codes. The 16 transformations generated by the two order reversals, transposition, and complementation are explicitly checked to preserve every compatibility relation. Their orbits on the 514 four-cliques partition the optimum set into \(46\) classes. There is one orbit of size \(2\), four of size \(4\), twenty of size \(8\), and twenty-one of size \(16\). The complete canonical-representative table is in `classes.csv`.

## Verification
`verify.py` uses only the Python standard library. It computes every deletion outcome twice, once by coordinate loops and once by string row/column removal, and requires the two implementations to agree for all \(512\times9\) deletion operations. It then recomputes the deletion-ball histogram, the exact 16-output set-packing maximum, all 514 optimal four-cliques, all 16 channel symmetries, the 46-orbit partition, and the canonical table. A successful replay ends with `VERIFY_OK`.

The exact deletion-ball-size distribution over all 512 arrays is
\[
(1:2),(2:16),(3:28),(4:60),(5:102),(6:152),(7:86),(8:64),(9:2).
\]
This distribution is supplementary to the main claim and is also checked by the verifier.

## Relationship to prior work
Bitar, Welter, Smagloy, Wachter-Zeh, and Yaakobi introduced the criss-cross insertion/deletion model and the deletion-ball notation used here. Their full paper proves a non-asymptotic cardinality bound only for \(n\ge 41\); it therefore does not determine the binary \(n=3\) optimum. The same paper develops deletion-ball structure for \(n\ge3\), which motivates an exact census at this smallest size with \(2\times2\) outputs. Welter, Bitar, Wachter-Zeh, and Yaakobi later treat multiple criss-cross insertions/deletions and general redundancy bounds, rather than an exact binary \(3\times3\) classification.

Searches for the exact \(n=3\) maximum, for a binary one-row/one-column deletion census, and for the numbers \(514\) and \(46\) together with criss-cross deletion terminology did not locate a published statement equivalent to the claim. The closest indexed results concern other finite deletion-code parameters, not two-dimensional \(3\times3\) criss-cross deletion balls.

## Limitations
This is an exhaustive finite theorem, not a formula for general \(n\). The classification is relative to the stated 16 channel symmetries; using a different equivalence relation would change the class count. The literature comparison cannot exclude an unindexed or unpublished small-parameter computation, so that possibility remains a residual originality risk. No independent external audit has been performed.
