# Exact finite-parameter 1-type growth in dense meet-trees

## Finding
Let \(\mathsf{DMT}\) be the complete theory of the Fraïssé limit of finite meet-trees in the language \(\{<,\sqcap\}\). For every nonempty finite parameter set \(A\), put
\[
B=\operatorname{dcl}(A)=\langle A\rangle_{\sqcap},\qquad s=|B|.
\]
Then the number of complete 1-types over \(A\) is exactly
\[
\boxed{|S_1(A)|=4s}.
\]
In particular, if \(m=|A|\ge 1\), then
\[
\boxed{4m\le |S_1(A)|\le 8m-4},
\]
and both bounds are attained. Thus the maximal finite-parameter 1-type growth function is
\[
\boxed{\tau_{\mathsf{DMT}}(m)=8m-4}.
\]
For the empty parameter set, separately, \(|S_1(\varnothing)|=1\).

## Assumptions and scope
A meet-tree is a lower semilinear order in which every two elements have a greatest common lower bound \(x\sqcap y\). Rosario Mennuni records that finite meet-trees form a Fraïssé class, that \(\mathsf{DMT}\) eliminates quantifiers, and that definable closure is exactly closure under meets. Estevan and Kaplan prove the sharper local fact that adjoining one point to a finite tree creates at most one additional meet point besides the new point itself.

The formula concerns complete 1-types over an arbitrary finite parameter set in the pure meet-tree theory. It is not a count of invariant global types and it does not concern cone-expansions such as \(\mathsf{DTR}\). The first public version of the primary source appeared on 2020-06-23 and lists MSC 03C45 as primary.

## Proof
Because \(B=\operatorname{dcl}(A)\), every automorphism fixing \(A\) fixes \(B\) pointwise and conversely. Hence \(S_1(A)\) and \(S_1(B)\) have the same cardinality. We may therefore assume from the start that the finite parameter set \(B\) is meet-closed.

View the Hasse diagram of \(B\) as a finite rooted tree, with the least element as root. Quantifier elimination implies that a complete 1-type over \(B\) is determined by the isomorphism type, over \(B\), of the finite meet-subtree generated by \(B\) and one realization \(x\). By Estevan–Kaplan's one-point extension lemma, this generated subtree contains, besides \(B\) and \(x\), at most one further point
\[
y=\max\{x\sqcap b:b\in B\}.
\]
We now count all possibilities.

First there are exactly \(s\) realized, hence algebraic, types \(x=b\) with \(b\in B\).

Next suppose that no extra meet point is created, so \(B\cup\{x\}\) is already meet-closed. There are exactly \(2s\) possibilities. The new point can be inserted strictly below the root (one possibility); it can subdivide any one of the \(s-1\) cover edges of the rooted tree; or it can lie in a new open cone immediately above any chosen \(b\in B\) (\(s\) possibilities). These three disjoint families contribute
\[
1+(s-1)+s=2s.
\]

Finally suppose that one extra meet point \(y\notin B\) is created. Then \(y<x\), and \(x\) must lie in a new cone above \(y\) distinct from the old branch containing the elements of \(B\) whose meet with \(x\) is \(y\). The point \(y\) can lie strictly below the old root (one possibility), or strictly inside any one of the \(s-1\) cover edges of \(B\). It cannot lie above a maximal old vertex, because then it would not be generated as a meet of \(x\) with an element of \(B\). Thus this case contributes exactly
\[
1+(s-1)=s
\]
types.

All listed finite extensions occur in the Fraïssé limit: density realizes every edge subdivision and the infinite-ramification axiom realizes every required fresh cone. The cases are pairwise nonisomorphic over \(B\), so they yield distinct quantifier-free, hence complete, types. Therefore
\[
|S_1(A)|=|S_1(B)|=s+2s+s=4s.
\]

It remains to optimize \(s=|\langle A\rangle_\sqcap|\) for \(m=|A|\). Write the meet-closure tree with the \(m\) generators marked black and the \(w=s-m\) additional meet points marked white. Every white point has at least two children in this finite closure tree: otherwise it could not be a genuinely new meet of generators. Since a tree on \(m+w\) vertices has \(m+w-1\) edges, summing child counts gives
\[
m+w-1\ge 2w,
\]
so \(w\le m-1\) and hence \(s\le 2m-1\). Equality is attained by taking the \(m\) parameters to be the leaves of any finite full binary meet-tree. At the other extreme, a chain of \(m\) parameters is already meet-closed, so \(s=m\). Substituting into \(|S_1(A)|=4s\) proves both sharp bounds and \(\tau_{\mathsf{DMT}}(m)=8m-4\).

## Verification
The bundled standard-library `verify.py` performs an independent finite structural replay. It enumerates every rooted labeled tree on up to six vertices via Prüfer codes and interprets each as a finite meet-tree. For every meet-closed base \(B\) of size \(s\le4\), it counts one-new-vertex extensions and two-new-vertex extensions whose closure over \(B\) and the distinguished realization uses the extra vertex. Uniformly over every labeled base it obtains exactly \(2s\) extensions of the first kind and \(s\) of the second kind. Adding the \(s\) realized types gives \(4s\).

The verifier also constructs full binary witnesses showing meet-closure size \(2m-1\) for \(1\le m\le8\), and chain witnesses showing closure size \(m\). Its expected final line is `VERIFY_OK`. The finite replay checks the local classification; the infinite statement itself is proved above from quantifier elimination, the one-point extension lemma, and the Fraïssé/density axioms.

## Relationship to prior work
Mennuni records the key structural facts used here: \(\mathsf{DMT}\) is the theory of the Fraïssé limit of finite meet-trees, it eliminates quantifiers, and \(\operatorname{dcl}(A)\) is the meet-closure of \(A\). He cites the bound \(|\operatorname{dcl}(A)|\le2|A|\) from Estevan–Kaplan, noting that the elementary powerset bound is far from optimal. Estevan–Kaplan prove the one-point extension description and later use only a polynomial upper bound on the number of 1-types over a finite tree in their NIP argument. These sources do not state an exact formula for \(|S_1(A)|\), nor the sharp maximized value \(8m-4\), in the inspected passages.

A prior result in the accompanying ledger identifies ordered tuple orbits of the universal homogeneous meet-tree with labeled rooted Greg trees. That concerns finite tuple-orbit enumeration rather than complete 1-types over a fixed finite parameter set; it supplies related closure combinatorics but does not imply the exact local type count without the extension classification above.

Targeted searches for “dense meet-tree” together with “number of 1-types”, \(S_1\), “type counting”, and the candidate constants \(4|A|\) and \(8m-4\), plus semantic database searches for finite-parameter type growth, located the cited qualitative/coarse bounds but no exact formula. The originality claim is therefore restricted to this exact finite-parameter count and its sharp optimization.

## Limitations
The literature search cannot exclude an unindexed observation or folklore calculation phrased in different terminology. The result concerns only 1-types in pure \(\mathsf{DMT}\); cone-expansions can contribute additional local data and need not satisfy the same formula. The maximized formula uses nonempty finite parameter sets; the empty set is the separate one-type case. No independent audit has yet been performed.
