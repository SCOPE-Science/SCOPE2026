# Exact weight enumerator and dual distance of the new quaternary Hermitian LCD \([22,10,9]\) code
## Finding

Let \(C'\) be the quaternary linear code generated by the explicit \(10\times22\) matrix in Example 2 of Abdukhalikov–Ho. Then
\[
W_{C'}(z)=1+594z^9+3333z^{10}+6798z^{11}+17919z^{12}+51282z^{13}
+89826z^{14}+143748z^{15}+194601z^{16}+201102z^{17}
+168993z^{18}+106590z^{19}+48279z^{20}+13662z^{21}+1848z^{22}.
\]
The Euclidean dual and Hermitian dual both have minimum distance
\[
d^\perp=7.
\]
Consequently the \(4^{10}\) codewords, arranged as rows, form an orthogonal array of strength \(6\). There are exactly \(88\) dependent \(7\)-subsets of generator columns, and therefore
\[
A_7(C'^\perp)=264.
\]

## Assumptions and scope

Arithmetic is over
\[
\mathbb F_4=\{0,1,\omega,\omega^2\},\qquad \omega^2+\omega+1=0.
\]
The object is the specific linear code \(C'\) printed in Example 2 of *On the equivalence between additive and linear codes*. The source obtains it from a previously known additive complementary-dual code and states that \(C'\) is Hermitian LCD with parameters \([22,10,9]_4\).

The Euclidean dual is taken with the ordinary dot product. The Hermitian dual uses conjugation \(a\mapsto a^2\). Conjugating every coordinate sends one dual to the other, so their Hamming weight distributions, and in particular their minimum distances, agree.

## Proof

The first ten columns of the printed matrix form \(I_{10}\), so \(\dim C'=10\). Exact enumeration of all \(4^{10}=1{,}048{,}576\) row combinations gives the coefficients displayed above; they sum to \(4^{10}\), and the least nonzero weight is \(9\), recovering the source parameter.

Let \(v_1,\ldots,v_{22}\in\mathbb F_4^{10}\) be the generator columns. A dual word supported on a coordinate set \(T\) is exactly a linear dependence among \(\{v_j:j\in T\}\). Exhaustive rank computation shows that every \(6\)-subset of columns has rank \(6\). Hence no nonzero dual word has weight at most \(6\).

The \(7\)-subset with zero-based column indices
\[
\{0,1,2,3,9,15,18\}
\]
has rank \(6\), so a dual word of weight \(7\) exists. Therefore
\[
d(C'^\perp)=7.
\]
Because every \(6\)-subset is independent, the projection of \(C'\) onto any six coordinates is surjective onto \(\mathbb F_4^6\), and each \(6\)-tuple occurs exactly \(4^{10-6}=256\) times. This is precisely the orthogonal-array strength-\(6\) property.

Finally, exhausting all \(\binom{22}{7}=170{,}544\) seven-coordinate subsets finds exactly \(88\) of rank \(6\). Since every \(6\)-subset is independent, each such seven-set is a circuit: its dependence space is one-dimensional and every coefficient in a nonzero dependence is nonzero. Each circuit therefore yields \(4-1=3\) scalar-multiple dual words of weight \(7\), giving
\[
A_7(C'^\perp)=88\cdot3=264.
\]
The MacWilliams transform of the displayed primal weight enumerator independently gives the same coefficient \(264\) at dual weight \(7\).

## Relationship to prior work

Abdukhalikov–Ho prove that a previously known additive complementary-dual \([22,10,9]^2_2\) code is equivalent to the explicit linear code \(C'\), and they verify that \(C'\) is a Hermitian LCD \([22,10,9]_4\) code, improving the previously known minimum distance \(8\) to \(9\). Their full text does not state a weight enumerator or generalized higher-support data for \(C'\).

The earlier quaternary Hermitian-LCD tables supplied the distance-\(8\) benchmark but predate this explicit distance-\(9\) linear representative. Exact searches for the parameter set together with “weight enumerator,” “weight distribution,” “dual distance,” “orthogonal array,” and numerical coefficients did not locate the invariants above.

The dual distance is not determined by the ordinary parameter triple \([22,10,9]_4\). Here \(d^\perp=7\) additionally certifies six-coordinate statistical uniformity of the whole code through the orthogonal-array correspondence, while the exact enumerator records the complete ordinary Hamming spectrum.

## Limitations

The result concerns this explicit \([22,10,9]_4\) representative. It does not classify all optimal quaternary Hermitian LCD codes with these parameters or assert that their weight distributions or dual distances coincide. The originality conclusion is literature-dependent: an equivalent representative may have been analyzed under different notation or in an unindexed source.

The orthogonal-array statement is a consequence of the verified dual distance and does not claim a new general equivalence between dual distance and orthogonal-array strength.
