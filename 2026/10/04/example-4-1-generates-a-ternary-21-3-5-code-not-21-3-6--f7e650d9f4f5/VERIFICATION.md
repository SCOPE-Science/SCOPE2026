`artifacts/verify.py` uses only the Python standard library.

It reconstructs the six factors printed in Example 4.1 over \(\mathbb F_3\), verifies
\[
x^{11}-2=f_1f_2f_3,\qquad x^{10}-2=f_4f_5f_6,
\]
and rebuilds the module generator \((f_2f_3,f_5f_6)\). Multiplication by \(x\) uses the source convention for a \(2\)-constacyclic block, so the last coefficient wraps to the first multiplied by \(2\).

The verifier checks the explicit multiplier \(h(x)=1+2x^2\), obtains a zero first block and the weight-five second block \(2+x^2+2x^4+x^6+2x^8\), and then exhausts all \(27\) codewords generated by \(1,x,x^2\). It independently recomputes the exact weight distribution, dimension, projective column multiplicities, and generalized Hamming weights. The computation proves only the finite statement about Example 4.1 and does not assess the general theorem beyond that example.
