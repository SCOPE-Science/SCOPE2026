# The \(q=9\) SIS count is \(10\), with four MDS \([4,2,3]\) constructions
## Finding

For symmetric \(2\times2\) matrices over \(\mathbb F_9\), using the skew-involutory condition
\[
A^{-1}=-A,
\]
there are exactly \(10\) skew-involutory symmetric (SIS) matrices. Thus the \(q=9\), \(n=2\) entry in Table 1 of Güday–Polat–Sahin, which reports \(8\) SIS matrices, undercounts the set by two.

For the standard systematic code generated by
\[
G=[I_2\mid A],
\]
exactly four of the ten SIS matrices give self-dual MDS \([4,2,3]_9\) codes, while the other six give self-dual \([4,2,2]_9\) codes. One explicit missed MDS witness is
\[
A=\begin{pmatrix}1&1\\1&-1\end{pmatrix},
\]
viewed inside the prime subfield \(\mathbb F_3\subset\mathbb F_9\). Its associated code has weight enumerator
\[
W(z)=1+32z^3+48z^4.
\]

## Assumptions and scope

Write
\[
\mathbb F_9=\mathbb F_3(u),\qquad u^2=-1=2.
\]
A SIS matrix here means a symmetric matrix \(A\in M_2(\mathbb F_9)\) satisfying the source definition of skew-involutory,
\[
A^{-1}=-A.
\]
Equivalently,
\[
A^2=-I_2.
\]

The code statement concerns the systematic length-four linear code generated by \(G=[I_2\mid A]\), the standard construction attached to such an anti-orthogonal symmetric matrix. No statement is made about higher matrix dimensions or about the source's later tables.

## Proof

Let
\[
A=\begin{pmatrix}a&b\\b&c\end{pmatrix}.
\]
The condition \(A^2=-I_2\) is equivalent to
\[
a^2+b^2=-1,\qquad b(a+c)=0,\qquad b^2+c^2=-1.
\]

If \(b=0\), then \(a^2=c^2=-1\). In \(\mathbb F_9\), the two square roots of \(-1\) are \(u\) and \(-u\), so this branch contributes exactly four diagonal matrices.

If \(b\ne0\), then \(c=-a\) and
\[
a^2+b^2=-1.
\]
The six solutions with \(b\ne0\) are
\[
(a,b)=(0,u),(0,-u),(1,1),(1,-1),(-1,1),(-1,-1).
\]
Thus the total number of SIS matrices is
\[
4+6=10.
\]
This exhausts all possibilities because the displayed equations are exactly the entries of \(A^2=-I_2\).

For every such symmetric \(A\),
\[
GG^T=I_2+AA^T=I_2+A^2=0.
\]
Since \(G\) has rank \(2\), its row space is a self-dual \([4,2]\) code over \(\mathbb F_9\).

A \([4,2]\) systematic code has minimum distance \(3\) exactly when every pair of columns of \(G\) is linearly independent. The four diagonal solutions and the two off-diagonal solutions with \(a=0\) each repeat a projective column direction, so their distance is \(2\). For the remaining four solutions
\[
(a,b)=(1,1),(1,-1),(-1,1),(-1,-1),
\]
both entries are nonzero and the last two columns have determinant
\[
-a^2-b^2=1,
\]
so all four projective column directions are distinct. Hence these four codes have distance \(3\), attaining the Singleton bound and therefore are MDS.

For the concrete choice
\[
A=\begin{pmatrix}1&1\\1&-1\end{pmatrix},
\]
we have \(A^2=-I_2\). Exhausting all \(9^2=81\) messages in \([I_2\mid A]\) gives
\[
A_0=1,\qquad A_3=32,\qquad A_4=48,
\]
which yields the stated weight enumerator.

## Verification

`artifacts/verify.py` uses only the Python standard library. It implements \(\mathbb F_9=\mathbb F_3[u]/(u^2+1)\), exhausts all \(9^3=729\) symmetric \(2\times2\) matrices, retains exactly those satisfying \(A^2=-I_2\), and confirms that their count is \(10\).

For each of the ten matrices it constructs \([I_2\mid A]\), verifies self-duality directly, enumerates all \(81\) codewords, and determines the minimum distance. It obtains exactly six distance-two codes and four distance-three codes. It separately checks the explicit matrix and the weight distribution \(1+32z^3+48z^4\). Successful replay prints `VERIFY_OK`.

## Relationship to prior work

Güday, Polat, and Sahin define skew-involutory matrices by the condition that the inverse equals the negative, characterize symmetric examples, and tabulate computational counts and code parameters. Their public Table 1 reports, for \(n=2\) and \(q=9\), exactly \(8\) SIS matrices with code parameter \([4,2,2]\) marked AMDS. The same table gives \(q+1\) SIS matrices for the neighboring square cases \(q=5,13,17,25\), but the present proof does not rely on that pattern: it explicitly solves the defining equations over \(\mathbb F_9\).

Targeted searches for the paper title together with \(q=9\), the counts \(8\) and \(10\), SIS terminology, and \([4,2,3]\) found no published correction. The explicit MDS witness also shows that the displayed \([4,2,2]\) parameter does not exhaust the code quality attainable from the ten \(q=9\) SIS matrices under the systematic construction.

## Limitations

The publisher's public page exposes the abstract and all three computational tables, but a complete article PDF was not available through the inspected open-access and institutional retrieval paths. The accepted correction is therefore deliberately tied to the public definition \(A^{-1}=-A\), symmetry, and the explicit \(q=9\), \(n=2\) table row. If the inaccessible body imposed an additional restriction on the acronym SIS beyond symmetry plus skew-involutivity, that would need separate comparison; no such restriction appears in the public definition or table description.

The result does not assess the source's counts for \(n\ge3\), nor does it claim a new general counting theorem. Its content is the exact finite correction at \(q=9\), the complete split of the ten associated systematic codes by minimum distance, and an explicit MDS witness.
