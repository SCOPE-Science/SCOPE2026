# The record-breaking \(\mathbb Z_4\) negacyclic \([36,2,8,16]\) code has a linear cyclic Gray image
## Finding

For the record-breaking length-\(36\) negacyclic \(\mathbb Z_4\)-code \(C\) in Table 5 of Aydin–Belghith–Idowu–Nguyen–Tran, with type \(4^2 2^8\), Lee distance \(16\), and printed generator string `303230323030321210301230123010323210`, the standard Gray image \(B=\phi(C)\) is a binary linear code with parameters
\[
[72,12,16].
\]
Under the coordinate order following the single \(72\)-cycle induced by negacyclic shift, \(B\) is binary cyclic with generator
\[
\begin{aligned}
p(x)={}&x^{60}+x^{58}+x^{57}+x^{55}+x^{52}+x^{51}+x^{50}+x^{48}+x^{47}+x^{46}+x^{44}+x^{43}\\
&+x^{38}+x^{37}+x^{36}+x^{35}+x^{33}+x^{31}+x^{29}+x^{27}+x^{25}+x^{24}+x^{23}+x^{22}\\
&+x^{17}+x^{16}+x^{14}+x^{13}+x^{12}+x^{10}+x^9+x^8+x^5+x^3+x^2+1.
\end{aligned}
\]
Its exact weight enumerator is
\[
\begin{aligned}
W_B(z)={}&1+9z^{16}+12z^{18}+27z^{24}+108z^{26}+324z^{30}+27z^{32}+324z^{34}+2432z^{36}\\
&+324z^{38}+27z^{40}+324z^{42}+108z^{46}+27z^{48}+12z^{54}+9z^{56}+z^{72}.
\end{aligned}
\]
The dual minimum distance is \(4\). Consequently the Gray rank and Gray-kernel dimensions are both \(12\).

## Assumptions and scope

The source represents generator polynomials by coefficient strings in descending degree order. Therefore its length-\(36\) string is reversed before being used as the coefficient vector in increasing powers of \(x\). The code is the ideal generated by that polynomial in
\[
\mathbb Z_4[x]/(x^{36}+1).
\]
The standard Gray map is applied coordinatewise:
\[
0\mapsto00,\qquad1\mapsto01,\qquad2\mapsto11,\qquad3\mapsto10.
\]
The source already supplies the quaternary type and Lee minimum distance. They are independently recovered here as consistency checks rather than treated as new claims.

## Proof

Reverse the displayed source string to obtain the coefficient vector of \(g(x)\) in increasing powers. Generate the ideal by the \(36\) negacyclic shifts of \(g\). Exact subgroup enumeration gives
\[
|C|=4096=4^2 2^8.
\]
Exactly \(1024=2^{2+8}\) codewords are annihilated by multiplication by \(2\), independently recovering the reported type. Exhausting the subgroup gives minimum Lee weight \(16\).

The Gray image contains exactly \(4096=2^{12}\) words. Row reduction over \(\mathbb F_2\) gives binary span dimension \(12\). Since the image contains zero and already has exactly as many words as its \(12\)-dimensional span, it equals that span and is therefore binary linear. Gray weight preservation transfers the Lee distribution to the displayed binary Hamming weight enumerator, in particular giving minimum distance \(16\).

Negacyclic shift sends
\[
(c_0,c_1,\ldots,c_{35})\mapsto(-c_{35},c_0,\ldots,c_{34}).
\]
On interleaved Gray coordinates this is one \(72\)-cycle: the \(36\) first Gray bits are followed by the \(36\) second Gray bits, because negation swaps the two Gray bits of a symbol. Reordering coordinates along that cycle converts the induced permutation into ordinary cyclic shift. Directly in this order, the image is closed under cyclic shift.

Taking the polynomial greatest common divisor of all binary codewords with \(x^{72}+1\) gives the displayed degree-\(60\) polynomial \(p(x)\). Its first \(12\) cyclic shifts are independent and generate exactly the \(4096\) reordered Gray words, so the reordered image is precisely the cyclic \([72,12,16]\) code \(\langle p(x)\rangle\).

For the dual distance, a binary generator matrix for \(B\) has \(72\) nonzero, pairwise distinct columns, ruling out dual words of weights \(1\) and \(2\). No three columns sum to zero, ruling out weight \(3\). Columns numbered \(0,64,1,9\) in the cyclic coordinate order sum to zero, giving a dual word of weight \(4\). Hence
\[
d(B^\perp)=4.
\]
Since \(B\) is linear, its translation kernel is all of \(B\), so both Gray rank and Gray-kernel dimension equal \(12\).

The verifier independently computes binary rank, equality with the full binary span, cyclic closure after the explicit \(72\)-cycle coordinate reorder, the binary cyclic generator polynomial, and equality of its cyclic span with the Gray image. It also reconstructs a binary generator matrix and checks the dual-distance lower bound through column dependencies together with an explicit weight-\(4\) dual witness. ## Relationship to prior work

Aydin et al. classify this row as one of their record-breaking even-length negacyclic \(\mathbb Z_4\)-codes and publish its type, Lee distance, and generator string. Their paper reviews the standard Gray map and explicitly notes that a Gray image of a \(\mathbb Z_4\)-linear code need not be binary linear. It does not give the rank, kernel, complete weight distribution, or binary generator polynomial of this displayed record-breaker.

Blackford's even-length negacyclic theory determines which binary linear cyclic codes can arise as Gray images of even-length negacyclic \(\mathbb Z_4\)-codes. Thus cyclicity after the appropriate Gray-coordinate permutation is established background, not claimed as a new general phenomenon here. Dougherty and Fernández-Córdoba likewise establish rank and kernel as standard structural invariants for cyclic and negacyclic quaternary codes. The new finite content is the exact identification of this recently published record-breaker's Gray image as linear, together with its complete binary cyclic description, weight distribution, and dual distance.

Exact searches of the source generator string, quaternary parameters, binary parameters, rank/kernel terminology, and weight coefficients found no prior statement of these invariants for this code.

## Limitations

This finding concerns one distinguished row of the source's record-breaking table. It does not claim that the other \(729\) new negacyclic codes have linear Gray images. The resulting binary \([72,12,16]\) code is characterized structurally here; no claim is made that its binary minimum distance is record-breaking. General theorems about Gray images and negacyclic codes remain prior background, and an unindexed database entry for an equivalent quaternary code could contain overlapping finite invariants.
