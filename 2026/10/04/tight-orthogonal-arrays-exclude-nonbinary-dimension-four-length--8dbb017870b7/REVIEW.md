# Review

## Correctness

PASS. Alderson's symbol-uniformity theorem for every successive shortening implies that any hypothetical dimension-\(4\), defect-\(q-1\) length-maximal code is an \(\operatorname{OA}(q^4,q^2+q+2,q,3)\). Direct substitution shows that this array attains Rao's strength-\(3\) bound. Noda's classification then excludes both permitted tight-array forms for every \(q\ge3\). The binary \([8,4,4]_2\) code supplies the matching \(q=2\) existence case. The bundled verifier independently checks the binary witness and the finite consistency checks; the universal exclusion rests on the stated theorems and algebra, not enumeration.

## Originality

PASS. Searches for the exact code parameters, the \(A^{q-1}\)MDS terminology, length-maximal dimension-\(4\) codes, tight orthogonal arrays, and the Alderson–Noda implication found no source stating this corollary. Alderson leaves the \(s=q-1\) dimension-\(4\) branch only partially restricted by \((q+2)\mid36\); Noda classifies the relevant tight orthogonal arrays but does not formulate the coding consequence. The closest literature therefore supplies the two ingredients separately rather than the final implication.

Residual risk: an older design-theory or coding-theory source may have observed the same consequence under different terminology.

## Value

PASS. This is a natural complete nonexistence classification for one of the two non-MDS dimension-\(4\) branches isolated by the recent length-maximal-code theory. It replaces a finite list of remaining parameter candidates with the exact statement that only the binary case exists, and it applies to arbitrary nonlinear \(q\)-ary codes rather than only linear codes.
