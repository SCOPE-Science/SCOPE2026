# All 231 triangular systoles share one free-homotopy type in the sixteen-vertex Poincaré sphere
## Finding
Let \(K=\Sigma^3_{16}\) be the Björner--Lutz sixteen-vertex triangulation of the Poincaré homology three-sphere. Define the simple noncontractible combinatorial \(1\)-systole to be the least number of edges in a simple closed edge path that is not null-homotopic.

For \(K\), this systole is
\[
3.
\]
Exactly \(231\) unoriented simple three-edge cycles attain the minimum. They are precisely the boundaries of the three-vertex cliques in the one-skeleton that are not triangular faces.

Under the standard identification
\[
\pi_1(K)\cong 2I,
\]
where \(2I\) is the binary icosahedral group of order \(120\), every one of the \(231\) shortest loops represents an element of order \(10\). Moreover, all \(231\) represented elements belong to a single conjugacy class of size \(12\), and that class contains the inverse of each of its elements. Consequently the complete shortest noncontractible layer consists of one unoriented free-homotopy type.

This concentration is not a consequence of simplicial symmetry: the published sixteen-vertex triangulation has trivial simplicial automorphism group.

## Assumptions and scope
A simple three-edge cycle is the boundary of a three-vertex clique in the one-skeleton. A facial triangle is contractible because it bounds a two-simplex. A nonfacial three-clique can still be contractible in principle, so nonfaciality alone is not used as a homotopy certificate.

Free homotopy classes of oriented loops correspond to conjugacy classes in the fundamental group. Forgetting loop orientation additionally identifies a conjugacy class with its inverse class. The result concerns only simple edge loops in this fixed triangulation and uses combinatorial edge count rather than a geometric Riemannian length.

## Proof
The exact facet presentation reconstructs
\[
f(K)=(16,106,180,90).
\]
The one-skeleton has \(411\) three-vertex cliques. Exactly \(180\) of them are triangular faces, leaving
\[
411-180=231
\]
nonfacial triangular loops.

To test their fundamental-group classes, collapse a lexicographic spanning tree of the one-skeleton. The resulting edge presentation has \(91\) generators, with one triangular relator for each of the \(180\) two-simplices. The supplied `group_certificate.json` assigns each of these \(91\) edge generators a word in two explicit permutations \(a,b\) of \(120\) points. The standalone verifier checks all \(180\) triangular relators exactly and enumerates the subgroup generated by \(a,b\), obtaining order \(120\). Two original edge generators map to \(a\) and \(b\), so the presentation maps surjectively to this order-\(120\) group.

The published identification of \(K\) as the Poincaré homology sphere gives
\[
|\pi_1(K)|=120.
\]
Therefore the verified surjection is an isomorphism, so permutation evaluation is a faithful test of loop homotopy classes.

The verifier then evaluates all \(231\) nonfacial triangular loops. Every image has order \(10\), so none is the identity. It computes the conjugacy class of one image inside the full \(120\)-element group; the class has size \(12\), contains the inverse of its representative, and contains the image of every one of the \(231\) loops. Hence every nonfacial triangular loop is noncontractible and all belong to one unoriented free-homotopy type.

No simple simplicial loop has fewer than three edges, while every facial three-cycle is contractible. Since noncontractible three-cycles exist, the simple noncontractible combinatorial \(1\)-systole is exactly \(3\), with precisely the \(231\) minimizers above.

## Verification
`verify.py` contains the complete ninety-tetrahedron presentation and reads only the accompanying permutation certificate. It reconstructs every face, builds the spanning-tree edge presentation, checks every triangular relator, enumerates the full \(120\)-element permutation group, enumerates every three-vertex clique, and evaluates every nonfacial triangular loop.

The exact successful replay output is:

`VERIFY_OK f=16,106,180,90 tree=15 edge_generators=91 perm_group=120 triangle_relators=180 cliques3=411 missing3=231 missing3_orders=10:231 conjugacy_class=12 inverse_stable=yes`

The group certificate is not accepted merely because it contains permutations: relator satisfaction, surjectivity, group order, all \(231\) loop orders, the conjugacy-class size, and inverse stability are recomputed from the embedded artifacts.

## Relationship to prior work
Björner and Lutz introduced the sixteen-vertex triangulation as an example produced by bistellar flips. Lutz's dissertation gives the exact ninety facets, the face vector, the Poincaré-sphere identification, and the fact that the triangulation has no nontrivial simplicial automorphism. Standard computational-topology documentation records that its fundamental group is the binary icosahedral group of order \(120\).

The inspected exact-object literature establishes the triangulation and its global topology but does not state the complete shortest noncontractible edge-loop census in the material examined. In particular, knowing that the fundamental group is binary icosahedral does not determine which three-vertex cliques are nontrivial, their element orders, or whether all shortest loops occupy one free-homotopy class. The present result supplies those inclusion-sensitive finite data.

## Limitations
The theorem is specific to this labelled sixteen-vertex triangulation. It does not classify longer simple loops, all conjugacy classes realizable by simple cycles, geometric geodesics, or analogous systoles in other triangulations of the Poincaré sphere. The originality assessment is literature-based; inaccessible or unindexed historical computations could contain the same finite loop census.
