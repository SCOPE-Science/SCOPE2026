# Scientific review

## Correctness — PASS

All quantifiers, boundary conventions, and edge cases are explicit in the proof: finite nonempty ordered levels; full interlevel transitive orientation; complex primitive roots; and unreduced, nonregular Mayer path chains. Deleting an allowed path always yields an allowed path, making the invariant chains the full path space. An equivariant splitting of each layer permutation module into a trivial line and its augmentation kernel gives chain blocks that do not interact. An explicit scalar rescaling of the optional coordinates proves those blocks depend only on the number of fixed augmentation factors. The root-of-unity deletion identity proves \(d^N=0\) and exact kernel/image quotients yield the claimed character. For the three-layer cubic-root case, ranks of every relevant universal matrix are given and checked directly. Recomputations over compatible small finite fields return all 41 stated comparisons, but the unbounded assertion rests on the symbolic proof, not modular tests.

## Originality — PASS (bounded evidence)

The closest primary text is Karaguler–Wei, *Mayer Path Homology* (arXiv:2605.16525), which supplies general definitions, low-degree invariant path-generator classifications, and first-cycle structure, rather than a complete symmetric-group character for all transitive complete layered digraphs. Shen–Liu–Wei (arXiv:2312.01268) studies general Mayer complexes and persistent Mayer Laplacians but does not present the specific augmentation-block representation theorem. Published indexed results on complete weak-order spaces concern ordinary top homology, not the complex root-of-unity path differential. Actual source, alias, and implication searches against the mathematical index and published literature found no same-family theorem. This is not a claim of absolute uniqueness; a general unindexed root-of-unity join/Künneth treatment remains a plausible source of equivalent results.

## Mathematical value — PASS

The general decomposition provides a finite-matrix computation of every homology character for arbitrary layer cardinalities, requiring universal matrices dependent only on the number of levels and Mayer parameters, not the total number of graph vertices. The unexpected symmetry under reversal/reordering of layer data is a structural invariant of digraphs whose directed ordering differs. The complete three-layer cubic-root representations distinguish the new Mayer groups from classical homology, including two degree-zero \(q=1\) classes even for these connected digraphs. The result is a natural family-wide test and exact benchmark for the recently introduced invariant, not a parameter-renaming or isolated numerical experiment.
