# Verification

The argument was checked directly from the defining quantifiers. The marked degree-one module is generated by oriented edges. In a cactus graph, deleting one edge from each cycle block gives a spanning tree, so the signed cycle sums are an integral basis of homology. The proposed chain extension maps every oriented cycle edge to the corresponding cycle class divided by that cycle length and every bridge to zero; summing around a cycle returns its homology class exactly.

For the lower bound, the check is basis-independent: a cointegral basis makes every integral cycle class an integral coordinate vector. A nonzero shortest-cycle class therefore has coordinate \(\ell^1\)-norm at least \(1\). Because every chain extension fixes that cycle, the triangle inequality over its \(g(X)\) edges forces operator norm at least \(1/g(X)\). This matches the explicit upper bound.

The proof requires no enumeration, floating-point computation, or external certificate. The rank-one case is not presented as new. The argument does not extend as written to graphs in which distinct simple cycles share edges.
