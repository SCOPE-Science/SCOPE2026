# Verification of the sharp positive-cone triangular-truncation bound

The proof in `RESULT.md` gives a global reduction from all positive contractions to projections, then to rank-one inputs in dimension three. It reduces the remaining problem to the larger root of a quadratic polynomial and one scalar maximization; no numerical sample or finite enumeration is used to conclude an infinite inequality.

The accompanying standalone Python script `verify_cone.py` verifies the exact radical identities and the extremizing projection with rational arithmetic in the quadratic field generated by the square root of two. It also tests 20,000 seeded random simplex points against the sharp value. The latter test is diagnostic, not an exhaustive proof, and cannot establish novelty.

Verification command: `python verify_cone.py`. Python 3's standard library is sufficient. The exact source code is embedded alongside this document. An independent audit has not been performed. The complete 1992 multiplier article was not available for a full scientific comparison.
