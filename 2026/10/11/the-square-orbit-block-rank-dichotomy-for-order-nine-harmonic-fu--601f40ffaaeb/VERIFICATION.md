# Reproduction and evidence

Execute `python3 verify_q9_fusion.py` with Python 3.9 or later. Only the Python standard library is needed. The program constructs the field with nine elements as quadratic pairs modulo three, checks that the chosen multiplicative generator has order eight, and enumerates the eighteen four-point affine squares.

For all four odd characters it checks every one of the 126 four-block matrices in ambient dimension eight. For all three nontrivial even characters it checks every block subset of size one through six in ambient dimension nine, totaling 1899 modular rank calculations. Reduction maps the primitive complex 24th root to an element of multiplicative order 24 modulo 97. Every nonzero minor modulo 97 proves a corresponding nonzero complex minor; no converse is assumed.

For the deficient four- and five-block configurations it additionally evaluates exact nonzero right/left kernel witnesses for the canonical square and its complement. These are integer identities in the ring generated by \(i\) and the primitive cube root \(\omega\), whose only needed relations are \(i^2=-1\) and \(\omega^2+\omega+1=0\). Affine field symmetries extend the certificates to all eighteen configurations. The paper construction supplies the bridge from the unnormalized matrices in the checker to the original orthonormal-plane representatives.

The verification proves exactly the complete cardinality-by-configuration rank statement in `RESULT.md` for these order-nine models. It does not establish a uniform theorem over other field sizes or independently audit literature priority.
