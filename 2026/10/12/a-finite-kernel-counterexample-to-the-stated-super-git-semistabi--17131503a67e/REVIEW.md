# Independent mathematical audit

## correctness

PASS

Over C take G=G_m, affine X=A¹ with rho(x)=x⊗t^m (integer m≥2), Δ=μ_m acting trivially, and χ=t. In O(Δ)=C[u,u⁻¹]/(u^m−1), rΔ(χ)=u has exact order m and is not 1. However x itself is a nonzero relative invariant of χ^m, so every x≠0 is χ-semistable. Every χ^n-semi-invariant of C[x] is scalar x^{n/m} when m|n and zero otherwise; thus origin is unstable, giving precisely D(x). Effective action G/μ_m is transitive and free on D(x), with closed orbits there and finite original stabilizer, establishing stability for all nonzero points under the paper’s definition. Proj(⊕_n A^{G,χ^n})=Proj C[x], deg x=m, a point. The source Lemma 4.8 proof only yields rΔ(χ)^n=1 for witness degree n, not rΔ(χ)=1. The counterexample meets the purely even reductive/normal ineffective-kernel hypotheses for all m; it rejects necessity, not sufficiency or the whole numerical theory.

## originality

PASS

The full primary paper arXiv:2609.14904v1 explicitly asserts character restriction rΔ(χ)=1 as necessary in Lemma 4.8 / Theorem 4.12(1). A public critical review noticed the unjustified jump from torsion to triviality, but did not construct a semistable point with nontrivial finite character restriction. The present concrete uniform m-family with calculated stable/semistable locus and graded quotient establishes an actual counterexample rather than only a proof gap. Ineffective GIT actions are classical; the novelty is the exact failure of this particular recent claimed equivalence, not the group action itself.

## value

PASS

Identifying an actual false necessary condition in a foundational Hilbert–Mumford analogue has direct interpretational consequence: semistability of a positive-power χ-invariant need only force torsion of χ on an ineffective finite kernel. The minimal honest affine example prevents incorrect character-descent hypotheses in subsequent super-GIT applications. It does not purport to replace the general theorem.
