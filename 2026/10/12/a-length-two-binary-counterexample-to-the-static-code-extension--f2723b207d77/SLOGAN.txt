Corollary 3.1.5 of Fakieh--Nauman fails already for the coordinate-line code \(C=\{(0,0),(1,0)\}\subset\mathbb F_2^2\): the embedding \(f(a,0)=(a,a)\) satisfies the stated staticity hypotheses but changes Hamming weight from \(1\) to \(2\), so it cannot extend monomially. The later proof that cites this corollary is therefore not established by that route as written.
