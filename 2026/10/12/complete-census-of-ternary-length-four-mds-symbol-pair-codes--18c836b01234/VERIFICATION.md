# Verification

The standalone `verify.py` uses only the Python standard library. It reconstructs all \(81\) ternary words of length \(4\), computes the cyclic symbol-pair distance directly, builds the exact compatibility graph, and exhaustively enumerates every maximal clique with Bron–Kerbosch search.

The replay checks the maximal-clique histogram \(6:1296, 7:28512, 9:8784\), hence maximum size \(9\) with exactly \(8{,}784\) labeled maximizers. It then translates every maximum code and tests additive closure in \(\mathbb F_3^4\), obtaining exactly \(252\) affine two-flats. Finally it traverses the action generated by independent coordinatewise symbol permutations together with a cycle rotation and reflection, obtaining exactly \(11\) orbits with sizes \(36,72,144,324,432,648,648,1296,1296,1296,2592\); the affine maxima are exactly the first three orbit sizes.

The script also checks the stated explicit non-affine witness and an additive-closure failure. The recorded output is stored in `verification_output.txt`.

Limits: this verifies only the exact finite domain stated in the finding and only the stated natural symmetry subgroup. It does not establish a general theorem for other parameters or identify the full isometry group.
