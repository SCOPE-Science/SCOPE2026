# Complete equality census for binary length-six single-deletion codes
## Finding
For binary length-six single-deletion-correcting codes \(C\subseteq\{0,1\}^6\), the maximum cardinality is \(10\), and exactly nine labeled maximum codes attain it. Under the explicit order-four symmetry group generated by global bit complementation and word reversal, the nine maxima split into six orbits of sizes \(1,1,1,2,2,2\). Exactly one maximum is a Varshamov--Tenengolts syndrome class, namely \(VT_0(6)\); the other eight maxima are not VT classes. All nine maximum codes contain the common four-word core \(\{000000,001100,110011,111111\}\).

The nine maximum codes, written as unordered sets of six-bit words, are:

1. `000000,000011,001100,001111,010010,101101,110000,110011,111100,111111`
2. `000000,000011,001100,001111,010101,100010,101110,110011,110100,111111`
3. `000000,000011,001100,001111,010101,100010,101110,110011,111000,111111`
4. `000000,000111,001100,010001,011101,101010,110000,110011,111100,111111`
5. `000000,000111,001100,010010,011110,100001,101101,110011,110100,111111`
6. `000000,000111,001100,010010,011110,100001,101101,110011,111000,111111`
7. `000000,001011,001100,010001,011101,101010,110000,110011,111100,111111`
8. `000000,001011,001100,010010,011110,100001,101101,110011,110100,111111`
9. `000000,001011,001100,010010,011110,100001,101101,110011,111000,111111`

Code 8 is \(VT_0(6)\).

## Assumptions and scope
For a word \(w=w_1\cdots w_6\), let \(D_1(w)\) be the set of distinct length-five words obtained by deleting one coordinate. A code is single-deletion-correcting exactly when \(D_1(u)\cap D_1(v)=\varnothing\) for every two distinct codewords \(u,v\). Only binary words of length six are considered. The symmetry statement concerns the explicit group generated by complementing every bit and reversing every word; no claim is made that this is the full automorphism group of the deletion-confusability graph.

## Proof
Construct the compatibility graph whose \(64\) vertices are the binary words of length six and where two vertices are adjacent exactly when their one-deletion shadows are disjoint. Single-deletion-correcting codes are precisely cliques in this graph. The bundled verifier uses a standard exact Bron--Kerbosch recursion with pivoting to enumerate every maximal clique from this graph as built directly from deletion shadows. It finds \(273\) maximal cliques, maximum clique size \(10\), and exactly nine maximum cliques. Thus no code of size \(11\) exists and the displayed list is exhaustive.

The verifier then applies the four explicit maps identity, complement, reversal, and complement-after-reversal to every maximum. Their induced orbits have sizes \(1,1,1,2,2,2\). It independently computes the VT syndrome \(s(w)=\sum_{i=1}^6 i w_i\pmod 7\). The seven VT classes have sizes \(10,9,9,9,9,9,9\); among the nine maximum codes only the zero-syndrome class occurs as an entire syndrome class. Direct set intersection across the nine maxima gives the four-word common core in the finding.

## Relationship to prior work
Kulkarni and Kiyavash, arXiv:1211.3128v1 (2012-11-13), define deletion-correcting codes by pairwise-disjoint deletion sets, state that exact search had confirmed VT optimality through length ten, and their Table I records the binary length-six optimum/best-known value \(10\). Their work therefore covers the optimum value but not the equality census here. Konstantinidis and Mastnak, arXiv:1507.00600v1, Example 26, explicitly display one ten-word length-six code (the seventh code above) and note that a Levenshtein length-six code of size ten is maximal; they do not classify all maximum codes. The new content is the exhaustive count of nine maxima, their six orbits under the stated group, the uniqueness of \(VT_0(6)\) among maximum VT classes, and the common core.

## Limitations
This is a finite exact classification only for binary block length six. The verifier proves completeness for the stated deletion-shadow definition, but it does not classify maxima at other lengths and does not claim the stated order-four symmetry group is the full automorphism group. An obscure unindexed historical equality classification could still exist; the inspected exact-parameter sources and database searches did not reveal one.
