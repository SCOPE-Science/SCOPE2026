# Complete equality census for the smallest optimal constant-GC reverse-complement DNA code
## Finding
For DNA words over \(\{A,C,G,T\}\), let reverse-complement mean reversal followed by Watson--Crick complementation \(A\leftrightarrow T\) and \(C\leftrightarrow G\). Consider codes of length \(4\) in which every word has GC-content \(2\), distinct codewords have Hamming distance at least \(3\), and
\[
d_H(x,y^{\mathrm{RC}})\ge 3
\]
for every ordered pair \(x,y\) in the code, including \(x=y\).

The known optimum is
\[
A_4^{\mathrm{GC,RC}}(4,3,2)=6.
\]
The complete equality layer contains exactly \(512\) labeled six-word codes.

Every maximum code \(C\) has a canonical ordinary parent
\[
D=C\cup C^{\mathrm{RC}},
\]
which is a constant-GC code of size \(12\) and minimum Hamming distance \(3\). Among all \(128\) labeled ordinary constant-GC optima of size \(12\), exactly \(16\) are reverse-complement invariant. Exactly \(8\) of those \(16\) contain no self-reverse-complement word; these are precisely the viable parents of reverse-complement-optimal codes.

Each viable parent is a disjoint union of six reverse-complement pairs. Every choice of one word from each pair is valid, so each parent supports exactly
\[
2^6=64
\]
maximum reverse-complement codes. Consequently
\[
8\cdot64=512.
\]

Under the explicit order-\(256\) constraint-preserving symmetry group described below, the \(512\) maxima form four orbits of size \(128\), each with stabilizer order \(2\).

## Assumptions and scope
The DNA alphabet is \(\{A,C,G,T\}\). GC-content is the number of coordinates occupied by \(C\) or \(G\). Reverse-complement is the involution obtained by reversing coordinate order and applying \(A\leftrightarrow T\), \(C\leftrightarrow G\).

The reverse-complement constraint is imposed for all codeword pairs, including a word paired with itself. Thus a word with reverse-complement distance below \(3\) cannot occur in any admissible code.

“Labeled” means that the four coordinate positions and the four nucleotide symbols are fixed.

The symmetry group used for the orbit statement has order \(256\). It is generated by coordinate permutations commuting with reversal; independent swaps \(A\leftrightarrow T\) and/or \(C\leftrightarrow G\) applied identically on each reversal-paired coordinate pair; and the global class exchange \(A\leftrightarrow C,\ T\leftrightarrow G\). The last generator preserves GC-content \(2\) because the block length is \(4\).

## Proof
There are
\[
\binom{4}{2}2^4=96
\]
length-four DNA words with GC-content \(2\). Of these, exactly \(72\) satisfy the necessary self reverse-complement condition.

On those \(72\) eligible words, form the compatibility graph joining \(x\ne y\) when both \(d_H(x,y)\ge3\) and \(d_H(x,y^{\mathrm{RC}})\ge3\). The verifier constructs this graph in two independent ways: directly from the two inequalities, and by requiring the four-word set \(\{x,x^{\mathrm{RC}},y,y^{\mathrm{RC}}\}\) to have ordinary Hamming distance at least \(3\). The graphs agree exactly.

A complete Bron--Kerbosch search finds maximum clique size \(6\) and exactly \(512\) maximum cliques. An independent fixed-size increasing-vertex search reproduces exactly the same \(512\) six-cliques and proves that no seven-clique exists.

For the parent structure, independently form the ordinary constant-GC graph on all \(96\) words using only the Hamming-distance-\(3\) condition. Its maximum clique size is \(12\), with exactly \(128\) labeled maxima. Exactly \(16\) of these are reverse-complement invariant. Eight contain a self-reverse-complement word and therefore cannot support a constrained code. The other eight are unions of six two-element reverse-complement pairs.

If \(C\) is any constrained maximum, then \(C\) cannot contain both members of one reverse-complement pair, and the defining inequalities imply that \(C\cup C^{\mathrm{RC}}\) is an ordinary constant-GC code of size \(12\). Hence it is one of the eight viable parents. Conversely, within any viable parent, every transversal choosing one member from each reverse-complement pair satisfies both required distance conditions because its parent already has ordinary minimum Hamming distance \(3\). Thus each parent yields all \(64\) transversals.

The verifier finally constructs all \(256\) stated symmetries, checks each one against the complete compatibility graph, and computes four orbits of \(128\) maxima each. Orbit--stabilizer gives stabilizer order \(2\).

## Verification
Run `python3 verify.py` in the package directory. The script uses only the Python standard library and reconstructs the \(96\)-word ambient set, both compatibility graphs, both exact clique searches, the ordinary parent census, all parent transversals, and the explicit symmetry action.

The replayed terminal line is:

`VERIFY_OK maximum=6 labeled_maxima=512 parents=8 children_per_parent=64 orbits=4 orbit_sizes=128,128,128,128 stabilizers=2,2,2,2`

The finite search is exhaustive for the stated parameter. It is not a claim about longer DNA words or other distance and GC-content parameters.

## Relationship to prior work
King introduced the standard constant-GC and reverse-complement extremal notation and gave general bounds. His 2003 Table 1 records the value \(6\) for the parameter \((n,d,w)=(4,3,2)\), with the table notation marking it optimal; Table 2 records the corresponding ordinary constant-GC optimum \(12\). Thus neither numerical optimum is new here.

The new statement is the complete equality census and its parent structure: \(512\) constrained maxima, exactly eight viable reverse-complement-invariant ordinary parents, exactly \(64\) transversals per parent, and four symmetry orbits under the stated group. The inspected 2003 full text gives bounds, constructions, and optimum table entries but does not enumerate equality cases or classify these parents.

Gaborit and King later developed linear and additive constructions and updated parameter tables, again emphasizing constructions rather than an all-code equality classification at this smallest optimal cell.

## Limitations
The result is finite and parameter-specific: length \(4\), GC-content \(2\), and both Hamming and reverse-complement distance at least \(3\). It does not classify unequal GC-content, longer strands, additional biochemical constraints, or codes under other reverse/reverse-complement conventions.

A literature search cannot exclude an obscure or unindexed finite enumeration. The main residual originality risk is a historical computational census not visible in the inspected primary full text or targeted exact-parameter searches.
