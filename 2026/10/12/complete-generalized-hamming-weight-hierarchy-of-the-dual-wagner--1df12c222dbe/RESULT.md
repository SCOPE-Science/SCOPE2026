# Complete generalized Hamming-weight hierarchy of the dual Wagner code

## Finding
Let \(W\) be the binary Wagner code generated by the stored \([23,14,5]_2\) matrix in the best-known-linear-code table, and let \(D=W^\perp\). Then \(D\) has dimension \(9\) and its complete generalized Hamming-weight hierarchy is
\[
(d_1,d_2,d_3,d_4,d_5,d_6,d_7,d_8,d_9)=(8,12,15,17,18,20,21,22,23).
\]
Thus every generalized weight of this specific dual code is fixed exactly, not merely bounded.

## Assumptions and scope
All codes are binary and all ranks are over \(\mathbb F_2\). Generalized Hamming weight \(d_r(D)\) means the minimum support cardinality among all \(r\)-dimensional subcodes of \(D\). The code \(W\) is the equivalence class represented by the 14-by-23 generator matrix stored by CodeTables for the optimal binary \([23,14,5]_2\) code; Simonis proved that this Wagner code is the unique equivalence class with those parameters, so the hierarchy is independent of the chosen representative.

The recent generalized-weight paper of Kurz, Landjev and Rousseva motivates the calculation: it formulates the projective extremal numbers \(m_q^{{(r)}}(k,w)\), determines the binary cases through dimension seven, and explicitly does not attempt the full dimension-eight layer. The present statement is only about the dual Wagner code, not a complete solution of all dimension-eight extremal tables.

## Proof
Let \(G\) be the 14-by-23 generator matrix of \(W\), and write \(G_X\) for the submatrix consisting of columns indexed by \(X\subseteq\{{1,\ldots,23\}}\). Since \(D=W^\perp=\ker G\), the subcode of \(D\) whose support is contained in \(X\) is exactly the kernel of \(G_X\). Therefore
\[
\dim D(X)=|X|-\operatorname{{rank}}_2(G_X).
\]
By the definition of generalized Hamming weights,
\[
d_r(D)=\min\bigl\{{|X|:|X|-\operatorname{{rank}}_2(G_X)\ge r}}\bigr\}.
\]
This converts each generalized-weight question into an exact finite rank minimization over the \(2^{{23}}\) coordinate subsets.

The bundled verifier enumerates every nonempty subset \(X\), computes \(\operatorname{{rank}}_2(G_X)\) by exact XOR Gaussian elimination, and records the least \(|X|\) at each nullity threshold. It obtains, successively for \(r=1,\ldots,9\),
\[
8,12,15,17,18,20,21,22,23.
\]
Because all \(2^{{23}}\) subsets are examined and all arithmetic is exact over \(\mathbb F_2\), this is an exhaustive proof of both the upper and lower sides of every displayed equality.

## Verification
The checker in `verify.cpp` embeds the published generator matrix and evaluates the rank-nullity criterion above for every coordinate subset. Recompiling that file with a standard C++17 compiler and running it produces the nine minima and terminates with `VERIFY_OK`. The stored run output is in `verification_output.txt`.

Representative supports attaining the minima include \(\{{3,6,8,9,10,11,12,16\}}\) for \(d_1=8\), \(\{{1,2,4,5,6,8,10,12,13,14,16,18\}}\) for \(d_2=12\), and the first 20 coordinates for \(d_6=20\). The verifier independently checks minimality by exhausting every smaller coordinate subset.

## Relationship to prior work
Kurz, Landjev and Rousseva (2026) study generalized Hamming weights through projective multiset extremal functions and identify the dimension-eight binary layer as outside the range they determine. Their paper cites Simonis's uniqueness theorem for the Wagner code but does not state the generalized-weight hierarchy displayed here.

The CodeTables entry supplies the exact Wagner generator matrix and records ordinary minimum distance \(5\) for \(W\), but it does not tabulate generalized weights of \(W^\perp\). Simonis (2000) proves uniqueness of the \([23,14,5]_2\) Wagner code. Nagy (2025), building on the Sidon-set literature, records that a largest Sidon set in \(\mathbb F_2^9\) has size \(24\) and is unique. Translating such a Sidon set to contain zero gives a 23-point projective configuration with at most three points per plane, so the consequence \(m_2^{{(2)}}(8,3)=23\) is already implied by that literature and is not asserted here as original. The additional statement here is the entire nine-entry hierarchy of the dual Wagner code.

## Limitations
The finite calculation concerns one code equivalence class, albeit the unique \([23,14,5]_2\) class. It does not classify all optimal projective multisets in dimension eight, determine \(m_2^{{(r)}}(8,w)\) for arbitrary \(r,w\), or establish generalized-weight optimality of \(D\) among all binary \([23,9]\) codes. The literature search found no prior table stating this hierarchy, but database and full-text search cannot logically exclude every older unindexed computation. Simonis's journal full text was not lawfully available from the inspected open sources; its accessible abstract establishes the uniqueness scope but leaves residual risk that an unindexed higher-weight calculation appears inside the article.
