# Finite checks and reproducibility

Run `python3 verify.py` with Python 3 and no third-party packages. Its successful output begins:

```text
VERIFY_OK exhaustive_maps_x_alphabets=864 independent_refinement_checks=864 direct_term_closures=15 randomized_invariants=1000
```

For each total function on \(1\) to \(4\) vertices and each alphabet size \(q\in\{1,2,3\}\), it independently compares the divisor–tail polynomial with explicit enumeration of all colored rooted forward traces through \(2n+1\) observations. The same cases also construct the modal color partition of the entire disjoint union of all colored copies and refine it to stabilization without using the trace enumerator. For \(n\le2\) and \(r\le2\), a separate concrete construction of the Boolean subalgebra generated by modal shifts of the input bits obtains the total number of term operations. A fixed-seed collection of 1,000 larger random maps checks basic invariants only.

The finite tests do **not** verify the general case by exhaustion; the proof handles arbitrary finite \(W\) and all \(r\ge0\). The code runs with deterministic inputs and prints examples as additional sanity checks. No independently performed external mathematical audit is asserted.
