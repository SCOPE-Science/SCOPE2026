# Double puncturing settles \(d_{\mathrm{LCD}}(55,8)=24\)

## Finding

For the binary LCD code \(C\) of parameters \([57,8,25]_2\) displayed by Lim, An, and Kim (arXiv:2609.02096v1), expand each hexadecimal digit into four binary digits in most-significant-bit-first order and delete the three appended zero columns. Among all \(\binom{57}{2}=1596\) double punctures of this displayed representative, exactly four coordinate pairs—\(\{9,18\}\), \(\{10,30\}\), \(\{34,48\}\), and \(\{41,42\}\), with coordinates numbered from \(1\)—produce an LCD code of minimum distance \(24\). Hence a binary LCD \([55,8,24]_2\) code exists. Since the general binary linear-code bound gives \(d(55,8)=24\), it follows that \(d_{\mathrm{LCD}}(55,8)=24\). This improves the value \(23\) reached at length \(55\), dimension \(8\), in the source's reported shortest-embedding experiments to the sharp bound \(24\).

## Assumptions and scope

All codes are binary linear codes. For a generator matrix \(G\), the code is LCD exactly when \(GG^T\) is nonsingular over \(\mathbb F_2\). The source prints its \([57,8,25]_2\) generator in hexadecimal after appending zero columns until the displayed length is divisible by four. The reconstruction used here expands hexadecimal digits in the ordinary most-significant-bit-first order and removes the final three zero padding columns. Reversing a fixed bit convention within every hexadecimal nibble only applies a coordinate permutation and therefore does not affect the existence, dimension, minimum distance, or LCD property.

The exact-value conclusion concerns \(d_{\mathrm{LCD}}(55,8)\), the largest possible minimum distance among binary LCD \([55,8]_2\) codes.

## Proof

First reconstruct the source's displayed matrix \(G\). Exact row reduction over \(\mathbb F_2\) gives \(\operatorname{rank}G=8\). Exact enumeration of all \(2^8-1=255\) nonzero row combinations gives minimum weight \(25\), and exact row reduction of \(GG^T\) gives rank \(8\), reproducing the source's LCD \([57,8,25]_2\) claim.

For every unordered pair \(S\) of the \(57\) coordinates, puncture \(G\) on \(S\). There are exactly \(1596\) such pairs. For each puncture \(G_S\), compute its row rank, the rank of \(G_SG_S^T\), and the minimum weight over all \(255\) nonzero row combinations. Exactly \(756\) double punctures remain LCD. Among them, exactly four have minimum distance \(24\):
\[
S\in\bigl\{\{9,18\},\{10,30\},\{34,48\},\{41,42\}\bigr\}.
\]
For the displayed witness \(S=\{9,18\}\), \(\operatorname{rank}G_S=8\), \(\operatorname{rank}(G_SG_S^T)=8\), and the exact weight enumerator is the polynomial given above, so its minimum distance is \(24\). Thus an LCD \([55,8,24]_2\) code exists.

Grassl's current binary linear-code table gives both lower and upper bound \(24\) for ordinary binary \([55,8]_2\) codes. Therefore every binary LCD \([55,8]_2\) code has minimum distance at most \(24\). Combining this upper bound with the explicit LCD witness proves
\[
d_{\mathrm{LCD}}(55,8)=24.
\]

## Relationship to prior work

Lim, An, and Kim give the motivating LCD \([57,8,25]_2\) code and derive the upper bound \(d_{\mathrm{LCD}}(55,8)\le 24\). Their dimension-eight results table reports minimum distance \(23\) at length \(55\), while their length-\(57\) code reaches its bound \(25\). The present puncturing calculation closes exactly that neighboring one-unit gap.

Grassl's binary-code table already contains ordinary linear \([55,8,24]_2\) codes and fixes the unrestricted linear optimum at \(24\), but ordinary optimality does not imply the LCD condition. The nonsingularity calculation for the punctured source matrix supplies the missing LCD witness.

Searches for the exact parameter, its LCD formulation, puncturing of the source \([57,8,25]_2\) code, and equivalent exact-value formulations found no prior statement of \(d_{\mathrm{LCD}}(55,8)=24\). The recent source itself surveys the relevant binary LCD construction literature and still reports only distance \(23\) for its length-\(55\), dimension-eight experiment.

## Limitations

The result determines one exact LCD distance parameter and classifies the double punctures of one displayed \([57,8,25]_2\) representative. It does not classify all binary LCD \([55,8,24]_2\) codes up to equivalence, nor all optimal puncturing relations from other \([57,8,25]_2\) representatives. The literature search cannot logically exclude an obscure or poorly indexed prior construction; that residual bibliographic risk does not affect the correctness of the explicit code or the exact-value deduction.
