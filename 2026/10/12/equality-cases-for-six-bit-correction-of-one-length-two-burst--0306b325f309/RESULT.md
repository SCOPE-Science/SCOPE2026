# Equality cases for six-bit correction of one length-two burst
## Finding
Let \(e_1,\ldots,e_6\) be the standard basis of \(\mathbb F_2^6\) and put
\[
E=\{0,e_i:1\le i\le6}\cup\{e_i+e_{i+1}:1\le i\le5}.
\]
Thus \(E\) consists of no error, one flipped bit, or two flipped adjacent bits, with no wrap-around adjacency. A code \(C\subseteq\mathbb F_2^6\) corrects one such burst exactly when the translates \(c+E\) are pairwise disjoint.

The maximum code size is \(4\). Exactly \(192\) labeled maximum codes exist. Every maximum is an affine two-dimensional subspace of \(\mathbb F_2^6\). There are exactly \(12\) admissible direction planes, and every admissible direction has all \(16\) affine cosets as maximum codes. Under the explicit group generated by the \(64\) binary translations and reversal of the six coordinates, the maxima split into seven orbits: two of size \(16\) and five of size \(32\).

## Assumptions and scope
The burst is noncyclic: the adjacent double errors are \(e_i+e_{i+1}\) only for \(1\le i\le5\). The result concerns arbitrary binary codes, not only linear or systematic codes. Labels of the six coordinates are retained when counting the \(192\) codes. The stated order-\(128\) action is an explicit isometry subgroup; it is not asserted to be the full isometry group.

## Proof
For distinct codewords \(x,y\), their error balls intersect exactly when \(x-y\in E+E\). If \(x\) and \(y\) agree in coordinates \(1\) and \(2\), then \(x-y\) is supported on the four consecutive coordinates \(3,4,5,6\). Split those four coordinates into the adjacent pairs \(\{3,4}\) and \(\{5,6}\). On each pair, every binary pattern is either zero, a single error, or the adjacent double error. Hence every vector supported on \(3,4,5,6\) is a sum of two members of \(E\). Therefore two codewords in a correcting code cannot agree on their first two coordinates. Projection to coordinates \(1,2\) is injective, proving \(|C|\le4\).

The equality classification is finite and exact. The verifier builds the compatibility graph on all \(64\) binary words using two independently evaluated criteria: disjoint error balls, and exclusion of the difference set \(E+E\). It exhaustively enumerates every four-clique and obtains exactly \(192\). For each such clique, the common-neighbor set is empty, which independently excludes any five-clique and confirms maximality. Translating each four-clique by one of its words produces a four-element set containing zero; every one is closed under binary addition, so every maximum is an affine two-flat. Deduplication yields exactly \(12\) direction planes, each with exactly \(16\) cosets, accounting for all \(192\) maxima.

## Verification
Running `python3 verify.py` reproduces the compatibility graph and the complete classification. The expected terminal line is:

`VERIFY_OK vertices=64 errors=12 bad_differences=44 edges=640 maximum=4 labeled_maxima=192 affine_maxima=192 directions=12 cosets_per_direction=16 natural_group_size=128 orbits=7 orbit_sizes=16x2,32x5 direction_orbits=7 direction_orbit_sizes=1x2,2x5 profile_class_sizes=16,32,32,48,64`

The file `directions.json` lists all \(12\) direction planes explicitly. The verifier also checks that coordinate reversal preserves the allowed error set and that the translation-plus-reversal action has exactly the seven stated orbits.

## Relationship to prior work
Abramson's 1958 technical report and 1959 paper introduced systematic binary codes correcting all single errors together with all double errors in adjacent digits. Later burst-distance work developed general linear-code formulations and bounds, and the modern SEC-DAEC literature continues to emphasize linear constructions for adjacent-error correction. Those results establish the model and construction context but do not state the complete arbitrary-code equality census at length six, the fact that all \(192\) equality cases are affine, the exact set of \(12\) directions, or the seven orbits under the declared action.

The closest classical perfect-code direction is the 1977 work on adjacent-error correcting binary perfect codes. The present length-six problem is not perfect: an error ball has \(12\) words, so four maximum balls cover \(48\) of the \(64\) ambient words rather than partitioning the space.

## Limitations
The classification is only for binary length \(6\), a single noncyclic burst of length at most \(2\), and the exact error set displayed above. The orbit statement is with respect to the explicit translation-plus-reversal subgroup only. No statement is made about longer lengths, cyclic wrap-around adjacency, multiple bursts, byte-organized SEC-DAEC variants, or the full graph automorphism group.
