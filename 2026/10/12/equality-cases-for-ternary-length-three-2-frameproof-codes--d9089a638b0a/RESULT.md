# Equality cases for ternary length-three 2-frameproof codes
## Finding
Let \(C\subseteq\{0,1,2\}^3\) be a 2-frameproof code: for every pair of distinct codewords \(a,b\in C\), the coordinatewise descendant set \(\operatorname{desc}(a,b)\) contains no codeword of \(C\setminus\{a,b\}\). The sharp size \(|C|=9\) is known from the equivalent separating-hash formulation. The equality cases are rigid: every size-nine code is the graph of a Latin square of order \(3\). Equivalently, for every equality case, projection onto each of the three coordinate pairs is a bijection onto \(\{0,1,2\}^2\).

There are exactly \(12\) labeled equality cases. Under independent permutations of the three symbols in each coordinate together with coordinate permutations, the natural group \((S_3)^3\rtimes S_3\) has order \(1296\), acts transitively on the \(12\) equality cases, and the stabilizer of each equality case has order \(108\). One representative is
\[
\{000,011,022,101,112,120,202,210,221\},
\]
which is the graph of the Latin square \(z=x+y\pmod 3\).

## Assumptions and scope
The alphabet is exactly \(\{0,1,2\}\), codewords have length exactly three, and coalition size is at most two. A word \(x\) belongs to \(\operatorname{desc}(a,b)\) precisely when \(x_i\in\{a_i,b_i\}\) for each coordinate \(i\in\{1,2,3\}\). The classification is labeled before quotienting by the natural Hamming-isometry group; no claim is made for larger alphabets or longer codes.

The numerical optimum \(9\) is prior work. The contribution here is the complete equality classification at the ternary parameter, its exact labeled count, and its natural-symmetry orbit and stabilizer.

## Proof
For coalition size two, a code fails the frameproof condition exactly when it contains a three-element subset \(\{x,a,b\}\) in which one word is a descendant of the other two. Thus the problem is a finite independence problem in a three-uniform forbidden-triple hypergraph on the \(27\) ternary words. Direct construction from the definition gives exactly \(972\) forbidden triples.

The bundled verifier performs an exhaustive increasing-index search. At each search node it stores the selected words and a bit set of still-eligible later words. Whenever two words have already been selected, every later word that completes a forbidden triple with that pair is deleted from the candidate bit set. This invariant is exact: a partial selection survives if and only if it contains no forbidden triple, and every valid labeled subset is visited once in lexicographic order. The search finds no valid ten-word subset and finds exactly \(12\) valid nine-word subsets. This independently recovers the known optimum and exhausts its equality cases.

For every one of the \(12\) equality cases, the verifier then checks that each two-coordinate projection has all \(9\) ordered pairs. Fixing the first two coordinates therefore writes the code uniquely as \(\{(r,c,L(r,c)):r,c\in\{0,1,2\}\}\). Bijectivity of the other two projections says exactly that each row and each column of \(L\) is a permutation, so \(L\) is a Latin square. Conversely, the verifier independently enumerates all Latin squares of order \(3\), obtains exactly \(12\) graphs, and checks that this set is identical to the complete frameproof equality census.

Finally, the verifier enumerates all \(6^3\cdot6=1296\) independent symbol/coordinate permutations. The orbit of the displayed representative contains all \(12\) maxima, and exactly \(108\) group elements fix it, establishing the transitivity and stabilizer claim.

## Relationship to prior work
Staddon, Stinson, and Wei give the nonbinary frameproof definition and identify a \(w\)-frameproof code with a separating hash family of type \(\{1,w\}\). Bazrafshan's sharp-bound work proves the general bound \(C(3,q,\{1,2\})\le q^2\) and supplies optimal Latin-square constructions, so the value \(9\) and the existence of Latin-square extremizers at \(q=3\) are not new. Shangguan and Ge later restate the same sharp \(q^2\) regime in the separating-hash literature.

The inspected sharp-bound sources construct extremizers but do not classify all equality cases at \(q=3\), count the labeled extremizers, or give their full natural-isometry orbit and stabilizer. The later Latin-square-based 2-IPP construction of Batra and Singh concerns a stronger property and, in its stated nonbinary construction, even alphabet sizes larger than three; it therefore does not imply this ternary frameproof equality classification.

## Limitations
This is a finite equality classification at one natural sharp parameter. The maximum \(9\) itself is prior work, and the result does not claim a classification for general \(q\). The main residual originality risk is an obscure or unindexed small-parameter table or note that may already record the same twelve equality cases or their single equivalence class. Searches of the exact separating-hash parameter, frameproof aliases, Latin-square formulation, and the directly relevant historical sources found no such classification.
