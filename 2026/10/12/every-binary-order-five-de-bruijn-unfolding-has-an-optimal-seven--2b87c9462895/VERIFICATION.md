# Finite verification

Compile `verify_order5.cpp` using a standards-compliant C++17 compiler:

```sh
c++ -O2 -std=c++17 -Wall -Wextra -pedantic verify_order5.cpp -o verify_order5
./verify_order5
```

Expected exact output from the supplied source:

```text
VERIFY_OK cycles=2048 unfoldings=65536 candidates=120 full_factor_witnesses=65536 min_seven_attractors=30 max_seven_attractors=120 cuts_with_30=4 cuts_with_120=22
```

The checker generates all rooted cycles by edge-simple Euler-circuit recursion on the complete order-four binary de Bruijn digraph, anchoring its unique `00000` edge. Its candidate position masks are generated by all increasing seven-subsets with endpoint and gap conditions, and it compares interval unions for all thirty short factors of each word. For each of 65,536 unfolded words it additionally checks every nonempty factor against an actual successful seven-position witness, independently of the short-factor reduction.

The theorem's search-space completeness is justified mathematically in `RESULT.md`; the program is the finite computational step, not a substitute for that argument. Enumeration is exhaustive only within the fixed order-five binary family. This document does not claim a formal-proof-assistant certificate, independent audit, or a result for higher de Bruijn orders.
