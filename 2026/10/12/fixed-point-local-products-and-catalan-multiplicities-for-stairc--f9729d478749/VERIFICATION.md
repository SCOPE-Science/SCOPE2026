# Reproduction and limits

Run `python3 ferrers_local_checker.py` with Python 3.10 or newer. It requires only the Python standard library. The recorded output is in `ferrers_local_checker_output.txt`.

The script tests all 285 admissible fixed-point charts for \(2\le m\le11\), comparing an independently constructed chart generator set with the three disjoint factor blocks. It verifies that each omitted original monomial is generated by the factors, computes minimal-generator counts, and compares resulting embedding dimensions against the independent derivatives of admissible quadratic Ferrers minors. It also counts bounded-degree semigroup monomials and compares them to Narayana Hilbert-series coefficients for \(1\le t\le6\), and checks multiplicity maxima for \(3\le m\le8\).

These are exact finite computations, not an exhaustive infinite certificate. For all \(m\ge3\), the scientific argument is the explicit Laurent-semigroup decomposition and the published general Hilbert-series identity. Independent mathematical audit has not been performed.
