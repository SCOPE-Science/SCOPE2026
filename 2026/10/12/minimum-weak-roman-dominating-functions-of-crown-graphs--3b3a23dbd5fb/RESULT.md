# Minimum weak Roman dominating functions of crown graphs
## Finding
For every integer \(n\ge3\), let \(\operatorname{Cr}_n=K_{n,n}-M_n\) have bipartition \(A=\{a_1,\ldots,a_n\}\), \(B=\{b_1,\ldots,b_n\}\), with deleted pairs \(a_i b_i\). The weak Roman domination number is \(\gamma_r(\operatorname{Cr}_3)=3\) and \(\gamma_r(\operatorname{Cr}_n)=4\) for every \(n\ge4\). Moreover, the minimum weak Roman dominating functions admit a complete classification. For \(n=3\), there are exactly \(14\), all \(\{0,1\}\)-valued: either one whole bipartition class is labeled \(1\), or one side has one \(1\) at index \(i\) and the other side has two \(1\)'s on an index set containing \(i\). For \(n=4\), there are exactly \(90\): the \(62\) \(\{0,1\}\)-valued minimum functions consist of a whole side, a \(1+3\) support whose singleton index lies in the triple, or an arbitrary \(2+2\) support; the remaining \(28\) are either \(f(a_i)=f(b_i)=2\), or one label \(2\) at index \(i\) on one side together with two opposite-side labels \(1\) whose index set contains \(i\). For every \(n\ge5\), every minimum function has side weight \(2+2\) and is exactly one of: (i) \(f(a_i)=f(b_i)=2\) for one index \(i\); (ii) one label \(2\) at index \(i\) on one side and two opposite-side labels \(1\) on a two-set containing \(i\), with either orientation; or (iii) two labels \(1\) on each side, on index sets \(I,J\in\binom{[n]}2\) satisfying \(I\cap J\ne\varnothing\). Hence the number of minimum functions is \(14\) for \(n=3\), \(90\) for \(n=4\), and \(n(2n^2-n+1)/2\) for \(n\ge5\). The \(\{0,1\}\)-valued minimum weak Roman functions are exactly the minimum secure dominating sets; thus the additional minimum weak Roman functions using a label \(2\) number \(28\) when \(n=4\) and \(n(2n-1)\) for \(n\ge5\).

## Assumptions and scope
A weak Roman dominating function on a graph \(G\) is a map \(f:V(G)\to\{0,1,2\}\) such that for every vertex \(v\) with \(f(v)=0\), there is a neighbor \(u\) with \(f(u)>0\) for which moving one unit from \(u\) to \(v\) leaves no undefended vertex. Its weight is \(\sum_{v\in V(G)}f(v)\). The graph \(\operatorname{Cr}_n\) is the crown graph \(K_{n,n}-M_n\), with deleted matched pairs \(a_i b_i\).

## Proof
First note a support lemma. For a set \(D\subseteq V(\operatorname{Cr}_n)\), write \(P=\{i:a_i\in D\}\) and \(Q=\{i:b_i\in D\}\). Then \(D\) dominates the crown graph exactly when the following two symmetric conditions hold: if \(Q=\varnothing\), then \(P=[n]\); if \(|Q|=1\), its unique index lies in \(P\); if \(|Q|\ge2\), there is no further condition from vertices of \(A\). The analogous statement holds with \(P,Q\) interchanged. This follows because \(a_i\) is adjacent to every vertex of \(B\) except \(b_i\).

For \(n\ge4\), no weak Roman function of weight at most \(3\) exists. Since neither side can be completely positive with that weight, both sides must contain positive weight. A side-weight split \(1+1\) immediately fails after the unique defender of a zero vertex is moved. For a split \(1+2\), choose a zero vertex on the side opposite the unique unit; after that unit is moved, the revised support lies entirely in one bipartition class and cannot dominate because \(n\ge4\). The case \(2+1\) is symmetric. Weight \(4\) constructions below therefore prove \(\gamma_r=4\). For \(n=3\), the same argument excludes weight \(2\), while the listed weight-\(3\) functions work, so \(\gamma_r=3\).

Now suppose \(n\ge5\) and the weight is \(4\). A side-weight split \(1+3\) is impossible: there is a zero vertex on the side opposite the unique unit such that moving that unit leaves a support contained in the other bipartition class but not equal to it. Hence the split is \(2+2\). On either side, weight \(2\) is either one label \(2\) or two labels \(1\).

If both sides have one label \(2\), at indices \(i,j\), then \(i=j\) is necessary because otherwise the zero vertex matched to the unique opposite-side positive vertex is undefended. When \(i=j\), every zero vertex can be defended by the opposite label \(2\), and the support lemma verifies the revised support.

If one side has a label \(2\) at index \(i\) and the other has labels \(1\) on a two-set \(J\), then \(i\in J\) is necessary because otherwise the vertex opposite index \(i\) is undefended. If \(i\in J\), the support lemma shows that every zero can be defended: when a unit label must move, choose the unit whose removal leaves the singleton opposite-side support at an index present in the revised support on the first side.

Finally suppose both sides have two labels \(1\), on two-sets \(I,J\). If \(I\cap J=\varnothing\), then because \(n\ge5\) there is an index outside \(I\cup J\). Defending the corresponding zero vertex removes one of the two opposite-side units and leaves a singleton support whose index is absent from the revised first-side support, violating the support lemma. Conversely, if \(I\cap J\ne\varnothing\), the same lemma gives an explicit defender for every zero: with \(I=J\), either unit works; with \(I\cap J=\{h\}\), a zero indexed by the noncommon element of the opposite support is defended by the common-index unit, while any other zero is defended by the noncommon unit. This proves the classification for \(n\ge5\).

The cases \(n=3,4\) are the boundary cases in which an entire side, or the complement of a singleton on a side, can fit within the minimum weight. Applying the same support lemma gives exactly the configurations stated in the finding. Counting gives \(14\) for \(n=3\), \(90\) for \(n=4\), and for \(n\ge5\)
\[
n+2n(n-1)+\binom n2\left(\binom n2-\binom{n-2}2\right)=\frac{n(2n^2-n+1)}2.
\]
The \(\{0,1\}\)-valued minimum functions are precisely secure dominating functions at the same weight, giving \(n(n-1)(2n-3)/2\) such functions for \(n\ge5\); subtracting yields \(n(2n-1)\) additional minimum weak Roman functions using a label \(2\).

## Relationship to prior work
Henning and Hedetniemi introduced weak Roman domination and established the basic parameter inequalities. Pushpam and Mai later studied weak Roman domination on several graph classes under MSC \(05C69\). Chellali, Haynes and Hedetniemi proved general comparisons among weak Roman, secure, total and \(2\)-rainbow domination. Their 2014 full text includes an example for a complete graph with a perfect matching deleted, which is a different non-bipartite graph from the crown graph. The searched literature and database records did not identify a crown-graph classification of minimum weak Roman functions. A separate secure-domination classification for crown graphs gives exactly the \(\{0,1\}\)-valued part of the present result; the label-\(2\) families and their counts are not implied by that set-only classification.

## Limitations
The proof classifies minimum weak Roman functions only; it does not enumerate all weak Roman functions of higher weight. The literature search cannot exclude an unindexed or differently named equivalent result, especially under the aliases complete bipartite graph minus a perfect matching and bipartite Kneser graph \(H(n,1)\). The foundational 2003 source was verified through bibliographic metadata and abstract; a later primary full text was used for detailed comparison.
