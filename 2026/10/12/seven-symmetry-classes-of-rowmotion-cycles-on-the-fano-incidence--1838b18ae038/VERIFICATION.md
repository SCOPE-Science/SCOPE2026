# Reproducibility and finite certificates

The labelled Fano plane is generated by nonzero three-bit vectors. Every line is a distinct triple \(\{a,b,a\oplus b\}\). The seven lines are sorted lexicographically. A fourteen-bit integer encodes an ideal: point bits 0–6, line bits 7–13. Inclusion of a line requires inclusion of its three points.

Run `python3 verify.py` from the directory containing all package files. Expected checks:

```text
VERIFY_OK points=7 lines=7 ideals=458 rowmotion_bijection=true
VERIFY_OK cycles=3:29,5:35,7:28 order=105 total_cycles=92
VERIFY_OK incidence_automorphisms=168 cycle_orbit_classes=7
VERIFY_OK cycle_classes=3x1,3x14,3x14,5x7,5x7,5x21,7x28
VERIFY_OK equivariance=all_458_ideals_x_168_transformations
VERIFY_OK seven_cycle_certificates_disjoint_and_cover_all_458_ideals=true
VERIFY_OK orbit_types.csv=generated
```

The seven rows in `orbit_types.csv` specify complete representative cycles. Each projective symmetry is given by the images of the three standard basis vectors; the verifier constructs all 168 invertible choices, transforms each cycle, confirms exact cardinalities, and proves their disjoint union equals the complete ideal set.

Run `c++ -std=c++17 -O2 verify_independent.cpp -o verify_independent` and `./verify_independent`. Expected:

```text
VERIFY_INDEPENDENT_OK points=7 lines=7 ideals=458
VERIFY_INDEPENDENT_OK cycle_lengths=3:29,5:35,7:28 order=105
```

The C++ verifier enumerates all 16384 masks and derives rowmotion using minimal absent elements and downward closure rather than the closed formula used by the Python verifier. Both executions completed successfully. Computation is an exhaustive finite proof for the stated fourteen-element poset, not a proof for an infinite family of planes. The originality comparison is based on inspected publicly available sources and does not rule out an unindexed earlier enumeration.
