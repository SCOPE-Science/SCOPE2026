# Reproduce the exact finite census

Prerequisites: Python 3 and a C++17 compiler invoked as `c++`. Run `sh run_checks.sh` from this directory. The command produces its own intermediate tables and orbit-representative file.

- `planes.cpp`: enumerates all proper four-edge-colorings after a first-line normalization in the three-dimensional vector-space model over the ternary field.
- `factor.cpp`: independently enumerates the same normalized coloring count using Singer difference set \(\{0,1,3,9\}\) on thirteen cyclic points.
- `gens.py`, `make_mapping.py`: derive the group generated by four transvections and its action on 52 line–point incidences.
- `orbits.cpp`: exhaustive generated-action union-find orbit decomposition, with representative table.
- `groupconj.py`, `burnside.cpp`: independently compute all conjugacy classes and Burnside fixed-point totals.
- `matchings.py`: a third route to the labeled coloring census using pairwise disjoint perfect matchings and two-color completions of the remaining cycles.
- `verify_codes.py`: checks all 20 displayed representatives for constant composition and exact distance constraint.

All geometric objects are generated from definitions. No nonstandard third-party libraries, random seeds, external data or precomputed tables are required.
