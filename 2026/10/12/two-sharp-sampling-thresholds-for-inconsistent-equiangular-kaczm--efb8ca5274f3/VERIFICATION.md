# Algebraic and finite-path verification

With Python 3 and SymPy available, run `python verify.py` next to this file and `RESULT.md`.

The script constructs all six three-update randomized reshuffling matrices and fixed-residual affine forcing vectors exactly over the field generated by \(\sqrt3\), checks their matrix second moments and mixed terms, and reproduces all key contraction, noise and stationary polynomial identities symbolically. It tests rational sign brackets for both unique threshold roots and the one-to-two-epoch ordering reversal at \(\eta=6/5\).

The finite direct path tests enumerate all 27 IID index triples and six reshuffling permutations at six rational stepsizes and two starting vectors; longer tests enumerate all 36 independent two-epoch permutations and all 729 IID index sequences at two initial conditions. The path enumerations are exhaustive **only for the chosen finite settings**, not for all real \(\eta\), epochs or problem geometries. The paper's all-parameter assertions rely on the displayed analytic proof, including the polynomial sign transformations and geometric-factor monotonicity.

No external/independent audit has been performed, and no result about non-equilateral rows, random per-visit noise, or almost-sure convergence is certified.
