The claim quantifies over all nonempty fuzzy frames, all propositional valuations and all modal formulas, using the 2026 fuzzy Gödel infimum/supremum conventions. The proof reduces witness existence for arbitrary formula values to extremum attainment for arbitrary functions from the world set into the unit interval. Finite positive support ensures necessity attainment because zero-weight edges contribute the constant value one. If that support is infinite, a single atom can be assigned strictly positive but decreasing values below its accessibility weights, yielding unattained infimum zero. For possibility, finite positive-level sets force every positive supremum onto a finite set, while any infinite fixed positive level permits a strictly increasing atomic sequence with unattained limit. The zero-supremum and empty-support boundaries, as well as the nonempty-world assumption, are handled explicitly. Countable-subset selection uses ordinary choice. Exact rational checking covers 4,368 finite cases and 12 prefixes but is not treated as a proof of the infinite claims.

## Value — PASS

The boundary is motivated directly by the difference between a witnessed model under one valuation and a frame that guarantees witnessing under every valuation. It completely distinguishes two natural operator classes, proves that their difference persists on infinite frames, and identifies the precise decay-to-zero condition for the possibility operator. The structural distinction is useful for choosing frame classes on which modal computations have actual witnesses without assuming that the world set is finite. This is a standalone exact classification; no complexity or axiomatization improvement is asserted.
