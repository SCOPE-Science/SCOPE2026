The length-64 extended \(C_{1,5}\) cyclic code is precisely the classical binary affine-line code of \(\operatorname{AG}(3,4)\): its \(336\) weight-four line vectors span the full \(51\)-dimensional code. This identifies a recent completely regular code instance with an earlier finite-geometry code and transfers, rather than rediscovers, its established symmetry and design theory.
