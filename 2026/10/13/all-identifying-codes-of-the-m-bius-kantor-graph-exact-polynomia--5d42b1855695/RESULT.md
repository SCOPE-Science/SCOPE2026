# All identifying codes of the Möbius–Kantor graph: exact polynomial and thirteen optimum orbits

## Finding
Let \(G\) be the Möbius–Kantor cubic graph, represented as the generalized Petersen graph \(GP(8,3)\). For a vertex set \(C\subseteq V(G)\), call \(C\) an identifying code when the sixteen traces \(N[v]\cap C\), one for each \(v\in V(G)\), are all nonempty and pairwise distinct. Its identifying-code enumerator is \(I_G(z)=\sum_{C\text{ identifying}}z^{|C|}\). Then
\[
I_G(z)=584z^{8}+3840z^{9}+5440z^{10}+3888z^{11}+1780z^{12}+560z^{13}+120z^{14}+16z^{15}+z^{16}.
\]
In particular, the minimum identifying-code size is exactly \(8\), and there are exactly \(584\) minimum codes. The automorphism group has order \(96\), with exactly thirteen orbits on these minimum codes, having sizes \(2,6,24,24,48,48,48,48,48,48,48,96,96\). The attached `orbits.csv` gives an explicit representative and structural profile for each orbit. Exactly \(16229\) of all \(65536\) vertex subsets are identifying codes.

## Assumptions and scope
The graph has vertex labels \(u_i=i\), \(v_i=8+i\) for \(0\le i<8\); all subscripts are taken modulo \(8\). The edges are \(u_i u_{i+1}\), \(u_i v_i\), and \(v_i v_{i+3}\) for each \(i\). These define a connected simple cubic bipartite graph on \(16\) vertices with \(24\) edges; its girth is \(6\). The two bipartition classes are \(A=\{1,3,5,7,8,10,12,14\}\) and \(B=V(G)\setminus A\). Codes use *closed* neighborhoods and separate individual vertices, including their nonempty traces. The result concerns this finite graph only; it does not assert a parameter formula for all generalized Petersen graphs.

## Proof
For each vertex \(v\), let \(Q_v=N[v]\) be its four-vertex closed neighborhood. For an unordered pair of distinct vertices \(a,b\), let \(D_{a,b}=Q_a\mathbin{\triangle}Q_b\). For any \(C\subseteq V(G)\), its trace at \(v\) is nonempty if and only if \(C\cap Q_v\neq\varnothing\); and two traces are distinct if and only if \(C\cap D_{a,b}\neq\varnothing\). Consequently an identifying code is exactly a hitting set for the \(16+\binom{16}{2}=136\) listed sets \(Q_v,D_{a,b}\), where repetitions are discarded.

Constructing those masks from the three edge formulas gives \(136\) *distinct* nonempty constraints: \(40\) of cardinality \(4\), \(48\) of cardinality \(6\), and \(48\) of cardinality \(8\). Each eight-element constraint contains one of the \(88\) four- or six-element constraints. Therefore hitting those \(88\) constraints is necessary and sufficient; no eight-element constraint contributes an additional requirement. This reduction is a finite identity checked for each of the \(48\) eight-element masks by `verify.py`.

For exhaustive counting, associate to a vertex set the sixteen-bit integer \(m=\sum_{v\in C}2^v\). Iterate the exact range \(0\le m<65536\). For each \(m\), compute all sixteen traces \(m\mathbin{\&}Q_v\) and check nonemptiness and distinctness. Independently test intersection with the \(88\) reduced constraints. The two tests agree on *every* one of the \(65536\) possibilities. Tallying successful masks by population count yields the nine coefficients displayed in the finding, and zero successful masks of size below \(8\). This proves the minimum and complete polynomial because every vertex subset has exactly one such mask. The separate `verify_independent.cpp` directly re-enumerates the full \(65536\)-mask range using only neighborhood signatures and agrees coefficient by coefficient.

For the orbit classification, `verify.py` constructs automorphisms by injecting the sixteen vertices in a connected breadth-first vertex order while enforcing all previously determined adjacency and nonadjacency relations. Every automorphism is found, because its image assignments satisfy these exact tests; conversely all completed assignments are graph automorphisms. The search finds precisely \(96\) permutations. Applying them to each of the \(584\) minimum-code masks and extracting disjoint orbits gives thirteen orbits, with representatives and orbit sizes in `orbits.csv`. All orbit images are checked to remain among the optimum codes, every optimum code belongs to exactly one orbit, and sizes sum to \(584\).

The bipartition-size counts for minimum codes, with the two sides unordered, are \((0,8):2\), \((1,7):48\), \((2,6):72\), \((3,5):192\), and \((4,4):270\). These are obtained from the same complete enumeration and sum to \(584\).

## Verification
Run `python3 verify.py` in the same directory as `orbits.csv` using the Python standard library; it validates all graph definitions, both complete-mask tests, the reduced-constraint argument, every coefficient, all bipartition profiles, the full automorphism group, and the CSV representatives. Independently run `c++ -std=c++17 -O2 verify_independent.cpp -o verify_independent && ./verify_independent` to replay the direct signatures with separate code and no data dependency. Both commands were executed against the complete attached sources and yielded the expected success lines. The finite exhaustive loops, not extrapolated samples or cached outputs, constitute the verification.

## Relationship to prior work
Araujo-Pardo, Balbuena, Montejano and Valenzuela investigate identification in partial linear spaces and characterize the stronger property of admitting a \((1,\leq k)\)-identifying code for regular incidence graphs. In that property the entire vertex set must distinguish every set of up to \(k\) possible faulty vertices; it does not enumerate or optimize the selected landmarks for single faults. The earlier full 2010 proceedings version and the 2011 journal text discuss small cubic bipartite incidence graphs, but do not imply the displayed single-fault code polynomial or orbit table. Foucaud and collaborators study *edge-identifying codes*, equivalently identifying codes of line graphs; those are different vertex sets and neighborhood systems. The canonical graph construction is available in graph-generator documentation. The present claim is restricted to the exact one-fault identifying-code enumeration and its minimum-code orbit classification.

## Limitations
Originality was checked against discoverable papers and research records, not against all unpublished or unindexed enumerations. The 2010 primary paper offers closely related terminology with a different quantifier; this distinction matters and should be verified when comparing subsequent results. The orbit counts have a finite exhaustive certificate, not an independent external audit. No general graph-family formula or resilience claim is made.
