# Complete census of optimal standardized-deletion permutation codes in \(S_5\)

## Finding
Let \(S_5\) denote the set of permutations of \(\{0,1,2,3,4\}\). After deleting one entry from a permutation, standardize the four surviving entries by replacing the smallest with 0, the next with 1, and so on. A code corrects a single standardized deletion if every two distinct codewords have disjoint sets of possible four-letter outputs.

**Exact five-cell result.** The largest such code in \(S_5\) contains **8** permutations. On the fixed, labeled positions and symbols there are exactly **1,568** eight-word optimal code sets. Under the natural group generated by reversing all positions, complementing all symbol values, and inverting all permutations, the optimal sets form **220 classes**: two orbits of size 1, one of size 2, forty-three of size 4, and 174 of size 8. Precisely 36 optimal sets contain neither the increasing nor the decreasing permutation.

The two-signature congruence construction of Gabrys et al. (2014) has one class of size 8 at length five; it is just one of these 1,568 labeled optima. This comparison is about the displayed fixed-length construction, not the optimality of that construction at other lengths.

## Assumptions and scope
The alphabet is precisely \(\{0,1,2,3,4\}\), all five entries appear once per word, and the channel deletes exactly one entry, leaving only the relative order of the four survivors. Nothing about zero deletions, two deletions, a different alphabet or length, or absolute-value deletions is claimed. A code is an unordered set of distinct permutations; permuting its codewords does not produce a new code.

For a permutation \(p\), let \(\mathcal D(p)\subset S_4\) be its set of distinct standardized one-deletion outputs. Then the correctness criterion is exactly \(\mathcal D(p)\cap\mathcal D(q)=\varnothing\) for distinct codewords \(p,q\). There are \(5!=120\) possible input permutations and \(4!=24\) possible outputs. Throughout the exhaustive calculations both sets are listed in lexicographic order using zero-based values.

The eight-word construction from the double-signature congruences is the following list of permutations, all expressed over \(\{0,1,2,3,4\}\): `01234`, `03214`, `10243`, `14203`, `30241`, `34201`, `41230`, `43210`.

## Proof
**Finite reduction and bound.** Index the 120 permutations lexicographically. For each \(p\), associate the 24-bit integer \(b(p)\), whose bit indexed by \(t\in S_4\) is one exactly when \(t\in\mathcal D(p)\). Thus \(p,q\) may share a code precisely when the bitwise intersection of \(b(p)\) and \(b(q)\) is zero. This condition is an exact restatement of the channel, not a relaxation or a sample.

The accompanying independent C++ and Python verifiers build every mask directly from all five deletions. Both enumerate candidate code sets in ascending lexicographic input-index order, retaining only pairwise-compatible extensions. Every admissible code set of a specified size has a unique increasing index sequence and therefore appears in exactly one complete branch. Pruning a branch when fewer compatible candidates remain than needed is valid since no extension can supply the missing codewords. Exhaustive enumeration finds precisely 1,568 admissible eight-element sets and **zero** admissible nine-element sets. Any code of size greater than nine contains a nine-element subcode; therefore size eight is the exact maximum. The construction stated above, independently checked against all distinct deletion outputs, attains eight.

**Equality classification.** Reversing positions and complementing values commute with standardized deletion; inversion preserves it by transposing the permutation matrix and then deleting the corresponding row and column (the standard inversion/deletion duality). These three operations generate an eight-element symmetry group: inversion interchanges coordinate and value reversal. Applying all eight group elements to each of the 1,568 distinct optimal sets, taking its lexicographically smallest image as canonical, and identifying equal canonical images produces the orbit distribution \(1:2,\ 2:1,\ 4:43,\ 8:174\). It accounts for all \(2+2+172+1,392=1,568\) sets. The accompanying `representatives.csv` contains every canonical code and orbit size, with no omitted classes.

**Construction comparison.** For each \(p\), compute the binary ascent signature of \(p\) and of \(p^{-1}\), and take the weighted sums of their bit positions modulo five, as in the Gabrys et al. double-syndrome code construction. All 25 classes are enumerated; their largest cardinality is 8, attained at exactly one syndrome pair. That particular class is in the optimum census. The separate complete census shows that the syndrome construction does not exhaust the 1,568 optimizers.

## Verification
From the directory containing `verify.py`, `verify.cpp`, and `representatives.csv`, run `python3 verify.py`, then `g++ -std=c++17 -O2 verify.cpp -o verify && ./verify`. The Python program directly materializes 120 deletion-output sets, verifies pairwise compatibility and the symmetry generators on all relevant pairs, exhaustively enumerates eight- and nine-element sets, checks all 220 canonical representatives and orbit sizes against the CSV, and checks the double-signature and monotone-word counts. The C++ program independently constructs 24-bit deletion masks using integer ranking, and exhaustively counts admissible sets of eight and nine. Both complete with a verification-success message. The Python nine-word search visits 98 one-word branches, 2,732 two-word branches, 24,318 three-word branches, 62,064 four-word branches, 37,398 five-word branches, 4,843 six-word branches, and 62 seven-word branches, and reaches zero nine-word leaves; the remaining branches are rigorously pruned by the shortfall bound above.

## Relationship to prior work
Gabrys, Yaakobi, Farnoud, Sala, Bruck and Dolecek (ISIT 2014) define exactly this standardized-deletion channel, establish deletion/insertion duality and develop asymptotically optimal double-signature permutation codes. Their five-page primary text contains general bounds and a construction, not the 1,568-set or 220-orbit equality census proved here. The double-signature construction does attain the exact five-cell optimum but does not describe its other labeled or symmetry-distinct realizations.

Classical Ulam-distance permutation codes retaining absolute symbols are not the same channel: two deletions that erase different numeric values may produce the same **standardized** output even though their unstandardized outputs differ. Accordingly, previously known small Ulam-code classifications do not imply this equality census. A related 2016 journal treatment addresses several models of rank-modulation deletion; the complete journal text was inaccessible at this check, so a possible earlier subsidiary enumeration remains a stated bibliographic risk, not a finding of noncoverage.

## Limitations
Only the fixed five-cell, exactly-one-standardized-deletion model has been settled. The result gives a complete finite census, not a formula for larger lengths, a new asymptotic rate, or a decoder beyond the established construction. The classification is complete relative to the specified eight-element symmetry group, not under every conceivable bijection of the 120-word alphabet. Reproduction of the complete finite search is essential to the numerical part of the proof. The priority comparison cannot exclude unindexed work or a matching count embedded in the inaccessible full 2016 journal article. The conference work is from 2014; the first exactly date-stamped publicly accessible full-text upload independently confirmed here is April 14, 2015, so the precise date of its earlier 2014 public circulation remains uncertain.
