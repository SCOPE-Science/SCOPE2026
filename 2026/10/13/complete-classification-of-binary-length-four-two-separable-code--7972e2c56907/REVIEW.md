## correctness

Binary coordinate-descendant profiles are distinct for every singleton and pair exactly when the code is overline-2 separable. An independent min/max-bit encoding of coordinate parent-symbol sets exhaustively checked all C(16,7)=11440 seven-word sets and C(16,8)=12870 eight-word sets, obtaining 240 admissible sevens and zero eights. Any larger code contains an inadmissible eight-subcode by heredity. Explicitly enumerating 16 bit translations and all 24 coordinate permutations partitions all 240 sevens into exactly two orbits of sizes 48 and 192 (stabilizers 8 and 2); the distinguishing pairwise distance multisets are (4,8,8,1) and (4,10,6,1). The finite universe really is exhausted; this is not extrapolation.
