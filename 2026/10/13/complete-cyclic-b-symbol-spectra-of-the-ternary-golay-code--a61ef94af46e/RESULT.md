# Complete cyclic \(b\)-symbol spectra of the ternary Golay code
## Finding
Let \(G_{11}\) be the cyclic ternary Golay code in \(\mathbb F_3[x]/(x^{11}-1)\) generated by
\[
g(x)=2+x^2+2x^3+x^4+x^5.
\]
For a codeword \(c=(c_0,\ldots,c_{10})\) and \(1\le b\le 11\), define its cyclic \(b\)-symbol Hamming weight by
\[
w_b(c)=\#\{i\in\mathbb Z/11\mathbb Z:(c_i,c_{i+1},\ldots,c_{i+b-1})\ne(0,\ldots,0)\}.
\]
Then the complete enumerators \(W^{(b)}(z)=\sum_{c\in G_{11}}z^{w_b(c)}\) for \(b=2,3,4,5\) are
\[
W^{(2)}(z)=1+44z^7+88z^8+110z^9+220z^{10}+266z^{11},
\]
\[
W^{(3)}(z)=1+22z^8+44z^9+132z^{10}+530z^{11},
\]
\[
W^{(4)}(z)=1+22z^9+44z^{10}+662z^{11},
\]
and
\[
W^{(5)}(z)=1+22z^{10}+706z^{11}.
\]
For every \(6\le b\le 11\),
\[
W^{(b)}(z)=1+728z^{11}.
\]
Thus the minimum \(b\)-symbol distances are \(7,8,9,10,11\) for \(b=2,3,4,5,6\), agreeing with the published distance hierarchy, while the coefficient data above give the full distributions.

## Assumptions and scope
The statement concerns the standard cyclic coordinate order of the ternary \([11,6,5]_3\) Golay code. The cyclic \(b\)-symbol metric depends on coordinate order, so no claim is made that these enumerators are invariant under arbitrary coordinate permutations. The result is an exact finite statement for this code, not an asymptotic formula or a classification of all equivalent realizations.

## Proof
Since \(\deg g=5\), every codeword has a unique representation \(a(x)g(x)\) with \(\deg a<6\). Hence there are exactly \(3^6=729\) codewords, and multiplication has degree at most \(10\), so the coefficient vector is obtained without modular wraparound.

The supplied verifier exhausts all \(729\) message polynomials. For each resulting codeword it computes \(w_b\) directly by testing all eleven cyclic length-\(b\) windows. It also computes \(w_b\) independently from the cyclic zero gaps. If the nonzero word has zero-gap lengths \(\ell_1,\ldots,\ell_r\), then exactly \(\max(\ell_j-b+1,0)\) starting positions inside gap \(j\) give an all-zero window, so
\[
w_b=11-\sum_{j=1}^r\max(\ell_j-b+1,0).
\]
The two calculations agree for every codeword and every \(1\le b\le 11\). Tallying the direct values yields the displayed coefficients. As a separate normalization check, the \(b=1\) tally is
\[
1+132z^5+132z^6+330z^8+110z^9+24z^{11},
\]
which is the ordinary Hamming weight enumerator recorded for this code in the 2026 source.

## Verification
Run `python3 verify.py` in the package directory. The program constructs the code from the generator polynomial, confirms that all \(729\) codewords are distinct, compares direct window counting with the zero-gap formula for every \(b\), checks every enumerator coefficient against `certificate.json`, verifies that every enumerator sums to \(729\), reproduces the published ordinary Hamming enumerator, and reproduces the published minimum-distance profile. A successful replay ends with `VERIFY_OK`.

## Relationship to prior work
Panraksa's 2026 paper determines the cyclic symbol-pair distance and the complete minimum \(b\)-symbol distance hierarchy for this ternary Golay code, and analyzes the cyclic orbits of the minimum Hamming-weight supports. It does not state the full \(b\)-symbol coefficient distributions above. Guan, Luo, Luo, Fei, and Wang independently use the same Golay distance hierarchy as an example in their symbol-block framework, again without coefficient distributions. Shi, Özbudak, and Solé prove a general stability theorem for cyclic \(b\)-symbol weight enumerators once \(b\) reaches the code dimension; that theorem explains the stabilization for \(b\ge6\) but does not determine the four nonstable spectra \(b=2,3,4,5\). Exact-distribution results for special irreducible cyclic-code families provide nearby methodology, but the inspected literature does not supply these Golay coefficients.

## Limitations
The novelty claim is restricted to the explicit coefficient distributions for \(b=2,3,4,5\), together with their exact finite verification. The stabilized range \(b\ge6\) is compatible with known general theory and is included only to complete the profile. Search cannot exclude an obscure or unindexed prior table, so residual bibliographic risk remains. No decoder-performance theorem is claimed.
