# Complete equality-case census for binary 3 by 3 one-crisscross-error codes
## Finding
For binary \(3\times3\) arrays, let the cover weight \(w_C(A)\) be the minimum number of rows and columns whose union contains every nonzero entry of \(A\), and let \(d_C(A,B)=w_C(A-B)\). Among arbitrary, not necessarily linear, codes \(C\subseteq\mathbb F_2^{3\times3}\) with \(d_C(A,B)\ge3\) for all distinct \(A,B\in C\), the maximum cardinality is \(8\). There are exactly \(487808\) labeled maximum codes.

Every maximum code has a sharp projection rigidity: for each of the three row positions, the eight row vectors appearing among its codewords are exactly the eight elements of \(\mathbb F_2^3\); the same statement holds for each of the three column positions. Exactly \(109952\) labeled maxima are affine \(3\)-flats in \(\mathbb F_2^9\), and the remaining \(377856\) maxima are nonlinear.

Under the natural cover-metric isometry group generated by arbitrary translations of \(\mathbb F_2^{3\times3}\), independent permutations of the three rows and three columns, and transposition, the \(487808\) maxima form exactly \(59\) orbits. Their labeled orbit-size distribution is \(128:1,768:2,1152:2,2304:8,3072:1,4608:21,6144:1,9216:9,18432:13,36864:1\). No assertion is made that this displayed generating set is a classification of all abstract isometries beyond the natural operations stated here.

## Assumptions and scope
Arrays are binary and have exactly three rows and three columns. A cover may mix rows and columns. Minimum distance means minimum cover distance. Codes need not be linear. “Labeled” means that row positions, column positions, and the zero/one symbols are fixed. “Affine” means a translate of a three-dimensional binary linear subspace of the nine-dimensional ambient vector space.

The distance threshold \(3\) is the first one that corrects an arbitrary single crisscross error, because a single crisscross error is supported inside one row or one column and unique correction requires minimum cover distance at least \(3\).

## Proof
Fix any row position. If two distinct codewords agreed on that entire row, their difference would be supported on the other two rows and therefore would have cover weight at most \(2\), contradicting minimum distance \(3\). Thus projection onto any fixed row is injective. Its target has only \(2^3=8\) binary triples, so every such code has at most \(8\) words. The same argument applies to every column. Consequently any size-eight code must project bijectively onto \(\mathbb F_2^3\) on every row and every column.

For the equality cases, translation invariance lets one translate a maximum code so that it contains the zero matrix. A second codeword can then occur exactly when its support has cover weight \(3\). By König’s theorem this is equivalent, for a \(3\times3\) binary support matrix, to the existence of a perfect matching in the associated bipartite support graph. There are exactly \(247\) nonzero matrices of cover weight \(3\). Form the compatibility graph on these \(247\) matrices, joining \(X\) and \(Y\) when \(w_C(X-Y)=3\). A normalized maximum is then exactly a seven-clique, with the zero matrix adjoined.

The verifier exhaustively enumerates all such seven-cliques in increasing vertex order and finds exactly \(7622\). It separately checks the projection-bijection condition for every resulting eight-word code. Translation-point incidence gives the total number of labeled maxima: if \(N\) denotes that total, then \(8N=512\cdot7622\), hence \(N=487808\).

A normalized affine maximum contains zero and is therefore linear. Direct closure under binary addition holds for exactly \(1718\) of the \(7622\) normalized maxima. The same pointed-translation incidence gives \(1718\cdot512/8=109952\) labeled affine maxima and hence \(377856\) nonlinear maxima. Finally, the verifier generates the stated natural isometries on normalized maxima, including re-normalization by translation through a codeword, and obtains the reported \(59\) labeled orbits and orbit-size distribution.

## Verification
Run `python3 artifacts/verify.py`. It uses only the Python standard library. It recomputes cover weights from matchings, constructs the full normalized compatibility graph, enumerates every normalized equality case without using a stored list, checks row and column projection rigidity, tests affine closure, and recomputes the natural-isometry orbit partition. ## Relationship to prior work
Blaum and Bruck’s public 1997 technical report and its later journal version study MDS array codes of minimum crisscross distance \(3\) for correcting one erroneous row or column, establishing the coding problem and explicit optimal constructions. Wachter-Zeh’s 2014 treatment formalizes the cover metric for arbitrary \((m\times n,M,d)^C_q\) codes, identifies cover weight with minimum vertex cover in the bipartite support graph, recalls the Singleton-like bound for linear codes, and studies list decoding and known optimal constructions. These sources motivate the exact \(3\times3\) binary equality problem but do not provide the complete nonlinear equality-case census, affine/nonlinear split, or the natural-isometry orbit decomposition reported here.

## Limitations
The result is finite and specific to binary \(3\times3\) arrays at minimum cover distance \(3\). The exhaustive computation is a finite proof only for this parameter set. The natural group used for the orbit census has order \(512\cdot6\cdot6\cdot2=36864\); no stronger claim about a separately classified full isometry group is needed. Literature searches cannot rule out every obscure or unindexed prior finite enumeration, so that remains the principal originality risk.
