# Complete higher-support profile of the distance-optimal binary cyclic \([15,6,6]\) code
## Finding

Zhang and Zhu's Example 2 gives the binary cyclic code
\[
C=C(4,1,1,1)
\]
of length \(15\), generated by
\[
g(x)=x^9+x^7+x^6+x^3+x^2+1,
\]
with parameters
\[
[15,6,6]_2.
\]

Its complete generalized Hamming-weight hierarchy is
\[
(d_1,d_2,d_3,d_4,d_5,d_6)
=
(6,9,11,13,14,15).
\]

More strongly, the complete support-size distribution is determined in every subcode dimension. The notation \(w:N\) means that exactly \(N\) subcodes of the indicated dimension have support size \(w\).

For \(r=1\),
\[
6:25,\qquad 8:30,\qquad 10:3,\qquad 12:5.
\]

For \(r=2\),
\[
9:40,\quad 10:150,\quad 11:195,\quad 12:105,\quad 13:90,\quad 14:60,\quad 15:11.
\]

For \(r=3\),
\[
11:30,\quad 12:335,\quad 13:390,\quad 14:420,\quad 15:220.
\]

For \(r=4\),
\[
13:105,\qquad14:255,\qquad15:291.
\]

For \(r=5\),
\[
14:15,\qquad15:48.
\]

For the unique six-dimensional subcode,
\[
15:1.
\]

Thus the generalized Hamming weights are attained by exactly
\[
25,\ 40,\ 30,\ 105,\ 15,\ 1
\]
subcodes in dimensions \(1,\ldots,6\), respectively.

## Assumptions and scope

The source fixes
\[
m=4,\qquad n=15
\]
and gives the generator polynomial
\[
g(x)=x^9+x^7+x^6+x^3+x^2+1.
\]
Since
\[
\deg g=9,
\]
the six rows
\[
g(x),\ xg(x),\ldots,x^5g(x)
\]
generate the code without wraparound in their degree-\(<15\) representatives.

The claim concerns this exact cyclic code presentation. It does not assert that every binary \([15,6,6]\) code has the same higher-support profile.

## Proof

Represent a binary polynomial of degree below \(15\) by its coefficient bit vector. The six shifted generator rows are linearly independent, so they form a generator matrix \(G\) of rank \(6\).

Enumerating the \(64\) messages gives the ordinary weight distribution
\[
1+25z^6+30z^8+3z^{10}+5z^{12}.
\]
In particular, the minimum nonzero weight is \(6\), independently reproducing the minimum-distance parameter printed in the source.

Because the message-to-code map
\[
\mathbb F_2^6\longrightarrow C
\]
is an isomorphism, \(r\)-dimensional code subcodes correspond bijectively to \(r\)-dimensional message subspaces. Every binary message subspace has a unique reduced-row-echelon basis.

The exact numbers of \(r\)-dimensional subspaces are
\[
63,\ 651,\ 1395,\ 651,\ 63,\ 1
\]
for \(r=1,\ldots,6\), so there are
\[
2824
\]
positive-dimensional subspaces in total.

For a basis
\[
u_1,\ldots,u_r
\]
of a message subspace, the support of the corresponding code subcode is exactly
\[
\operatorname{Supp}(u_1G)\cup\cdots\cup\operatorname{Supp}(u_rG).
\]
Indeed, a coordinate vanishes on the whole generated subcode if and only if it vanishes on every basis word.

Therefore an exhaustive reduced-row-echelon census of the \(2824\) message subspaces gives every code subcode exactly once. Counting the support union of each basis yields the distributions stated in the Finding. Taking their minima gives
\[
(6,9,11,13,14,15).
\]

This is an exhaustive finite proof for the stated code; no sampling or timeout inference is used.

## Verification

`artifacts/verify.py` uses only the Python standard library.

It reconstructs the six shifted rows directly from
\[
g(x)=x^9+x^7+x^6+x^3+x^2+1,
\]
checks rank \(6\), enumerates all \(64\) codewords, and verifies the ordinary weight distribution
\[
1+25z^6+30z^8+3z^{10}+5z^{12}.
\]

It then enumerates every positive-dimensional subspace of \(\mathbb F_2^6\) exactly once in reduced-row-echelon form. For every basis it computes the bitwise union of the corresponding codeword supports. The subspace totals are checked against the Gaussian binomial coefficients, and every complete histogram is compared with `artifacts/certificate.json`.

The certificate also contains one explicit reduced-row-echelon basis attaining the minimum support in each dimension.

Successful replay prints `VERIFY_OK`.

## Relationship to prior work

Zhang and Zhu construct several infinite families of distance-optimal binary cyclic codes and shortened descendants. Their Example 2 gives the exact generator above and the parameters \([15,6,6]_2\). Their paper does not discuss generalized Hamming weights or complete subcode-support distributions.

The parameter triple alone does not identify this code. Another published binary cyclic \([15,6,6]\) code arising from a subfield-code construction has ordinary weight enumerator
\[
1+30z^6+15z^8+18z^{10},
\]
which differs from the independently reconstructed enumerator of the present code. Thus that parameter-matching code cannot be equivalent to the code studied here.

Focused searches using the exact generator polynomial, the \([15,6,6]\) parameters, generalized-Hamming terminology, the hierarchy
\[
(6,9,11,13,14,15),
\]
and subcode-support terminology did not locate a prior complete higher-support profile for this exact code.

## Limitations

The result is an exact finite classification for the particular \(m=4\) source code. It does not give a general higher-support formula for the whole Zhang--Zhu family.

The census classifies subcodes by support size, not by automorphism-group orbit.

The source's distance-optimal \([15,6,6]\) parameters are prior work. Only the complete support distributions, generalized Hamming hierarchy, and exact minimizer multiplicities are claimed as new.

An older equivalent presentation or an unindexed code database could contain the same higher-support data; no such coverage was found in the searches performed.
