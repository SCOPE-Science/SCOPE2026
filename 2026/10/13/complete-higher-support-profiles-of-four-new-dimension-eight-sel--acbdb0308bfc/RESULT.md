# Complete higher-support profiles of four new dimension-eight self-orthogonal binary codes
## Finding
For the four binary self-orthogonal dimension-eight codes displayed in An–Kaplan–Kim–Luo–Wang with ordinary parameters \([91,8,42]_2\), \([98,8,46]_2\), \([114,8,54]_2\), and \([191,8,94]_2\), the complete generalized Hamming-weight hierarchies are

\[
(42,64,75,81,84,87,89,91),
\]
\[
(46,70,82,88,91,94,96,98),
\]
\[
(54,82,96,103,107,110,112,114),
\]
and
\[
(94,142,166,178,184,187,189,191).
\]

The exact numbers of \(r\)-dimensional subcodes attaining the minimum support \(d_r\), in order \(r=1,\ldots,8\), are respectively

\[
(54,982,872,334,5,12,1,1),
\]
\[
(74,2337,6468,1481,19,12,1,1),
\]
\[
(70,2016,4715,805,66,23,2,1),
\]
and
\[
(94,4340,24800,25420,4774,125,2,1).
\]

Thus the four source codes, which were introduced to close ordinary self-orthogonal minimum-distance entries in dimension eight, also have explicitly determined support growth at every subcode dimension and an exact census of all minimizers.

## Assumptions and scope
Each code \(C\) is exactly the binary code generated by the hexadecimal matrix printed in Section 5 of arXiv:2511.05440. The source appends zero columns only to make each printed row length a multiple of four; the verifier removes precisely those trailing padding bits. The claim is about these four displayed representatives. It does not assert that every self-orthogonal code with the same \([n,8,d]_2\) parameters has the same higher weights or the same extremal-subcode multiplicities.

For a linear code \(C\), \(d_r(C)\) is the minimum cardinality of the union of coordinate supports of an \(r\)-dimensional subcode of \(C\).

## Proof
Let \(G\) be one of the source generator matrices, of rank eight, and let \(g_j\in\mathbb F_2^8\) be its \(j\)-th column. Because \(G\) has full row rank, every \(r\)-dimensional subcode of \(C\) is uniquely \(UG\) for an \(r\)-dimensional message subspace \(U\leq\mathbb F_2^8\).

A coordinate \(j\) vanishes on all of \(UG\) exactly when \(u\cdot g_j=0\) for every \(u\in U\), equivalently when \(g_j\in U^\perp\). If \(m_G(v)\) denotes the multiplicity of the column vector \(v\) in \(G\), define

\[
M_G(W)=\sum_{v\in W}m_G(v).
\]

Then

\[
|\operatorname{{Supp}}(UG)|=n-M_G(U^\perp).
\]

Orthogonal complementation bijects \(r\)-subspaces with \((8-r)\)-subspaces. Hence

\[
d_r(C)=n-\max_{\substack{{W\leq\mathbb F_2^8\\ \dim W=8-r}}}M_G(W),
\]

and the number of minimizing \(r\)-subcodes equals the number of maximizing \((8-r)\)-subspaces in this formula.

The finite calculation is exhaustive. Every subspace of \(\mathbb F_2^8\) is generated once by its reduced-row-echelon basis. The numbers of subspaces in dimensions \(0,1,\ldots,8\) are checked as

\[
(1,255,10795,97155,200787,97155,10795,255,1).
\]

For each of the four codes the bundled verifier computes the answer in two ways: directly, by taking the union of supports of encoded RREF basis vectors, and through the column-intersection identity above. The two exhaustive routes agree on every reported minimum and multiplicity.

## Verification
The standalone script `artifacts/verify.py` parses the published hexadecimal generators, verifies that discarded padding bits are zero, checks binary rank eight and pairwise self-orthogonality, and reproduces the published ordinary minimum distances \(42\), \(46\), \(54\), and \(94\). It then enumerates all subspaces of \(\mathbb F_2^8\), checks the Gaussian-binomial subspace counts, computes the direct support minima, independently computes the maximizing column-section masses, and asserts all four hierarchies and all four minimizer-count vectors. Its completed replay returns `VERIFY_OK`.

## Relationship to prior work
An–Kaplan–Kim–Luo–Wang introduce these four dimension-eight self-orthogonal codes and use them to settle four exact ordinary minimum-distance entries; their Section 5 and Table 2 provide the generators and the \(d_1\) values, not the full higher-support profiles or the number of extremal subcodes in each dimension.

Meng and coauthors study weight hierarchies for two specific self-orthogonal defining-set code families, showing that generalized weights are a natural invariant in this subject, but those families are different from the four shortest-embedding representatives here. Kurz–Landjev–Rousseva determine optimal binary generalized-weight data only through dimension seven, so their exact tables do not cover these dimension-eight codes. San-José gives a general algorithm for computing generalized Hamming weights, but not the four code-specific values or minimizer multiplicities reported here.

## Limitations
The result is finite and representative-specific. It does not classify all optimal self-orthogonal dimension-eight codes, does not determine code equivalence or automorphism groups, and does not prove that these hierarchies are optimal among all binary \([n,8]\) codes. Exact literature and database searches found no statement of these four complete hierarchy-and-multiplicity profiles, but an unindexed computation or supplement could still contain equivalent data.
