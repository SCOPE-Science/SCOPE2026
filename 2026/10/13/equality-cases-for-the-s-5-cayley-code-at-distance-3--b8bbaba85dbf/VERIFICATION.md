# Verification

Run `python verify.py` with a standard Python 3 interpreter. No third-party package is required.

The verifier first builds the Cayley graph of \(S_5\) generated by all ten transpositions and computes shortest-path distances from the identity. It separately computes \(5-c(\pi^{-1}\sigma)\) and requires exact agreement, so the subsequent census does not rely on an untested distance formula.

For a normalized code containing the identity, exactly \(74\) nonidentity permutations are eligible. The verifier builds the \(74\)-vertex compatibility graph with \(1536\) edges and exhaustively enumerates all maximal cliques. It requires the complete histogram
\[
4:1250,\qquad 5:6480,\qquad 6:2520,\qquad 9:12.
\]
Thus the largest normalized code has \(10\) words and there are exactly \(12\) normalized maxima.

For every normalized maximum the verifier checks that the five even words form an order-\(5\) subgroup, that the odd half is both a left and right coset in its order-\(20\) normalizer, and that its quotient coset has order \(4\). It verifies six possible order-\(5\) subgroups and two normalized maxima per subgroup. Left translation and exact set deduplication then produce \(144\) labeled maxima. Every one is rechecked for minimum distance and the common pair-cycle profile \((4,1):25\), \((5):20\).

Finally the verifier checks that the maps generated by left multiplication, right multiplication, and inversion preserve every pairwise distance. It distinguishes exactly \(28{,}800\) maps of the forms \(x\mapsto axb\) and \(x\mapsto ax^{-1}b\), and breadth-first action on one maximum reaches all \(144\) maxima. Hence the stated orbit has size \(144\) and stabilizer order \(200\).

The verification is exhaustive only for the finite parameter \(S_5\), minimum distance \(3\). It does not establish any claim for larger symmetric groups or other distances, and it does not assert that the displayed isometry group is the full isometry group.
