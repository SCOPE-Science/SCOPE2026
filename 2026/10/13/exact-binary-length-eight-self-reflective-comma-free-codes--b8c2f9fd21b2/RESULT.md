# Exact binary length-eight self-reflective comma-free codes

## Finding
For binary length-eight comma-free codes invariant under word reversal, the maximum cardinality is **18**. Precisely **12 distinct labeled codes** attain this maximum. Bitwise complementation permutes the twelve codes without fixed points, giving six complement-exchanged pairs. Every optimal code contains exactly six palindromic words and six pairs of mutually reversed nonpalindromic words.

In the original terminology of self-reflective dictionaries, the exact extremal quantity is
\[
W_r(8,2)=18.
\]
The file `optimal_codes.txt` lists the twelve complete optimizers (one comma-separated, lexicographically ordered eighteen-word code per line, after a summary line).

## Assumptions and scope
Fix the labeled alphabet \(\Sigma=\{0,1\}\). For \(x\in\Sigma^8\), write \(r(x)\) for reversal and \(\bar x\) for bitwise complementation. A code \(C\subseteq\Sigma^8\) is **comma-free** if, for all \(x,y,z\in C\) and every \(s\in\{1,\ldots,7\}\), the length-eight substring beginning at zero-based offset \(s\) in the sixteen-character concatenation \(xy\) is different from \(z\). In particular, the definition permits \(x=y\) and/or \(z=x\). The code is **self-reflective** if \(r(C)=C\). We distinguish codes as subsets of the fixed labeled alphabet, not up to an unspecified equivalence relation. No Hamming-distance or deletion-correction condition is imposed.

## Proof
The proof is a finite exhaustive combinatorial certificate with a complete, independently reproduced search:

**1. Reversal-orbit reduction.** The involution \(r\) partitions all \(2^8=256\) words into \((256+16)/2=136\) orbits: sixteen singleton palindromic orbits and 120 doubletons. A reversal-invariant code is uniquely the union of whole orbits. We discard each orbit \(G\) whose own union fails the comma-free condition; no admissible code can contain it. Exactly 56 orbits survive, comprising twelve singleton and 44 two-element orbits. This classification is generated by testing every eight-bit string directly.

**2. Necessary compatibility graph and certified upper bound.** Make a graph \(H\) on the 56 surviving orbits. Distinct orbits \(G,H\) are adjacent precisely when \(G\cup H\) is comma-free. A valid self-reflective code selects a clique of this graph. The graph has 929 edges. Give each vertex its orbit size, either one or two. Exhaustively enumerate maximal cliques by the standard Bron--Kerbosch branching recursion, which processes possible vertices and excludes previously explored choices; its pivoted alternative is independently implemented. Both implementations enumerate precisely 2107 maximal cliques. Among them the maximum weight is 18 and exactly 16 maximal cliques have weight 18. Every clique is contained in a maximal clique, and all weights are positive, so every admissible code contains at most eighteen words.

**3. Necessary is not sufficient, and exact equality classification.** Pairwise compatibility alone does **not** ensure a code is comma-free: the splice of words from two distinct orbits could equal a word from a *third* orbit. Therefore, for every maximal clique, the programs independently reconstruct the full selected word set and test all ordered triples \((x,y,z)\) and all seven proper overlap positions. Among the sixteen weight-eighteen maximal cliques, exactly twelve pass this complete comma-free test; four fail. Conversely, an admissible code of size eighteen must be a weight-eighteen clique of \(H\), hence must itself be maximal, since any strict extension would contradict the proven eighteen-word weight cap. Thus the twelve surviving cliques are all and only the equality cases, and at least one gives the matching lower bound.

**4. Structure of the equality cases.** For each of the twelve passing code sets, direct reversal-orbit counting yields six palindrome singletons and six nonpalindromic reversal doubletons. Complementing every bit maps each selected code to a different one of the twelve, so the twelve partition into six complement pairs. These assertions are checked independently against the explicit list.

The two standalone source programs embody the entire argument. The Python version enumerates the graph with strings and an unpivoted Bron--Kerbosch recursion; the C++17 version uses bit-integer overlap masks and a pivoted recursion. The algorithms are exhaustive by the standard recursion invariant: each branch records one potential added vertex, intersects the remaining candidate and excluded sets with its neighborhood, and moves the explored vertex to the excluded set so a maximal clique is eventually reported exactly once.

## Relationship to prior work
Churchill (2009) introduced self-reflective comma-free dictionaries and the notation \(W_r(k,n)\), derived general bounds including for even word length, and gave constructions for word length four and for odd lengths. His Theorem 6 and Appendix A were compared to the present binary length-eight equality classification; those statements alone do not determine the twelve length-eight optimizers. The basic comma-free property goes back to Golomb, Gordon and Welch (1958). Wang and Tonchev (2009) report a general comma-free-code search algorithm and bounds but do not, in the publicly accessible abstract, specify the reversal-invariant equality classification at these parameters. Fimmel, Michel, Pirot, Sereni and Strüngmann (2023) classify numerous length-two and length-three codes; their *self-complementary* property acts on alphabet symbols and differs from reversal invariance of length-eight words. The present exact equality census is not claimed as a general optimality theorem for other word lengths or alphabets.

## Limitations
Only binary block length eight with **closure under reversal** is covered. A self-reflective code is not necessarily invariant under bit complement; complementation exchanges the twelve optimizers in pairs. The result does not classify unrestricted comma-free codes or stronger cross-bifix-free/non-overlapping codes. Reproducing the numerical certificate requires running the supplied exhaustive programs; their published outputs alone are not a substitute for the proof of exhaustive coverage. A historically earlier unpublished or unindexed enumeration, or an inaccessible full-text conference source, might independently contain these exact values; no absolute claim of priority is made.
