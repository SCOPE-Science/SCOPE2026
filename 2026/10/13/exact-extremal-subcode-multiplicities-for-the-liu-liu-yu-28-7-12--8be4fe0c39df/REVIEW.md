# Review

## Correctness

PASS. The primary construction is reconstructed over \(\mathbb F_8\) from the stated trace-norm function. Exact enumeration gives \(|S|=28\), rank \(7\), and reproduces the published weight enumerator \(1+63z^{12}+63z^{16}+z^{28}\). For an \(r\)-dimensional message subspace \(U\), a coordinate vanishes on all of \(U\) exactly when its generator column lies in \(U^\perp\), so support minimization is exactly a maximum-intersection problem for \((7-r)\)-subspaces. Every subspace of \(\mathbb F_2^7\) is enumerated once in reduced-row-echelon form, with dimension counts independently checked against Gaussian binomial coefficients. This proves the hierarchy and the minimizer counts without extrapolation.

PASS for the exact minimizer-count claim. The primary 2026 paper provides the code and ordinary weight distribution but not the displayed counts of generalized-weight minimizers. The 1994 work classifies the four binary \([28,7,12]\) self-complementary equivalence classes, and chain-condition literature is close enough that no novelty is claimed for the generalized-weight values alone. The inspected optimum-distance-profile source treats the four historical representatives but answers a different nested-chain question. Published-record and literature searches using exact parameters, the hierarchy, the multiplicity vector, and affine-section aliases found no covering statement of \((63,336,64,315,378,28,1)\). Some older full text was unavailable, leaving a residual risk of an unindexed equivalent count.

## Value

PASS. The source identifies the \([28,7,12]\) code and its dual as best-known examples. The vector of numbers of subcodes attaining each generalized Hamming weight is a natural incidence invariant strictly finer than the ordinary weight enumerator and the weight hierarchy alone. The affine-section form gives a reusable geometric description of the same extremal data, with the nontrivial three-dimensional maximum attained exactly \(64\) times.
