# Reproducibility

Run `python3 verify.py` using Python 3's standard library. It constructs the finite-field arithmetic (including \(\mathbb F_4\)), multiplies basis elements in the radical-square-zero path algebra, and directly tests whether the unital algebra generated by each ordered input tuple spans the complete algebra. This algorithm is intentionally independent of the symbolic commutator criterion.

The exhaustive cases include single and parallel arrows, a two-cycle, disconnected vertices, fields of sizes \(2,3,4\), and different tuple lengths. All eleven observed counts agree with the stated formula. The script exits after printing `VERIFY_OK` when successful. The general statement is proved symbolically in `RESULT.md`, not inferred from finite experiments.

The literature comparisons and the symbolic proof have received a self-review; no independent audit has been performed. Non-loopless quivers and higher radical nilpotence index are outside the theorem.
