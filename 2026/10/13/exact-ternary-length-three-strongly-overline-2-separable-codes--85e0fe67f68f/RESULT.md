# Exact ternary length-three strongly \(\overline{2}\)-separable codes
## Finding
Let \(Q=\{0,1,2\}\), and for a nonempty set \(A\subseteq Q^3\) define its descendant as
\[
\operatorname{desc}(A)=A(1)\times A(2)\times A(3),
\]
where \(A(j)\) is the set of symbols occurring in coordinate \(j\). A code \(C\subseteq Q^3\) is strongly \(\overline{2}\)-separable when, for every nonempty \(C_0\subseteq C\) with \(|C_0|\le 2\), the intersection of all coalitions \(A\subseteq C\) satisfying \(\operatorname{desc}(A)=\operatorname{desc}(C_0)\) is exactly \(C_0\).

The exact maximum is
\[
|C|=10.
\]
There are exactly \(54\) labeled maximum codes, and exactly \(20\) of them contain \(000\). Under the standard Hamming-isometry group \((S_3)^3\rtimes S_3\), generated by independent symbol permutations in the three coordinates together with coordinate permutations, all \(54\) maxima lie in one orbit. Since this group has order \(1296\), every maximum has stabilizer order \(24\).

A canonical representative is
\[
\{000,001,012,022,102,110,121,202,211,220\}.
\]
Every maximum has symbol multiplicities \((4,3,3)\) in each coordinate. Among its \(\binom{10}{2}=45\) unordered pairs, exactly \(3\) have Hamming distance \(1\), \(30\) have distance \(2\), and \(12\) have distance \(3\). For a pair \(\{x,y\}\), let \(B(x,y)=\operatorname{desc}(\{x,y\})\cap C\). Exactly \(33\) pairs satisfy \(|B(x,y)|=2\), while \(12\) satisfy \(|B(x,y)|=3\).

## Assumptions and scope
The code is an unordered set of distinct ternary words of length three. “Labeled” means that the coordinate positions and the symbols \(0,1,2\) are fixed rather than quotiented by isometry. The group \((S_3)^3\rtimes S_3\) is the full standard Hamming-isometry group on \(Q^3\).

The finding is specific to alphabet size \(3\), length \(3\), and the strongly \(\overline{2}\)-separable condition. It does not assert an exact formula for other alphabet sizes or for strongly \(\overline{t}\)-separable codes with \(t>2\).

## Proof
A failure of strong \(\overline{2}\)-separability must occur for a two-word coalition \(C_0=\{a,b\}\): a one-word descendant contains only that word, so a same-descendant coalition cannot omit it. For a pair \(\{a,b\}\), failure occurs exactly when there is a coalition \(X\) contained in the descendant box \(\operatorname{desc}(\{a,b\})\), omitting at least one of \(a,b\), with
\[
\operatorname{desc}(X)=\operatorname{desc}(\{a,b\}).
\]
Thus the property is equivalent to avoiding every finite forbidden set \(\{a,b\}\cup X\) arising in this way.

The verifier derives these obstructions directly from the definition over all \(27\) ternary words and then inclusion-minimizes them. Exactly \(891\) minimal forbidden sets remain, all of cardinality \(4\). This is an equivalence, not a heuristic filter: every strong-separability failure supplies one of the generated sets, and any code containing one of them has a witnessed failure.

Independent symbol permutations in the three coordinates preserve descendants and act transitively on \(Q^3\). Hence any nonempty code can be moved so that it contains \(000\). The verifier therefore performs a complete include-or-exclude search through the remaining \(26\) words, rejecting precisely those partial sets that already contain a minimal forbidden set. The only pruning rule is the elementary cardinality bound that a branch with fewer remaining words than the current best cannot improve the best. The exhaustive search proves that no normalized code has size \(11\) and finds exactly \(20\) normalized codes of size \(10\).

Expanding those \(20\) codes by all independent coordinatewise symbol permutations gives exactly \(54\) labeled maxima. Coverage is independently checked by the incidence identity
\[
20\cdot 27=54\cdot 10,
\]
because the word-transitive action makes every labeled maximum normalizable at each of its ten codewords. The verifier then applies all \(1296\) Hamming isometries and obtains a single orbit of size \(54\), giving stabilizer order \(24\).

Finally, every one of the \(54\) maxima is replayed against the original definition: for each singleton or pair \(C_0\), all nonempty coalitions of the code are enumerated, all coalitions with the same descendant are intersected, and the result is checked to equal \(C_0\). This is independent of the forbidden-set test used during the extremal search.

## Relationship to prior work
Jiang, Cheng, and Miao introduced strongly separable codes and studied the \(q\)-ary strongly \(\overline{2}\)-separable case of length three. Their full preprint gives a construction of size
\[
q^2+s q-2s^2
\]
under explicit parity conditions and then a uniform lower-bound family of size \(\frac{1}{8}(9q^2-w^2)\). At \(q=3\), their stated construction yields \(9\) codewords. Their conclusion describes length three as an infinite-series construction problem rather than giving a finite exact optimum or equality classification.

Zhang, Jiang, and Cheng later derive general upper bounds for strongly separable codes. Their inherited strongly \(\overline{2}\)-separable upper bound specializes at length three and \(q=3\) to \(12\), so it does not imply the exact value \(10\). Their main structural results concern strongly \(\overline{3}\)-separable codes of length three, a different coalition parameter.

The exact value \(10\), the count \(54\), and the single-orbit classification were not found in the checked exact-parameter, alias, numerical-invariant, or structural searches.

## Limitations
This is a finite exact classification at the first ternary alphabet size. The proof relies on exhaustive finite search, but the search space, obstruction derivation, normalization, independent definition replay, and symmetry calculation are all reproduced by the supplied verifier. No claim is made about a closed form for larger alphabets. A residual priority risk remains for an obscure or unindexed small-parameter enumeration not found in the inspected literature and semantic searches.
