# Finite cyclic rotations obstruct isotypic block recovery without the group data
## Finding

For the output convention of Burnik's universal isotypic block-diagonalization problem, where the finite output includes the number and dimensions of the nonzero real isotypic components, the Cayley-table information cannot in general be omitted. More precisely, let \(\mathcal D\subseteq \mathrm O(3)\) be the represented subspace of finite-order orthogonal matrices, and interpret \(A\in\mathcal D\) as the single-generator representation of the finite cyclic group \(\langle A\rangle\) on \(\mathbb R^3\). There is no Type-2 computable procedure which, from a Cauchy name of \(A\) alone, outputs the isotypic block-dimension code required by the universal isotypic block-diagonalizer. Indeed, for every integer \(n\ge 3\), put \(A_n=\operatorname{diag}(1,R_{2\pi/n})\), where \(R_\theta\) is planar rotation through angle \(\theta\). Then \(A_n\to I_3\), every \(A_n\) has finite order, the real representation generated by \(A_n\) has two nonzero isotypic components of dimensions \(1\) and \(2\), while the representation generated by \(I_3\) has one isotypic component of dimension \(3\). Since a Type-2 computable map into a discrete finite-code space is continuous, this jump is impossible. Consequently the full isotypic-UBD output of Theorem 5.3 is not computable from the generator matrices alone, even for one orthogonal generator in dimension \(3\).

This gives a negative answer to the “only the matrices \(\rho(s)\) without the group” branch of Question 8.3 in Burnik's paper, for the same isotypic-output convention used in Theorem 5.3.

## Assumptions and scope

The input class is
\[
\mathcal D=\{A\in \mathrm O(3): A\text{ has finite order}\},
\]
equipped with the subspace representation inherited from Cauchy names for real matrices. For each input \(A\), the relevant finite group is its cyclic image \(\langle A\rangle\), acting on \(\mathbb R^3\) by powers of \(A\).

The requested output is the isotypic universal block-diagonalization output used by Burnik: in particular, it includes a finite discrete code for the number of nonzero real isotypic components and their dimensions. No claim is made about the vacuous problem of outputting an arbitrary one-block universal diagonalizer while forgetting the isotypic block code.

## Proof

For every integer \(n\ge3\), let
\[
A_n=\operatorname{diag}(1,R_{2\pi/n}),
\qquad
R_\theta=\begin{pmatrix}\cos\theta&-\sin\theta\\\sin\theta&\cos\theta\end{pmatrix}.
\]
Then \(A_n\in\mathcal D\), its order is exactly \(n\), and \(A_n\to I_3\) in the ordinary matrix norm, hence also in the represented-space topology induced by Cauchy names.

For \(n\ge3\), the first coordinate is the one-dimensional trivial real representation. The rotation plane is a two-dimensional irreducible real representation: a proper nonzero real invariant subspace would be a real invariant line, hence would supply a real eigenvector for \(R_{2\pi/n}\), but a nontrivial rotation by an angle different from \(\pi\) has no real eigenvector. The two summands are inequivalent. Thus the nonzero real isotypic components for \(A_n\) have dimensions \(1\) and \(2\).

At the limit input \(I_3\), the generated finite group is trivial and the whole space is three copies of the trivial irreducible representation. Hence there is exactly one nonzero isotypic component, of dimension \(3\).

Therefore the discrete number-of-blocks coordinate of any correct output equals \(2\) at every \(A_n\) and equals \(1\) at \(I_3\). A Type-2 computable map to a discrete represented space is continuous, so its discrete output must be locally constant at every point of its domain. The convergent sequence \(A_n\to I_3\) contradicts that requirement. Hence the isotypic block-dimension code, and therefore Burnik's full isotypic-UBD output, is not Type-2 computable from the generator matrix alone on this promised finite-order class.

## Verification

The proof is symbolic and has no finite-search or numerical-completeness step. The load-bearing checks are: every \(A_n\) lies in the promised domain because \(A_n^n=I_3\); \(A_n\to I_3\) because \(2\pi/n\to0\); for \(n\ge3\), \(R_{2\pi/n}\) has no real invariant line; the isotypic block count is therefore \(2\) along the sequence and \(1\) at the limit; and Type-2 computability implies continuity while the finite block code is discrete.

Burnik's Theorem 5.3 explicitly makes the block data part of the output, and Question 8.3 explicitly asks whether the result remains computable when only the matrices \(\rho(s)\) are supplied without the group data.

## Relationship to prior work

Burnik proves uniform Type-2 computability when a Cayley table for the finite group, a generating set, and Cauchy names of the representing matrices are supplied. The proof recovers discrete isotypic ranks from character and projector formulas. The paper then asks whether the group information can be removed.

The same paper recalls an older noncomputability result for diagonalizing the algebra generated by an arbitrary symmetric matrix. That result does not imply the statement here: the present obstruction persists on the much narrower promise class of finite-order orthogonal matrices and targets the real isotypic block code of a finite cyclic representation.

Targeted searches for finite-order orthogonal representations, cyclic rotations approaching the identity, isotypic decomposition from generator matrices alone, and universal block diagonalization without a Cayley table did not locate this three-dimensional discontinuity argument.

## Limitations

The result proves noncomputability of the full isotypic-output problem because its discrete block code jumps. It does not claim that an orthogonal matrix \(U\) alone is noncomputable if no isotypic block boundaries are required; on the displayed family the identity basis itself can be used continuously.

No exact Weihrauch degree is determined. The result also does not show that the entire Cayley table is minimal advice; it only proves that the generator matrix alone is insufficient.
