# Local three-weight depth census for the quaternary \([21,4,11]\) example
## Finding
For the quaternary \([21,4,11]\) code \(C_2\) displayed in Example 2.1 of Kawamoto, Kato, and Maruta, let \(m_C(H)\) denote the number of generator-matrix columns lying in a projective plane \(H\subset \mathrm{PG}(3,4)\), counted with multiplicity. Define
\[
E=\{H:m_C(H)\equiv0\pmod 4\},\qquad e(P)=|\{H\in E:P\in H\}|.
\]
Then the 85 projective points have the exact local-depth distribution
\[
(N_0,N_1,N_2,N_3,N_4,N_5,N_6,N_7)=(2,1,16,9,25,23,2,7),
\]
where \(N_j=|\{P:e(P)=j\}|\). In particular, the point \(P=(0,0,1,3)\) exhibited in the source is the unique 1-locally 3-weight center modulo 4, and exactly 16 projective points are 2-locally 3-weight centers modulo 4.

## Assumptions and scope
The field is \(\mathbb F_4=\{0,1,\alpha,\alpha^2\}\) with \(\alpha^2=\alpha+1\), encoded by \(0,1,2,3\) exactly as in the source. The code is the specific code generated by the four 21-symbol rows printed in Example 2.1; no equivalence-class uniqueness for all quaternary \([21,4,11]\) codes is claimed.

For \(n=21\), \(q=4\), and \(w=3\), Definition 2.1 of the source has only one exceptional residue: \(n+3\equiv0\pmod4\). Thus a point is 1-locally 3-weight precisely when exactly one incident plane lies in \(E\), and it is 2-locally 3-weight precisely when exactly two incident planes lie in \(E\).

## Proof
Normalize every nonzero vector of \(\mathbb F_4^4\) by scaling its first nonzero coordinate to 1. This gives all \(85=(4^4-1)/(4-1)\) points of \(\mathrm{PG}(3,4)\). Apply the same normalization to nonzero linear forms, which gives all 85 projective planes.

Normalize the 21 nonzero columns of the displayed generator matrix and retain their projective multiplicities. For every normalized linear form \(h\), sum those column multiplicities over the points \(x\) satisfying \(h\cdot x=0\). The resulting plane-multiplicity spectrum is
\[
1^2,2^4,3^{12},4^{12},5^{22},6^{16},7^6,8^4,9^3,10^4,
\]
which reproduces the spectrum printed in the source. Hence exactly 16 planes are exceptional modulo 4: twelve 4-planes and four 8-planes.

For each of the 85 points, exhaustively count incident exceptional planes. This yields
\[
0^2,1^1,2^{16},3^9,4^{25},5^{23},6^2,7^7.
\]
The unique depth-one point is exactly \(P=(0,0,1,3)\), and its column multiplicity is zero, agreeing with the source's description of it as a 0-point. The source's plane \(H=[1,1,0,0]\) has multiplicity 8, is exceptional, and contains \(P\). The exhaustive count also gives 16 depth-two points. Because local 3-weight status for \(s=1,2\) is equivalent here to depths one and two, the stated local-center classification follows.

As an incidence checksum, the total depth is \(336\), equal to \(16(4^2+4+1)\), since every projective plane in \(\mathrm{PG}(3,4)\) contains 21 points.

## Verification
The accompanying `verify.py` is a standalone Python program using only the standard library. It reconstructs \(\mathbb F_4\), all 85 projective points and planes, the printed generator matrix, the plane spectrum, the 16 exceptional planes, and the complete depth histogram. It asserts the unique depth-one point, the 16 depth-two points, the source's 8-plane through the exhibited point, and the incidence checksum before printing `VERIFY_OK`.

## Relationship to prior work
Kawamoto, Kato, and Maruta introduce the \(s\)-locally \(w\)-weight notion, give necessary conditions for the cases \(w=3\) and \(s=1,2\), and in Example 2.1 exhibit this \([21,4,11]_4\) code together with the particular 0-point \(P=(0,0,1,3)\) and an 8-plane through it, proving that the code is 1-locally 3-weight at that point. Their example also prints the global plane-multiplicity spectrum. The inspected article does not give a census over all 85 projective points, does not state uniqueness of the exhibited 1-local center, and does not count the 2-local centers.

The global spectrum alone does not determine how the 16 exceptional planes intersect pointwise, so it does not imply the depth histogram. CodeTables records parameter bounds and constructions for quaternary linear codes, not this pointwise local-depth invariant.

## Limitations
This is an exact finite classification for the specific displayed generator matrix. It does not classify all quaternary \([21,4,11]\) codes, nor does it claim that the depth histogram is invariant across inequivalent codes with the same weight or plane-multiplicity spectrum. The originality search cannot exclude an unindexed older computation of the same projective multiset, although no such source was located.
