# Verification and reproducibility

The universal assertion is proved by localized invertible block elimination. For any pivot \(s=x_{ab}\ne0\), the invertible \(2\times2\) block has determinant \(-s^2\), and the third-minor ideal is generated by the entries of its Schur complement. The hollow diagonal contributes precisely \(-2u_iv_i/s\), while off-pivot entries can be eliminated. Because \(2\) is a unit in \(\mathbb C\), the resulting chart ideal is \((u_iv_i)\) in disjoint variable pairs. This equality yields reducedness, a regular sequence, complete local-product normal forms and the projective saturated decomposition. It is a proof for all \(n\ge3\), not a finite extrapolation.

`CHECK.py` was run with Python 3.13.5 and SymPy 1.14.0; `CHECK_OUTPUT.txt` records the exact output. The script checks all \(3\times3\) minors of the substituted hollow matrix for \(n=3,4,5,6\) against the monomial node ideal, recovers pivot minor relations, and verifies the closed degree and component formulas through \(n=11\). No random floating-point data are used.

The tests do not prove the assertions for unbounded \(n\); the symbolic proof supplies that step. The result is projective and is not a claim about possible embedded structure at the irrelevant vertex of the affine cone. The calculations and this review are not an independent audit.
