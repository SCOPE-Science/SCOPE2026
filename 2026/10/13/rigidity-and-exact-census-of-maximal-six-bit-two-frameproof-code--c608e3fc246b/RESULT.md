# Rigidity and exact census of maximal six-bit two-frameproof codes

## Finding
Let \(C\subseteq\{0,1\}^6\) be a binary code. The code is **two-frameproof** when, for each pair of distinct codewords \(a,b\in C\), the coordinatewise descendant set \(\operatorname{desc}(\{a,b\})=\{z:z_i\in\{a_i,b_i\}\text{ for all }i\}\) meets \(C\) only in \(\{a,b\}\). Then \(|C|\leq 8\). Exactly \(240\) unordered codes attain equality on the six labeled positions. Every optimum is an affine translate of a three-dimensional binary linear code equivalent under coordinate permutations to a one-coordinate puncturing of the simplex \([7,3,4]\) code. All \(240\) belong to one orbit under coordinate permutations and coordinatewise bit complementation.

## Assumptions and scope
Alphabet \(\{0,1\}\), exactly six **labeled** coordinates, distinct words, unordered code sets; no restriction to linear codes. The descendant condition concerns coalitions of size at most two. It is equivalent, for every three pairwise distinct \(a,b,c\in C\), to the simultaneous inequalities
\[
\bigvee_{i=0}^{5}(a_i\oplus c_i)(b_i\oplus c_i)=1,
\qquad\text{and the two cyclic variants.}
\]
Here \(\oplus\) is binary addition and the disjunction asserts that some coordinate distinguishes the designated putative victim. A one-member coalition cannot frame a distinct codeword.

## Proof
Bitwise translation \(C\mapsto C\oplus t\) preserves the condition. Any nonempty code can therefore be translated so that \(0\in C\). For a triple \(a,b,c\), the test for whether \(c\) is outside the descendants of \(a,b\) is exactly \((a\oplus c)\mathbin{\&}(b\oplus c)\ne0\), interpreting six bits as an integer mask. This gives a finite, purely combinatorial decision procedure.

Enumerate every increasing list \(0=c_0<c_1<\cdots<c_{s-1}\le63\). Start from the singleton containing zero. At each extension, admit a new integer word only if all three outsider inequalities hold for every pair already selected. The extension test is necessary and sufficient, so induction on the number of selected words shows that the procedure enumerates **all** permissible normalized codes, without omissions or duplicates. One implementation tests these three conditions directly when adding each word; another precomputes forbidden completions of every pair and propagates a bit mask. Both enumerate exactly \(30\) normalized size-eight codes and no normalized size-nine code. Heredity of the frameproof property rules out every larger size; translation rules out all unnormalized size-nine codes.

Every one of the \(30\) enumerated normalized optimal codes is closed under bitwise addition, as checked by all \(64\) ordered sums within each code. Thus each is a three-dimensional vector subspace. Its weight enumerator is \(1+4z^3+3z^4\); equivalently, the six columns of any rank-three generator matrix are six distinct nonzero vectors of \(\mathbb F_2^3\), proving that it is a punctured simplex code. For a concrete example, the code with decimal bit-mask words `0,7,25,30,42,45,51,52` is generated by `7,25,42`, whose six columns in this order have decimal values `3,5,1,6,2,4` as nonzero three-bit columns. The omitted seventh column is `7`.

There are \(30\) normalized optimal subspaces, each with \(2^6/2^3=8\) distinct affine cosets, giving precisely \(30\cdot8=240\) labeled code sets. Exhaustive action by the \(6!\) position permutations on the displayed example, followed by all \(2^6\) translations, produces exactly these same \(240\) sets, so there is a single equivalence class.

## Verification
Run `python3 verify.py`; it independently enumerates all ordered-by-mask extensions with direct triple tests, verifies the absence of nine-word codes, tests addition closure of all \(30\) normalized maximizers, counts the \(240\) translates, and verifies one orbit by all permutations and translations. Run `g++ -std=c++17 -O2 verify.cpp -o verify` and `./verify`; its distinct bit-mask forbidden-triple enumeration reproduces the optimum and normalized count. Both source files are complete and rely only on standard libraries. These finite enumerations are exhaustive because all \(64\) possible binary words are traversed under the stated admissibility test; no extrapolation beyond length six is asserted.

## Relationship to prior work
Chee and Zhang (arXiv:1206.5863v1, 2012) develop constructions and asymptotic bounds for frameproof codes, without this six-bit equality census. Shangguan, Wang, Ge and Miao (arXiv:1411.5782v1, 2014) develop general bounds and a different small-length theorem for coalition parameter at least three, rather than this \(2\)-frameproof six-coordinate census. Zhou and Zhou (arXiv:2002.11266v1, 2020) study wide-sense frameproof codes, which coincide with ordinary frameproof codes on a binary alphabet, and give general upper bounds; their main explicit even-length bound is stated for lengths at least eight. No equivalent count or affine-rigidity classification was located in the inspected source sections. Existing simplex-code constructions are not themselves claimed to be new.

## Limitations
The exact enumeration is for length six only. It does not establish unknown larger-length capacities or global priority. Other inaccessible or unindexed sources may contain the same small equality census. The mathematical claim is supported by an exhaustive finite proof algorithm and executable implementations, not an independently certified formal proof.
