For the explicit length-\(128\) generalized-Hermitian AG code \(C(D,67P_\infty)\), the \(128\)-map partial \(2\)-PD family of the source contains an optimal \(32\)-map subfamily for the source information set.  A vertical-fiber obstruction proves that no subfamily of the same source automorphism family can use fewer than \(32\) maps, while an explicit \(32\)-map witness covers all \(8128\) coordinate pairs.
