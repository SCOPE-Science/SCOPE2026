# Sharp one-agent alphabet bound and two-agent divergence for repeated truthful announcements
## Finding

For each integer \(a\ge1\) and each integer \(k\ge0\), consider the class of all finite nonempty S5 epistemic models with \(a\) knowledge agents and all fixed announcement-free epistemic formulas containing at most \(k\) distinct propositional letters. Repeat ordinary **truthful public announcements of the same formula**: at every stage keep exactly those worlds satisfying it in the present induced submodel. The empty outcome is treated as a terminal fixed state. If \(h\) is the first stage with no further deletion, define \(B(a,k)\) as the supremum of \(h\) over these models and formulas.

The exact bound is
\[
B(a,k)=\begin{cases}
1& k=0,\\
2^k& k\ge1\text{ and }a=1,\\
\infty& k\ge1\text{ and }a\ge2.
\end{cases}
\]
The finite bounds are attained. In the two-agent branch, a **single fixed formula of modal depth one using one proposition** witnesses arbitrarily many strict rounds. Furthermore, the bound \(2^k\) for one agent holds even for infinite models.

## Assumptions and scope

An S5 epistemic model consists of a nonempty set \(W\), an equivalence relation \(R_i\) on \(W\) for each agent, and a valuation \(V\) of propositional letters. The static language is generated by the Boolean constants \(\top,\bot\), a finite set of letters, negation, conjunction, and the standard knowledge diamonds \(\Diamond_i\). Disjunction is an abbreviation. In particular, the announced formula has no nested dynamic announcement operators and no common-knowledge operator. The same syntactic formula is announced at every stage.

For fixed \(\varphi\), put \(W_0=W\) and
\[
W_{t+1}=\{w\in W_t:(M\upharpoonright W_t,w)\models\varphi\},
\]
where the restriction is the induced submodel of the original equivalence relations and valuation. Once \(W_t=\varnothing\), define all later \(W_s\) to be empty, without assigning truth values to an empty pointed model. Define \(h=\min\{t\ge0:W_t=W_{t+1}\}\). For finite \(W\), this exists; the proof establishes existence on arbitrary one-agent \(W\) as well. For \(h=0\), the first announcement makes no change. The bounds count strict updates, including a final update to the empty set.

## Proof

**No letters.** In a nonempty S5 model, every formula built without propositional letters is constant across all worlds: this is proved by structural induction. The Boolean cases are immediate. If a subformula is constant, a knowledge diamond also has the same constant truth value at every world, since each equivalence class is nonempty. Consequently the first announcement removes either all worlds or none, and \(h\le1\). Announcing \(\bot\) achieves \(h=1\). This works with any positive number of agents.

**One agent: upper bound.** Fix one agent and \(k\) propositional letters. Each initial equivalence class \(C\) evolves independently, remaining an equivalence class whenever it is nonempty. Associate to each world its fixed Boolean \(k\)-type in \(\{0,1\}^k\), and let \(T_t(C)\subseteq\{0,1\}^k\) be the set of types present in \(C\cap W_t\). For every static modal formula \(\psi\), its truth at a world in the current class depends only on the world's Boolean type and on \(T_t(C)\). Indeed, this follows by induction: for \(\Diamond\psi\), the question is whether at least one type in \(T_t(C)\) makes \(\psi\) true. Thus all present worlds with the same type agree on \(\varphi\) and are retained or removed together. A strict deletion in a class removes at least one type, and never introduces types. Therefore a class changes strictly at most \(2^k\) times, and once it has no deletions, its current type set stays fixed forever. Since **every** class is fixed after \(2^k\) rounds, independently of its size and of the number of classes, so is the entire model. This reasoning does not require \(W\) to be finite.

**One agent: sharpness.** Suppose \(k\ge1\), put \(N=2^k\), and choose one S5 equivalence class containing one world of each Boolean type \(s\in\{0,\ldots,N-1\}\). Let \(\theta_s\) be the propositional conjunction defining precisely type \(s\). Announce
\[
\varphi_k=\bigvee_{0\le s<t<N}(\theta_s\wedge\Diamond\theta_t).
\]
A remaining world of type \(s\) satisfies \(\varphi_k\) exactly when some strictly larger type remains. Hence each update deletes exactly the largest remaining type. There are precisely \(N\) strict rounds, with empty result after the last; thus \(h=N\).

**At least two agents: unboundedness.** Fix two distinguished agents \(a,b\), one letter \(p\), and the depth-one formula
\[
\chi=(p\wedge\Diamond_a\neg p)\vee(\neg p\wedge\Diamond_b p).
\]
For each \(n\ge1\), let \(W=\{0,\ldots,n-1\}\), make \(p\) true at exactly the even integers, and let the \(a\)-equivalence classes be \(\{0,1\},\{2,3\},\ldots\), with a terminal singleton when necessary. Let the \(b\)-classes be \(\{0\},\{1,2\},\{3,4\},\ldots\), again with a terminal singleton when necessary. All additional agents, if any, have identity relations. Restrict to any initial segment \(\{0,\ldots,m-1\}\). For even \(i\), the first disjunct of \(\chi\) holds exactly when its \(a\)-partner \(i+1\) remains; for odd \(i\), the second holds exactly when its \(b\)-partner \(i+1\) remains. Thus precisely worlds \(i<m-1\) satisfy \(\chi\). Induction on the round number gives
\[
W_t=\{0,\ldots,n-t-1\}\quad(0\le t\le n),
\]
where the last set is empty. Therefore \(h=n\) for arbitrarily large \(n\), while both the single letter and the formula remain unchanged. This completes the exact classification.

## Verification

The standalone `verify.py` implements recursive Boolean/modal truth on induced S5 submodels and the repeated announcement operation. Invoking `python verify.py` reported `VERIFY_OK` after checking all exact sharp one-agent constructions for \(0\le k\le5\), all two-agent path lengths \(1\le n\le160\), and 2,850 seeded random one-agent instances across \(1\le k\le3\). A total of 3,016 instances passed. These checks are finite cross-checks and are not used to infer the unbounded or infinite-model results; those follow from the above proofs.

## Relationship to prior work

Yamada's *Eventual and Strong Eventual Notions in Public Announcements* (2026) investigates repeated **believed** public announcements, which keep the world set fixed and remove accessibility arrows; its Definitions 5 and 8 and Lemmas 6–7 are particularly relevant. Lemma 6 uses disappearance of proposition-valuation types to prove finite stabilization in a single-agent K45 believed-announcement setting. Moreover, its Lemma 7 defines the same alternating one-letter diamond formula as \(\chi\) above (there called \(D\)) and uses it for rank peeling under believed announcements. These are genuine prior mathematical ingredients, not newly invented formulas or methods. The statement here is instead the exact sharp **ordinary, world-deleting PAL** threshold as a joint function of the number of agents and letters, including the fixed one-letter two-agent witness. Neither the source's eventual-truth classification nor its arrow-deletion statement implies the whole displayed spectrum without a separate world-deletion argument and matching constructions.

Miller and Moss (2005) study iterated modal relativization and satisfiability complexity; their muddy-children illustration yields arbitrarily many rounds while simultaneously increasing the numbers of children and associated propositional letters. It therefore does not supply a uniform two-agent, one-letter witness or the one-agent sharp alphabet threshold. Sadzik (2006) studies long-term behavior under richer product updates with epistemic events, including public announcements as a special case; the examined theorems concern event-frame dynamics, finite evolution, and eventual truth rather than this numerical agent–alphabet classification.

## Limitations

The finite-model supremum is defined with the empty induced result absorbing; a convention forbidding empty outcomes would change the extremal formulation. The theorem concerns fixed announcement-free formulas with no common-knowledge operators; allowing richer connectives may change the bound. The sharp one-agent formula grows with the alphabet size. No bound independent of carrier size is claimed for two or more agents. The type-elimination upper-bound mechanism appears in related earlier work on **believed** announcements; an older equivalent statement of the exact ordinary-public-announcement spectrum under another vocabulary is a residual literature risk. Computational tests do not certify novelty or prove the general theorem independently.
