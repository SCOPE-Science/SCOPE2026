# The DAPW mixed-record likelihood uses the wrong denominator for discrete lower records
## Finding
Consider the mixed-record scheme for the discrete Alpha-power Weibull (DAPW) stress-strength model. Let
\[
L_1>L_2>\cdots>L_m
\]
be ordinary strict lower record values from an integer-valued strength variable with PMF
\[
p(k)=\Pr(X=k)
\]
and CDF
\[
F(k)=\Pr(X\le k).
\]

The source's Eq. (14) uses
\[
L_{\mathrm{pub}}
=
p(L_1)
\prod_{i=2}^{m}
\frac{p(L_i)}{F(L_{i-1})}.
\]

For a discrete strict lower record, the next record must be strictly below the current one. Conditional on
\[
L_{i-1}=\ell,
\]
the next lower record is the first future observation falling in
\[
\{0,1,\ldots,\ell-1\}.
\]
Therefore
\[
\boxed{
\Pr(L_i=j\mid L_{i-1}=\ell)
=
\frac{p(j)}{F(\ell-1)},
\qquad
j<\ell.
}
\]
The correct record-value likelihood is consequently
\[
\boxed{
L_{\mathrm{strict}}
=
p(L_1)
\prod_{i=2}^{m}
\frac{p(L_i)}{F(L_{i-1}-1)}.
}
\]

The difference is not a notation convention. The source denominator
\[
F(L_{i-1})
\]
includes the mass at the current record value, even though a tie does not create an ordinary strict lower record. Its likelihood differs from the strict-record likelihood by
\[
\boxed{
\frac{L_{\mathrm{pub}}}{L_{\mathrm{strict}}}
=
\prod_{i=2}^{m}
\frac{F(L_{i-1}-1)}{F(L_{i-1})}.
}
\]
Whenever
\[
p(L_{i-1})>0,
\]
each affected factor is strictly smaller than one. More importantly, these factors depend on the distributional parameters, so the error cannot be absorbed into a multiplicative constant that leaves maximum likelihood or Bayesian inference unchanged.

For the DAPW family at
\[
(\alpha,\theta,\beta)=(2,1/2,1)
\]
and the admissible strict lower-record sequence
\[
(L_1,L_2,L_3)=(2,1,0),
\]
the exact values are
\[
\boxed{
L_{\mathrm{pub}}
=
0.0296696393189962\ldots,
}
\]
\[
\boxed{
L_{\mathrm{strict}}
=
0.0597390364794552\ldots,
}
\]
and
\[
\boxed{
\frac{L_{\mathrm{pub}}}{L_{\mathrm{strict}}}
=
0.496654132163646\ldots.
}
\]
Thus Eq. (14) can change the likelihood by about a factor of two even in a short three-record example.

The source's upper-record factor does not have the same off-by-one defect. A strict upper record after value \(u\) requires
\[
X>u,
\]
whose probability is
\[
1-F(u).
\]
Hence the denominator used in its upper-record Eq. (15) is consistent with ordinary strict upper records.

## Assumptions and scope
The result concerns ordinary strict records, the convention used in standard record theory: a new lower record must be less than every previous observation. Weak records, which count ties, are a different object.

The parent distribution is integer-valued on
\[
\{0,1,2,\ldots\},
\]
as in the DAPW model considered by the source.

The correction concerns the lower-record component of the mixed upper-lower likelihood. It does not challenge the paper's stress-strength identity
\[
R=\Pr(Y<X)
\]
or the upper-record denominator
\[
1-F(u).
\]

No claim is made that every numerical table in the article was necessarily generated by literal implementation of the printed Eq. (14). The analytic likelihood itself is the object corrected here.

## Proof
Let the current strict lower record be
\[
L_{i-1}=\ell.
\]
Future observations are independent draws from the same discrete parent law. A new strict lower record occurs at the first future draw satisfying
\[
X<\ell.
\]

For any
\[
j<\ell,
\]
condition on the event that a future draw falls below \(\ell\). The value of that draw has distribution
\[
\Pr(X=j\mid X<\ell)
=
\frac{p(j)}{\Pr(X<\ell)}.
\]
Because the variable is integer-valued,
\[
\Pr(X<\ell)
=
\Pr(X\le \ell-1)
=
F(\ell-1).
\]
Therefore
\[
\Pr(L_i=j\mid L_{i-1}=\ell)
=
\frac{p(j)}{F(\ell-1)}.
\]

Multiplying the initial-record mass and the successive transition probabilities gives
\[
L_{\mathrm{strict}}
=
p(L_1)
\prod_{i=2}^{m}
\frac{p(L_i)}{F(L_{i-1}-1)}.
\]

By contrast, the source uses
\[
F(L_{i-1})
=
F(L_{i-1}-1)+p(L_{i-1}).
\]
Thus it normalizes by an event that includes a tie at the current record value. Such a tie does not satisfy the strict lower-record condition.

Dividing the source likelihood by the correct likelihood gives
\[
\frac{L_{\mathrm{pub}}}{L_{\mathrm{strict}}}
=
\prod_{i=2}^{m}
\frac{F(L_{i-1}-1)}{F(L_{i-1})}.
\]
For a nondegenerate DAPW mass at each displayed record value, the ratio is parameter-dependent and strictly below one.

For the numerical DAPW example, the source PMF and CDF give
\[
F(0)=0.4142135623730951\ldots,
\]
\[
F(1)=0.6817928305074290\ldots,
\]
\[
F(2)=0.8340080864093424\ldots.
\]
Substitution into the two likelihoods yields the values stated above.

## Verification
The included checker implements the DAPW CDF and PMF exactly from the source's Eqs. (1)-(2).

It verifies that the PMF is nonnegative and normalized numerically for the example
\[
(\alpha,\theta,\beta)=(2,1/2,1).
\]

For the strict lower-record sequence
\[
(2,1,0),
\]
it independently evaluates
\[
L_{\mathrm{pub}}
=
p(2)\frac{p(1)}{F(2)}\frac{p(0)}{F(1)}
\]
and
\[
L_{\mathrm{strict}}
=
p(2)\frac{p(1)}{F(1)}\frac{p(0)}{F(0)}.
\]
The checker reproduces the displayed ratio
\[
0.496654132163646\ldots.
\]

It also verifies the transition normalization
\[
\sum_{j=0}^{\ell-1}
\frac{p(j)}{F(\ell-1)}
=
1
\]
for several current lower-record values \(\ell\), while the source-normalized probabilities sum to
\[
F(\ell-1)/F(\ell)<1.
\]

## Relationship to prior work
The 2026 source explicitly models a discrete parent law and describes the mixed design as lower records for strength and upper records for stress. Its Eq. (14) nevertheless inserts the continuous-style lower-record denominator
\[
F(L_{i-1})
\]
without the lattice shift required by strict discrete records.

Classical record theory defines lower records strictly: a lower record is less than all previous observations. Modern record software likewise distinguishes ordinary strict records from weak records that include ties. For an integer-valued distribution this distinction changes the normalizing event from
\[
X\le \ell
\]
to
\[
X<\ell.
\]

The paper's own upper-record likelihood illustrates the correct discrete event logic: it divides by
\[
1-F(U_{j-1}),
\]
which is exactly
\[
\Pr(X>U_{j-1}).
\]
The lower analogue must therefore use
\[
F(L_{i-1}-1)
=
\Pr(X<L_{i-1}).
\]

Focused searches using the exact DOI, DAPW name, lower-record likelihood, mixed-record terminology, strict/weak record aliases, and the characteristic \(F(\ell-1)\) shift did not locate a published corrigendum or a source already identifying this DAPW-specific error.

A separate result on the same 2026 paper concerns certification of truncation error in the stress-strength infinite sum. That issue is logically independent: it does not alter the mixed-record likelihood and does not imply the denominator correction here.

## Limitations
The finding corrects the likelihood conditional on an observed strict lower-record sequence. It does not analyze the separate stopping-design issue that a nonnegative integer-valued strict lower-record process eventually reaches its minimum and then produces no further strict lower records.

The paper's mixed-record numerical experiments are not reconstructed here.

Weak lower records, in which ties may count as records, require a different stochastic model and are not what is analyzed here.
