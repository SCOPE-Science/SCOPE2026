# Reproducible verification

Run `python3 verify.py` (Python 3 with the standard library only). It generates all \(80\) edges of \(Q_5\), checks the third-edge conflict criterion against a separately implemented Hamming-distance predicate for all \(3160\) edge pairs, and creates the exact \(51\)-vertex compatibility graph after fixing edge \((0,1)\). The greedy-color clique recursion counts zero 12-cliques in \(59\) visited search nodes and twelve 11-cliques in \(265\) visited search nodes. Greedy colors bound clique size because each color class is independent; this justifies every pruned branch. The search is complete, not sampled or time-limited.

The code independently validates an explicit 12-edge witness. It applies all \(32\cdot 5!\) natural cube automorphisms and finds exactly \(80\) distinct images, all compliant with edge-open packing and all unions of four disjoint three-edge stars. Double counting under edge transitivity gives exactly \(80\) maximum packings and the orbit equality. `verification_output.txt` contains the exact expected output, which can be regenerated byte-for-byte.

This is a transparent computational proof of one fixed finite case; no statement of an infinite family is computationally certified. Verification is same-model only; an independent audit has not been performed.
