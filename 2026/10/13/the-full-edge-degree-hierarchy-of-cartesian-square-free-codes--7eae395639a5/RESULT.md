# The full edge-degree hierarchy of Cartesian square-free codes
## Finding

Let
\[
X=A_1\times\cdots\times A_m\subseteq\mathbb F_q^m,
\qquad
0\in A_i,
\]
with
\[
2\le n_1\le\cdots\le n_m,
\qquad n_i=|A_i|.
\]
Consider the homogeneous Cartesian square-free code
\[
C=C_{m-1}^{X,S}.
\]
Its dimension is \(m\), because there are exactly \(m\) square-free monomials of degree \(m-1\).

Put
\[
P=\prod_{i=1}^m(n_i-1).
\]
Then every generalized Hamming weight of \(C\) is
\[
\boxed{
 d_r(C)
 =P+\sum_{j=m-r+1}^{m}\prod_{i\ne j}(n_i-1)
 },
\qquad 1\le r\le m.
\]

Equivalently,
\[
d_r(C)=P+\min_{|I|=r}\sum_{i\in I}\frac{P}{n_i-1},
\]
and the minimum is attained by
\[
I=\{m-r+1,\ldots,m\}.
\]
Thus the optimal \(r\)-dimensional monomial span is formed from the degree-\((m-1)\) monomials that omit the variables whose Cartesian sets are largest.

There is also a complete projective consequence. For the projective square-free code
\[
C_m^{\mathbb P,S}(m)
\]
over \(\mathbb F_q\),
\[
\boxed{
 d_r\bigl(C_m^{\mathbb P,S}(m)\bigr)
 =(q-1)^{m-1}(q+r-1)
 },
\qquad 1\le r\le m+1.
\]

The recent source gives exact generalized weights through a shadow-minimization theorem, but its explicit general formulas stop after the first two weights in this edge-degree case. The formulas above determine the full hierarchy.

## Assumptions and scope

The notation is that of Carvalho, López, and San-José. The code
\[
C_d^{X,S}
\]
is generated by evaluating all square-free monomials of total degree \(d\) on the Cartesian set \(X\).

The hypotheses
\[
0\in A_i
\]
are essential for the source's exact homogeneous shadow theorem used below. The ordering
\[
n_1\le\cdots\le n_m
\]
is only a normalization; without ordering, the formula says to choose the \(r\) smallest values among
\[
\left\{\prod_{j\ne i}(n_j-1):1\le i\le m\right\}.
\]

The projective statement uses the source's affine-to-projective tensor relation for the full affine set
\[
\mathbb F_q^{m+1}
\]
and homogeneous degree \(m\).

## Proof

There are exactly \(m\) square-free monomials of degree \(m-1\):
\[
M_i=\prod_{j\ne i}x_j,
\qquad 1\le i\le m.
\]

Let
\[
B_X=\prod_{j=1}^m\{0,1,\ldots,n_j-1\}
\]
be the exponent box used for the Cartesian footprint. For a monomial \(M_i\), its shadow consists of exponent vectors
\[
\beta=(\beta_1,\ldots,\beta_m)\in B_X
\]
satisfying
\[
\beta_j\ge1\quad\text{for every }j\ne i.
\]
There is no restriction on \(\beta_i\).

Define the common positive core
\[
Q=\{\beta\in B_X:\beta_j\ge1\text{ for all }j\}.
\]
Then
\[
|Q|=P=\prod_{j=1}^m(n_j-1).
\]
For each \(i\), define the zero slice
\[
Z_i=\{\beta\in B_X:\beta_i=0,\ \beta_j\ge1\text{ for }j\ne i\}.
\]
Its size is
\[
|Z_i|=P_i:=\prod_{j\ne i}(n_j-1).
\]
Moreover,
\[
\nabla_X(M_i)=Q\sqcup Z_i.
\]
The sets
\[
Q,Z_1,\ldots,Z_m
\]
are pairwise disjoint except that the core \(Q\) is common to every monomial shadow. In particular, for any index set
\[
I\subseteq\{1,\ldots,m\},
\qquad |I|=r,
\]
one has the exact disjoint decomposition
\[
\nabla_X(\{M_i:i\in I\})
 =Q\sqcup\bigsqcup_{i\in I}Z_i.
\]
Therefore
\[
\left|\nabla_X(\{M_i:i\in I\})\right|
=P+\sum_{i\in I}P_i.
\]

The source's exact homogeneous footprint theorem identifies the generalized Hamming weight with the minimum such shadow size over \(r\) degree-\((m-1)\) monomials. Hence
\[
d_r(C)=P+\min_{|I|=r}\sum_{i\in I}P_i.
\]
Since
\[
P_i=\frac{P}{n_i-1}
\]
and
\[
n_1\le\cdots\le n_m,
\]
we have
\[
P_1\ge P_2\ge\cdots\ge P_m.
\]
The minimum is thus obtained by the \(r\) indices
\[
m-r+1,\ldots,m,
\]
which proves the affine formula.

For the projective consequence, apply the affine formula in \(m+1\) variables to
\[
X=\mathbb F_q^{m+1},
\qquad d=m.
\]
Now every Cartesian size equals \(q\), so
\[
P=(q-1)^{m+1}
\]
and every slice has size
\[
(q-1)^m.
\]
Thus the affine code has
\[
d_r=(q-1)^m(q-1+r),
\qquad 1\le r\le m+1.
\]
The source's affine-to-projective relation multiplies every projective generalized weight by \(q-1\). Dividing gives
\[
d_r\bigl(C_m^{\mathbb P,S}(m)\bigr)
=(q-1)^{m-1}(q+r-1),
\]
for the entire range
\[
1\le r\le m+1.
\]

## Verification

`artifacts/verify.py` uses only the Python standard library.

First, it enumerates the exponent boxes for several heterogeneous Cartesian size vectors. For every subset of the degree-\((m-1)\) monomials it builds the shadow directly and checks the exact decomposition
\[
|\nabla_X(I)|=P+\sum_{i\in I}P_i.
\]
It then checks that the minimum for each \(r\) is attained by the indices with the largest \(n_i\), as the closed formula predicts.

Second, it performs a direct coding-theoretic check over \(\mathbb F_3\) on
\[
X=\{0,1\}\times\mathbb F_3\times\mathbb F_3.
\]
For the degree-two square-free code, it explicitly evaluates the three generators, enumerates every linear subspace of the three-dimensional message space, and obtains
\[
(d_1,d_2,d_3)=(6,8,12),
\]
which agrees with the formula for Cartesian sizes
\[
(2,3,3).
\]

Successful replay prints `VERIFY_OK`.

## Relationship to prior work

Carvalho, López, and San-José introduce Cartesian square-free codes and prove that, when every Cartesian factor contains zero, their homogeneous generalized Hamming weights are exactly the corresponding minimum shadow sizes. This reduces the coding problem to finite combinatorics.

Their explicit general homogeneous formula is stated only in a restricted range of \(r\). Specializing to
\[
d=m-1
\]
leaves only the first two generalized weights covered by that formula, even though the code has dimension \(m\). The present argument exploits the exceptional simplicity of the complete list of degree-\((m-1)\) square-free monomials: every shadow is a common positive core plus one private zero slice. This makes every remaining generalized weight explicit.

The same source transfers affine homogeneous generalized weights to projective square-free codes. At projective edge degree \(d=m\), its displayed general explicit range again gives only the first two weights; the formula here gives all \(m+1\).

Earlier square-free evaluation-code work determines minimum distance and low generalized weights, while work on toric square-free codes studies a different evaluation set in which every coordinate is nonzero. Those results do not imply the Cartesian-zero edge hierarchy above.

## Limitations

The theorem is specific to the edge degree
\[
d=m-1
\]
for Cartesian square-free codes containing zero in every Cartesian factor. At smaller degrees, monomial shadows overlap in substantially more complicated ways and this core-plus-slice decomposition does not persist.

The projective consequence concerns the edge degree
\[
d=m
\]
in projective dimension \(m\). No claim is made for the full generalized-weight hierarchy at other projective degrees.

The result determines generalized weights, not the number or orbit structure of all minimizing subcodes.
