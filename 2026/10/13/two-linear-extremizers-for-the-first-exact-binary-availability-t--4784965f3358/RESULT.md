# Two linear extremizers for the first exact binary availability-two LRC case
## Finding

Kang, Xiong, Hsieh, and Lai prove
\[
M_{\max}(2,8,4,2,2,2)=8
\]
for binary all-symbol locally recoverable codes with
\[
(r,\delta,a)=(2,2,2).
\]
Among linear codes attaining this exact size, there are exactly two coordinate-permutation equivalence classes.

Label the seven nonzero vectors of
\[
\mathbb F_2^3
\]
by the integers \(1,\ldots,7\) through their three-bit binary expansions. Representatives are generated by the column multisets
\[
A=(1,1,2,2,4,5,6,7)
\]
and
\[
B=(1,1,2,3,4,5,6,7).
\]

The first class contains the attaining construction exhibited in the source. Its Hamming weight enumerator is
\[
W_A(z)=1+5z^4+2z^6.
\]
Its seven two-dimensional subcodes have support-size distribution
\[
6:2,\qquad 7:4,\qquad 8:1,
\]
and its coordinate-permutation automorphism group has order
\[
32.
\]

The second class is the seven-point binary simplex generator with one projective point repeated. Its weight enumerator is
\[
W_B(z)=1+3z^4+4z^5.
\]
Its two-dimensional support-size distribution is
\[
6:1,\qquad 7:6,
\]
and its coordinate-permutation automorphism group has order
\[
48.
\]

Both classes have generalized Hamming-weight hierarchy
\[
(4,6,8).
\]
Thus the published binary extremizer is not linearly unique, but these two classes exhaust all linear extremizers.

## Assumptions and scope

The source's all-symbol availability definition is used with
\[
(r,\delta,a)=(2,2,2).
\]
For every coordinate \(i\), there must be two mutually disjoint helper sets, each of size at most \(2\), such that puncturing to \(i\) together with either helper set gives a local code of minimum distance at least \(2\).

The source's optimum is for arbitrary, possibly nonlinear, codes. The result here classifies only the linear extremizers of size \(8\). A binary linear code of size \(8\) has dimension \(3\), so every candidate has a \(3\times8\) generator matrix.

Equivalence means permutation of the eight code coordinates. Row operations do not change the code.

## Proof

A column of a rank-three binary generator matrix is one of the eight vectors of
\[
\mathbb F_2^3.
\]
Up to row operations and coordinate permutations, the generator is described by a multiplicity vector
\[
(m_0,m_1,\ldots,m_7)
\]
modulo the natural action of
\[
\operatorname{GL}(3,2)
\]
on the nonzero column types.

There are exactly
\[
\binom{15}{7}=6435
\]
nonnegative multiplicity vectors with total \(8\).

For each vector, rank \(3\) is required. For every nonzero message
\[
u\in\mathbb F_2^3,
\]
the codeword weight is
\[
w(u)=\sum_{u\cdot c=1}m_c.
\]
Thus the global-distance condition is checked exactly by requiring
\[
\min_{u\ne0}w(u)\ge4.
\]

The local condition is also checked directly. For every coordinate \(i\), enumerate every helper set
\[
H\subseteq\{1,\ldots,8\}\setminus\{i\},
\qquad 1\le |H|\le2.
\]
A helper set is valid precisely when the punctured code on
\[
\{i\}\cup H
\]
has minimum distance at least \(2\). Availability two requires two valid helper sets that are disjoint.

Exactly \(28\) of the \(6435\) multiplicity vectors have rank \(3\), global distance at least \(4\), and the required availability at all eight coordinates. Every survivor has
\[
m_0=0
\]
and minimum distance exactly \(4\).

The group
\[
\operatorname{GL}(3,2)
\]
has \(168\) elements. Its action splits the \(28\) survivors into exactly two orbits, of sizes
\[
21
\quad\text{and}\quad
7.
\]
Representatives are \(A\) and \(B\), proving the classification.

For \(A\), the seven nonzero word weights are
\[
4,4,4,4,4,6,6.
\]
For \(B\), they are
\[
4,4,4,5,5,5,5.
\]
This gives the two displayed weight enumerators and also proves the classes are inequivalent.

Enumerating the seven two-dimensional message subspaces gives support sizes
\[
6,6,7,7,7,7,8
\]
for \(A\), and
\[
6,7,7,7,7,7,7
\]
for \(B\). Hence both generalized hierarchies are
\[
(4,6,8).
\]

The multiplicity-vector stabilizers inside \(\operatorname{GL}(3,2)\) have orders \(8\) and \(24\). Internal permutations among equal columns contribute factors \(4\) and \(2\), respectively, so the coordinate-permutation automorphism orders are
\[
32
\quad\text{and}\quad
48.
\]

## Verification

`artifacts/verify.py` uses only the Python standard library.

It enumerates all \(6435\) multiplicity vectors on the eight possible binary column types. For every vector it reconstructs an explicit length-eight generator-column list, checks rank \(3\), computes all seven nonzero codeword weights, and tests the local condition at every coordinate.

No shortcut is used for repair availability: every helper set of size \(1\) or \(2\) is tested by direct enumeration of the punctured local linear code, and two disjoint valid helper sets are required.

The verifier constructs all \(168\) elements of \(\operatorname{GL}(3,2)\), checks the two orbit sizes, and independently recomputes the weight enumerators, two-dimensional support spectra, generalized Hamming weights, stabilizers, and permutation-automorphism orders.

Successful replay prints `VERIFY_OK`.

## Relationship to prior work

The primary source develops a four-block linear-programming bound for locally recoverable codes with availability. It proves the nonlinear optimum
\[
M_{\max}(2,8,4,2,2,2)=8
\]
and supplies a checked binary construction attaining the bound. It does not classify the optimal linear codes or state a second inequivalent optimal linear construction.

The classical equidistant binary \([8,3,4]\) Hadamard subcode is not a covering result. In its standard column model it uses the zero column together with all seven nonzero vectors of \(\mathbb F_2^3\). Direct application of the same availability test shows that it does not satisfy the required all-symbol \((2,2,2)\)-availability.

Focused searches under the exact source parameters, binary \([8,3,4]\) equivalence, repeated-point simplex constructions, both displayed weight enumerators, and automorphism data did not locate a prior availability-constrained classification.

## Limitations

The theorem classifies linear size-eight extremizers only. No classification of nonlinear extremizers is claimed.

The proof is a complete finite classification specific to dimension \(3\) and length \(8\); it does not provide an asymptotic classification method.

The automorphism groups are coordinate-permutation automorphism groups of the binary linear codes, not automorphism groups of a chosen collection of repair sets.

A classical database may contain the same underlying abstract \([8,3,4]\) codes. The originality claim is the availability-constrained equality classification for the newly exact parameter row.
