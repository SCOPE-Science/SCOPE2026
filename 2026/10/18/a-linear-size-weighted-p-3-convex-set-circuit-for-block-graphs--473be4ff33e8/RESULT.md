# A linear-size weighted \(P_3\)-convex-set circuit for block graphs

## Finding
Let \(G\) be any finite connected simple **block graph**: each maximal 2-connected block is a clique, with bridge blocks regarded as cliques of order two. The single-vertex graph is allowed. A set \(S\subseteq V(G)\) is \(P_3\)-convex when every vertex outside \(S\) has at most one neighbour in \(S\). Define its multivariate convex-set polynomial by
\[
Z_G(\mathbf x)=\sum_{\substack{S\subseteq V(G)\\S\text{ is }P_3\text{-convex}}}\prod_{v\in S}x_v.
\]
There is an explicit, uniformly valid arithmetic circuit for \(Z_G\) of size \(O(|V(G)|)\), constructed from the maximal-clique incidence tree using only addition and multiplication. Given an ordinary edge-list representation of \(G\), construction and evaluation at any specified vertex weights use \(O(|V(G)|+|E(G)|)\) arithmetic operations, including the standard block decomposition. Hence the entire cardinality enumerator \(Z_G(z,\ldots,z)\) has an exact succinct circuit and can be expanded in polynomial time. The result allows unbounded clique size and arbitrarily many clique blocks.

Here is the complete recurrence, including boundary conventions. Root the bipartite incidence tree between graph vertices and maximal clique blocks at any graph vertex \(r\). A graph vertex \(v\) has child blocks \(\mathcal B_v\); a block \(B\) with parent \(v\) has child vertices \(U_B=B\setminus\{v\}\). For a graph vertex \(u\), let \(A_u\) be the weighted contribution with \(u\) selected, and let \(B_u^0,B_u^1\) be contributions with \(u\) unselected and respectively zero or one selected neighbour *in descendant blocks*. No contribution with two descendant selected neighbours is allowed. Each weight \(x_u\) is included exactly once, at its graph-vertex node.

For a child block \(B\) of \(v\), set
\[
\begin{aligned}
\alpha_B&=\prod_{u\in U_B} B_u^0+\prod_{u\in U_B}A_u,\\
\beta_B&=\prod_{u\in U_B}(B_u^0+B_u^1),\\
\gamma_B&=\sum_{u\in U_B}A_u\prod_{w\in U_B\setminus\{u\}}B_w^0.
\end{aligned}
\]
The vertex messages satisfy
\[
\begin{aligned}
A_v&=x_v\prod_{B\in\mathcal B_v}\alpha_B,\\
B_v^0&=\prod_{B\in\mathcal B_v}\beta_B,\\
B_v^1&=\sum_{B\in\mathcal B_v}\gamma_B\prod_{C\in\mathcal B_v\setminus\{B\}}\beta_C.
\end{aligned}
\]
All empty products equal one and all empty sums equal zero, so a leaf vertex has \(A_v=x_v\), \(B_v^0=1\), \(B_v^1=0\). Finally,
\[
\boxed{Z_G(\mathbf x)=A_r+B_r^0+B_r^1.}
\]
All products with a single exceptional summand can be evaluated by successive two-state accumulations, without divisions or large auxiliary tables.

## Assumptions and scope
Graphs are finite, simple, undirected and connected. A block graph is equivalently a graph in which each biconnected component with at least one edge is complete. Each edge lies in exactly one clique block, and distinct clique blocks share at most one cut vertex. The graph-vertex/clique-block incidence graph is a tree; the one-vertex case has no blocks. The weights \(x_v\) are independent commuting indeterminates, so the theorem also applies after specializing them to elements of any commutative ring. Arithmetic-operation bounds are not claims of constant bit complexity; expanded multivariate output can itself be exponential. Only **ordinary** \(P_3\)-convexity, generated by all three-vertex paths, is considered, not convexity restricted to induced paths.

## Proof
**1. Exact local clique restriction.** Let \(S\) be \(P_3\)-convex and let \(B\) be a clique block. If \(B\setminus S\) contains \(w\), then \(w\) is adjacent to all selected vertices of \(B\), and therefore \(|B\cap S|\le 1\). Thus for every clique block the selected vertices are either none, exactly one, or all of \(B\). This elementary local restriction is already a feature of known counting approaches; the contribution here is the arbitrary-depth, shared-cut-vertex composition below.

**2. The clique/vertex incidence structure.** Distinct blocks intersect only at cut vertices; the incidence graph with one node for each original vertex and each clique block is connected and has no cycle. Indeed, an incidence cycle would give a cycle using edges of different biconnected components. Hence it is a tree. Its total number of incidences is \(|V(G)|+b-1\), where \(b\) is the number of blocks; in particular it is \(O(|V(G)|)\).

**3. State completeness.** Fix a rooted subtree at vertex \(v\) and omit the parent clique block. If \(v\) is selected, its number of selected neighbours places no restriction on its own \(P_3\)-convexity status. If \(v\) is not selected, at most one selected neighbour may occur in the descendant blocks, since a second could never be repaired by adding a parent contribution. These are precisely the three states \(A_v,B_v^0,B_v^1\). Every descendant vertex other than \(v\) is already checked against all its incident clique blocks within the subtree, except for the boundary block at \(v\).

**4. Block transition.** Consider a clique block \(B\) with parent vertex \(v\) and child vertices \(U_B\). If \(v\) is selected, the clique restriction forces either (i) no child selected, in which case every child is unselected and sees the selected neighbour \(v\), so its lower state must be \(B_u^0\); or (ii) every child selected, contributing \(A_u\). These disjoint choices give \(\alpha_B\). If \(v\) is unselected and no child is selected, child lower states may be \(B_u^0\) or \(B_u^1\), yielding \(\beta_B\). If \(v\) is unselected and has exactly one selected neighbour in this block, there is a unique selected child \(u\); every other child is unselected and sees one selected neighbour in \(B\), requiring its lower state \(B_w^0\). These disjoint choices give \(\gamma_B\). Any block with two selected children and unselected parent is forbidden, and there are no other local possibilities.

**5. Vertex transition and uniqueness.** If \(v\) is selected, child blocks are independent given that state, producing \(A_v=x_v\prod_B\alpha_B\). If \(v\) is unselected, different child blocks contribute disjoint sets of selected neighbours of \(v\). Either every block contributes zero (\(B_v^0\)), or exactly one uniquely chosen block contributes one (\(B_v^1\)). These are the displayed recurrences. The incidence tree ensures every vertex's label and each local condition are considered exactly once. Induction from the leaves proves that the message polynomials enumerate precisely, and without repetitions, their stated partial labelings. At the root there is no parent block, so summing the three allowed states gives exactly \(Z_G\), including the empty and full sets.

**6. Complexity.** The block-cut decomposition of a graph is computable in \(O(|V|+|E|)\) time. For a block with child vertices \(u_1,\dots,u_t\), all three block messages are computed in \(O(t)\) additions/multiplications by maintaining \(p_0=\prod B_{u_i}^0\), \(p_A=\prod A_{u_i}\), \(p_\beta=\prod(B_{u_i}^0+B_{u_i}^1)\), and \(p_1=\sum_j A_{u_j}\prod_{i\ne j}B_{u_i}^0\). On appending child \(u\), update \(p_1\leftarrow p_1 B_u^0+p_0 A_u\), then \(p_0\leftarrow p_0B_u^0\). The analogous two-state accumulator combines child blocks at a vertex. Since the incidence tree has \(O(|V|)\) edges, there are \(O(|V|)\) arithmetic gates after block decomposition. Evaluating all gates at numerical weights is linear in this count. Using ordinary polynomial convolutions at \(x_v=z\) gives polynomial-time coefficient extraction. This proves the theorem.

## Verification
The standalone file `verify.py` implements the univariate specialization of the recurrence over exact integer-coefficient polynomial arrays, **and separately** enumerates all subsets of the vertices, checking the condition on every exterior vertex directly. It tests 1,816 generated connected block-graph instances with at most twelve vertices (many parameter instances may be isomorphic), including arbitrary clique-chain compositions, independently seeded gluings and single-clique cases. Each computed coefficient vector agrees with exhaustive subset enumeration. Running `python3 verify.py` from the artifact directory prints `PASS` and reproducible examples. These finite experiments are checks, not the proof for unbounded graphs.

For example, the friendship graph of \(k\) triangles sharing one center satisfies
\[
Z_{F_k}(z)=1+2kz+z(1+z^2)^k.
\]
For three triangles sharing a common center, this is \(1+7z+3z^3+3z^5+z^7\). By contrast, arranging the same three triangle blocks in a path (successive triangles share distinct cut vertices) produces
\[
1+7z+4z^2+3z^3+2z^5+z^7.
\]
Thus even with the same multiset of maximal clique sizes, the convex-set polynomial can detect the **incidence arrangement**. Both expressions follow from the recurrence and were independently enumerated.

## Relationship to prior work
Dourado, Grippo, Lin and Protti (first public arXiv version March 5, 2026) introduced a detailed counting study of \(P_3\)-convex sets. Their Theorem 3 gives a linear-time algorithm on trees, Theorem 14 handles threshold graphs, and their Sections 4.1–4.3 develop general exponential-time counting strategies; Section 4.3.1 explicitly uses the elementary none/one/all clique-colouring restriction. Those results are credited. The present statement uses that restriction but adds a three-state, cut-vertex-compatible weighted transfer on the entire **unbounded-clique, arbitrarily many block** family, yielding a succinct multivariate generating circuit and linear arithmetic-time evaluations, rather than enumerating clique-colour choices across all blocks.

Known work on \(P_3\)-convexity Carathéodory, hull and other extremal parameters concerns different invariants. Published mathematical-record searches on clique blocks, block graphs, exact counting and equivalent exterior-neighbour formulations returned no statement implying this all-block-graph weighted-circuit theorem. A prior result on \(P_3\)-convex sets of one-subdivisions of arbitrary graphs has a different graph domain: one-subdivisions are bipartite, so its formula does not supply the present arbitrary triangle-containing block-graph result. These comparisons do not establish definitive global bibliographic priority.

## Limitations
No tractability claim is made for all chordal graphs or all split graphs; counting \(P_3\)-convex sets is already \(\#\mathrm P\)-complete on split graphs. The \(O(|V|)\) statement concerns size of an arithmetic **circuit**, not the number of monomials after full expansion, and arithmetic-operation counts do not bound machine-word cost of potentially large integers. The full publication record may contain equivalent formulations under tree-factor, hypergraph-incidence or locally constrained subset terminology. Independent mathematical and bibliographic audits have not been carried out.
