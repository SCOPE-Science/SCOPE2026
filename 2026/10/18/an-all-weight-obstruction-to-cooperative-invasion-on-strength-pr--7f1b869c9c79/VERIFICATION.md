# Verification and limits

Run `python verify.py` using the Python standard library. It independently constructs finite neutral copying generators on all mixed configurations, differentiates the fixation harmonic equation, and constructs the killed two-lineage meeting generator. Exact Gaussian elimination over rational numbers establishes equality of the two benefit-coefficient computations, the exact cost formula, and strict positivity of the all-weight star expression on four test cases. The general proof uses voter duality, a quadratic-variation identity, and a strictly positive edge-crossing hazard argument; a finite computation is not a proof for every size or weighting. Independent scientific audit has not been performed.
