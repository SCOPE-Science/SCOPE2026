# Independent mathematical audit

## correctness

PASS

The finite p-morphism equation represents precisely the Heyting endomorphisms. For the frozen general normal form, a level cannot send two points to different target levels because its fixed strict source suffix would have to cover and also omit points of the higher target antichain. The nondecreasing level sequence visits every level above its first and cannot revisit any of them, because cross-level comparability would force that repeated level's image to be a singleton. This verifies the frozen classification and its surjection-based counts. The repaired retraction theorem has a direct proof: a dual idempotent fixes its image, an upset with a first occupied level j, a nonempty subset C there and the full fixed suffix above it. A source on level j cannot jump to a fixed higher nonsingleton level because its upper cone maps onto that entire higher level, not just its selected point. If j>1, each point below level j must map below every c in C while still lying in the image; this forces C to be a singleton and the whole prefix to collapse to it. If j=1 the image subset C is fixed and the remaining bottom points map freely into C. Both constructions satisfy back-lifting. Restricting upsets to the dual image and using surjectivity onto that image gives the stated algebra rank. The rank families are disjoint with gap 2^(n_2)−1 between their closest values. Thus the polynomial counts all and only idempotents, with the stated multiplicity for each specified dual image.
