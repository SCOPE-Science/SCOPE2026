All minimum maximal independent sets of the direct product \(P_n\times K_q\) are explicitly classified and counted for every \(n,q\ge2\): for \(q\ge3\), the count is \(\binom{r+t-1}{t}q(q-1)^{r-1}\), where \(r=\lfloor(n+1)/3\rfloor\) and \(t=n-3r+1\), with exactly one extra set at \((n,q)=(3,3)\). Apart from that exception, every minimum set uses only singletons in monochromatic runs, separated by one empty fiber; the two-color case is a square of an explicit binomial coefficient.
