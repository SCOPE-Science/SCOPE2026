# Exact four-coordinate \(q\)-ary limited-permutation code capacity

## Finding
For every integer \(q\ge 2\), the largest zero-error code of length four for the radius-one \(\ell_\infty\)-limited permutation channel has size
\[
\boxed{A_q(4;1)=\frac{q^2(q+1)(q+2)}{6}.}
\]
The optimum is attained independently in each fixed-multiset component. For multiplicity partitions \((4)\), \((3,1)\), \((2,2)\), \((2,1,1)\), and \((1,1,1,1)\), respectively, the exact maximum numbers of codewords per component are \(1,2,2,3,4\). These component maxima and their simultaneous attainability constitute one exact-capacity classification.

## Assumptions and scope
Let \(\Sigma\) be any set with \(|\Sigma|=q\), \(q\ge 2\). An input word has four coordinates \(w=w_1w_2w_3w_4\). In one use, the channel may swap no coordinates, one adjacent pair in positions \((1,2)\), \((2,3)\), or \((3,4)\), or both disjoint adjacent pairs \((1,2)\) and \((3,4)\). These are exactly the permutations with Chebyshev displacement at most one. Write \(\mathcal B(w)\) for the resulting set of output words. A code \(C\subseteq\Sigma^4\) is correcting when \(\mathcal B(u)\cap\mathcal B(v)=\varnothing\) for every two distinct codewords \(u,v\in C\). Denote its maximum possible cardinality by \(A_q(4;1)\). There is no field structure or other algebraic restriction on \(\Sigma\). Swaps are simultaneous and pairwise disjoint: successively applied overlapping swaps are a different channel.

## Proof
**Decomposition.** Each permissible permutation preserves the multiset of the input's four symbols. Distinct multiplicity components of \(\Sigma^4\) therefore have disjoint output universes. The global optimum is the sum of the individual component optima. Renaming the distinct symbols within one component preserves its incidence system of channel balls, so its optimum depends only on the multiplicity partition.

**Exhaustive local action.** For any word, the five potential outputs are its original form and those obtained by the swap-site sets \(\{1\},\{2\},\{3\},\{1,3\}\), where site \(i\) swaps positions \(i\) and \(i+1\). Collapsing identical outputs when symbols repeat gives the following complete table. The third column records the multiset of ball sizes across *all* words in one fixed-multiset component; the last column records the exact maximum of pairwise disjoint balls.

| Multiplicities | Component size | Ball sizes, with multiplicities | Maximum code size |
| --- | ---: | --- | ---: |
| \((4)\) | 1 | \(1\) (once) | 1 |
| \((3,1)\) | 4 | \(2\) (twice), \(3\) (twice) | 2 |
| \((2,2)\) | 6 | \(2\) (twice), \(4\) (twice), \(5\) (twice) | 2 |
| \((2,1,1)\) | 12 | \(3\) (four times), \(4\) (twice), \(5\) (six times) | 3 |
| \((1,1,1,1)\) | 24 | \(5\) (24 times) | 4 |

These ball-size profiles follow by evaluating the specified five swap patterns for the distinct permutations of the canonical words \(aaaa,aaab,aabb,aabc,abcd\). Thus the table is a finite calculation independent of \(q\); the appendix script independently regenerates it.

**Upper bounds.** The one-word component is immediate. Every ball in a \((3,1)\) component has at least two words, so three disjoint balls would need six outputs, exceeding four. In a \((2,2)\) component, every three distinct centers have total ball cardinality at least \(2+2+4=8\), exceeding the six possible outputs. In a \((2,1,1)\) component, four pairwise disjoint balls would have total size at least \(4\cdot3=12\), the size of the entire output universe. Equality would force *all four centers* to have size-three balls. With \(a\) repeated and \(b,c\) distinct, those centers are exactly \(aabc, aacb, bcaa,cbaa\), but both \(aabc\) and \(aacb\) belong to each other's output balls, so these four balls cannot be disjoint. Thus at most three are possible. In the all-distinct component, every ball has five words, and five disjoint balls would require 25 outputs although there are only 24; therefore at most four centers are possible.

**Lower bounds and simultaneous attainment.** Each bound is attained by the following centers, where distinct formal letters denote distinct actual symbols. Each set of displayed centers has disjoint channel balls, as can be checked by applying the five patterns (and is regenerated by the standalone checker):

| Multiplicities | Optimal centers |
| --- | --- |
| \((4)\) | `aaaa` |
| \((3,1)\) | `aaab`, `baaa` |
| \((2,2)\) | `aabb`, `bbaa` |
| \((2,1,1)\) | `aabc`, `acba`, `bcaa` |
| \((1,1,1,1)\) | `abcd`, `bcda`, `cdab`, `dabc` |

For example, the three balls in the \((2,1,1)\) line are exactly
\[
\begin{aligned}
\mathcal B(aabc)&=\{aabc,aacb,abac\},\\
\mathcal B(acba)&=\{abca,acab,acba,caab,caba\},\\
\mathcal B(bcaa)&=\{baca,bcaa,cbaa\}.
\end{aligned}
\]
They are disjoint. For the all-distinct line, the four balls have five outputs each and are likewise pairwise disjoint. Alphabet relabeling transports these constructions to every component of each given partition. Hence every local maximum can be attained at once.

**Summation.** There are \(q\) components of type \((4)\); \(q(q-1)\) of type \((3,1)\); \(\binom q2\) of type \((2,2)\); \(q\binom{q-1}2\) of type \((2,1,1)\); and \(\binom q4\) of type \((1,1,1,1)\). The numbers of components with more distinct letters are interpreted as zero when \(q\) is too small. Adding the maxima gives
\[
A_q(4;1)=q+2q(q-1)+2\binom q2+3q\binom{q-1}2+4\binom q4
=\frac{q^2(q+1)(q+2)}6.
\]
This proves the theorem for all integer alphabet sizes \(q\ge2\). \(\square\)

## Verification
Execute `python3 verify.py` from the same directory as this document. The script constructs every word of each of the five canonical components, computes its exact output ball from the five allowed simultaneous swap patterns, and checks the listed optimal constructions. It tests all \(43{,}023\) subsets of size one above the claimed maximum across the nontrivial components, ruling out larger packings in each. It also constructs a complete code over \(q=2,3,4,5,6\), with sizes \(8,30,80,175,336\), and verifies globally that their balls are disjoint. Expected terminal line: `VERIFY_OK; 43023 forbidden subsets; q=2..6 complete constructions`. Finite checks corroborate the five exact local combinatorial cases; the arbitrary-alphabet conclusion follows from the proof, not from extrapolating tests.

## Relationship to prior work
Langberg, Schwartz, and Yaakobi introduced the \(\ell_\infty\)-limited permutation channel [1]. Their 2017 article's Table II already reports the **binary** value \(A_2(4;1)=8\), which is not claimed here as new. Their Theorem 29 gives a sharp three-coordinate covering bound \(T_q=(q^3+2q)/3\); the corresponding length-three exact capacity is also known. The 2025–2026 literature [2,3] develops asymptotic rates, finite-state block-code criteria, and finite covering bounds, but does not present the all-\(q\) four-coordinate optimum and its five component capacities. In particular, for \(q\ge3\), the exact formula gives the strict short-block inequality \(A_q(4;1)<qT_q\), with gap \(q^2(q-1)(q-2)/6\); this is not obtained by simply adjoining an unrestricted symbol to a length-three optimum.

## Limitations
This theorem concerns length four only, one simultaneous layer of disjoint adjacent swaps, and unique decoding for *every* permitted output. It does not determine any longer-block asymptotic capacity, covering number, optimum list size, or performance under successive overlapping swaps. The finite verifications are exhaustive only for the specified five canonical local components and for the cited small-alphabet construction instances. Literature comparison is limited to the cited primary works and searches; an unindexed earlier equivalent exact classification cannot be excluded without independent review.
