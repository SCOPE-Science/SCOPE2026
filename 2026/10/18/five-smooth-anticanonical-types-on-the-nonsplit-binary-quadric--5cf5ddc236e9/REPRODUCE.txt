Exact finite-field verification

Requirements: Python 3.10+ and SymPy 1.12+ (tested with SymPy installed in the execution environment).

Run in a directory containing the embedded files:

    python verify_orbits.py
    python verify_direct.py

Each script is standalone; no supplementary data file is read. Both use exact integer arithmetic and polynomial ideal computations over GF(2), with no random sampling or network access. The two scripts use distinct degree-two monomial index orders and independent orbit-reduced versus direct full-parameter enumeration. Their expected final counts are in EXPECTED.json.

The two generators of the section ideal are a fixed nonsplit quadratic form and a varying quadratic form modulo multiples of the fixed form. Every one of the 511 nonzero quotient sections is included in the direct check. Affine Gröbner tests require the unit ideal in each of four coordinate charts for geometric smoothness; this is equivalent to absence of singular geometric points.
