# Five-sparse Walsh support spectra stratified by affine rank on \(\mathbb F_2^d\)

## Finding
Let \(d\ge4\), \(G=\mathbb F_2^d\), and let \(f:G\to\mathbb C\) have exactly five nonzero values. Define the unnormalized Walsh transform
\[
\widehat f(\xi)=\sum_{x\in G}f(x)(-1)^{\langle x,\xi\rangle}.
\]
Put \(r=\dim\operatorname{aff}(\operatorname{supp}f)\), necessarily \(r\in\{3,4\}\). The complete possible Walsh-support cardinalities, **separately for each affine type**, are
\[
\begin{array}{c|c}
r&|\operatorname{supp}\widehat f|\\\hline
3&2^{d-3}\{4,5,6,7,8\}\\
4&2^{d-4}\{12,13,14,15,16\}.
\end{array}
\]
Every listed size occurs on **every fixed five-point support of the specified rank**, with all five coefficients nonzero. Consequently, over all exactly five-sparse functions the spectrum is exactly
\[
2^{d-4}\{8,10,12,13,14,15,16\}.
\]
In particular the possible support sizes \(9\cdot2^{d-4}\) and \(11\cdot2^{d-4}\) are excluded. The geometry distinguishes the sharp minima \(8\cdot2^{d-4}\) (rank three) and \(12\cdot2^{d-4}\) (rank four).

## Assumptions and scope
The transform convention above is unnormalized; a nonzero constant factor does not affect support. All coefficients are arbitrary nonzero complex numbers, not necessarily real, positive, or equal in magnitude. Affine rank means the dimension of the smallest affine subspace containing the five support points. A five-point subset of a binary vector space has affine rank three or four, since a rank-two affine subspace contains only four points. Affine changes of the time coordinates preserve Fourier support cardinalities, and passing from an affine span of rank \(r\) to ambient dimension \(d\) repeats each local Fourier value exactly \(2^{d-r}\) times.

## Proof
**Reduction to two affine orbits.** Translate one support point to zero. Five points then yield four nonzero difference vectors spanning either dimension three or four. In rank four they are a basis, so an affine automorphism sends the set to \(A_4=\{0,1,2,4,8\}\) in four-bit notation. In rank three the five-set lies in an affine three-plane and its complement inside that eight-point plane has three elements. Any three distinct binary points are affinely independent, so all five-sets in the three-plane are affinely equivalent. We may use \(A_3=\{0,1,2,4,3\}\). Thus precisely these two representatives suffice.

**Exact row-space criterion.** For \(r\in\{3,4\}\) write \(W_\xi=(({-1})^{\langle x,\xi\rangle})_{x\in A_r}\in\{\pm1\}^5\) for the Walsh row at \(\xi\in\mathbb F_2^r\). Given coefficients \(c\in\mathbb C^5\), their Fourier zeros are precisely \(\xi\) for which \(W_\xi c=0\). Let \(U\) be the complex row span of these zero rows. Necessarily \(\dim U<5\); if \(e_j\in U\) for a coordinate vector \(e_j\), then \(c_j=0\), contradicting exact five-point support. Conversely, suppose \(U\) is spanned by Walsh rows, \(\dim U<5\), and contains none of \(e_1,\ldots,e_5\). Its annihilator \(U^\perp\) is a nonzero complex vector space. Each coordinate functional and each Walsh row outside \(U\) is a nonzero linear functional on this annihilator. Finitely many proper hyperplanes cannot cover a complex vector space, so some \(c\in U^\perp\) avoids all these hyperplanes. Such \(c\) has all five entries nonzero, and the Fourier zeros are **exactly** the Walsh rows lying in \(U\). Therefore the eligible row-generated proper subspaces \(U\) give all possible supports, with no approximation or nonconstructive missing case.

**Finite exact classification.** Enumerate every distinct span generated by any subset of the \(2^r\) rows \(W_\xi\). Start from the zero space and adjoin each Walsh row, maintaining reduced row-echelon representatives for subspaces of rank less than five. For each subspace test whether it contains one of the five standard coordinate vectors, then count Walsh rows in that subspace. The appended self-contained script `verify_five_walsh.py` implements this complete closure algorithm. It calculates ranks modulo \(101\). This is **exact** for these integer matrices: every nonzero \(k\)-by-\(k\) minor for \(1\le k\le5\) is a nonzero integer bounded in absolute value by \(k^{k/2}\le5^{5/2}<101\) (Hadamard), so the minor vanishes over \(\mathbb Q\) if and only if it vanishes modulo \(101\). The row reduction therefore computes precisely the complex row-span lattice.

The generated-subspace closure has respectively \(95\) and \(537\) distinct proper subspaces in ranks three and four. After excluding coordinate-containing subspaces, the exact numbers of eligible subspaces, grouped by number of **nonzero** local Fourier coefficients, are
\[
\begin{array}{c|rrrrr}
r=3:\ \mathrm{nonzeros}&4&5&6&7&8\\\hline
\mathrm{eligible\ spans}&8&32&24&8&1\\
\end{array}
\]
\[
\begin{array}{c|rrrrr}
r=4:\ \mathrm{nonzeros}&12&13&14&15&16\\\hline
\mathrm{eligible\ spans}&80&160&80&16&1.
\end{array}
\]
These counts follow from exhausting all row-generated subspaces, not sampling coefficients. The criterion in the preceding paragraph makes each column both necessary and achievable. To make existence independently transparent, the verifier also checks explicit nonzero integer coefficient witnesses for each local support size. Finally multiply each local frequency count by \(2^{d-r}\) to obtain the formulas for every \(d\ge4\).

## Verification
Run `python3 verify_five_walsh.py` with Python 3.8 or later. The script has no external dependencies, constructs each Walsh row from binary parity, deduplicates its full span closure, uses only exact modular integer arithmetic with a provably sufficient modulus, checks eligibility and the five witness supports, and asserts both displayed frequency distributions before printing `VERIFY_OK`. The computational step is a **finite exhaustive proof component** for the two specified matrices, not evidence that a bounded experiment establishes a general infinite-dimensional claim. The general \(d\) reduction is proved algebraically above. The accompanying `verification_output.txt` records the reproduced result.

## Relationship to prior work
Biró and Lev investigate how the geometry of support sets sharpens uncertainty inequalities on finite affine planes, motivating attention to affine support rank; their rank-two prime-field theorem does not imply the five-point rank-three/rank-four dichotomy. Krahmer, Pfander and Rashkov display a numerical uncertainty diagram for groups of order sixteen, including the Boolean four-cube; the diagram addresses **global cardinality pairs**, not a proof and complete affine-rank stratification of the exact five-sparse support spectrum. A published exact row-space census proves absence of the single \((5,9)\) pair on the Boolean four-cube; its classification of seven prescribed Fourier zeros does not determine every admissible nonzero count for either affine support type. The current result gives both full rank-stratified spectra and the excluded size eleven, uniformly for all higher binary dimensions.

## Limitations
This classification concerns exactly five-point time supports over \(\mathbb F_2^d\). It does not enumerate coefficients, Fourier zero-set shapes, or arbitrary sparsities, and does not assert an optimal norm inequality. The global support-pair diagram at dimension four has earlier numerical evidence, so novelty is specifically the complete rigorous **affine-type refinement**, not discovery of the entire numerical diagram. The finite calculation relies on faithfully executing the included algorithm; its mathematical completeness is established by the span-closure argument and the explicit determinant bound. Other literature may contain an equivalent affine-stratified classification under different terminology.
