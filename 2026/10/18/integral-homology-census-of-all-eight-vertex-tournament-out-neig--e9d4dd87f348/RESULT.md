# Integral homology census of all eight-vertex tournament out-neighborhood complexes

## Finding
For each tournament \(T\) on exactly eight vertices, write \(N^+(v)=\{w:v\to w\}\). Its **directed out-neighborhood complex** is the simplicial complex
\[
\mathcal N^+(T)=\{\sigma\subseteq V(T):\sigma\subseteq N^+(v)\text{ for some }v\in V(T)\}.
\]
Across all \(6880\) tournament isomorphism classes, every reduced integral homology group is free abelian and vanishes outside dimensions \(0,1,2\). There are exactly \(26\) different reduced Betti triples, with the complete multiplicities below.

## Assumptions and scope
A tournament is a finite loopless complete oriented graph with precisely one direction on every pair of distinct vertices. The complex is generated by **out-**neighborhoods, not in-neighborhoods or transitively ordered directed cliques. Repeated out-neighborhoods, the empty face, and isolated vertices are handled by the standard simplicial convention. Ordinary reduced simplicial homology is taken with coefficients in \(\mathbb Z\). The statement is exhaustive **only for order eight**; it asserts neither a homotopy-type classification nor torsion-freeness for larger tournaments.

## Proof
**1. Exhaustiveness of the tournament census.** There is one one-vertex tournament. To obtain the representatives of order \(n+1\), extend *each* order-\(n\) representative by one new vertex in all \(2^n\) choices of the incident arc orientations, and discard isomorphic duplicates. Deleting an arbitrary vertex of any order-\(n+1\) tournament proves inductively that every isomorphism class is represented. The Python implementation uses the least upper-triangular adjacency word among all relabelings that preserve the vertexwise outdegree and cyclic-triangle-count signature; these signatures are graph-isomorphism invariants, so this gives an exact canonical key. The independent C++ implementation tests direct adjacency-preserving bijections, using only signature partitions to accelerate exhaustive isomorphism checking. Both independently generate the class counts
\[
1,1,2,4,12,56,456,6880
\]
for orders \(1\) through \(8\). The terminal count independently agrees with McKay's published catalogue.

**2. Exact simplicial chains.** For each representative, a nonempty vertex subset \(\sigma\) is declared a face if and only if its bitmask is contained in at least one outgoing-neighborhood bitmask. Thus every face of the complex is enumerated, with no sampling. All integral boundary matrices use increasing vertex order and the signed alternating deletion formula
\[
\partial_k[v_0,\ldots,v_k]=\sum_{j=0}^{k}(-1)^j[v_0,\ldots,\widehat{v_j},\ldots,v_k].
\]
The reduced augmentation map sends each vertex to \(1\), giving \(\operatorname{rank}\widetilde\partial_0=1\) for the nonempty complexes here.

**3. Integral torsion certificate.** For every nontrivial simplicial boundary matrix, both verifiers repeatedly choose an entry \(\pm1\), use its inverse (also \(\pm1\)) to eliminate its row and column over the integers, and recurse on the exact integer Schur complement. This is a composition of unimodular row and column operations. If no unit pivot remains, *every entry of the residual matrix is explicitly checked to be zero*. Both independent implementations encounter zero residual matrices for every boundary of all \(6880\) complexes. Consequently each boundary has integral Smith diagonal entries only \(1\) and \(0\): its image is primitive in its target. Since the kernel of any integer map between free abelian groups is also primitive, every integral homology quotient \(\ker\partial_k/\operatorname{im}\partial_{k+1}\) is torsion-free. The positive-control six-vertex real-projective-plane triangulation, whose first integral homology has order-two torsion, is correctly flagged as having a nonzero nonunit residual by the Python verifier.

**4. Betti numbers and frequencies.** Let \(f_k\) be the exact number of faces on \(k\) vertices and \(r_k\) the rank of its oriented boundary from faces on \(k\) vertices to faces on \(k-1\) vertices. Then for \(1\le k\le8\),
\[
\widetilde\beta_{k-1}=f_k-r_k-r_{k+1},\qquad r_1=1,\quad r_9=0.
\]
Collecting these vectors over distinct isomorphism representatives yields precisely the displayed \(26\) triples, with the indicated exact multiplicities summing to \(6880\). Both implementations independently regenerate *and assert equality with* the entire frequency table. They find no nonzero Betti numbers above degree \(2\). The unique class with \(\widetilde\beta_1=6\) is reconstructed from the explicit out-neighborhood list above.

## Verification
The standalone files `verify_t8.py` and `verify_t8.cpp` implement independent exhaustive generation and integer elimination algorithms using only the respective Python 3 and C++17 standard libraries. Replay using

```sh
python3 verify_t8.py
c++ -std=c++17 -O2 verify_t8.cpp -o verify_t8
./verify_t8
```

Each program reconstructs all \(6880\) isomorphism classes from the one-vertex tournament, checks the full distribution, and prints `VERIFY_OK` on success. The Python script additionally verifies detection of torsion in the standard ten-triangle six-vertex triangulation of the real projective plane. `spectrum.csv` is a human- and machine-readable redundant record of the distribution; neither verifier requires this file or any downloaded tournament list to run. The two checked outputs agree in every entry.

## Relationship to prior work
Dochtermann and Singh introduced these directed neighborhood complexes and their equivalence in homotopy type to directed Hom complexes from an oriented edge. Their full paper gives a twelve-class homology table for order five, a vanishing theorem restricting possible homology dimensions, and expressly asks whether tournament neighborhood homology can contain torsion. These results neither enumerate nor determine the integral homology of the \(6880\) order-eight isomorphism classes.

A publicly available exact computation establishes torsion-freeness through seven vertices, but it does not cover order eight or its Betti spectrum. A separate published computation classifies order-six homotopy types, not order-eight integral homology. McKay's tournament catalogue supplies representatives and the class count \(6880\), but no neighborhood-complex homology. Search comparisons for directed-neighborhood, directed-Hom, integral torsion, order-eight counts and equivalent terminology identified no stronger result implying the table in this report.

## Limitations
These are rigorous finite computations of **integral homology**, not an infinite-family theorem. Vanishing homology does not imply contractibility, and free integral homology does not imply a wedge-of-spheres homotopy type. The bound of nine vertices is only a necessary condition for any first torsion example, not evidence that one exists. The proof relies on replayable exact integer arithmetic and complete combinatorial generation, not on probabilistic samples. A later or unindexed census using equivalent directed-Hom terminology remains a residual originality risk.
