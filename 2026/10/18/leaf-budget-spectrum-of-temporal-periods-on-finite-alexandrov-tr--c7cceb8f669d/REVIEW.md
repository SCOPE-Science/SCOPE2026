# Scientific review

**Correctness — PASS.** The proof obtains a stable image for each monotone self-map, shows that its automorphism acts faithfully on its maximal points via the pair of maximal-descendant set and principal-ideal size, and bounds the maximal-point count by the ambient number of leaves. It rigorously derives the prime-power cycle budget and constructs every admissible period on the same fixed tree. The diamond example checks that the tree-order hypothesis matters. The embedded standalone checker verifies finite cases but is not treated as an infinite proof.

**Originality — PASS, with residual risk.** The recent foundational article by Vooijs and Fernández-Duque defines exactly the Alexandrov dynamic-topological semantics and treats tree-like unravellings, but does not establish the fixed-tree sharp leaf-period spectrum. Classical Landau function results are explicitly excluded from the novelty claim. Targeted literature and mathematical-record searches sought equivalent formulations via monotone endomorphisms, automorphism actions on tree maxima, Landau permutation orders, and finite temporal-model periods. Existing sources on continuum tree maps are semantically different. An equivalent older theorem in finite-poset transformation-semigroup literature remains an unresolved risk.

**Value — PASS.** The exact possible eventual truth-pattern periods on a natural finite topological model class depend only on the number of leaves, not the number or height of interior points. The spectrum has real arithmetic gaps, and its optimal period can exceed the number of leaves. This gives a sharp, reusable finite temporal-cycle constraint with a constructive realization for every fixed tree shape, rather than a routine size-dependent finiteness observation.

The paper is a self-contained mathematical contribution in a restricted semantic class; it does not establish complexity or axiomatization claims beyond that class.
