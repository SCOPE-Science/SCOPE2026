Reproduction commands (Python 3):
python3 verify_direct.py
python3 verify_quotient.py
python3 verify_orbits.py
python3 verify_reconstruction.py

The first, second and fourth verifiers use only the standard library. The third
requires networkx >=3.6,<4. Run from the directory containing these files.
Each checker prints PASS lines only after all its assertions succeed.
The stored outputs contain the results from these source files.
