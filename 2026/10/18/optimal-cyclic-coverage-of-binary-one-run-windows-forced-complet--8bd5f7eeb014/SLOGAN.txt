For every \(k\ge2\), the shortest cyclic binary word containing every length-\(k\) word with one linear run of ones has length exactly \(k^2-k+2\), and each optimum uses exactly once every length-\(k\) word with one *circular* run of ones. There are exactly \(2^{k-2}\) optimal cycles up to rotation; the additional windows are uniquely forced by degree balancing in a de Bruijn graph.
