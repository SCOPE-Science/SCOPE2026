# Verification and limits

Run `python3 verify.py` from this directory. It uses only the Python standard library.

The program checks three exact identities in the algebraic field generated by the two radicals, including the quartic remainder coefficient identity and the polynomial for the extremal Bernoulli probability. It also checks 200 randomly chosen finite weighted integrated-remainder instances, 200 two-valued witness upper bounds, and 1000 two-point operator-norm comparisons. The deterministic random seed is fixed in the code.

The analytic inequalities for arbitrary probability spaces follow from the exact remainder, nearest-root estimates, and a two-valued construction. Finite randomized examples do not prove those infinite-dimensional assertions. The comparison coefficients are explicit but not optimal. No independent mathematical audit is claimed.
