# Independent mathematical audit

## correctness

PASS

Independence gives one term p^(|S|−1)(1−p)^(n−|S|) for each connected S containing the immune vertex. For a separate exhaustive certificate set x=p/(1−p)>0 and divide R_v by (1−p)^(n−1). The resulting F_v is the connected-subset generating polynomial counting vertices other than the root. Across each incident branch a connected set either takes nothing or takes the adjacent vertex with a rooted connected set from its side. Hence F_v=product over neighbors u of (1+x F_(u→v)), recursively. Starting with one vertex, enumerate by every possible leaf attachment, and merge only when a bijection preserves all adjacencies (degree data are just a prefilter). Removing a leaf from any nontrivial tree proves exhaustiveness. For orders 2–7 this gave 1,1,2,3,6,11 classes; all but A and B have a site with coefficientwise nonnegative differences against all competitors. For A, sites 0 and 4 strictly dominate all others by this same positive-activity certificate; F_0−F_4=x(x²−1), whose sign changes at x=1, i.e. p=1/2. For B, sites 0,1,4 dominate all other sites strictly, F_1=F_4, and F_0−F_1=x(x²+x−1), with the single positive zero corresponding to p=(3−sqrt(5))/2. This proves both exclusions and all tie/strict regimes, without inferring nonoptimality solely from the absence of a strictly positive difference certificate.
