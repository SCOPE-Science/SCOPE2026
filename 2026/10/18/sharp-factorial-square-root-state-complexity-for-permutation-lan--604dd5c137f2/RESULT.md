# Sharp factorial square-root state complexity for permutation languages

## Finding
Let \(\sqrt L=\{w\in\Sigma^*:ww\in L\}\). Among all languages \(L\) accepted by a **minimal complete permutation DFA** with exactly \(n\) states, the maximum number \(R_{\mathrm{perm}}(n)\) of states of the minimal complete DFA for \(\sqrt L\) is
\[
R_{\mathrm{perm}}(n)=\begin{cases}1,&n=1,2,\\n!,&n\ge3.\end{cases}
\]
For every \(n\ge3\), two input letters suffice to attain the factorial maximum, whereas one letter never suffices. The binary witnesses have one accepting state. This concerns a *fixed repetition of the input word*, not concatenation square \(L\cdot L\) and not the existential-power operator \(\{w:\exists k\ge1,\ w^k\in L\}\).

## Assumptions and scope
The alphabet is finite and nonempty. DFAs are complete, count both accepting and rejecting states, and may accept the empty word. A permutation DFA has every letter induce a bijection of its finite state set; \(n\) is the number of states in its **minimal** such DFA (equivalently minimal complete DFA). State complexity concerns an ordinary complete deterministic automaton for the resulting language; its alphabet is unchanged. For a transition word \(w\), write \(g_w(q)=\delta(q,w)\). Then \(g_{uv}=g_v\circ g_u\).

## Proof
**1. General upper bound.** Let \(A=(Q,\Sigma,\delta,q_0,F)\) be any \(n\)-state permutation DFA, and let \(G=\{g_w:w\in\Sigma^*\}\). Since \(Q\) is finite and all generators are permutations, \(G\) is a subgroup of \(S_Q\), of cardinality at most \(n!\). Construct a complete DFA with state set \(G\), initial state \(e\), action \(g\xrightarrow{a}g_a\circ g\), and final set
\[
T=\{g\in G:g(g(q_0))\in F\}.
\]
The state after reading \(w\) is \(g_w\), and membership in \(T\) is equivalent to \(ww\in L\). Thus \(\operatorname{sc}(\sqrt L)\le |G|\le n!\).

If \(n\le2\), every permutation on \(Q\) squares to the identity. Hence \(ww\in L\) holds independently of \(w\): \(\sqrt L\) is either \(\Sigma^*\) or the empty language, and its minimal complete DFA has one state. This upper bound is automatic and attainable for each feasible \(n=1,2\).

**2. Binary witness and input minimality.** Fix \(n\ge3\) and \(Q=\{0,1,\ldots,n-1\}\). Take \(\Sigma=\{a,b\}\), initial and unique final state \(0\), with \(a\) the cycle \((0\ 1\ \cdots\ n-1)\) and \(b\) the transposition \((0\ 1)\). Conjugating \(b\) by powers of \(a\) gives adjacent transpositions around the cycle, so these two letters generate all of \(S_n\). Every input state is reachable. If \(i\ne j\), some permutation sends \(i\) to \(0\) but not \(j\), so the states are distinguishable with final set \(\{0\}\). The input DFA is minimal and has exactly \(n\) states.

**3. Triviality of the right stabilizer.** In the group construction the final set is
\[
T=\{g\in S_n:g^2(0)=0\}.
\]
We claim that no nonidentity \(d\in S_n\) satisfies \(Td=T\), where \(Td=\{td:t\in T\}\) and products denote function composition (right factor acts first). If \(Td=T\), then because \(e\in T\), necessarily \(d\in T\). Put \(x=d(0)\). Thus \(d(x)=0\).

If \(x=0\), choose \(a\ne0\) moved by the nonidentity permutation \(d\), and let \(t=(0\ a)\). Since \(t^2=e\), \(t\in T\). Yet \((td)^2(0)=t(d(a))=d(a)\ne0\), because \(d(0)=0\) and \(d(a)\notin\{0,a\}\). Hence \(td\notin T\), a contradiction.

If \(x\ne0\), choose \(a\in Q\setminus\{0,x\}\), possible since \(n\ge3\), and set \(t=(0\ a)\in T\). As \(t(x)=x\), we obtain \((td)^2(0)=t(d(x))=t(0)=a\ne0\). Again \(td\notin T\). The claim follows.

**4. Myhill–Nerode separation.** Suppose two reachable group states \(g,h\in S_n\) are distinct, and set \(d=g^{-1}h\ne e\). By the preceding claim, some \(t\in S_n\) has exactly one of \(t,td\) in \(T\). As all of \(S_n\) is generated by the alphabet actions, choose a continuation word \(u\) whose permutation is \(t g^{-1}\). From state \(g\), reading \(u\) reaches \(t\); from state \(h\), it reaches \(td\). Hence \(g\) and \(h\) have different right languages. All \(n!\) group states are reachable and pairwise distinguishable. Therefore \(\operatorname{sc}(\sqrt L)=n!\), achieving the general upper bound.

**5. Optimal alphabet size.** Over a unary alphabet, if the unique letter acts by the permutation \(s\), then reading \(ww\) with \(w=a^k\) applies \(s^{2k}\). An automaton on the original \(n\) states with letter action \(s^2\), the original initial state, and the original final set recognizes \(\sqrt L\). Thus unary inputs give at most \(n\) states for the root. Since \(n!>n\) when \(n\ge3\), unary alphabets cannot attain the factorial bound. The binary witness does.

## Verification
A standalone Python 3 checker (`artifacts/check_square_root.py`) exhaustively constructs the permutation group for each \(2\le n\le6\), checks original-state reachability and distinction, enumerates \(T\), computes its right stabilizer, and checks that the predicted minimal root complexity equals \(1\) at \(n=2\) and \(n!\) for \(3\le n\le6\). For \(3\le n\le5\), it additionally checks every ordered pair of group states for a distinguishing continuation. The expected terminal line is `ALL CHECKS PASSED`; its exact stdout is in `artifacts/check_output.txt`. These finite checks corroborate but do not replace the universal group-theoretic proof.

## Relationship to prior work
Caron, Hamel-De Le Court, Luque, and Patrou (2020), *New tools for state complexity*, Section 5.2, give the unrestricted DFA square-root worst-case \(n^n-\binom n2\), using the full transformation monoid. That theorem does not give the sharp worst case when every input letter is a permutation, because its witness uses nonbijective transformations. The present exact \(n!\) result is a restricted-class extremum, not a competing universal bound. Onishchenko (first publicly posted May 2, 2026) proves a different \(n^3\) bound for **nondeterministic** state complexity of square root. Hospodár and Mlynárčik (2020) examine permutation-language operations including the **concatenation square** \(L^2\), but not the fixed-word square-root operation in this theorem. The standard symmetric-group generating pair used here was already known; the separate contribution is the exact root-state separation and alphabet threshold.

## Limitations
The bound concerns complete DFAs for the fixed repetition \(ww\) of inputs recognized by **permutation DFAs**; it makes no new assertion about ordinary unrestricted DFAs, NFAs, or other powers \(w^k\). It does not count the number of distinct minimizing witnesses or optimize witness description length. Originality has been compared with identified primary literature and indexed research results, but differently formulated or unindexed earlier theorems remain possible. This result has not undergone independent scientific validation.
