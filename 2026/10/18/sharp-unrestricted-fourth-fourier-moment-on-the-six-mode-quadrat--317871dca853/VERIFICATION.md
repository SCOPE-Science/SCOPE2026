# Reproduction and evidence

Run `python3 checker.py` in a directory containing the standalone embedded script. The package includes the actual standard-output transcript as `checker_output.txt`.

The checker verifies exact equality of the coefficient dictionaries generated by 36 ordered convolution pairs and the closed fourth-moment polynomial (27 distinct monomial types). It also tests 600 deterministic random complex arrays against the modulus reduction and both analytic bounds, checks the nonuniform character-phase equality profile, confirms continuous/finite-grid agreement for grid orders 5, 6, 7, and 9, and tests strict alias excess at order 4.

The analytic proof in RESULT.md, not these finite checks, establishes the inequality and equality classification for all complex coefficients. There is no external independent audit and no claim that random tests exhaust the infinite coefficient space.
