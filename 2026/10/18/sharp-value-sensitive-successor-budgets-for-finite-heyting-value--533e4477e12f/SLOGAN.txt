For a finite Heyting truth-value algebra, the exact values of \(q\) modal boxes can always be preserved using at most \(q\operatorname{width}(J(L))\) successors, and this bound is sharp; the more precise minimum-witness budget for fixed output values is also attained. For any particular finite instance, optimal successor pruning is exactly a hypergraph hitting-set problem and is NP-complete already for Boolean depth-one models with an unbounded number of boxed atoms.
