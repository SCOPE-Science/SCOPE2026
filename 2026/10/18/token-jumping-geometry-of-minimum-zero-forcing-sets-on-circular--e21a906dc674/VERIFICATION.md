# Reproducibility and checks

Run `python3 verify_prism_reconfig.py` using Python 3.9+; no external packages are needed. The program independently constructs the underlying graphs and computes every legal force from a selected four-element initial configuration. For each integer \(n\) from \(6\) through \(15\), it tests all \(\binom{2n}{4}\) four-subsets and all \(\binom{2n}{3}\) three-subsets. It compares the successful four-subsets with the five explicit symmetry orbits, then constructs one-token reconfiguration adjacency through shared triples, testing component count, edge count, degree counts and the entire quotient matrix. The four-subset comparisons totaled exactly 91,992.

For \(n\in\{24,40,80\}\), it additionally constructs the full graph from the five proven symmetry orbits and verifies connectivity and the edge formula. These larger checks do not independently enumerate all initial four-subsets and are not presented as such. Output was recorded in `prism_reconfig_check_output.txt` and regenerated by running the standalone checker from the actual package.

**Proof limits:** No finite computation certifies every \(n\). The theorem relies on the explicit local orbit/intersection analysis and constructive paths in `RESULT.md`. The exhaustive test checks only the stated finite cases. No independent scientific audit has been performed.
