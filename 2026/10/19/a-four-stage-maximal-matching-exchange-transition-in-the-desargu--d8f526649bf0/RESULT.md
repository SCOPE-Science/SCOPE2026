# A four-stage maximal-matching exchange transition in the Desargues graph

## Finding
Let \(D=GP(10,3)\) be the Desargues graph on twenty vertices. For each integer \(k\), let \(\mathcal E_k(D)\) have as vertices the **inclusion-maximal** matchings consisting of exactly \(k\) graph edges. Join two states when one edge of the matching can be replaced by one different edge and the resulting same-size matching remains inclusion-maximal. Then the only nonempty layers are \(6\leq k\leq10\), with the complete classification
\[
\begin{aligned}
\mathcal E_6(D)&\cong5K_1,\\
\mathcal E_7(D)&\cong30C_4,\\
|V(\mathcal E_8(D))|&=1620,\quad |E(\mathcal E_8(D))|=3360,\quad\operatorname{diam}\mathcal E_8(D)=14,\\
|V(\mathcal E_9(D))|&=1120,\quad |E(\mathcal E_9(D))|=2160,\quad\operatorname{diam}\mathcal E_9(D)=12,\\
\mathcal E_{10}(D)&\cong60K_1.
\end{aligned}
\]
Both \(\mathcal E_8(D)\) and \(\mathcal E_9(D)\) are **connected**. Thus the same cardinality-preserving one-edge replacement rule yields isolated minimum maximal matchings, thirty four-cycles one level above minimum, full connectivity in the next two layers, and isolated perfect matchings at the top. There are \(2925\) maximal matchings in total.

## Assumptions and scope
The generalized Petersen model has vertices \(u_i,v_i\) indexed by \(i\in\mathbb Z/10\mathbb Z\), and the thirty undirected edges \(u_iu_{i+1}\), \(u_iv_i\), and \(v_iv_{i+3}\), with indices modulo ten. A matching is a set of edges with pairwise disjoint endpoints. It is *inclusion-maximal* if no additional graph edge can be inserted; this is not synonymous with maximum-cardinality matching. Equivalently, its unmatched vertices form an independent set. Exchanging an edge means deleting precisely one currently selected edge and inserting precisely one different edge, with the intermediate **final** state required to be inclusion-maximal and a matching. The temporary matching immediately after deletion is not required to be maximal. No moves changing the matching cardinality are allowed. Component diameter is the maximum graph distance over vertices of that component, with an isolated vertex assigned diameter zero.

## Proof
**Cardinality boundary.** The Desargues graph is connected, 3-regular and bipartite with ten vertices in each part; an explicit bipartite double-cover reconstruction is independently checked by the companion program. Its independence number is exactly ten: in any regular bipartite graph the degree count gives \(|N(S\cap A)|\geq|S\cap A|\), and the same for the other part, so an independent set has size at most one bipartition class. Moreover an independent set of size ten must equal one entire class: equality in both neighbor inequalities makes the two portions of the graph indexed by its selected and omitted parts nonadjacent, contradicting connectedness unless the set is one full side.

For a maximal \(k\)-matching, all \(20-2k\) unmatched vertices form an independent set. If \(k<5\), that number exceeds ten. If \(k=5\), the ten unmatched vertices would be a full bipartition class and the ten covered vertices would form the other side, which has no internal edge; this contradicts the existence of five matched edges. Thus \(k\geq6\). The matching with six edges
`(0,1), (3,13), (5,6), (8,18), (12,19), (14,17)`
using vertices \(0,\ldots,9=u_0,\ldots,u_9\) and \(10,\ldots,19=v_0,\ldots,v_9\) is inclusion-maximal; the exact checker tests its feasibility and all unmatched adjacencies. Ten is an upper bound by vertex-disjointness, and the programs exhibit states at every size from six through ten.

**Exhaustive counting certificate.** The first standalone program (`verify_generalized_petersen.py`) lexicographically constructs the thirty graph edges. It visits each include/exclude branch for each edge, disallowing an inclusion whose endpoints meet an earlier edge. Consequently **every matching appears exactly once**, and none of the generated sets fails matching feasibility. On reaching an assignment, it retains the state if and only if every graph edge meets the set of occupied endpoints. This is exactly inclusion-maximality, not an estimate or sample. Sorting the results by cardinality gives the state counts \(5,120,1620,1120,60\).

**Exact exchange graph.** For each retained state, the first program tries every deleted edge of that state and every graph edge absent from the state; a trial becomes a neighbor if and only if it belongs to the retained maximal-matchings lookup for the same cardinality. This exactly describes all allowed exchanges, not a subset of possible moves. Exhaustive breadth-first traversal gives the component counts and sizes. For each connected component it then runs breadth-first shortest paths from **every** state; the largest finite distance is therefore its exact diameter. The respective exchange-edge counts are \(0,120,3360,2160,0\); the component-size distributions are \(\{1:5\},\{4:30\},\{1620:1\},\{1120:1\},\{1:60\}\). In the seven-edge layer all vertices have exchange degree two; together with the observed thirty size-four connected components and simple undirected exchanges, each component is exactly \(C_4\). The ten-edge layer is isolated because exchanging a single edge of a perfect matching would require that replacement edge to have exactly the same two endpoints, impossible in a simple graph.

**Independent reconstruction.** The second standalone program (`verify_cover_independent.py`) constructs the Petersen graph as the disjointness graph of two-element subsets of a five-element set and constructs its Kronecker bipartite double cover, which is isomorphic to \(GP(10,3)\). It enumerates matchings by resolving the least uncovered vertex: leave it unmatched, or pair it with any remaining neighbor. At terminal states it tests independence of the unmatched vertices. Hence this search independently generates every inclusion-maximal matching once without inspecting edge-subset branches. For reconfiguration, it groups maximal matchings by their common \((k-1)\)-edge deletions and joins each pair in a group: precisely the one-edge exchanges. It then obtains components and all eccentricities with a separate graph traversal. Its complete invariant dictionaries agree byte-for-byte with those of the first implementation, including the diameters \(14\) and \(12\), which completes the finite proof.

## Verification
With Python 3.9 or later, in the directory containing these files, run `python3 verify_generalized_petersen.py` and `python3 verify_cover_independent.py`. They use only the standard library, produce the same canonical JSON output and terminate with `VERIFY_OK`. The files `verify_generalized_petersen.out` and `verify_cover_independent.out` are their recorded outputs. Verification includes both the small Petersen comparator and the Desargues graph; only the Desargues claims above are the finding. Both exhaustive searches and repeated all-source shortest-path searches are finite with termination witnessed by the provided run outputs. They are computational proof of an exact **finite** claim, not a theorem about arbitrary generalized Petersen graphs or an extrapolation from sampled cases.

## Relationship to prior work
Bousquet and collaborators study token-jumping reconfiguration of same-sized matchings, but their admissible intermediate matchings need not be inclusion-maximal. Their general graph does not establish the connectivity or diameters of this maximal-only induced subgraph. Mühlenthaler's degree-constrained subgraph reconfiguration similarly preserves degree bounds rather than the global edge-domination/maximality condition. Birand and collaborators use maximal matchings of this **same** Desargues graph in a local-pooling calculation and report the ratio \(3/5\), which relates to its previously known minimum maximal matching size six, but the paper does not classify exchange graphs. A published matching-complex computation gives the ordinary face-count vector and homotopy type for this graph; those data do not determine the adjacency of maximal faces under one-edge replacement. Skupień's maximal-matching results for the Petersen graph concern the smaller graph, not its bipartite double cover.

These distinctions are mathematical: counting all matchings or calculating homology does not reconstruct a facet-exchange graph; allowing nonmaximal intermediate states adds paths that are prohibited here. Levit and Mandrescu study uniqueness of maximum matchings in special graph families rather than reconfiguration of all inclusion-maximal matchings of this graph. No claim of novelty is made for the definition of maximal matching, the Desargues graph, or the previously known minimum size six.

## Limitations
The result classifies one canonical finite graph and one specifically defined exchange operation. It does not establish a family-wide connectivity theorem for generalized Petersen graphs, nor does it allow intermediate states of different sizes or nonmaximal matchings. The complete combinatorial counts and diameters depend on independently reproducible exhaustive computations and are not supplied as short handwritten formulas. Published indexes and inspected sources cannot rule out all unindexed or unpublished equivalent enumerations. A separate independent scientific audit has not been performed.
