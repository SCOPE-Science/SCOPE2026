# Reproducible verification and scientific limits

Run `python3 check.py` from the extracted package. The program uses only Python's standard library and tests finite differences of the original two-channel nonlinear incidence update, exact threshold-root residuals, zero-mediation cutoff ordering, coupled-channel leakage thresholds, and sample logarithmic/power scaling. The analytic proof in RESULT.md, not a finite cutoff test, establishes the all-parameter results and infinite-cutoff limits.
