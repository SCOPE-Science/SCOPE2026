# Reproducibility and verification

The analytic proof is in `RESULT.md`; it establishes the classification and count for every odd \(N\ge3\). The sole executable dependency is `verify.py`, which needs Python 3.9+ with NumPy 1.20+.

To repeat the finite numerical checks, run:

```sh
python verify.py
```

At preparation, the checker printed:

```
N=3: 6 exact permutation configurations checked
N=5: 120 exact permutation configurations checked
N=7: 5040 exact permutation configurations checked
N=9: 500 random configurations checked
VERIFY_OK
```

For each checked permutation the program constructs the canonical transition matrix and the centered circulant and verifies their similarity by exact comparison of integer-valued matrix entries. It computes subleading spectral radii with NumPy and checks the claimed equality classification numerically at absolute tolerance \(3\times10^{-8}\). It separately constructs the groups generated by independent swaps of reflection pairs and asserts their predicted cardinality.

The verification does not enumerate all permutations for \(N\ge9\), and floating-point eigenvalues do not certify exact equality. No infinite proof follows from this code alone; the Fourier equality-case argument, odd-power-sum identity, and group-intersection count supply that proof. Independent audit has not been performed.
