# Verification of the stated sampling theorem

Run `python3 check_dodeca.py` (Python 3 standard library). The code constructs all 20 exact dodecahedral vertices in the field generated by a root of \(\varphi^2=\varphi+1\), pairs antipodes and checks that every coordinate has squared radius three. It verifies the 10-by-10 odd evaluation determinant 1024 and the leading six-by-six even evaluation determinant 32; it checks the Petersen adjacency relation and explicit isomorphism to the edge-disjointness graph of \(K_5\).

It also compares the four-dimensional negative-eigenvalue projector against centered K5 edge-incidence Gram vectors, verifies the bipartite-component formula for all 1024 touched antipodal-pair patterns, enumerates all 210 four-pair subsets, and classifies all 4845 four-vertex erasures. Actual output: `EXACT_VERIFY_OK`; full-rank count 2960, rank-15 count 1840, rank-14 count 45.

Computations are finite exhaustive calculations over the specified vertices.
