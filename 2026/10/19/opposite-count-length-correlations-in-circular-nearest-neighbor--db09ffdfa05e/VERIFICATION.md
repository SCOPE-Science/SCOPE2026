# Reproducible finite checks

Execute `python3 verify.py` in an ordinary Python 3 environment; only the standard library is needed. The program verifies, with exact rational arithmetic, all \(3!+4!+5!+6!+7!+8!=46{,}230\) possible rank permutations of independent exponential gaps. Independent order-statistic increment formulas calculate means and second moments of weighted reciprocal minima on each chamber. Checks for \(n=5,6,7,8\) reproduce the displayed covariance and variance identities exactly. The proof, rather than the finite checks, establishes the formulas for all \(n\ge5\). No external formal certification or independent audit has been performed.
