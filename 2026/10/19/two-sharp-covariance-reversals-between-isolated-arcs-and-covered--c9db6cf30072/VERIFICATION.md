# Reproduction and limits

Run `python verify.py` with Python 3.10 or later from a directory containing that file. No external Python modules are required. The program checks exact rational moment formulas and validates numerical signs and root brackets using high-precision decimal arithmetic. The deterministic finite simplex grids are quadrature approximations, not complete proofs of all real thresholds. The complete proof of the two sign changes is the strict-convexity argument in `RESULT.md`. The earliest source's publication date is independently displayed as 2007-03-02 on the linked full-text primary article; priority is not independently certified.
