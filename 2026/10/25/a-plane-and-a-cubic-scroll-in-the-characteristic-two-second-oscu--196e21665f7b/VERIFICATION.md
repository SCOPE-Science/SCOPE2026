# Reproducibility
Run `python CHECKER.py` in a Python environment with SymPy. The program recomputes all characteristic-two polynomial identities from symbolic integer polynomials modulo two, tests four smooth-scroll local charts, and exhausts projective \(\mathbb F_2\)-rational points. Expected output includes `PASS` and rational singular-locus counts \(7,9,3,13\). The proof is independent of this finite census. The method does not compute the full nonreduced Jacobian scheme, settle historical novelty, or supply an independent audit.
