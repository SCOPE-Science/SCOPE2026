# A sharp forest-width classification of unary automata and one-hole state complexity

## Finding
For a unary regular language \(L\), define \(w(L)\) as the smallest treewidth of the simple undirected transition support of an epsilon-free, loop-free nondeterministic finite automaton with one initial state that recognizes \(L\). Then
Then \(w(L)=0\) exactly for the empty language or the empty-word language; \(w(L)=1\) for all remaining eventually two-periodic languages; and \(w(L)=2\) otherwise.
The second case means that some integer \(N\) satisfies \(a^n\in L\iff a^{n+2}\in L\) for every \(n\ge N\). In addition, for every integer \(m\ge1\), a forest-support automaton recognizing the cofinite language \(L_m=\{a^n:n\ge0,\ n\ne m\}\) has at least \(m+3\) states, and that bound is achieved by a deterministic automaton with path support.

## Assumptions and scope
Automata are finite and unary, with a single initial state, any subset of final states, partial and nondeterministic transitions, **no epsilon transitions**, and **no directed self-loops**. Both directed arcs on the same unordered vertex pair are allowed. The undirected support is a simple graph: it has an edge when at least one directed transition links its endpoints. Treewidth zero means edgeless; treewidth one means forest. The state count includes inaccessible states, although they cannot help minimize. The exact one-hole state bound is claimed only for positive integer \(m\); the empty-word hole is excluded.

## Proof
The support of a directed forest is bipartite. Let an accepting run be a walk in that forest. Every walk with at least as many edges as vertices repeats a vertex, and a nonsimple walk in a forest contains two consecutive transitions from one vertex to a neighbor and immediately back. Both directed arcs occur on this accepting run. Repeating the resulting two-step closed subwalk arbitrarily often yields accepting runs of all lengths obtained by adding nonnegative even increments. If infinitely many lengths of a fixed parity are accepted, one sufficiently long accepting walk consequently forces every larger length of that parity to be accepted. Each parity therefore has either finitely many accepted lengths or an eventual full tail. This is eventual two-periodicity.

Conversely let membership be eventually two-periodic, with cutoff \(N\ge1\). Take the directed path \(q_0\to q_1\to\cdots\to q_{N+1}\) together with the return arc \(q_{N+1}\to q_N\). Choose initial state \(q_0\), and mark \(q_j\) final precisely when length \(j\) belongs to the language for \(j<N\), and mark \(q_N,q_{N+1}\) in accordance with the periodic tail. This partial deterministic unary automaton has forest support. The no-edge automata recognize precisely the empty language and the language containing only the empty word.

Every unary regular language has an eventually periodic membership sequence. Take a period \(p\) and an eventual cutoff; replace the period by an even multiple \(k=\operatorname{lcm}(p,2)\). A directed path feeding a directed simple cycle of length \(k\), with appropriate final states, recognizes the language. When the language is not eventually two-periodic, \(k\ge4\); the underlying support is a unicyclic graph with a pendant path, and hence has treewidth exactly two. Forest support is impossible by the first paragraph. This proves the three cases.

For \(m\ge1\), the deterministic path of states \(q_0,\ldots,q_{m+2}\) with transitions \(q_j\to q_{j+1}\) for \(0\le j\le m+1\), plus \(q_{m+2}\to q_{m+1}\), and final states all except \(q_m\), accepts exactly the lengths different from \(m\). Its simple support is a path, using \(m+3\) states. Conversely, in any forest-support automaton for this language, an accepting run of length \(m+2\) cannot have a consecutive reversed pair of edges: deleting that pair would give an accepting run of length \(m\), which is forbidden. Every nonsimple walk in a forest has such a reversed pair. Thus this accepting run is a simple path with \(m+3\) distinct states, proving the lower bound. The argument permits nondeterminism, arbitrary orientation of distinct edges, and multiple final states.

## Verification
An independent standalone enumeration script iterates over all directed arc choices on each unordered state pair for state counts one through four, keeps exactly the configurations with undirected forest support, and follows the finite reachable-subset dynamics from the singleton initial state. The enumerated graph counts are \(1,4,37,586\), respectively. In all \(628\) cases the eventual reachable-subset period is at most two. This finite test is a consistency check, not the proof of the classification or the sharp infinite state bound. Reproduce using `python3 verify.py`; the run output appears in `verify_output.txt`.

## Relationship to prior work
Grobler, Koziel, and Siebertz (2026), *Every Regular Language Has a Bipartite Cactus Automaton*, proves a general bipartite-cactus representation theorem. That provides relevant motivation for examining whether the graph restriction can be sharpened to a forest for unary languages. The result above identifies precisely when this strengthening is possible and also determines a natural family of exact forest-state costs. The published 2021 article of Kutrib, Malcher, and Schneider treats automata whose transition relation is symmetric, a stricter orientation requirement than undirected **support** being a forest. Its unary language classification therefore cannot be substituted directly for the present statement.

## Limitations
The graph classification concerns unary **regular** languages and the particular loop-free epsilon-free support model defined above; it does not classify state complexity for all eventually two-periodic languages. The sharp forest-state optimum is established for the single missing positive length only. The full text of the 2026 motivating preprint could not be inspected; an equivalent result in that source or other unindexed literature remains an originality risk. No independent external mathematical audit has been performed.
