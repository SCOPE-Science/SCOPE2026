# Verification record
The analytic proof uses standard Thue–Morse substitution recognizability, explicit Birkhoff-sum identities, Chinese remainder cohomology, and a primitive decorated substitution. Run `python3 verify.py` with the Python standard library. Tests are exact finite congruences, substitution checks, and finite word-support checks; they do not substitute for the universal proof.
