# Reproducibility and evidence

Run both bundled standalone standard-library programs in a directory containing the four script/output artifacts:

```
python3 prism_morse_certificate.py > morse_replay.txt
python3 prism_f2_independent.py > f2_replay.txt
cmp morse_replay.txt prism_morse_certificate_output.txt
cmp f2_replay.txt prism_f2_output.txt
```

The Morse script enumerates all nonempty matchings for each \(3\le n\le8\), applies the explicit face-pairing permutations, tests acyclicity on all complete Hasse edges, and computes every signed integral Morse boundary between neighboring critical-cell dimensions. The face counts are 31, 107, 341, 1,103, 3,543, 11,395. The matching-pair counts are 12, 51, 168, 545, 1,764, 5,691. Full verification of acyclicity examines 48, 252, 1,020, 4,002, 15,022, and 55,272 Hasse coverings. The \(n=5\) signed Morse boundary is zero, while the \(n=8\) boundary is a rank-one integer matrix with a unit entry and no other nonzero invariant factor. These are complete finite certificates, not sampling.

The independent program enumerates matching faces from vertex-occupancy rules and performs original mod-two simplicial-chain rank elimination, obtaining reduced Betti vectors \((6),(4),(2,2),(12),(14),(3,7)\) in their respective nonzero dimensions. The mod-two check corroborates but does not establish integral homotopy.

The attached numerical outputs were generated by actually running the attached scripts. Proof scope excludes any \(n>8\); broad bibliographic novelty is not formally certified, and independent scientific audit has not been performed.
