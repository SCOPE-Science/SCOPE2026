# Reproducibility
Run `python3 verify.py` with Python 3.10 or newer and no external packages. The verifier enumerates the raw \(\binom{k+2}{2}\) degree-\(k\) monomials for every integer \(1\le k\le8\), computes the minimal nonnegative-additive generating list in increasing order, and compares it with the claimed formula. It independently checks that every raw monomial is generated by the proposed list and that deleting any proposed generator makes that element unreachable from the rest.

Observed generator counts: `3, 5, 7, 9, 11, 13, 15, 17`; observed terminal line: `VERIFY_OK`. The algorithm checks only finitely many exponents, while the general theorem is established by the written reduction and valuation proof. No external validation has been conducted.
