# Reproducible verification

Run `python3 verify.py` using Python 3 and the standard library only. The program constructs the original permutation-matrix context, forms all intersections of its models, derives every closed set independently of the theorem, checks all intervals against the Möbius defining recurrence, and tests the one-round Horn rules on every atom subset for \(n=2,3,4\). It also checks strict log-concavity and signed chessboard matching counts against the Möbius value.

Completed output:

EXHAUSTIVE 2 closed 4 intervals 9 ranks [1, 2, 1] mobius 1 PASS
HORN 3 subsets 512 necessary_premises 36 one_round=PASS

HORN 4 subsets 65536 necessary_premises 144 one_round=PASS

The sum is 66,064 raw assignments and 798 intervals. No homology computation or topological simple-homotopy certificate is generated by this program; the all-size homotopy equivalence is proved using a published poset fiber theorem. A finite computation cannot prove the infinite-parameter conclusions.
