# Verification evidence

Execute `python3 verify.py` in a directory containing this file and the packaged checker. It enumerates all partial injections on bases with one through six points and checks every rank/parameter stratum by actual semigroup products against the formula. It separately checks 70 noncanonical sandwich maps and the exact moment identity for integers up to 29. A passing test prints `ALL_SANDWICH_NILPOTENT_CHECKS_PASSED 139 exhaustive rank strata 103771 evaluated elements 70 noncanonical sandwiches`.

The proof of the infinite parameter family is mathematical inclusion-exclusion, followed by a probability argument. Exhaustive tests of small dimensions are not an infinite proof. The historical originality comparison includes materially read primary texts and specifies an uninspected 2004 full text as a residual risk. Independent external mathematical audit is not performed.
