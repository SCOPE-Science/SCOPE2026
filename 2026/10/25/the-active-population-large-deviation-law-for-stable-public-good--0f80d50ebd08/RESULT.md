# The active-population large-deviation law for stable public-goods equilibria on paths

## Finding

Fix an externality parameter \(\delta\in(1/\varphi,1)\), where \(\varphi=(1+\sqrt5)/2\), in the linear public-goods network game with best response
\[
x_i=\max\!\left(0,1-\delta\sum_{j\sim i}x_j\right).
\]
Let \(P_n\) be the path on \(n\) vertices. Count each locally asymptotically stable equilibrium of the random-order best-response process once, and choose one uniformly from this finite set. If \(A_n\) is its number of active vertices, then the number \(c_{n,a}\) of stable equilibria with exactly \(a\) active vertices is
\[
c_{n,a}=\binom{2n-3a+3}{2a-n-1}
\]
whenever \(k=n-a+1\ge1\) and \(m=2a-n-1\) satisfies \(0\le m\le\lceil k/2\rceil\); otherwise \(c_{n,a}=0\).

All logarithms are natural. Define the binary entropy \(H(q)=-q\log q-(1-q)\log(1-q)\), with \(0\log0=0\), and
\[
h(\alpha)=(2-3\alpha)\,
H\!\left(\frac{2\alpha-1}{2-3\alpha}\right),
\qquad \frac12\le\alpha\le\frac35.
\]
Let \(\lambda>1\) be the positive solution of \(\lambda^5=\lambda^3+1\). The active fraction \(A_n/n\) obeys a large-deviation principle with rate
\[
I(\alpha)=
\begin{cases}
\log\lambda-h(\alpha),&\alpha\in[1/2,3/5],\\
+\infty,&\text{otherwise}.
\end{cases}
\]
For every closed set \(F\subset\mathbb R\) and every open set \(G\subset\mathbb R\), the rate function satisfies
\[
\limsup_{n\to\infty}\frac1n\log\Pr(A_n/n\in F)\le-\inf_{\alpha\in F}I(\alpha),
\qquad
\liminf_{n\to\infty}\frac1n\log\Pr(A_n/n\in G)\ge-\inf_{\alpha\in G}I(\alpha).
\]
The rate has a unique zero at
\[
\alpha_*=\frac{1+3r^3}{2+5r^3}
=0.5569404629\ldots,
\qquad r=\lambda^{-1},\quad r^2+r^5=1.
\]
Thus, under uniform selection from stable equilibria, the active fraction concentrates exponentially near approximately \(55.694\%\). This is a counting-measure benchmark, not a claim about the absorption probabilities of the random dynamics.

## Assumptions and scope

The graph is the unweighted path \(P_n\), the activity constraints are \(x_i\in[0,1]\), and \(\delta\) is fixed strictly inside \((1/\varphi,1)\). Stability means local asymptotic stability in probability under single-vertex best-response updates chosen uniformly at each discrete time. Equilibria are counted as distinct stable strategy profiles. On this open parameter interval, the block conditions below are strict, so the admissible support sequence identifies a unique stable equilibrium. The result concerns the distribution across stable equilibria, not the distribution generated by any specified initial condition or update trajectory.

## Proof

The published path classification for this parameter interval says that each stable active set is a sequence of blocks of size \(1\) or \(2\), separated by exactly one inactive vertex, and no two size-\(2\) blocks can be consecutive. The conditions can also be checked directly. A singleton block has activity \(1\); the two vertices in a size-\(2\) block each have activity \(1/(1+\delta)\). An inactive separator between two singleton blocks is valid because \(2\delta>1\). A separator between a singleton and a size-\(2\) block is valid precisely when
\[
\delta\left(1+\frac1{1+\delta}\right)>1
\quad\Longleftrightarrow\quad
\delta^2+\delta-1>0,
\]
which holds for \(\delta>1/\varphi\). A separator between two size-\(2\) blocks would require \(2\delta/(1+\delta)\ge1\), impossible for \(\delta<1\). A size-\(3\) block has no all-positive equilibrium for \(\delta>1/2\): symmetry gives \(x_1=x_3=1-\delta x_2\) and \(x_2=(1-2\delta)/(1-2\delta^2)\); for \(1/2<\delta<1/\sqrt2\) the middle value is negative, while for \(1/\sqrt2<\delta<1\) the endpoint value \(x_1=(1-\delta)/(1-2\delta^2)\) is negative, and at \(\delta=1/\sqrt2\) the equations are inconsistent. For every block length \(\ell\ge4\), the magnitude of the smallest adjacency eigenvalue is \(2\cos(\pi/(\ell+1))\ge2\cos(\pi/5)=\varphi\), so stability requires \(\delta<1/|\lambda_{\min}(P_\ell)|\le1/\varphi\), impossible in the stated interval.

Suppose a configuration has \(k\) active blocks and \(m\) of those blocks have size \(2\). Its active population is \(a=k+m\), and the \(k-1\) inactive separators give
\[
n=a+k-1=2k+m-1.
\]
Hence \(k=n-a+1\) and \(m=2a-n-1\). Choosing \(m\) nonconsecutive positions for the size-\(2\) blocks among \(k\) positions can be done in \(\binom{k-m+1}{m}\) ways. Substitution yields
\[
c_{n,a}=\binom{k-m+1}{m}
=\binom{2n-3a+3}{2a-n-1},
\]
with the stated feasibility conditions.

For the joint generating function, assign weight \(t=x^2y\) to a size-\(1\) block and \(u=x^3y^2\) to a size-\(2\) block. The exponent of \(x\) counts each active vertex and its following separator; subtract one final \(x\) because the last block has no trailing separator. The generating function of nonempty block words with no consecutive size-\(2\) symbols is
\[
S(t,u)=\frac{t+u+tu}{1-t-tu}.
\]
Consequently,
\[
F(x,y)=\sum_{n\ge1}\sum_a c_{n,a}x^ny^a
=\frac{xy+x^2y^2+x^4y^3}{1-x^2y-x^5y^3}.
\]
At \(y=1\), the denominator is \(1-x^2-x^5\). Its unique singularity of smallest modulus is the positive simple root \(r\in(0,1)\) of \(r^2+r^5=1\): equality in \(|z^2+z^5|\le |z|^2+|z|^5\) on \(|z|=r\) forces \(z^2\) and \(z^5\) to have the same positive phase, and \(\gcd(2,5)=1\) then forces \(z=r\). Thus the total number of stable equilibria grows as \(C\lambda^n\), with \(\lambda=1/r\) and \(\lambda^5=\lambda^3+1\).

For \(a/n\to\alpha\in(1/2,3/5)\), Stirling's formula applied to the exact binomial coefficient gives
\[
\frac1n\log c_{n,a}\longrightarrow
(2-3\alpha)\log(2-3\alpha)
-(2\alpha-1)\log(2\alpha-1)
-(3-5\alpha)\log(3-5\alpha)
=h(\alpha).
\]
The same expression extends continuously to the endpoints with \(h(1/2)=h(3/5)=0\). There are at most \(n\) feasible active counts, so summing these coefficients has the same exponential scale as their maximum; normalizing by the total count gives the stated rate function \(I=\log\lambda-h\). This is the finite-type Laplace principle, with Stirling's estimate uniform over the feasible integer range.

To identify the typical active fraction, differentiate on \((1/2,3/5)\):
\[
h'(\alpha)=
\log\frac{(3-5\alpha)^5}{(2-3\alpha)^3(2\alpha-1)^2},
\]
and
\[
h''(\alpha)=
-\frac{25}{3-5\alpha}
+\frac9{2-3\alpha}
-\frac4{2\alpha-1}<0.
\]
The strict inequality follows after putting the terms over a common positive denominator: its numerator is
\[
-25B^2-20BC-4C^2<0,
\quad B=2\alpha-1>0,\quad C=3-5\alpha>0,
\]
using \(2-3\alpha=B+C\). Hence \(h\) has a unique maximizer. Setting \(s=r^3\) and \(\alpha_*=(1+3s)/(2+5s)\) gives
\[
2-3\alpha_*=\frac{1+s}{2+5s},\quad
2\alpha_*-1=\frac{s}{2+5s},\quad
3-5\alpha_*=\frac1{2+5s}.
\]
The identity \(r^2(1+r^3)=1\) implies \(s^2(1+s)^3=1\), so \(h'(\alpha_*)=0\). Strict concavity makes this the unique maximizer; substitution also gives \(h(\alpha_*)=\log(1/r)=\log\lambda\). Therefore \(I\) has its unique zero at \(\alpha_*\), and the large-deviation bounds imply exponential concentration of \(A_n/n\) there.

## Verification

The analytic proof covers every \(n\) and every fixed \(\delta\in(1/\varphi,1)\); it does not infer an infinite statement from computation. The included standalone script independently enumerates admissible block words and checks the exact coefficient formula and total-count recurrence for \(1\le n\le25\). These finite checks are consistency checks only. Numerical values were obtained from the unique root of \(r^2+r^5=1\); the formulas, not the decimals, define the constants exactly.

## Relationship to prior work

Misiak and Dziubiński classify stable path equilibria in this same parameter interval and derive the total-count recurrence \(e_n=e_{n-2}+e_{n-5}\) with initial values \(e_1=1,e_2=1,e_3=1,e_4=2,e_5=1\). Their result supplies the block structure and total growth rate used here. The present refinement counts equilibria by active population and derives the full exponential rate profile under uniform selection; it does not claim a new classification of stable supports.

Bramoullé, Kranton, and D’Amours characterize equilibria and stability in linear network games through network and active-subgraph spectral properties. Chadha and Kulkarni study maximum aggregate play and welfare, including path and tree networks. Those results address equilibrium feasibility, stability, or extrema over equilibria, rather than the exponential distribution of active populations across all stable path equilibria.

## Limitations

The uniform distribution over stable equilibria is a mathematical counting measure, not a behavioral or dynamical equilibrium-selection model. The large-deviation statement does not give the probability that a random-order trajectory reaches a particular equilibrium. The result is restricted to unweighted paths and \(\delta\in(1/\varphi,1)\); other graph families or parameter intervals require new support classifications. Novelty is assessed against the inspected literature and database searches, not guaranteed against all unpublished or unindexed work.
