For each fixed run budget \(2k+1\) and alphabet size \(q\ge2\), the maximum number of distinct scattered palindromes is \(n^{k+1}/[2^k(k+1)^{k+1}]+O_{q,k}(n^k)\). Asymptotically optimal words have a palindromic run-symbol skeleton, equally long paired outer runs, and a central run twice as long as each outer run.
