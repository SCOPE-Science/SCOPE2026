# A four-element obstruction to existential-fusion preservation

## Finding

There is a four-element finite commutative residuated chain, with truth filter generated by its monoid unit, for which a homomorphism between one-point models destroys the truth of an existential-positive sentence when the syntax is allowed to use residuated fusion. Four is the smallest possible carrier size for such a counterexample in this unit-generated-filter setting.
Equivalently, the sentence \(\exists x\exists y\,(R(x)\otimes P(y))\) is true in a one-point model and false in a homomorphically related one-point model, and four is the minimum source-algebra size for this failure in the fragment generated by \(\exists,\wedge,\vee,\otimes\).

The sentence is

\[
\exists x\exists y\,(R(x)\otimes P(y)).
\]

This is a failure for the fragment using fusion \(\otimes\), not a failure of the classical finite homomorphism preservation theorem for the fragment using only lattice conjunction \(\wedge\), lattice disjunction \(\vee\), and existential quantification.

## Assumptions and scope

Let the carrier be \(A=\{\bot,a,e,b\}\), linearly ordered by
\[
\bot<a<e<b.
\]
The lattice operations are minimum and maximum. The monoid unit is \(e\), which is strictly below the lattice top \(b\), so the algebra is nonintegral. Define the commutative fusion operation \(\otimes\) by the following table.

| \(\otimes\) | \(\bot\) | \(a\) | \(e\) | \(b\) |
|---|---:|---:|---:|---:|
| \(\bot\) | \(\bot\) | \(\bot\) | \(\bot\) | \(\bot\) |
| \(a\) | \(\bot\) | \(a\) | \(a\) | \(b\) |
| \(e\) | \(\bot\) | \(a\) | \(e\) | \(b\) |
| \(b\) | \(\bot\) | \(b\) | \(b\) | \(b\) |

The truth filter is \(F=\uparrow e=\{e,b\}\). The relevant fragment is generated from atomic predicates by existential quantification, lattice meet \(\wedge\), lattice join \(\vee\), and fusion \(\otimes\); residual implication is not included. The models have one-element domains, so every existential quantifier is witnessed and all formula values are defined.

## Proof

**The algebra is residuated.** The element \(e\) is an identity and \(\bot\) is absorbing. On nonbottom elements, a product is \(b\) if at least one factor is \(b\); otherwise it is \(a\) if at least one factor is \(a\); otherwise it is \(e\). This rule proves associativity, and the table is commutative and monotone in each argument. On a finite chain every monotone map preserves binary joins; because multiplication by any fixed element also sends \(\bot\) to \(\bot\), it preserves all joins. Therefore each map \(y\mapsto x\otimes y\) has a right adjoint, explicitly
\[
x\to z=\max\{y\in A:x\otimes y\le z\}.
\]
It follows that \(x\otimes y\le z\) if and only if \(y\le x\to z\). Thus this is a bounded commutative residuated chain. The set \(F=\{e,b\}\) is a proper prime lattice filter and is exactly the upset generated by the unit.

**The homomorphism changes sentence truth.** Let \(M\) and \(N\) have the same one-element domain \(\{u\}\) and the same algebra \((A,F)\). Set
\[
R^M(u)=a,\qquad P^M(u)=b,
\]
and
\[
R^N(u)=a,\qquad P^N(u)=e.
\]
Take the identity algebra map and identity domain map. The domain map is a protomorphism: the only designated atomic value in the source is \(P^M(u)=b\), and its target value \(P^N(u)=e\) is also designated; the value \(R^M(u)=a\) is not designated, so it imposes no condition. Hence the pair is a homomorphism of the many-valued models.

Since both domains are singletons, the value of the displayed sentence in \(M\) is
\[
R^M(u)\otimes P^M(u)=a\otimes b=b\in F,
\]
whereas its value in \(N\) is
\[
R^N(u)\otimes P^N(u)=a\otimes e=a\notin F.
\]
Thus the sentence is true in \(M\) and false in \(N\), proving failure of preservation.

**Minimality of the carrier size.** A nontrivial residuated algebra cannot have its monoid unit equal to the lattice bottom, since the bottom is absorbing. If the carrier has fewer than four elements and the unit is not the lattice top, its only possible three-element order is \(\bot<e<b\). With the unit-generated truth filter, the designated values are \(\{e,b\}\); the only undesignated value is \(\bot\). Because \(\bot\) is absorbing for fusion, a designated value of a fusion node in this three-element chain is possible only when both inputs are designated. By induction on the formula, choosing a true disjunct at each join and a witness at each existential quantifier, every true existential-fusion-positive sentence has a witnessing branch whose atoms are all designated. A homomorphism preserves those atomic truth values; fusion preserves designatedness because it is monotone and \(e\otimes e=e\), and lattice meet and join preserve designatedness by the filter property. Hence no source algebra of fewer than four elements can witness this failure. If the unit is the top, then the algebra is integral and a fusion product can equal the top only when both factors are the top, so the same preservation argument applies. The four-element example attains the lower bound.

The accompanying dependency-free script checks the multiplication table exhaustively for commutativity, associativity, monotonicity, unit, bottom absorption, and the residuation equivalence for all \(4^3\) triples. It also checks the two sentence values and the atomic truth-preservation condition for the displayed homomorphism. The minimality argument is proved above rather than inferred from finite enumeration.

## Relationship to prior work

Carr's study of homomorphism preservation for many-valued structures proves a finite preservation theorem for the fragment built from existential quantification and lattice conjunction/disjunction. It separately exhibits failure when residuated conjunction is admitted in a nonintegral UL-chain and discusses preservation questions for nonintegral algebras. That example establishes the qualitative obstruction but uses an infinite truth-value algebra. The present result gives an explicit four-element finite residuated chain and proves that no smaller source carrier can witness this particular kind of failure. Brinke, Dawar, Grädel, and Pago study preservation in semiring semantics with a different homomorphism condition based on value-order inequalities; their lattice-semiring theorem does not directly cover the designated-filter semantics used here. This result does not contradict the finite homomorphism preservation theorem for the lattice fragment.

## Limitations

The result is a minimal counterexample for the stated unit-generated-filter semantics and existential-positive syntax extended by fusion. It does not classify all finite residuated chains, all designated filters, or all fragments involving residual implication.
