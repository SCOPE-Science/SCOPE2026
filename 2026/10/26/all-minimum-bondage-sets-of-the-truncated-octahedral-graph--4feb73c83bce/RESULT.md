# All minimum bondage sets of the truncated-octahedral graph

## Finding
Let \(T\) be the 24-vertex truncated-octahedral graph (equivalently, the Cayley graph on \(S_4\) generated by its three adjacent transpositions). A **bondage set** is an edge set \(F\) such that deleting \(F\) strictly increases the domination number. For this graph the minimum possible size is five [1].

**Theorem.** Exactly **276** five-edge sets are bondage sets in \(T\). Under its full graph automorphism group of order 48, they form **eight orbits**, of sizes
\[
12,\quad24,\quad24,\quad24,\quad48,\quad48,\quad48,\quad48.
\]
Every such set isolates at least one vertex by deleting all three incident edges. Exactly 240 sets isolate one vertex and exactly 36 isolate two vertices; none isolate more than two. Every vertex is isolated by exactly 13 of these 276 minimum bondage sets.

For an explicit complete classification, order the vertices lexicographically as the permutations of \((0,1,2,3)\). Number an edge when first encountered in the following traversal: for vertex indices \(i=0,\ldots,23\), and adjacent transposition positions \(j=0,1,2\) in that order, include edge \(\{i,q\}\) precisely if the index \(q\) of the swapped permutation exceeds \(i\). This produces edge indices \(0,\ldots,35\). The eight orbit representatives, with orbit sizes, are:

| Five edge indices | Orbit size |
| --- | ---: |
| (0,1,2,5,6) | 12 |
| (0,1,2,3,4) | 24 |
| (0,1,2,8,22) | 24 |
| (0,1,2,9,16) | 24 |
| (0,1,2,3,14) | 48 |
| (0,1,2,5,9) | 48 |
| (0,1,2,7,8) | 48 |
| (0,1,2,9,10) | 48 |

Thus the census is an exact classification of **all optimal edge-failure configurations**, not just a witness that five edges suffice.

## Assumptions and scope
A dominating set \(D\subseteq V(T)\) contains every vertex or a neighbor of every vertex. Write \(\gamma(T)\) for its minimum cardinality. Deleting edges does not remove vertices. The graph \(T\) has 24 vertices, 36 edges, and degree three, so a dominating set has cardinality at least six. A bondage set \(F\) obeys \(\gamma(T-F)>\gamma(T)\). All edge sets are unordered and all vertices and edges are labelled by the canonical permutation construction above; automorphism-orbit counts discard that labelling as indicated.

## Proof
The proof is finite but **exhaustive**, with an independently coded second enumeration. The two included programs implement the following complete reduction and all finite calculations. No probabilistic estimate or partial sample is used.

**1. Identify the graph and minimum dominating sets.** Adjacent transpositions generate a connected cubic graph on the 24 permutations of four symbols. The graph is the truncated octahedral graph [2]. Enumerate each \(k\)-subset for \(k=6,7,8\) and test whether the bitwise union of its closed neighborhoods is all 24 vertices. Exact counts for these three layers are respectively \(0,0,1767\). Since each closed neighborhood has size four, there are no smaller dominating sets. Hence \(\gamma(T)=8\), and the family \(\mathcal D\) of all minimum dominating sets has exactly 1767 members.

**2. Reduce bondage to explicit covering.** For \(D\in\mathcal D\) and \(v\notin D\), define
\[
E(D,v)=\{\{u,v\}\in E(T):u\in D\}.
\]
This set is nonempty and has one, two or three edges. Because \(v\notin D\), the set \(D\) fails to dominate \(v\) in \(T-F\) if and only if \(E(D,v)\subseteq F\). Consequently,
\[
\gamma(T-F)>8\quad\Longleftrightarrow\quad
\forall D\in\mathcal D\ \exists v\notin D:\ E(D,v)\subseteq F.
\]
The reverse implication holds because deleting edges cannot create a dominating set of fewer than eight vertices. This logical equivalence is exact for every edge set \(F\), with no reliance on a particular algorithm.

**3. Exhaust the minimum-size failures.** There are \(\binom{36}{5}=376992\) five-edge subsets. For every such \(F\), form the set of \(D\in\mathcal D\) killed by a contained pattern \(E(D,v)\). Exactly 276 of the 376992 sets kill all 1767 members. An independent verifier directly deletes the five edges, recomputes all 24 closed neighborhoods, and tests every original minimum dominating set until a survivor is found. It also obtains 276, by a disjoint computational route.

**4. Classify by stars and symmetry.** Check the three incident edges of every vertex against all 276 successful failures. Exactly 240 contain the full star of one vertex and exactly 36 contain the full stars of two vertices; no successful five-set lacks a full star. By vertex-transitivity, the total count of star incidences, \(240+2\cdot36=312\), gives exactly \(312/24=13\) configurations per vertex.

Permuting the four symbol values and optionally reversing the four permutation positions gives 48 distinct graph automorphisms. This is the complete automorphism group of the truncated-octahedral graph [2]. Applying the 48 maps to each of the 276 edge subsets gives the eight disjoint orbits and exact representatives shown in the table. Their sizes sum to 276, completing the classification.

## Verification
Run `python3 verify.py` (standard library only). It independently generates all vertices and edges, enumerates every six-, seven-, and eight-vertex candidate, checks every five-edge failure by the exact \(E(D,v)\)-criterion, and constructs all 48 automorphisms and the complete orbit partition. It returns `VERIFY_OK`, the counts 1767 and 276, and the eight representative-orbit pairs.

For an algorithmically distinct replay, run `g++ -O3 -std=c++17 verify_direct.cpp -o verify_direct && ./verify_direct`. This enumerator reconstructs the reduced graph **for each** of the 376992 five-edge deletions and directly recomputes domination from the resulting closed neighborhoods. It prints `FAILURE_COUNT=276`. Both checks were run successfully from the packaged source files.

## Relationship to prior work
Srivastava [1] established \(\gamma(T)=8\) and the bondage number \(b(T)=5\), thereby giving a counterexample to the planar inequality \(b(G)\le\Delta(G)+1\). Those results are prior work, **not** claimed here. The present exact 276-count, eight-orbit classification, and universal vertex-isolation property refine the extremal five-edge configurations. The standard permutation-graph realization and order-48 automorphism group are recorded in [2].

## Limitations
This is a complete finite census for a single named 24-vertex graph, not a theorem about all planar or cubic graphs. The computation supplies an exhaustive finite proof, not an analytic classification for arbitrary graph orders. A complete independent mathematical audit and historical-priority determination have not been performed. The primary preprint [1] could be inspected via its public abstract and bibliographic record, but its complete text was not available through the attempted public access paths; an unstated enumeration or appendix remains a residual priority risk.
