# Reproduction

Use Python 3 with SymPy and NumPy and a C++17 compiler. From the directory containing the embedded files, run:

```
python genquartic_maps.py
python quartic_representative_check.py
python quartic_walsh.py
python quartic_nets_walsh.py
c++ -std=c++17 -O3 quartic_pencil_count.cpp -o quartic_pencil_count
./quartic_pencil_count
c++ -std=c++17 -O3 quartic_orbit_count.cpp -o quartic_orbit_count
./quartic_orbit_count
c++ -std=c++17 -O3 nets_direct.cpp -o nets_direct
./nets_direct
```

Compare the exact counters against `verification_results.txt`. The binary arrays `smoothquartic.bin` and `quartic_gentable.bin` are regenerated by `genquartic_maps.py`; `smoothquartic_orbits.json` is also regenerated. The supplied `quartic_reps.csv` contains 78 exact representatives matching the generator's `smooth_orbits`. The Walsh approach and C++ approach independently compute autocorrelations, while sharing the explicitly algebraic smoothness classification. The `quartic_direct_check.py` script can check any chosen coefficient-mask interval independently by affine Gröbner tests (for example `python quartic_direct_check.py 1 5001`); partial intervals are not used as evidence of complete enumeration. The complete indicator is verified instead at all 279 projective-form orbits, with each member related by invertible substitutions.

These checks are exact finite certificates conditional on correct execution of the supplied ordinary programs and libraries. An external independent audit has not been performed.
