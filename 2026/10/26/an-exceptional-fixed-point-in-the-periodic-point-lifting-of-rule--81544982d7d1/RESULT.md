# An exceptional fixed point in the periodic-point lifting of Rule 54

## Finding

Let \(F:\{0,1\}^{\mathbb Z}\to\{0,1\}^{\mathbb Z}\) be elementary cellular automaton Rule 54, with
\[
(Fx)_i=f(x_{i-1},x_i,x_{i+1}),\qquad
f(a,b,c)=1\ \text{exactly for }abc\in\{001,010,100,101\}.
\]
Put \(Y=F(\{0,1\}^{\mathbb Z})\). For every positive integer \(n\), write \(P_n=\{x:\sigma^n x=x\}\), the configurations whose spatial period divides \(n\). Then
\[
\boxed{F(P_n)=Y\cap P_n\quad\text{for every }n\ge2,}
\]
whereas \(F(P_1)=\{0^{\mathbb Z}\}\) and \(Y\cap P_1=\{0^{\mathbb Z},1^{\mathbb Z}\}\). In particular, every one-step image configuration of least spatial period at least two has a predecessor with the *same least spatial period*. The unique failure among all specified \(n\)-periodic image points is the target \(1^{\mathbb Z}\) when the specified period is \(n=1\); this target has a \(2\)-periodic predecessor \((01)^{\mathbb Z}\), but has no fixed predecessor.

The conclusion concerns one application of the original, non-surjective Rule 54 to bilateral configurations; it makes no assertion about preimages after arbitrary additional time steps.

## Assumptions and scope

The alphabet is binary, indices range over all of \(\mathbb Z\), and \(\sigma\) denotes spatial translation by one cell. A configuration lies in \(P_n\) if its least period **divides** \(n\), not necessarily if its least period equals \(n\). Image membership refers to an arbitrary bi-infinite predecessor, initially with no periodicity restriction. The distinct notions of periodic *spatial input*, periodic *spatial output*, and periodicity under repeated applications of \(F\) must not be interchanged.

The local rule above is the Wolfram-code-54 convention. The primary classification is MSC2020 37B15 (cellular automata and symbolic dynamics). The motivating publicly deposited study of Rule 54 first appeared on 2014-10-12 [1]; the accompanying periodic-preimage comparison [2] is later supporting literature, not a claim of originating the present result.

## Proof

**Four-state labelled graph.** Encode a successive pair of input bits \(ab\) by vertex \(2a+b\in\{0,1,2,3\}\). For every \(abc\), place a directed edge \(ab\to bc\) labelled \(f(a,b,c)\). The labelled adjacency matrices are represented by the following rows of target vertices, grouped by label:

| Source vertex | Label 0 targets | Label 1 targets |
|---|---|---|
| 0 | \(\{0\}\) | \(\{1\}\) |
| 1 | \(\{3\}\) | \(\{2\}\) |
| 2 | \(\varnothing\) | \(\{0,1\}\) |
| 3 | \(\{2,3\}\) | \(\varnothing\) |

Let \(R_0,R_1\) be the resulting Boolean \(4\times4\) adjacency matrices. For a finite binary word \(w=w_1\cdots w_n\), put \(R(w)=R_{w_1}\cdots R_{w_n}\), using Boolean multiplication. An edge of \(R(w)\) is exactly an input path whose output label is one copy of \(w\). Consequently \(w^{\mathbb Z}\in Y\) if and only if the directed graph of \(R(w)\) contains a directed cycle. A loop in \(R(w)\) is equivalent to an input periodic with period dividing \(n\); a cycle of length \(k\) gives an input with period dividing \(kn\). The first equivalence follows because a directed cycle can be repeated bi-infinitely, while every bi-infinite path in a finite graph gives a directed cycle, and a stationary \(n\)-step path begins and ends at the same pair state.

**Finite closure lemma.** The Boolean monoid generated by \(R_0,R_1\) and the identity has exactly 109 matrices, classified as follows:

| Directed-cycle class | Number of distinct matrices |
|---|---:|
| A loop exists | 77 |
| No directed cycle exists | 31 |
| A directed cycle exists but no loop exists | 1 |

The unique matrix in the last class is \(R_1\). The only labelled transition *into* \(R_1\) in the right-multiplication Cayley graph is \(I\xrightarrow{1}R_1\); there is no labelled transition into \(I\). Thus the only finite binary word \(w\) satisfying \(R(w)=R_1\) is the one-letter word `1`. The matrix \(R_1\) has no diagonal entry but its square has a diagonal entry.

This is an exhaustive finite lemma, not an extrapolation from a bounded set of binary words. The accompanying `verify.py` constructs the two Boolean generators directly from the eight Rule-54 transitions, starts from \(I\), repeatedly appends *both* letters until all products are closed, checks all 109 resulting matrices, tests cycles of lengths at most four, and tests all incoming edges to the two exceptional monoid states. There are only \(2^{16}\) possible Boolean \(4\times4\) matrices; the queue procedure terminates only after verifying closure under both generators. In any graph on four vertices, a directed cycle exists if and only if one exists of length at most four, so the cycle classification is exhaustive. The short transparent checker is the finite certificate for the lemma.

**Lift every nontrivial period.** Suppose \(n\ge2\) and \(y=w^{\mathbb Z}\in Y\), with \(|w|=n\). By the graph equivalence, \(R(w)\) has a directed cycle. Its absence of a loop would force \(R(w)=R_1\), and hence \(w=1\), contradicting \(n\ge2\). Hence \(R(w)\) has a loop, giving a predecessor in \(P_n\). The reverse inclusion \(F(P_n)\subseteq Y\cap P_n\) follows from the commutation \(F\sigma=\sigma F\).

When \(y\) has *least* period \(n\), any spatial period of a predecessor is necessarily a multiple of \(n\), again because \(F\sigma=\sigma F\). Therefore a predecessor in \(P_n\) has least period exactly \(n\).

**Sharp fixed-point exception.** The only constant inputs are \(0^{\mathbb Z}\) and \(1^{\mathbb Z}\), and both map to \(0^{\mathbb Z}\). However the period-two alternating input \((01)^{\mathbb Z}\) has every local window `010` or `101`, both mapped to one. Hence \(1^{\mathbb Z}\) is in \(Y\cap P_1\) but not in \(F(P_1)\), while a period-two predecessor exists. This is the sole obstruction.

## Verification

The self-contained Python 3 program `verify.py` uses only exact integer arithmetic. It checks the eight local transitions, closes the 11-state reachable subset automaton, compares its word language to a separate finite forbidden-pattern automaton, exhaustively closes the 109-matrix Boolean relation monoid and checks its 31/77/1 cycle partition and unique incoming-edge property. Independently, it exhausts each input ring through length 12 (8,190 binary ring configurations in total), comparing same-ring images with all periodic image outputs obtained from the relation graphs. These bounded ring tests corroborate, but do not replace, the finite-closure proof covering arbitrary word length.

The verifier additionally checks an exact rational word-counting identity for the one-step image using the reachable subset automaton; this is an auxiliary consistency check, not a separately asserted research contribution. Run `python3 verify.py` from the package directory. Expected prefix: `VERIFY_OK`.

## Relationship to prior work

Martínez, Adamatzky and McIntosh [1] provide Rule 54's de Bruijn and subset-diagram representations and discuss Garden-of-Eden output configurations and ring dynamics. Their subset representation is substantial prior coverage of *word recognition*, but the inspected text does not state the uniform same-period lifting theorem for all positive ring lengths or the unique exceptional fixed target. The present proof uses the older graph framework with an additional 109-element Boolean relation-monoid calculation.

Mariot, Leporati, Dennunzio and Formenti [2] develop general methods for the periods of preimages in **surjective** cellular automata. Rule 54 is not surjective (for example, the output word `10101` is impossible), so their surjectivity-based statements do not imply this all-period theorem. Their de Bruijn approach motivates the choice of invariant and supplies a relevant methodological comparison. General mechanisms for periodic preimages, not independent novelty of that method, are credited to the literature.

Earlier exact evaluation of the present same-period classification in an obscure catalogue remains a legitimate historical-priority uncertainty.

## Limitations

This is a theorem about one-step spatial preimages of Rule 54, not a temporal reversibility result. It does not characterize *all* possible predecessor periods or their multiplicities, nor does it classify all dynamical attractors. Although the finite computational certificate is exhaustive over its clearly specified finite state space, its conclusions depend on the stated four-vertex model and the accompanying graph-theoretic reduction. Priority is assessed against available literature and research records, not certified by a universal absence-of-prior-work argument.
