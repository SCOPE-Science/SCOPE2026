# Scientific review

## Correctness — PASS

The claim is for every \(m\ge1\) and every target length. A greedy matching identity gives the exact last embedding position \(E(u)\); deleting one letter changes \(E\) by precisely zero or two except for the terminal deletion, which changes it by one or two. This proves the if-and-only-if local criterion, including endpoint effects. The run decomposition is exhaustive and unambiguous. Odd-coefficient extraction of the two rational run generating functions gives the bivariate formula. Independent literal subsequence enumeration checks 1,398,078 target words, and an independent stars-and-bars recurrence check covers 160 source parameters. Finite checks do not prove the infinite statement; the exact grammar and algebra do.

## Originality — PASS, with qualifications

The closest primary paper, Kosche–Koß–Manea–Siemer (arXiv:2108.13968, Theorem 3.1, Proposition 3.6), supplies generic MAS conditions and an exponential/linear phenomenon for larger even alphabets, but not the explicit binary length-refined distribution. Its descending-SAS fact already covers the shortest-count part in a more general alphabetic setting; this is credited. Manea–Ringleb–Siemer–Winkler (arXiv:2504.21471) focuses on output-sensitive algorithms, not this rational bivariate law. OEIS A005314 already contains the numerical totals, so the univariate integer sequence itself is not novel. The inspected evidence revealed no published equality with the binary MAS distribution, but the full text of Troníček (COCOA 2023) could not be accessed and an independent equivalent identity may exist.

## Mathematical value — PASS

This gives a complete structural and length-refined census for a canonical binary source and pins down the sharp exponential-versus-linear contrast between the minimal and shortest absent-subsequence sets at the smallest nonunary alphabet size. The run-language explanation is not a mere integer-sequence relabeling: it supplies testable membership restrictions and every coefficient simultaneously. The target family is mathematically motivated by minimally long subsequence-universal words and the published alphabet-size contrast, not selected from an arbitrary finite table. No general theorem about all binary words is asserted.

## Closest literature and limitations

The 2021 primary paper's general characterization is essential background, not the newly proved bivariate formula. The 2025 enumeration-algorithm work is related but does not state this family-specific law. The 2023 counting-algorithm source is inaccessible in full, leaving an explicit originality risk. The total count matches an unrelated pre-existing OEIS sequence, and no independent audit has been performed.
