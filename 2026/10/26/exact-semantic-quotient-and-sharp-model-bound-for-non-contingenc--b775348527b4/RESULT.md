# Exact semantic quotient and sharp model bound for non-contingency over KD45

## Finding

Fix an integer \(k\ge 1\), let \(V=\{0,1\}^k\), and write \(m=2^k\). Consider the single-agent propositional modal language generated by Boolean connectives and non-contingency \(\Delta\varphi:=\Box\varphi\lor\Box\neg\varphi\), interpreted over arbitrary serial, transitive, and Euclidean (\(\mathrm{KD45}\)) Kripke frames. Two pointed models satisfy the same formulas precisely when they have the same current propositional valuation \(a\in V\) and their **successor valuation supports** \(S\subseteq V\) coincide, except that all nonempty singleton supports are indistinguishable.

Consequently there are exactly \(m(2^m-m)\) complete pointed propositional modal theories and exactly
\[
2^{m(2^m-m)}=2^{2^k(2^{2^k}-2^k)}
\]
formulas modulo semantic equivalence. Every formula is equivalent to a Boolean combination of current-world atoms and depth-one non-contingency tests on propositional formulas. Every satisfiable formula has a model of at most \(m\) worlds, and this bound is optimal for every \(k\ge1\). The corresponding full-Boolean \(\Box\)-language has \(m(2^m-1)\) pointed theories and \(2^{m(2^m-1)}\) inequivalent formulas.

## Assumptions and scope

The language contains \(p_1,\ldots,p_k\), Boolean constants, classical negation, conjunction, and \(\Delta\), with other Boolean operations defined as usual. A model has nonempty world set \(W\), a relation \(R\subseteq W\times W\) that is serial (every world has a successor), transitive, and Euclidean (\(xRy\land xRz\Rightarrow yRz\)), and an arbitrary Boolean valuation of each atom at each world. The pointed-model semantics is \(M,w\models\Delta\varphi\) iff either every \(R\)-successor of \(w\) satisfies \(\varphi\) or every successor refutes \(\varphi\). No finiteness of \(W\) is assumed. All logical equivalences quantify over *all* such frames, valuations, and pointed worlds.

For a pointed model \((M,w)\), set \(a=\operatorname{val}(w)\in V\) and \(S=\{\operatorname{val}(u):wRu\}\subseteq V\). By seriality \(S\ne\varnothing\). Define \([S]\) to identify all nonempty singleton sets into one class while leaving each set with at least two elements separate. These classes, indexed together with \(a\), are the canonical profiles.

## Proof

**1. Successor-cluster lemma.** Put \(C=R(w)\). If \(u\in C\), transitivity gives \(R(u)\subseteq C\). Euclideanness, applied to \(wRu\) and \(wRv\), gives \(uRv\) for each \(v\in C\), hence \(R(u)=C\). In particular \(uRu\) for every \(u\in C\). Thus every world in \(C\) has precisely the same nonempty successor set \(C\). The possibly external pointed world \(w\) need not belong to \(C\).

**2. Recovering a nonsingleton support.** For every \(A\subseteq V\), let \(\theta_A\) be a propositional formula whose truth set among assignments in \(V\) is exactly \(A\) (a disjunctive normal form suffices). Then
\[
M,w\models\Delta\theta_A \quad\Longleftrightarrow\quad S\subseteq A\ \text{or}\ S\subseteq V\setminus A.
\]
Every singleton \(S\) makes every such test true. Conversely, for an arbitrary nonempty support \(S\), define an equivalence relation on \(V\): assignments \(b,c\in V\) are equivalent when every Boolean function constant on \(S\) takes the same value at \(b,c\). If \(|S|\ge2\), its unique nonsingleton equivalence class is exactly \(S\); each assignment outside \(S\) forms a singleton class. Indeed every allowed function is constant on \(S\), whereas any pair not both in \(S\) can be separated by the indicator of a suitable set \(A\) containing all of \(S\) or disjoint from it. Hence the complete vector of tests \(\{\Delta\theta_A:A\subseteq V\}\) determines every support of size at least two, and identifies all singleton supports.

**3. No nested modality detects more.** Induct on any formula \(\varphi\) to construct its truth function \(F_\varphi(a,S)\). Atoms and Boolean connectives depend only on \(a\) and inherited inputs. By step 1, evaluating \(\varphi\) at any successor of \(w\) uses the same support \(S\) and that successor's assignment \(b\in S\). Thus
\[
F_{\Delta\varphi}(a,S)=1\ \Longleftrightarrow\ \bigl\{F_\varphi(b,S):b\in S\bigr\}\ \text{has cardinality one}.
\]
For singleton supports the right-hand side is always true. For nonsingleton supports the preceding inductive truth functions already depend only on \((a,S)\). Hence every formula is constant on the profiles \((a,[S])\). Current-world atoms distinguish distinct \(a\); step 2 distinguishes distinct nonsingleton supports and separates each from the singleton class. Since the set of profiles is finite, Boolean combinations of these distinguishing formulas define the characteristic function of *every* profile and therefore every arbitrary union of profiles. This proves expressive completeness and the depth-one normal form.

**4. Exact counts and realization.** Among the \(2^m-1\) nonempty subsets of \(V\), exactly \(m\) are singletons, yielding \(2^m-m\) support classes. There are \(m\) independent choices of root assignment, giving \(m(2^m-m)\) distinguishable pointed theories. Since the language realizes every Boolean function on those theories, the number of inequivalent formulas is \(2^{m(2^m-m)}\). Every pair \((a,S)\) is realized in a serial transitive Euclidean model: make one reflexive complete cluster with one world of each assignment in \(S\); choose an existing world as the distinguished point when \(a\in S\), or add a distinguished noncluster world pointing to the entire cluster when \(a\notin S\). For singleton equivalence profiles a single reflexive world with assignment \(a\) suffices. Thus every satisfiable formula has a witnessing model of at most \(m\) worlds: when \(S\ne V\) with \(a\notin S\) the construction uses at most \(|S|+1\le m\), and when \(S=V\) it uses \(m\).

**5. Sharpness.** Define the finite depth-one formula
\[
\Psi_k=\bigwedge_{\varnothing\ne A\subsetneq V}\neg\Delta\theta_A.
\]
The empty conjunction does not arise for \(k\ge1\). A pointed model satisfies \(\Psi_k\) exactly when \(S=V\): full support crosses every proper nonempty cut, while any nonempty proper support \(S\) makes \(\Delta\theta_S\) true. Such a model needs at least \(m\) successor worlds, and is realized by a reflexive complete cluster on exactly \(m\) worlds. This proves sharpness of the satisfiability bound and of the uniform witness bound for distinguishing \(\Psi_k\) from false. For the ordinary \(\Box\)-language, the tests \(\Box\theta_A\) identify \(S\) exactly, including each singleton, giving \(m(2^m-1)\) pointed theories; Boolean closure again realizes all unions.

## Verification

A standalone exact finite checker (`checker.py`) independently enumerates the nonempty successor supports and their Boolean non-contingency test signatures for \(k=0,1,2,3\), including the boundary case \(k=0\) as a diagnostic only. It tests the profile quotient, canonical realizations, repeated additional successor worlds, a deterministic family of genuinely nested non-contingency formulas for \(k=1,2\), and the full-support sharpness certificate. The analytic proof above, not finite enumeration, establishes the theorem for all \(k\ge1\) and arbitrary frame cardinalities. Run with Python 3.10 or later: `python3 checker.py`.

## Relationship to prior work

Fan, Wang and van Ditmarsch's *Knowing Whether* (arXiv:1312.0144), particularly Proposition 6, establishes a semantic inexpressibility phenomenon for knowing-whether versus standard knowledge on serial, transitive, Euclidean frames. Its singleton-successor examples motivate and agree with the identified indistinguishability mechanism; this familiar inexpressibility is **not** asserted as new. Wang and Zenger's *Proof Theory for Non-Contingency Logic* (arXiv:2609.38975; initially posted September 30, 2026) studies the proof theory and broader non-contingency semantics; its inspected full text does not state the finite free-algebra census, canonical finite quotient, or sharp \(2^k\)-world bound. Ding and Yang's 2026 *A General Theory of Propositional Modal Bundled Modalities* (arXiv:2603.26268) concerns bundled modalities and provides further nearby context; a full-text coverage claim is not made here.

The present result refines known expressive weakness of knowing-whether into an exact profile equivalence and a cardinality formula for every finite variable set. 
## Limitations

The language is single-agent, Boolean, and has a fixed finite nonzero number of variables. Allowing primitive \(\Box\), additional agents, different accessibility axioms, or infinitely many distinct variables changes the profile space. The comparison to the full \(\Box\)-language is for pointed semantic equivalence, not computational complexity or minimal formula length. The enumerations count semantic equivalence classes, not syntactic formulas. The analytic theorem is internally reviewed but not independently audited. Earlier literature could contain an equivalent quotient or free-algebra enumeration under alternative terminology, particularly in non-contingency algebras.
