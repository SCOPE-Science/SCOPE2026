# Reproduction and finite exhaustiveness

Run `python3 verify_exact_cover.py` and `python3 verify_affine_cosets.py` in the directory containing the embedded files. They require only Python 3 standard-library modules and do not download or import other research files. The saved outputs are `verify_exact_cover.out` and `verify_affine_cosets.out`.

The exact-cover script recursively branches on the first uncovered pair of the nine-point base set, covers all 36 pairs exactly once using 12 of the 84 triples, and finds 840 labeled solutions after 8,863 calls. It constructs adjacency from exactly six shared blocks; the group-theoretic lemma proves this condition is precisely a six-cycle switch. All-roots BFS checks 840 sources and all 705,600 ordered source-target pairs, including that the distances are prescribed by intersection size. Its reported degree is 36, edge count 15,120, and distance layers are (1, 36, 395, 408).

The coset script constructs exactly 432 affine maps, all 840 image systems, and computes the minimum of the exact transposition word length over every stabilizer element in each coset. Unlike BFS, this method determines lower and upper bounds simultaneously through the cycle-count identity. It also verifies that all 36 point-transpositions give distinct six-block-exchange neighbors. The methods are logically complementary: all-system enumeration through pair exact cover versus stabilizer/coset enumeration through invertible matrices.

The outputs saved in the package were generated by directly executing these embedded code paths. Both were re-executed after extracting the package for bytewise output comparison. The finite certificate does not imply analogous claims for other orders and is not an independent external audit.
