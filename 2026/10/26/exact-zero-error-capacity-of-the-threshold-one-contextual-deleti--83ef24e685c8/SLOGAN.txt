Deleting the first symbol of every noninitial run has an exact, all-alphabet output description: a word \(y\) is attainable from an input of length \(n\) if and only if \(|y|+t(y)\le n\), where \(t(y)\) counts its symbol changes. For any alphabet size \(q\ge2\), this gives the exact finite-length optimal zero-error code size and capacity \(\log_q((1+\sqrt{4q-3})/2)\); the binary code size is \(2(F_{n+2}-1)\).
