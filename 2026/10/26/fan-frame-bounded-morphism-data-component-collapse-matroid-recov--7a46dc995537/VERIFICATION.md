# Checks and scope

Run `python3 verify.py` using Python 3 standard library only. It directly enumerates bounded morphisms, checking both the forth and back relations, over specified finite sources and fans. It verifies the scalar and marked formulas, independently canonicalizes graph isomorphism classes up to eight incidence worlds, and verifies the six- and eight-world thresholds. The accompanying `verification-output.txt` is the recorded result. This is a finite reproducibility check, not an infinite mathematical proof or independent scientific audit.
