## Exact replay

Run these commands from the directory containing all supplied files:

```sh
python3 verify_census.py > replay_census.json
python3 verify_independent.py > replay_independent.json
```

Requires Python 3 and SymPy (checked with Python 3.13.5, SymPy 1.14.0). Compare the scientific numerical fields with `census_output.json` and `independent_output.json`. The two reference outputs are generated by the included source and are not independent external certifications.

The first checker proves the 21-by-21 first-jet matrix invertible, enumerates the 2,187 locally smooth forms, forms 18 projective orbits, and checks geometric smoothness of orbit representatives through characteristic-two Gröbner unit-ideal tests on all projective affine charts. It counts 50,400 qualifying smooth unordered pairs and 16,800 pencils, then constructs 108 orbits and checks base reducedness by chartwise Jacobian ideals. Group invariance extends every representative test to its full orbit.

The second checker runs geometric smoothness tests on all 2,187 forms rather than relying on group orbit representatives and counts all-smooth pencils independently using both XOR summation and the cubic moment of the 14-dimensional binary Walsh transform. It confirms 1,512 smooth forms, 50,400 qualifying unordered pairs, and 100,800 ordered pairs.

All tests use exact arithmetic over \(\mathbf F_2\). A unit Gröbner ideal on each affine chart excludes singular points even over the algebraic closure; finite-field sampling would not suffice. No classification of abstract curve isomorphism classes or residual Frobenius splitting is asserted. Independent external audit has not been performed.
