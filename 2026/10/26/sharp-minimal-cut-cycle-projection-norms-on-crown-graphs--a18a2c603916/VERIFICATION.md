# Reproducibility and boundaries
The accompanying `verify_crown.py` is a standalone Python 3 program using only the standard library. Run `python3 verify_crown.py` to form the grounded graph Laplacians from the actual graph edge lists and reconstruct both canonical projections with exact rational arithmetic. All \(328\) edge columns for \(3\le n\le10\) pass cut and cycle absolute-column norm identities, the effective-resistance diagonal, matrix symmetry, cycle-flow conservation and, for \(n\le6\), matrix idempotence.

The analytical proof separately derives the group-module intertwiner obstruction, averaging optimality for every simultaneous-permutation invariant norm, exact electrical current orbit types, and the all-parameter comparison. The finite program cannot prove these infinite or representation-theoretic steps. No external or independent audit has been conducted.
