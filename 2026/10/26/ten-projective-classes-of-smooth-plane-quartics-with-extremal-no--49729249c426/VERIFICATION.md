# Reproduction and scientific checks

From the directory containing `RESULT.md` and `verification/`, run:

```sh
g++ -std=c++17 -O2 verification/enumerate.cpp -o verification/enumerate
./verification/enumerate
python verification/groebner.py
python verification/orbits.py
```

All scripts write output files under `verification/`, so execute them with the package root as the current working directory. The expected stdout for each program is embedded as `verification/enumeration_output.txt`, `verification/groebner_output.txt`, `verification/orbits_output.txt`. All programs must run without external network access; Python needs `sympy` for the Gröbner verification, and the other Python program uses only the standard library. Finite-field operations use exact integer arithmetic modulo three.

The C++ program enumerates all nonzero coefficient vectors of a nine-dimensional kernel and tests geometric smoothness through a degree-seven Jacobian rank of 36. The Gröbner implementation independently reconstructs the kernel, enumerates scalar-normalized quartics and checks the ideal generated by the three derivatives on all three projective charts. Each finds exactly 222 smooth normalized equations. The two normalized lists can be compared after dividing each coefficient vector by its first nonzero coefficient; this comparison was performed and gave identical sets. The projective program independently enumerates all 5,616 invertible projective matrices and confirms a six-set orbit of size 234, a stabilizer of size 24, and quartic stabilizer-orbit lengths \(24\) (nine times) and \(6\) (once).

The `verification/orbit_representatives.txt` coefficients are lexicographically ordered as specified in `RESULT.md`; the file lists all ten representatives and their relative orbit sizes. The `verification/smooth_coefficients.txt` list has 444 vectors, including both scalar versions of each smooth curve; the independently produced `verification/groebner_smooth_coefficients.txt` list has 222 normalized vectors.

**Limits:** Reproduction establishes the finite classification and its algebraic geometric-smoothness criterion; it does not prove historical publication priority or substitute for independent external validation.
