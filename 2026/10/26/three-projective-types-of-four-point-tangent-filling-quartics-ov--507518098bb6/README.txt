Requirements: Python 3, NumPy, SymPy. Run python enumerate_tangent_quartics.py, python check_geometric_smoothness.py, then python classify_projective_orbits.py. These programs exhaust contact constraints, certify geometric smoothness over an algebraic closure via Gröbner unit ideals, and classify orbits under the stabilizer of the pencil center. Coefficient order is (X^i Y^j Z^(4-i-j)) with i ascending 0..4, j ascending 0..4-i.
