# Two letters suffice for the full accepting-state spectrum of permutation right quotients

## Finding

Let \(\operatorname{asc}(K)\) denote the minimum number of accepting states of any complete deterministic finite automaton recognizing a regular language \(K\). A **permutation language** is one recognized by a complete deterministic automaton in which every input symbol acts bijectively. For a fixed alphabet \(\Sigma\), define the right quotient
\[
KL^{-1}=\{x\in\Sigma^*: \text{there exists }y\in L\text{ with }xy\in K\}.
\]
For every pair of integers \(m,n\geq 1\), **the exact spectrum of \(\operatorname{asc}(KL^{-1})\) for permutation languages \(K,L\) over the fixed binary alphabet \(\Sigma=\{a,b\}\) with \(\operatorname{asc}(K)=m\) and \(\operatorname{asc}(L)=n\) is \(\mathbb N_{>0}\)**. If \(m=0\) or \(n=0\), the spectrum is \(\{0\}\).

This is the sharp minimum-alphabet refinement of the known unrestricted-alphabet spectrum: over a unary alphabet, for \(m,n\geq 1\), the exact spectrum is only \(\{1,2,\ldots,mn\}\). In particular, the minimum alphabet size for realizing every positive quotient accepting-state complexity with fixed positive input complexities is exactly two.

## Assumptions and scope

All automata below are complete deterministic permutation automata. Input languages use the *same* alphabet. The accepting-state complexity counts final states in a minimal DFA, not total states or final states in an arbitrary presentation. The output quantity is for **right** quotient, with \(x\) preceding the deleted suffix \(y\).

For every \(m,n\geq1\) and \(\alpha\geq m\), we explicitly construct binary permutation automata \(A\) and \(B\) with input accepting-state complexities \(m,n\) and quotient accepting-state complexity \(\alpha\). Values \(1\leq\alpha<m\) follow from the published unary interval theorem (Rauch--Holzer 2022, Corollary 32), since \(\alpha\leq mn\). A unary witness is also a binary witness: add a second letter acting as the identity on every state, which preserves reachability, distinguishability, and the accepted language's accepting-state complexity under deletion of the added letter.

## Proof

**Binary high-range construction.** Fix positive integers \(m,n\) and \(\alpha\geq m\), and write \(k=\alpha+1\) and \(h=n+1\). Thus \(k\geq2\), \(h\geq2\), and \(1\leq m<k\). On \([k]=\{1,\ldots,k\}\), let \(a=(1\,2\,\cdots\,k)\) and \(b=(1\,2)\), acting on the right. The two permutations generate the symmetric group \(S_k\), including the case \(k=2\).

Define \(A\) to have states \([k]\), start state \(1\), actions \(a,b\), and final set \(F_A=\{1,\ldots,m\}\). Define \(B\) to have state set \([k]\times\mathbb Z/h\mathbb Z\), start state \((k,0)\), actions
\[
(q,r)\cdot a=(qa,r+1),\qquad(q,r)\cdot b=(qb,r),
\]
where the second coordinate is reduced modulo \(h\), and final set
\[
F_B=\{(k,r):r\neq h-1\}.
\]
In particular, \(|F_B|=h-1=n\). These are permutation automata on the *same two-letter alphabet*.

**Independent permutation and counter controls.** A word \(w\) acts on \(B\) as \((q,r)\mapsto(q\rho_w,r+|w|_a)\), where \(\rho_w\in S_k\) is its permutation action and \(|w|_a\) is the number of occurrences of \(a\), modulo \(h\). The projected action of \(a,b\) generates \(S_k\). Moreover, \(a^k\) acts as the identity permutation and adds \(k\) to the counter; \((ab)^{k-1}\) acts as the identity permutation and adds \(k-1\): the permutation \(ab\) is a \((k-1)\)-cycle with one fixed point (when \(k=2\), it is the identity). Since \(\gcd(k,k-1)=1\), these two zero-permutation words generate *every* counter shift modulo \(h\). Thus every pair in \(S_k\times\mathbb Z/h\mathbb Z\) is induced by a positive word. The use of positive words is legitimate because the finite monoid generated by permutations is a group; alternatively, exponents solving the Bezout congruence can be reduced to nonnegative residues modulo \(h\).

**Minimality.** Since \(S_k\) is transitive, every state of \(A\) is reachable. Given distinct states \(p,q\), there is a permutation sending \(p\) into the nonempty final set and \(q\) to the nonfinal state \(k\). Hence \(A\) is minimal, and \(\operatorname{asc}(L(A))=m\).

The full product action just established is transitive on \([k]\times\mathbb Z/h\mathbb Z\), so every state of \(B\) is reachable. To distinguish \((p,r)\) from \((q,s)\), when \(p\neq q\) choose a permutation sending \(p\) to \(k\) and \(q\) elsewhere, together with a counter shift placing \(r\) in any allowed final residue. When \(p=q\) but \(r\neq s\), choose a permutation sending \(p\) to \(k\) and a counter shift placing exactly one of \(r,s\) at the excluded residue \(h-1\). Full-product controllability realizes these actions by words. Thus \(B\) is minimal, and \(\operatorname{asc}(L(B))=n\).

**Right quotient.** Let \(H=\{\rho\in S_k:k\rho=k\}\) be the stabilizer of \(k\). Since the full product \(S_k\times\mathbb Z/h\mathbb Z\) acts on \(B\), the set of first-coordinate permutations induced by words accepted by \(B\) is *exactly* \(H\). Indeed, acceptance forces \(k\rho=k\), and each \(\rho\in H\) can be paired with counter residue \(0\), which is accepted because \(h\geq2\).

The standard right-quotient construction keeps the transitions and start state of \(A\), replacing its final set by
\[
\widetilde F=\bigcup_{w\in L(B)}\rho_w^{-1}(F_A)
=\bigcup_{\rho\in H}\rho^{-1}(F_A)
=[k-1].
\]
The last equality holds because \(F_A\) is a nonempty subset of \([k-1]\), and \(H\cong S_{k-1}\) is transitive on \([k-1]\) while fixing \(k\). The resulting quotient DFA is minimal by the same transitivity/distinguishability argument used for \(A\). Therefore its accepting-state complexity is \(k-1=\alpha\).

**All spectrum values and sharpness.** The construction covers every \(\alpha\geq m\). Rauch--Holzer's unary permutation-automaton theorem gives every \(\alpha\in[1,mn]\); as \(mn\geq m\), these intervals cover every positive integer. Zero is impossible for a quotient of two nonempty permutation languages: for any accepted suffix and any final state in a reachable permutation automaton for \(K\), that suffix has a reachable preimage, yielding a word in the quotient. If \(m=0\) or \(n=0\), the respective language is empty and the quotient is empty. Finally, the unary spectrum is bounded above by \(mn\), so unary alphabets cannot realize all positive values. This proves the stated sharp binary-alphabet threshold.

## Relationship to prior work

German (2026) proved that the unrestricted-alphabet right-quotient accepting-state spectrum of permutation languages is complete for positive input complexities, but the explicit high-range witnesses there have **three** letters: a cycle, a transposition, and an independent counter-increment letter. The present construction removes that third letter by coupling the counter increment to the cycle and using the two coprime identity relations \(a^k\) and \((ab)^{k-1}\). Thus the output spectrum itself is not new; the sharp **fixed binary-alphabet realization** is the claim.

Rauch and Holzer (2022) proved the unary interval \([1,mn]\), supplying both the low-range witnesses and the lower bound of two on any alphabet universally realizing the unbounded spectrum. Hospodár and Mlynárčik (2020) studied **total state complexity** of permutation-language operations, a different invariant that does not give the current accepting-state result.

## Limitations

The result concerns complete deterministic permutation automata, binary alphabets, right quotient, and accepting-state complexity; it makes no assertion about nondeterministic automata, smallest total-state witnesses, or the left-quotient spectrum. The explicit high-range witnesses use \(k\) and \(kh\) states, but no state-size optimality is claimed. Searches and source comparisons do not rule out unindexed equivalent work; novelty is relative to the examined literature. The verification code is finite corroboration, not an infinite certificate. Independent mathematical review has not been conducted.
