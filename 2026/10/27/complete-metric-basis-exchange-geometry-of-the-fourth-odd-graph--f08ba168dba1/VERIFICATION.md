# Reproducibility and limits

The six packaged source/output artifacts consist of three standalone exact programs and their deterministic standard output. Compile the two C++17 files with `g++ -std=c++17 -O3`, execute them, and execute `verify_intersection.py` with Python 3.10 or later. These three source files have no external data dependencies.

The complete C++ enumeration checks all 324,632 candidate five-subsets using the shortest-path metric of disjoint triple adjacency. It constructs every valid exchange, computes all 48 orbits generated by the six adjacent transpositions of the seven ground symbols, and performs a full breadth-first search in the 149,184-node exchange graph from one representative of each orbit. The resulting exact eccentricity histogram is 146,160 at distance five and 3,024 at distance six. The independent Python intersection-signature script counts all four- and five-sets, builds all exchanges independently, verifies connectivity, independently checks all 48 symmetry orbits, and performs independent shortest-path searches for two six-step witnesses. The smaller C++ code verifies the pinned-vertex census and minimum using pair-separation bitsets.

Checks are finite exhaustive computations for the specified 35-vertex graph and not an analytic classification of higher Odd graphs. The 2016 exact-minimum paper was not available as full text; no independent external scientific review or verification has been performed.
