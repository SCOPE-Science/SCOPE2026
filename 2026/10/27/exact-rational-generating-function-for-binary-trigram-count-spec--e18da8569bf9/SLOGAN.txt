The number of distinct binary length-\(n\) trigram-count multispectra has an explicit rational generating function with denominator \( (1-z)^5(1+z)(1+z^2)(1+z+z^2) \) and leading growth \(13n^4/288\). This exactly determines the maximum size of a noiseless binary length-three multiset-read reconstruction code for every blocklength.
