# Finite-base one-type spectra recover the five random-graph reducts, but their tails collide

## Finding
Let \(R=(V,E)\) be the countable Rado graph, and let \(G_0,G_c,G_s,G_{cs},G_=\) be its five closed permutation supergroups, in the standard order: graph automorphisms, graph automorphisms with global complementation, graph automorphisms with Seidel switching, the group generated by both operations, and all permutations of \(V\). For every finite individually named \(A\subseteq V\), put \(m=|A|\). Write \(t_H(m)\) for the number of orbits of the pointwise stabilizer \(H_{(A)}\) on \(V\setminus A\). Equivalently, \(t_H(m)\) is the number of *nonalgebraic complete one-types* over the named parameters \(A\) in the corresponding \(\omega\)-categorical reduct.

These numbers depend only on \(m\), not on the induced graph on \(A\), and are exactly
\[
\begin{aligned}
t_{G_0}(m)&=2^m,\\
t_{G_c}(m)&=\begin{cases}1,&m\le1,\\2^m,&m\ge2,\end{cases}\\
t_{G_s}(m)&=\begin{cases}1,&m=0,\\2^{m-1},&m\ge1,\end{cases}\\
t_{G_{cs}}(m)&=\begin{cases}1,&m\le2,\\2^{m-1},&m\ge3,\end{cases}\\
t_{G_=}(m)&=1.
\end{aligned}
\]

In the displayed group order, the five columns of the one-type table for \(m=0,1,2,3\) are
\[
(1,1,1,1,1),\quad (2,1,1,1,1),\quad
(4,4,2,1,1),\quad (8,8,4,4,1).
\]
The full finite-base numerical one-type profile distinguishes all five groups, with *sharp maximal parameter size three*: the prefixes through \(m=2\) do not distinguish \(G_{cs}\) from \(G_=\), whereas the prefix through \(m=3\) distinguishes every pair. In contrast, the asymptotic tails do not identify all reducts: \(t_{G_0}(m)=t_{G_c}(m)\) for every \(m\ge2\), and \(t_{G_s}(m)=t_{G_{cs}}(m)\) for every \(m\ge3\). For complete one-types including algebraic realizations, add \(m\) to each entry.

## Assumptions and scope
The Rado graph has the finite extension property: every finite binary adjacency vector to any fixed finite base is realized by infinitely many vertices. A *switch* at a vertex set reverses all edges between that set and its complement. A *global complement* reverses every edge. The five groups above are the distinct closed groups in Thomas's reduct classification; this pre-existing classification is assumed, not reproved. The theorem concerns named bases and one new vertex, not arbitrary unlabelled bases or higher-arity types.

## Proof
Fix an enumeration \(A=\{a_1,\ldots,a_m\}\) and a vertex \(x\notin A\). Encode its adjacency to \(A\) as a binary vector \(b=(b_i)\in\mathbf F_2^m\). Every vector occurs by the extension property. Two vectors lie in one \(H_{(A)}\)-orbit precisely when the corresponding finite induced graphs on \(A\cup\{x\}\) are connected by the finite complement-and-switch moves allowed by \(H\) that preserve all edges *inside* \(A\). This equivalence follows from the finite interpolation description of the five closed groups and the ultrahomogeneity of the Rado graph: a finite allowed move sends the first extension graph to the second, after which a graph automorphism sends the transformed named tuple back to the target and fixes the named base. Conversely every group element has an allowed finite move description on the finitely many vertices under consideration.

Use switching bits \(s_1,\ldots,s_m,s_x\in\mathbf F_2\), and a complement bit \(c\in\mathbf F_2\). On each pair of distinct vertices \(i,j\) the edge indicator changes by
\[
\Delta e_{ij}=s_i+s_j+c\pmod 2.
\]
The named base must remain fixed, so
\[
s_i+s_j+c=0\qquad(1\le i<j\le m).
\]
The adjacency vector \(b\) changes by translation through \(d\in\mathbf F_2^m\), with
\[
d_i=s_i+s_x+c.
\]
For \(G_0\), all switching and complement bits are ineffective, giving \(2^m\) singleton vector orbits. For \(G_c\), all \(s\)-bits vanish; if \(m\ge2\), a named pair forces \(c=0\), so the \(2^m\) vectors remain distinct. When \(m=1\), either value of \(c\) is allowed, interchanging the two vectors. The empty base has one vector.

For \(G_s\), \(c=0\). When \(m\ge2\), the base-pair equations force all \(s_i\) equal; the same description holds vacuously for one named vertex. The only possible vector translations are the zero vector and the all-ones vector, so \(2^m\) adjacency vectors form \(2^{m-1}\) two-element orbits for \(m\ge1\).

For \(G_{cs}\), if \(m\ge3\), summing the three base constraints for distinct indices gives \(c=0\); hence the same two-element vector orbits as \(G_s\). For \(m=2\), the single constraint is \(c=s_1+s_2\), and \((d_1,d_2)\) can be prescribed arbitrarily, giving one orbit on all four vectors. The cases \(m=0,1\) are likewise transitive. The full symmetric group is transitive on \(V\setminus A\). This proves all five formulas without a restriction on \(m\).

The stated sharpness follows by directly comparing the five ordered lists of counts at parameter sizes \(0,1,2,3\). Their tails agree in the two asserted pairs by the formulas; their finite prefixes nevertheless separate every group. All computations and logical cases above include the empty base.

## Verification
The accompanying standalone `verify.py` exhaustively enumerates the permitted binary switching/complement vectors and the resulting stabilizer orbits for each base size \(0\le m\le7\), comparing them against the formulas. It also independently enumerates the same finite edge-state actions on tuples of \(1\le n\le5\) distinct vertices, checks the sharp parameter-size separation, and tests the asserted infinite-tail identities on a finite range. Execute `python3 verify.py`; the archived `verification_output.txt` records an execution ending with `ALL_CHECKS_PASS`. The unrestricted theorem is proved by the preceding finite-bit argument, not by finite testing.

## Relationship to prior work
Thomas classified the five random-graph reduct groups; Bodirsky and Pinsker (2009, 2010) gave independent descriptions of their generators and broader model-theoretic classification results. Those group classifications, the Rado extension property, and standard facts about types and oligomorphic automorphism groups are prior results. The present assertion is the exact **individually named finite-base one-type spectrum** for all five groups, including the sharp three-parameter numerical reconstruction and the eventual-tail collisions. The latter numerical assertions do not occur as stated in the inspected full-text sections of the cited classification papers; they follow here from the explicit simultaneous binary stabilizer equations, rather than from a title comparison. This is a close, elementary consequence of the published finite group descriptions, and any prior implicit derivation would reduce its novelty.

## Limitations
The formulas are for nonalgebraic one-types only; algebraic types add exactly one per named point. They do not assert that one-type numerical tails classify a reduct, nor that type counts alone determine any higher-arity orbit partition. The group taxonomy is used as an established theorem. An original 1991 primary paper was accessible at abstract level only, so previously unrecognized implicit numerical coverage cannot be excluded. The independent audit of this result has not been performed.
