The proof is a self-contained argument for all finite total-functional frames. Its critical hypotheses are total functionality, nonemptiness, finiteness, arbitrary Boolean valuations and the basic one-agent modal language without a universal modality. The root orbit map is well defined exactly for tail inequality plus period divisibility. Finite full Boolean codes distinguish all worlds in a chosen target orbit, yielding a separating formula of depth no more than the largest source orbit. The sharpness construction compares all valuation words shorter than the source cardinality; it is not a claim about global frame bisimulation.

Run `python3 checker.py` with the Python standard library, without datasets or network access. The script independently enumerates all total functions on 1–4 worlds, enumerates colour words, checks theory inclusion versus signature domination, and tests finite pairs of lassos. The expected final marker is `ALL_CHECKS_OK`. These finite tests are regression evidence, not independent validation and not a proof by enumeration for arbitrary size.
