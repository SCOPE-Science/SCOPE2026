# Exact finite verification

Run `python icosa_exact.py` in a directory containing `volume_spectrum.json`. The executable uses only the Python standard library and enumerates all 4096 vertex subsets in the exact integer-pair arithmetic of the quadratic field generated by the golden ratio. It validates each purported facet with exact supporting-plane signs; it validates face cyclic order using exact comparisons before applying the signed determinant formula. The program independently regenerates all 13 cardinality rows, checks their 4096 total subsets, compares the resulting census byte-independent as parsed data to `volume_spectrum.json`, and verifies all 29 distinct volume classes.

The reproducible run finished with `ALL_EXACT_4096_SUBPOLYTOPE_CHECKS_PASSED`. It additionally verified that the twelve zero-volume five-vertex subsets are exactly the neighbor rings, while the 75 zero-volume four-subsets consist of 60 ring subsets plus 15 antipodal-pair planes. All choices with six or more vertices have positive Euclidean volume.

For independent numerical corroboration, install the optional dependencies in `requirements-numeric.txt` and run `python crosscheck_numeric.py` in the same directory. SciPy/Qhull independently constructs the convex hull of every subset; the completed run gave `ALL_4096_INDEPENDENT_NUMERICAL_HULL_CHECKS_PASSED` and maximum absolute volume error 1.0658141036401503e-14. This floating-point check alone cannot prove the exact census; the exact exhaustive enumeration and determinant identities are the proof.

The classifier does not cover vertices chosen continuously from faces or the sphere, random rotations as new vertices, unequal retention probability tables, or more than twelve original vertices. Independent mathematical audit has not been performed.
