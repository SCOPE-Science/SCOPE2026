# Verification

The all-order theorem is proved in RESULT.md. The two executable finite checks below independently implement the NOR transitions and compare all sampled attractor basins; neither is a substitute for the proof or an independent review.

## Python checker

Python 3 and the openly available NetworkX library are required. From the directory containing the supplied files, run:

```sh
python3 verification/check_trees.py
```

Expected output is embedded in `verification/check_trees.out`. The implementation enumerates all 433 nonisomorphic trees with four through eleven vertices and all 621,696 binary initial configurations. It reconstructs each orbit by iteration, compares observed basin dictionaries against formulas, and checks sharp path/broom/star extremes.

## C++ checker

This checker uses only the C++17 standard library. Run:

```sh
c++ -std=c++17 -O2 -Wall -Wextra -pedantic verification/check_labeled.cpp -o check_labeled
./check_labeled
```

Its output is embedded in `verification/check_labeled.out`. All labelled trees on four through seven vertices are generated by Prüfer codes (16, 125, 1296 and 16807 trees). Additionally 100 reproducible, deterministically seeded labelled trees for each order eight through twelve are tested. It exhausts every binary initial configuration for each tested tree, totaling 18,744 graph instances and 3,032,096 initial configurations.

## Checked proof obligations and limits

- The update rule is synchronous, binary, and consults open neighbors only; the complement of a star has one isolated vertex, which receives one after every update.
- Tree closed-neighborhood intersections have at most two elements for distinct centers; this ensures all possible periodic states are enumerated.
- Distinct initial states are counted once per eventual orbit. Two phase points are one primitive orbit.
- Fiber-count subtraction and the degree-excess optimization give exact all-order expressions, not empirical extrapolations.
- Originality is not computationally certified; the inaccessible earlier maxterm/minterm article remains an explicit literature risk.
- No external verification or independent mathematical audit was performed.
