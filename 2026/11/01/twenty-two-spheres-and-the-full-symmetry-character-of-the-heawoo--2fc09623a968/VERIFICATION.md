# Verification of the finite certificate

The standalone script `verify.py` (Python 3 standard library) reads the adjacent `cell_certificate.json` and makes no network calls. Run `python3 verify.py` to regenerate the full simplicial complex of graph-induced matchings and the full Fano graph symmetry action. The actual recorded successful output is provided in `verification_output.txt`; it ends with `VERIFY_OK`.

The checker uses two independent face criteria and verifies all \(190\) faces including the empty simplex. The certificate contains a 20-edge spanning tree, 64 ordered cancelling triangles, and 20 remaining triangles. Its key nonstandard test is that each cancelling triangle has exactly two edges already eliminated and exactly one fresh edge, and that all 84 one-skeleton edges have been eliminated by the end. A CW-complex cancellation argument promotes this exhaustive finite data to the integral wedge-of-spheres homotopy theorem. Merely computing field ranks would not establish that homotopy conclusion, so both approaches are provided.

The complete signed boundary matrices satisfy \(\partial_1\partial_2=0\), with verified ranks \(20,64\) over each of \(\mathbb F_2\), \(\mathbb F_3\), and \(\mathbb F_5\). All \(336\) graph automorphisms are generated by linear Fano symmetries and dualities, checked against *every* face, and evaluated using signed fixed simplex traces. Their degree-two character distribution is \((-4:21,-1:48,0:210,2:56,20:1)\), and the average trace is zero. The classification is only for this specified graph; there is no claim of external independent certification.
