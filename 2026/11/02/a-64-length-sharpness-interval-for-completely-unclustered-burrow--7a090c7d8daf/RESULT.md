# A 64-length sharpness interval for completely unclustered Burrows–Wheeler images

## Finding
For every integer \(31\le n\le64\) and every alphabet size \(k\ge3\), the least cyclic number of equal-letter runs of a primitive length-\(n\) necklace with completely unclustered Burrows–Wheeler transform is exactly
\[
U_k(n)=\left\lceil\frac n2\right\rceil.
\]
In fact, for each such \(n\), there exists a ternary last-column word \(L\) whose ordinary adjacent symbols are all different, whose standard permutation is one cycle, and which differs from a binary alternating word only by replacing either two, four, or six entries by the third symbol \(2\). The complete list of \(34\) such words is in `witnesses.tsv`. Four lengths (\(33,37,46,51\)) use six replacements; fourteen use two, and sixteen use four.

## Assumptions and scope
The ordered alphabet is \(\Sigma_k=\{0<1<\cdots<k-1\}\), with \(k\ge3\). A primitive necklace \([u]\) is a cyclic rotation class of an aperiodic length-\(n\) word. For a nonconstant cyclic word define \(\rho^{\circ}([u])=|\{i\in\mathbb Z/n\mathbb Z:u_i\ne u_{i+1}\}|\). Its Burrows–Wheeler transform \(\mathrm{BWT}([u])\) is the last column of the lexicographically sorted table of its cyclic rotations. A last column \(L=L_0\cdots L_{n-1}\) is *completely unclustered* if \(L_i\ne L_{i+1}\) for \(0\le i<n-1\); this is a linear, not cyclic, condition on \(L\). Define \(U_k(n)\) as the minimum \(\rho^{\circ}([u])\) over primitive necklaces whose transform is completely unclustered. The claim concerns the complete integer interval \(31\le n\le64\); it does not claim every larger length.

## Proof
**Lower bound.** The classical factor-two theorem for the run count of a Burrows–Wheeler transform of a Lyndon word states that \(\rho(\mathrm{BWT}(w))\le2\rho(w)\), where \(\rho\) counts linear runs. For the Lyndon representative \(w\) of a nonconstant primitive necklace, the first and last symbols differ, so \(\rho(w)=\rho^{\circ}([w])\). Consequently a completely unclustered BWT of length \(n\) requires \(n\le2\rho^{\circ}([w])\), proving \(U_k(n)\ge\lceil n/2\rceil\). This lower bound is also Proposition 3.2 of Kumallagov (2026).

**Certificate criterion.** For a proposed last column \(L\), let \(F=\operatorname{sort}(L)\). For each position \(i\), define the stable-sorting permutation \(\pi_L(i)\) as the position in \(F\) of the occurrence of \(L_i\) with the same rank among equal letters. If \(\pi_L\) is a single permutation cycle of length \(n\), the inverse Burrows–Wheeler transform yields one primitive necklace. This is the standard one-cycle criterion, recorded as Lemma 3 of Fici–Gabory–Romana–Sciortino (2025). For this necklace, the cyclic input run count equals \(d_H(L,F)\): each row's first letter is its successor position's preceding letter after stable matching, so a cyclic change occurs exactly when the corresponding first- and last-column symbols differ. This identity is Proposition 4.3 of Kumallagov (2026).

**Finite upper bounds.** The tab-separated file `witnesses.tsv` supplies an explicit word \(L\) of length \(n\) for every integer \(n=31,32,\ldots,64\). The complete certificate checks for each row are: (i) every letter belongs to \(\{0,1,2\}\); (ii) neighboring letters of \(L\) differ; (iii) \(\pi_L\) is a single \(n\)-cycle; (iv) \(d_H(L,\operatorname{sort}(L))=\lceil n/2\rceil\); (v) replacing its occurrences of \(2\) by the appropriate alternating binary letters gives a binary alternating word, and there are at most six occurrences of \(2\). Each assertion is integer-exact and is checked in the standalone `verify_direct.py`. For an independent algorithmic check, `verify_inverse.py` inverts each last column, reconstructs the complete lexicographically sorted rotation matrix, checks primitivity and the BWT, and directly counts cyclic input runs without using the Hamming identity. Both checks pass for all \(34\) lengths. Thus \(U_3(n)\le\lceil n/2\rceil\). Inclusion of the ternary alphabet in every \(\Sigma_k\), together with the common lower bound, proves the claimed formula for all \(k\ge3\).

## Verification
Place the four text artifacts `witnesses.tsv`, `verify_direct.py`, `verify_inverse.py`, and `check_output.txt` in one directory. Run `python3 verify_direct.py witnesses.tsv` and `python3 verify_inverse.py witnesses.tsv` using only Python's standard library. The recorded outputs are in `check_output.txt`. The first algorithm checks stable LF permutation cycles and Hamming certificates; the second independently reconstructs every input necklace by inverse BWT and explicitly sorts all rotations. Each runs on exactly the integer lengths \(31\) through \(64\). Witnesses, rather than an exhaustive search, suffice because the unconditional lower bound is known.

## Relationship to prior work
Kumallagov's 2026 manuscript introduced \(U_k(n)\), proved the general lower bound, gave examples through \(n=12\), and explicitly conjectured sharpness for all \(n\ge7\). Its prime-primitive-root construction independently implies the six cases \(n\in\{36,37,52,53,60,61\}\) in the present interval. The new certificate closes the remaining \(28\) lengths through \(64\), and supplies a uniformly sparse third-letter presentation for all \(34\). Fici, Gabory, Romana and Sciortino proved existence of completely unclustered BWTs at every nonbinary length, but their result does not assert minimum cyclic input runs. This is a finite extension of a still-open all-length conjecture, not a solution of that conjecture.

## Limitations
The proof depends on the cited unconditional run-amplification theorem and on finite exact certificates, not a uniform constructive argument valid at arbitrary length. The six-replacement bound is established only for the stated finite interval and is not asserted to be minimal. The certificates establish existence, not the number of extremizers or a classification of all sharp words. No independent mathematical audit has been performed.
