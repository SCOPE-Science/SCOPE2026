The binary four-column block-retrieval code \([e_1,e_1,e_2,e_3]\) has expected file-recovery times \((2,6)\), but no rank-three five-column code weakly improves both. In fact every five-column code has \(E_1>2\) or \(E_1=5/3\) and \(E_2\ge15/2\), refuting a proposed one-step monotonicity law for two-file retrieval while leaving the separate hyperbolic conjecture untouched.
