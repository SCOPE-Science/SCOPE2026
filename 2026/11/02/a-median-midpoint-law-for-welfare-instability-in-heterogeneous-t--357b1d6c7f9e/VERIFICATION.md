# Verification notes

The mathematical proof derives each of eight welfare profiles analytically and the exact median-based deviation test. The rational integral is evaluated over all ordered triples with no discretization of the probability space. Run `python3 verify.py` from the same directory; it requires only the standard library. That checker enumerates eight binary profiles and unilateral deviations for each tested generic rational type triple on a finite grid, including a non-Nash witness. This is corroboration, not a proof for all real types. No independent audit or validation has been performed.
