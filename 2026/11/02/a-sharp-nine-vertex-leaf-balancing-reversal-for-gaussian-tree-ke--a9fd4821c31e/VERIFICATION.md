# Reproducibility and mathematical limits

The standalone script `verify.py` requires Python 3's standard library only. Running `python verify.py` reconstructs all nine-vertex tree metrics, traps each algebraic powered distance between two rational numbers using an integer-hundredth-root inequality, and performs outward rational interval \(LDL^{\mathsf T}\) elimination. It verifies all six unrooted reversal classes and all ten ordered triples. The proof is analytic apart from this finite exact sign certificate; it does not rely on floating-point eigensolvers. No external or independent audit has been performed.

The verified strict exponent separator is \(137/100\); the exact critical exponents and their numerical values are not asserted. The scope is precisely three spine vertices and six positive attached leaves. A potential unindexed historical classification is an originality limitation, not a mathematical counterexample.
