## Correctness — PASS
For a symmetric source the reflection \(x\in S\iff F-x\notin S\) bijects pseudo-Frobenius gaps of \(S/3\) with minimal elements in the source's Frobenius residue class, under subtraction by positive source elements divisible by three. Every factorization of a nonzero residue has a one-generator subfactor of the same residue, or two generators of the opposite nonzero residue. Thus the residue module is generated by precisely the finite candidate set, and the minimum filter is exact. The case \(3\mid F\) is separately symmetric. The arithmetic sharpness family has an explicit complete Apéry set with genus half the conductor. The standalone exact checks agree with these deductions, but the universal argument is the proof.

## Mathematical value — PASS

It computes the entire pseudo-Frobenius set for all symmetric inputs with no fixed embedding dimension, with a demonstrably sharp upper bound attained in an infinite family. The fact is structural and applicable to ternary numerical-semigroup quotients, rather than an isolated example or a two-generator specialization.
