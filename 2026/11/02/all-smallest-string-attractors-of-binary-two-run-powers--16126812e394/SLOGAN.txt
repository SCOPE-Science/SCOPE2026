For every binary two-run power \((0^a1^b)^k\), with positive run lengths and at least two repetitions, a pair of positions is a string attractor exactly when it covers the four factors \(0,1,01,10\). There are exactly \((k-1)(k\max(a,b)+1)\) smallest pairs if a run has length one, but exactly \(2k(k-1)\) when both run lengths exceed one; in the latter case all pairs and their distances have explicit classifications.
