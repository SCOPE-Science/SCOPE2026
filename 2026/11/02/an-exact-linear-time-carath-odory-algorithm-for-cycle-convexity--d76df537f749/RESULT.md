# An exact linear-time Carathéodory algorithm for cycle convexity on cactus graphs

## Finding
Let \(G\) be any nonempty finite simple connected cactus graph. In *cycle convexity*, a vertex \(v\) may be added to a set \(X\) if the induced subgraph \(G[X\cup\{v\}]\) contains a cycle through \(v\). Write \(H(X)\) for the closure under repeated additions. The cycle-convexity Carathéodory number \(c_{cc}(G)\) is the largest cardinality of a set \(S\) admitting a vertex \(w\in H(S)\) such that \(w\notin H(S\setminus\{s\})\) for every \(s\in S\).

Construct the bipartite cycle-incidence forest \(F\): its nodes are all original vertices and one node for each (simple) cycle block \(C\) of \(G\); join \(v\) to \(C\) exactly when \(v\in C\). Bridge edges of \(G\) are omitted. For every oriented incidence define nonnegative integer messages by
\[
a_{v\to C}=\max\bigl(1,\max_{D\ni v,\,D\ne C}b_{D\to v}\bigr),
\qquad
b_{C\to v}=\sum_{u\in C\setminus\{v\}}a_{u\to C}.
\]
The maximum of an empty family is ignored. Since \(F\) is a forest, these are unambiguously determined by the components away from each oriented incidence. Then
\[
\boxed{c_{cc}(G)=\max_{v\in V(G)}\max\bigl(1,\max_{C\ni v}b_{C\to v}\bigr).}
\]
This formula, **including a maximum-cardinality Carathéodory independent set and a witnessing vertex**, is evaluable in \(O(|V(G)|+|E(G)|)\) time using two passes over the cycle-incidence forest and backtracking. If the cactus is a forest, the value is one. The formula also applies componentwise to a disconnected cactus forest by taking the largest component value.

## Assumptions and scope
The graph is finite, simple, nonempty, and cactus: each edge belongs to at most one simple cycle. A cycle block always has at least three vertices. Different cycle blocks meet in at most one vertex. The forest \(F\) can have several components because bridge edges are discarded. All maxima and witnesses concern the cycle convexity defined above, **not** triangle-only \(\Delta\)-convexity or \(P_3\)-convexity. Inputs can be given as edge lists; standard depth-first-search biconnected-component decomposition lists all cycle blocks in linear time for cactus graphs.

## Proof
**1. Factor-forest and closure lemma.** Each biconnected block of a cactus is either one edge or one simple cycle. The block-cutpoint graph is a tree, so deleting its bridge blocks and retaining all cycle-vertex incidences yields a forest. Every simple cycle of a cactus is a cycle block; therefore a vertex is added under cycle convexity **if and only if** it is the sole missing vertex of some cycle block. Consequently, a closure cannot transmit an activation across a bridge, and when a particular cycle node is removed from \(F\), the vertex-side branches cannot influence one another without an activation through that cycle.

**2. Essential certificates for a fixed target.** For a vertex \(v\) and a cycle incidence \(vC\), delete this incidence from \(F\). Define \(A(v\mid C)\) as the largest number of seeds in a set \(S\) contained in the \(v\)-side component, such that \(v\in H(S)\) there but \(v\notin H(S\setminus\{s\})\) for every seed \(s\). Similarly define \(B(C\mid v)\) for seed sets in the \(C\)-side component that generate the initially absent terminal \(v\), after reattaching the incidence \(vC\), essentially through \(C\). These maxima are finite. For a vertex \(v\), any essential certificate either is the singleton \(\{v\}\), or first activates \(v\) through a cycle \(D\) incident to \(v\) (other than a forbidden parent incidence). An essential certificate cannot contain a seed in any other branch: while \(v\) is missing, such seeds cannot help activate \(v\) through \(D\), and hence would be inessential. Thus
\[
A(v\mid C)=\max\bigl(1,\max_{D\ni v,\,D\ne C}B(D\mid v)\bigr).
\]
Fix now a cycle \(C\) and its intended missing vertex \(v\). Before the step that first activates \(v\) via \(C\), no other vertex of \(C\) can be activated *by \(C\)*, because \(v\) remains missing. Hence each \(u\in C\setminus\{v\}\) must be generated using seeds in its own \(u\)-branch of \(F-C\). These branches are pairwise disjoint. If a seed failed to be essential for its own \(u\), removing it would still allow all \(u\)'s to activate, then allow \(C\) to activate \(v\), contradicting the essentiality for \(v\). Conversely, unite an optimal essential certificate for every such \(u\). All the \(u\)'s activate, so \(C\) activates \(v\); deleting any chosen seed permanently blocks one \(u\), and because the incidence structure is a forest, there is no alternate route into \(v\). Therefore the union is itself essential and
\[
B(C\mid v)=\sum_{u\in C\setminus\{v\}}A(u\mid C).
\]
The two displayed recurrences prove the message equations by induction on the number of nodes in the relevant rooted incidence branch. The same first-activation argument applied at an unrestricted witness \(v\) proves the boxed global maximum. An arbitrary Carathéodory independent seed set has some witness, so this is both an upper bound and an achievable value.

**3. Linear time and witness construction.** The total size of all cycle-vertex incidence lists is linear in the graph size. To compute all oriented messages, process each tree component once bottom-up, then top-down. At a cycle node, \(b_{C\to v}\) equals the sum of all incident incoming \(a\) messages minus \(a_{v\to C}\); at a vertex node, \(a_{v\to C}\) is one or the largest of the other incoming \(b\) messages. Retain the largest two values and their multiplicities so every exclusion maximum is obtained in constant time. Hence each dart takes constant amortized processing time. Start from the vertex maximizing the global expression; store its selected cycle, and recursively select the largest incoming cycle at each child vertex or the singleton vertex when that is preferable. On entering a cycle, recur independently on every vertex other than its intended missing vertex. The branches are disjoint, so every vertex is visited at most once during witness extraction. The resulting seed set has the optimum cardinality and the chosen root is its essential witness.

**4. Illustrative sharp families.** For a single cycle of order \(\ell\ge3\), the value is \(\ell-1\). For a chain of \(t\ge1\) cycle blocks of lengths \(\ell_1,\ldots,\ell_t\), with consecutive blocks sharing distinct articulation vertices and all other blocks disjoint, the recurrence gives \(1+\sum_{i=1}^t(\ell_i-2)\). In particular a chain of \(t\) triangles has value \(t+1\). If \(t\ge2\) cycles of lengths \(\ell_1,\ldots,\ell_t\) share precisely one common vertex and are otherwise disjoint, the value is the sum of the two largest lengths minus three. Thus for all-triangle friendship graphs with at least two triangles the value is three, independent of the number of triangles. The friendship-graph value also follows from the earlier join-graph theorem of Nair et al.; the general incidence recurrence and arbitrary block chains do not. These contrasting families show that connectivity of the cycle blocks, not just a cycle count, controls the parameter.

## Verification
The included `verify.py` independently constructs the cycle-incidence recurrence and computes cycle-convex hulls by the criterion that a missing vertex has two neighbors in one connected component of the induced seed subgraph. It exhaustively tests every seed subset for the Carathéodory witness condition on all 103 connected cactus types in the NetworkX graph atlas through seven vertices, and separately checks four larger branched examples. It also builds a maximum essential witness and verifies deletion of every seed makes that witness unreachable. Its successful output ends in `VERIFY_OK`. Use `python -m pip install -r requirements.txt` followed by `python verify.py` (Python 3.11 or later). These finite checks corroborate, but do not replace, the branch-decomposition proof for all cactus graphs.

## Relationship to prior work
Nair, Anand, Chandran, and Nascimento (2026) introduced the corresponding Carathéodory problem, proved NP-completeness even for bipartite graphs, determined the value for forests and simple cycles, and studied several graph classes and graph products. The accessible full public rendering of that preprint was inspected across its definitions, general lemmas, graph-class theorems, extremal theorems, and products. Those results do not give the above incidence-forest formula, all-cactus algorithm, or maximum-witness construction; the cycle and forest cases are consistent special cases. Published results on the Carathéodory number in triangle-only \(\Delta\)-convexity cannot cover the claim: on a chordless four-cycle, triangle-only convexity has no activation, whereas cycle convexity has Carathéodory number three. Existing cactus block-decomposition algorithms address different graph invariants. Search-based noncoverage is provisional, not a proof of historical uniqueness.

## Limitations
The theorem requires cactus structure and the specified *cycle* closure. It does not extend automatically to graphs with overlapping cycles, to the \(P_3\)- or \(\Delta\)-convexity notions, or to enumeration of all optimal certificates. The proof is mathematical; the independent computational check is finite. Exhaustive historical-priority verification is not claimed, and no independent external mathematical audit has been performed.
