In a sequential \((1,3)\) bi-threshold sweep on the labelled cycle \(C_n\), every state lands after one sweep in a copy of the binary rotation on \(n-1\) bits, so every attractor is a binary necklace and all primitive-period counts are exact. Each nonconstant necklace has an individual attraction basin whose size is the sum of triangular numbers of its cyclic run lengths; the two constant fixed points each attract exactly \(n\) states.
