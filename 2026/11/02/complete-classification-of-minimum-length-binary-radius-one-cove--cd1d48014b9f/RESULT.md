# Complete classification of minimum-length binary radius-one covering cycles at order seven

## Finding

Let a binary cyclic word \(s=(s_0,\ldots,s_{L-1})\) have an indexed origin, with indices modulo \(L\). Call it a radius-one order-seven covering cycle when every \(t\in\{0,1\}^{7}\) differs in at most one coordinate from some cyclic length-seven window \((s_j,s_{j+1},\ldots,s_{j+6})\). Among all such cycles, the minimum length is \(L=22\).

At this minimum there are **exactly 132 indexed binary cycles**, all with exactly 11 zero and 11 one positions, and every one of their 22 cyclic windows is distinct. Their 132 configurations form six classes under cyclic rotation, and exactly **two** classes under rotation, reversal, and global binary complementation. These two full-symmetry classes have respectively 44 and 88 indexed members. Representatives, whose leftmost printed symbol is position zero, are:

- Class of size 44: `1101110111100100010000`.
- Class of size 88: `1101111001010110010000`.

For *each* of the 132 cycles, exactly 80 of the 128 target seven-bit words occur within Hamming distance one of a unique cyclic window, while the other 48 targets are within distance one of exactly two cyclic windows. No target has greater multiplicity.

## Assumptions and scope

The alphabet is \(\{0,1\}\), the channel metric is the ordinary **Hamming distance** (at most one substitution), the windows are cyclic and indexed, and the seven coordinates within a window retain their order. A circular word and a rotation of it count as different indexed words until symmetry classes are explicitly taken. A sequence of length less than seven has the natural cyclic length-seven windows obtained by repeatedly following its positions modulo the sequence length; these are included in the exhaustive lower-bound check. No deletion, edit-distance, reversal-equivalent window, or partial-word interpretation is used.

The word length \(L\) is a positive integer; the theorem tests all \(1\le L\le22\), and it makes no assertion about the distribution of longer covering cycles.

## Proof

The proof is a complete bounded integer census with all source code provided. Its exhaustive test is reducible to fixed-size bit arithmetic, with no probabilistic steps or untrusted search outcomes.

1. For a seven-bit vector \(a\) interpreted as an integer from 0 through 127, define the 128-bit neighborhood mask
   \[
   B(a)=\sum_{\substack{0\le t<128\\\operatorname{wt}(a\mathbin{\mathrm{xor}}t)\le1}}2^t.
   \]
   Each mask has exactly eight set bits, representing the center and its seven single-bit flips. Since each target is represented by a distinct bit position, the union of these neighborhoods covers all 128 possible targets exactly when their bitwise OR is the all-one 128-bit mask.

2. Every indexed binary word of length \(L\) corresponds bijectively to an integer \(x\) with \(0\le x<2^L\), with the bit at position \(j\) equal to \(s_j\). For \(L\ge7\), put \(z=x\mathbin{\mathrm{or}}(x\ll L)\). The cyclic window beginning at \(j\) is \(w_j=(z\gg j)\mathbin{\mathrm{and}}127\), for \(0\le j<L\). The two concatenated copies of the word supply every bit needed for all seven-symbol windows when \(L\ge7\). For \(L<7\), the verifier reads \(s_{(j+k)\bmod L}\) directly for every \(0\le k<7\).

3. The C11 program `cover_census.c` constructs all 128 neighborhood masks exactly, stored as two unsigned 64-bit halves, and loops through **every** \(x\in\{0,\ldots,2^L-1\}\) for every \(L=1,\ldots,22\). The acceptance predicate is precisely
   \[
   \bigvee_{j=0}^{L-1}B(w_j)=2^{128}-1.
   \]
   The loop contains \(\sum_{L=1}^{22}2^L=8{,}388{,}606\) candidates. Its exact counts are zero for \(L=1,\ldots,21\), and 132 for \(L=22\). This exhausts the entire finite domain relevant to a claimed minimum of 22 and proves both minimum length and total number of optima.

4. On all 132 accepted cycles, the same program computes Hamming weight and the smallest integer in each orbit generated by rotations, reversal, and complementation. It obtains two orbit representatives, encoded by integer values 141243 and 158331 (least-significant bit at position zero), and 132 accepted cycles of weight 11. The independent verifier `verify.py` reconstructs the full orbits, establishes their respective sizes 44 and 88, and checks that their union exhausts the accepted set. It also verifies that all 22 windows of each cycle are distinct, hence none of these cycles has nontrivial rotational period. There are therefore \(132/22=6\) rotation classes.

5. The independent verifier computes for each accepted cycle and each seven-bit target the exact number of windows whose Hamming distance from that target is at most one. It confirms 80 targets of multiplicity one, 48 of multiplicity two, and no other multiplicities, for **all 132** accepted cycles. These two multiplicities account for all \(22\cdot8=176\) target-window incidences.

The two implementations enumerate the candidate words independently; the C program uses dual 64-bit target masks and the Python program uses an arbitrary-precision 128-bit mask. Every test is finite, deterministic, and fully described by the supplied programs.

## Verification

In a directory containing the enclosed `cover_census.c`, `verify.py`, and `optimal_cycles.txt`, run:

```sh
gcc -O2 -std=c11 -Wall -Wextra -pedantic cover_census.c -o cover_census
./cover_census
python3 verify.py
```

The C program must print zero accepted words at lengths 1 through 21, 132 at length 22, two full-symmetry representatives, and weight-11 count 132. The Python program must print `VERIFY_OK`. The supplied `optimal_cycles.txt` records the complete 132-word inventory; it is checked by the Python program but is *not* used to generate its census. The C executable writes a separate `solutions.txt` in its working directory; that intermediate output is not needed by the Python program.

## Relationship to prior work

Chung and Cooper introduced de Bruijn covering codes and tabulated the minimum length 22 for the binary order-seven, radius-one case in their 2003 preprint (journal publication 2004). Their tabulated length does not specify the number, full symmetry types, weight profile, or exact target multiplicities of all optima. Chee, Etzion, Ta, and Vu use an order-seven radius-one covering sequence of length 22 in their 2025 two-dimensional covering construction (Example 26), but their inspected work gives constructions rather than a complete census of minimum cycles. This theorem refines that fixed natural design parameter with a complete exact classification; it is not a new proof of the already documented numerical length alone.

The ordinary size-minimum binary Hamming covering-code problem does not impose adjacency of codewords in a cyclic sequence, so classifications of ordinary covering code sets alone cannot enumerate these cycles. Near-optimal covering-sequence asymptotics likewise do not determine the finite classification here. Literature and research-record searches have not established an equivalent or stronger enumeration, but absence from search is not a proof of historical priority.

## Limitations

This is a complete finite result for the binary order-seven, Hamming-radius-one, **cyclic** problem only. The proof relies on exhaustive enumeration to length 22, not on an all-order structural theorem, and the code is ordinary executable mathematical verification rather than an independently audited formal proof. The first available public literature anchor is October 24, 2003. Historical priority remains exposed to unindexed or inaccessible earlier classifications; independent review has not been performed.
