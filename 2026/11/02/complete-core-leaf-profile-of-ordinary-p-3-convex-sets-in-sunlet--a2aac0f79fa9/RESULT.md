# Complete core–leaf profile of ordinary \(P_3\)-convex sets in sunlet graphs

## Finding
For every integer \(n\ge3\), let \(S_n=C_n\circ K_1\) have labelled cycle vertices \(c_0,\ldots,c_{n-1}\) and a leaf \(\ell_i\) attached to each \(c_i\), with subscripts interpreted modulo \(n\). A subset \(U\subseteq V(S_n)\) is **ordinary \(P_3\)-convex** if every vertex outside \(U\) has at most one neighbour in \(U\). Define the exact two-variable enumerator
\[
B_n(x,y)=\sum_{U\text{ ordinary }P_3\text{-convex}}x^{|U\cap\{c_i\}|}y^{|U\cap\{\ell_i\}|}.
\]
Then the following identity holds as an equality of polynomials with nonnegative integer coefficients:
\[
\boxed{B_n(x,y)=(1+y)^n+x^n(1+y)^n+
\sum_{m=1}^{\lfloor n/3\rfloor}\frac{n}{m}(1+y)^{n-2m}
\sum_{t=m}^{n-2m}\binom{t-1}{m-1}\binom{n-t-m-1}{m-1}x^t.}
\]
In particular, for each \(1\le m\le\lfloor n/3\rfloor\) and \(m\le t\le n-2m\), the number of admissible core sets having exactly \(t\) selected core vertices in \(m\) cyclic runs is
\[
\frac{n}{m}\binom{t-1}{m-1}\binom{n-t-m-1}{m-1},
\]
and **every** such core choice has exactly \(n-2m\) freely selectable leaves, independent of the run lengths.

The size enumerator \(Q_n(z)=B_n(z,z)\) satisfies the order-three polynomial recurrence
\[
\boxed{Q_n(z)=(1+z)^2Q_{n-1}(z)-z(1+z)^2Q_{n-2}(z)+z(1+z)Q_{n-3}(z),\quad n\ge3,}
\]
with *formal recurrence seeds*, not graph enumerators at these small indices,
\[
Q_0(z)=3,\qquad Q_1(z)=(1+z)^2,\qquad Q_2(z)=(1+z)^4-2z(1+z)^2.
\]
Equivalently, the complete generating function of the recurrence is
\[
\sum_{n\ge0}Q_n(z)u^n=\frac{3-2(1+z)^2u+z(1+z)^2u^2}{1-(1+z)^2u+z(1+z)^2u^2-z(1+z)u^3}.
\]
The scalar specialization has the explicit cyclic-run count
\[
B_n(1,1)=2^{n+1}+\sum_{m=1}^{\lfloor n/3\rfloor}\frac{n}{m}\binom{n-m-1}{2m-1}2^{n-2m}.
\]
It equals the previously tabulated integer sequence OEIS A073313 at index \(n\); neither that scalar recurrence nor the scalar numerical sequence is asserted to be newly discovered. What is determined here is the **full core–leaf joint distribution, together with the structural run classification and free-leaf rule**. Its first scalar values at \(n=3,\ldots,10\) are \(22,64,184,524,1488,4224,11992,34048\).

## Assumptions and scope
The graph is finite, simple, undirected, and consists of a simple cycle of length \(n\ge3\) with exactly one distinct degree-one leaf at each cycle vertex. The vertices are labelled by their cyclic positions; subsets are counted distinctly by their actual vertices, not modulo graph automorphisms. The convexity is generated by **all** three-vertex paths, not only induced paths; the defining condition is an outside vertex with at most one selected neighbour. The empty and full vertex sets are included. The variables \(x,y\) commute and record the selected core and pendant vertices separately.

## Proof
**1. Local characterization.** Write \(a_i=1\) if \(c_i\in U\), and \(b_i=1\) if \(\ell_i\in U\). A leaf outside \(U\) has at most one neighbour automatically. The only nontrivial restriction arises at an unselected core vertex; it is exactly
\[
a_i=0\quad\Longrightarrow\quad a_{i-1}+a_{i+1}+b_i\le1.
\]
Thus no cyclic block \(101\) may occur in the core indicator word. Conversely, if the core avoids this block and the indicated pendant restrictions hold, every outside vertex has at most one selected neighbour. This is an if-and-only-if characterization.

**2. Run decomposition.** If the core word is all zeros, all \(n\) leaves are independent free choices, contributing \((1+y)^n\). If the core word is all ones, all leaves are free and every core vertex is counted, contributing \(x^n(1+y)^n\). Every other allowed core word splits uniquely into \(m\ge1\) positive-length runs of ones, separated by \(m\) zero-runs each of length at least two: a single zero between two selected core vertices would be the forbidden block \(101\). With \(t\) ones, necessarily \(m\le t\le n-2m\) and \(m\le\lfloor n/3\rfloor\).

The positive one-run lengths \(r_1,\ldots,r_m\) summing to \(t\) have \(\binom{t-1}{m-1}\) ordered choices. The zero-run lengths \(g_1,\ldots,g_m\ge2\) summing to \(n-t\) have \(\binom{n-t-m-1}{m-1}\) ordered choices, by subtracting two from each. Choosing a labelled start vertex for a distinguished one-run gives \(n\) positions, and every resulting cyclic word has exactly \(m\) choices for the distinguished run. Dividing by \(m\) proves the stated exact labelled core count. In particular, the rational-looking prefactor always produces an integer.

**3. Free pendant vertices.** Every pendant leaf whose core vertex is selected can be chosen freely. In each zero-run, its first and last core vertices each have one selected core neighbour, so their leaves must be omitted; all \(g_j-2\) other zero-run leaves are unrestricted. Consequently the number of freely selectable leaves is
\[
t+\sum_{j=1}^{m}(g_j-2)=t+(n-t)-2m=n-2m.
\]
Multiplying the labelled core count by \(x^t(1+y)^{n-2m}\), then summing over all permissible \(m,t\), proves the joint polynomial identity. No possible convex set is omitted or counted twice because the core word and leaf choices specify it uniquely.

**4. Size recurrence.** Alternatively, assign to each cyclic binary triple \((a,b,c)\) the local weight \(z(1+z)\) when \(b=1\), weight \(1+z\) when \(b=0,a+c=0\), weight \(1\) when \(b=0,a+c=1\), and weight \(0\) when \(b=0,a+c=2\). On the ordered pair states \(00,01,10,11\) the overlap transfer matrix is
\[
M(z)=\begin{pmatrix}
1+z&1&0&0\\
0&0&z(1+z)&z(1+z)\\
1&0&0&0\\
0&0&z(1+z)&z(1+z)
\end{pmatrix}.
\]
For each \(n\ge3\), the cyclic product of local weights counts each valid labelled subset exactly once, hence \(Q_n(z)=\operatorname{tr}(M(z)^n)\). Direct determinant expansion gives
\[
\det(\lambda I-M(z))=\lambda\bigl(\lambda^3-(1+z)^2\lambda^2+z(1+z)^2\lambda-z(1+z)\bigr).
\]
The nonzero-eigenvalue power traces satisfy the displayed third-order recurrence. Newton identities give the formal initial values \(Q_0(z)=3\), \(Q_1(z)=(1+z)^2\), and \(Q_2(z)=(1+z)^4-2z(1+z)^2\). For all actual graph orders \(n\ge3\), these power traces equal the graph enumerators. Summing the recurrence yields the stated rational generating function.

**5. Scalar sum and growth.** On setting \(x=y=1\), the convolution
\[
\sum_{t=m}^{n-2m}\binom{t-1}{m-1}\binom{n-t-m-1}{m-1}=\binom{n-m-1}{2m-1}
\]
follows by coefficient extraction from two copies of \((1-u)^{-m}\), proving the scalar binomial formula. At \(z=1\), the nonzero eigenvalues are the three roots of \(\lambda^3-4\lambda^2+4\lambda-2\). Its unique real root is \(\alpha\approx2.83928675521416\); the conjugate roots have modulus \(\sqrt{2/\alpha}<\alpha\). Thus
\[
B_n(1,1)=\alpha^n+o(\alpha^n),\qquad
\frac{B_n(1,1)}{4^n}\sim\left(\frac\alpha4\right)^n.
\]
The second expression is the proportion of all \(2^{2n}=4^n\) vertex subsets that are convex. This scalar asymptotic also follows from the previously known OEIS recurrence and is given only as a consequence, not as a novelty claim.

## Verification
The independent standalone standard-library program `verify.py` builds the sunlet adjacency list literally and checks the outside-neighbour condition for **every one** of the \(2^{2n}\) vertex subsets for \(3\le n\le9\). It verifies the complete joint coefficient table against the run formula. It separately implements the cyclic four-state transfer and checks agreement with the run formula, Vandermonde specialization, and scalar order-three recurrence for \(3\le n\le22\). The verification run returned `BRUTE_JOINT_OK n=3..9`, `TRANSFER_AND_BINOMIAL_OK n=3..22`, and `VERIFY_OK`. These are finite consistency checks only. The proof above supplies the exhaustive infinite-family argument.

## Relationship to prior work
Dourado, Grippo, Lin, and Protti (arXiv:2603.04706v1, publicly posted March 5, 2026) study the count of ordinary \(P_3\)-convex vertex sets, prove a general hardness result, and give algorithms for trees and threshold graphs. The inspected introduction, definitions, tree algorithm and section organization do not assert the joint core–leaf polynomial for sunlets. Their general algorithms do not themselves state the displayed coefficients.

The sequence \(B_n(1,1)\), including its constant-coefficient recurrence, coincides *exactly* with **OEIS A073313**, documented since 2002 as a binomial transform of generalized Lucas numbers. That match is acknowledged explicitly: the main claim is the graph interpretation plus the full bivariate refinement and cyclic-run characterization, not rediscovery of A073313. Earlier work on \(P_3\)-convex **partitions** concerns a different output; separate counts on ladder/prism graph families do not imply a formula for sunlets. No examined source supplied an equivalent all-parameter joint core–leaf count, but priority under another formulation is not certified.

## Limitations
The result is for the stated sunlet family and ordinary path-of-length-two convexity, not induced-path convexity, other corona graphs, general unicyclic graphs, or enumeration modulo automorphisms. The scalar sequence and scalar recurrence were already recorded; any claim of novelty for those alone would be incorrect. Full historical priority under alternate terminology remains to be independently checked. The computational tests alone do not establish an infinite theorem, and no independent external mathematical audit has been performed.
