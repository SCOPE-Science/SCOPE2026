# Complete triplet-weight spectra for the binary length-\(32\) repeated-root cyclic code chain

## Finding

Let \(R=\mathbb F_2[x]/(x^{32}-1)\) and, for every integer \(0\le i\le32\), let \(C_i=\langle(1+x)^i\rangle\subseteq R\). Define the cyclic triplet weight of a codeword \(c=(c_0,\ldots,c_{31})\) by
\[
w_3(c)=\big|\{j\in\mathbb Z/32\mathbb Z:(c_j,c_{j+1},c_{j+2})\neq(0,0,0)\}\big|.
\]
The complete, exact triplet-weight enumerator of **every one of the 33 codes** is
\[
W_i(z)=\sum_{w=0}^{32}A_{i,w}z^w,
\]
with every integer coefficient \(A_{i,w}\) given by row \(i\), column `A_w`, in the accompanying `SPECTRUM.csv`. Each row also contains the dimension, least positive triplet weight, and number of codewords of that least weight. For the zero code \(C_{32}\), the minimum positive weight is indicated as \(0\) by convention and its minimum multiplicity is also \(0\).

For example, \(C_3\) and \(C_4\) share minimum triplet distance \(6\) but have, respectively, \(144\) and \(112\) minimum-weight nonzero words. The all-nonzero-triplet coefficient for the entire ambient space \(C_0\) is \(A_{0,32}=294{,}294{,}531\), whereas \(A_{16,32}=17{,}155\). These numbers are included as illustrative checks; the finding is the **complete table**, not an isolated coefficient or a formula extending beyond length \(32\). The unrestricted full-space row \(i=0\) can also be obtained from an existing general \(b\)-symbol enumerator recurrence and is **not** claimed as novel by itself.

## Assumptions and scope

All arithmetic defining the codes is over \(\mathbb F_2\). Positions and observed triplets are indexed cyclically, including the windows across the last-to-first boundary. Since \(x^{32}-1=(x+1)^{32}\) in characteristic two, \(C_i\) is the unique cyclic ideal generated by \((1+x)^i\) and has dimension \(32-i\). No restriction is imposed on the distribution of ones or their positions. The declared distance is \(\min\{w_3(c):0\neq c\in C_i\}\) for \(i<32\).

## Proof

**Characterization of the code chain.** Over \(\mathbb F_2\), Lucas's binomial-congruence criterion gives
\[
\binom{k}{j}\bmod 2=1\quad\Longleftrightarrow\quad(k\mathbin{\&}j)=j,
\]
where the right-hand side is binary digitwise containment. For \(c(x)=\sum_{k=0}^{31}c_kx^k\), its \(j\)-th Hasse derivative at \(1\) is
\[
H_j(c)=\sum_{k=j}^{31}\binom{k}{j}c_k\in\mathbb F_2.
\]
The root \(1\) has multiplicity at least \(i\) precisely when \(H_j(c)=0\) for all \(0\le j<i\). This proves the equivalence between code membership and the syndrome conditions used below.

**Low-index exact enumerator (\(0\le i\le11\)).** Track an \(11\)-bit Hasse syndrome \(s\), the last two bits \(a,b\), and an accumulated integer weight \(w\), separately for each initial pair \((c_0,c_1)\). Initialize \(s=c_0h_0\oplus c_1h_1\), \((a,b)=(c_0,c_1)\), \(w=0\), with count one, where \(h_k\) is the \(11\)-bit column \(h_{k,j}=\binom{k}{j}\bmod2\). For each \(k=2,\ldots,31\), append \(d\in\{0,1\}\), updating
\[
(s,a,b,w)\longmapsto\big(s\oplus dh_k,b,d,w+\mathbf1[a\lor b\lor d]\big).
\]
At the end add
\[
\mathbf1[c_{30}\lor c_{31}\lor c_0]+\mathbf1[c_{31}\lor c_0\lor c_1]
\]
to the accumulated weight. Thus the first 30 observed windows and both wrapping windows are counted exactly once. Summing over all four initial pairs yields a complete histogram \(H(s,w)\). For each \(0\le i\le11\), the output coefficient is
\[
A_{i,w}=\sum_{s:\;s\bmod2^i=0}H(s,w).
\]
This recurrence enumerates every \(32\)-bit word once, so it is exact, not a random or partial sample.

**High-index exact enumerator (\(12\le i\le32\)).** For each \(i<32\), every codeword has a unique representation
\[
c(x)=(1+x)^i q(x),\qquad \deg q<32-i.
\]
The product degree is less than \(32\), so there is no wraparound or quotient ambiguity. Enumerating all \(2^{32-i}\) binary coefficient vectors for \(q\) therefore traverses every codeword exactly once. The corresponding cyclic triplet weight is the population count of the 32-bit mask obtained by OR-ing the vector with its cyclic rotations by one and two positions. The source `verify.c` uses a Gray-code walk through the message space; each step toggles exactly the appropriate generator shift. For \(i=32\), the unique codeword is zero.

**Connection and completeness.** The low-index method covers \(i\le11\) and the generator method covers \(i\ge12\), with no missing index. The complete coefficient array produced by both exact finite procedures is compared entry by entry with `SPECTRUM.csv` in `verify.c`. This constitutes an independently replayable finite exhaustive proof for all \(33\times33\) coefficients. The independent Python checker also enumerates both sides of the method boundary at indices \(11\) and \(12\).

## Verification

In a clean directory containing the three supplied data/code files `SPECTRUM.csv`, `verify.c`, and `crosscheck.py`, execute:

```sh
cc -O3 -std=c11 -Wall -Wextra -pedantic -o verify verify.c
./verify
python3 crosscheck.py
```

The expected final lines are `VERIFY_OK` and `CROSSCHECK_OK`. The C verifier reconstructs all coefficients, checks \(\sum_w A_{i,w}=2^{32-i}\), checks the declared minimum distances and multiplicities, and rejects any mismatched data. The separate Python verifier regenerates selected rows with an independently implemented binomial generator, checks nested-code coefficient monotonicity and conservation, and evaluates the cyclic avoidance transfer matrix for \(A_{0,32}\).

## Relationship to prior work

Zhu–Sun–Wang (2016) determine **minimum symbol-pair distances** for the repeated-root cyclic codes of prime-power length. Mostafanasab–Sevim (2017) extend aspects of the minimum-distance analysis to longer symbol-read windows and selected repeated-root families. Those distance formulas do not give the distribution of how many codewords attain each possible triplet weight. Zhu–Shi–Özbudak (2021) determine complete \(b\)-symbol enumerators for a family of **irreducible** cyclic codes, not this binary repeated-root code chain. Vega's later semiprimitive-irreducible work similarly assumes lengths coprime to field order, contrary to the repeated-root length \(32\) here. Abdukhalikov–Chen–Feng (2023) provide a general recurrence for the full ambient-space \(b\)-weight enumerator, which covers the \(i=0\) row but not the weight enumerators of the nontrivial repeated-root subcodes. The present contribution is the concrete full 33-code triplet-weight coefficient table, not a claimed general all-length formula or the already-known definitions and distance reductions.

## Limitations

The exact table applies only to binary cyclic length \(32\), triplet-window length \(3\), and the full chain of powers of \((1+x)\). It does not determine analogous distributions for different lengths, alphabets, or read-window sizes. Although two exact enumeration approaches cover the parameter range and independent replay checks are provided, there has been no independent scientific audit, and historical-priority checks cannot exclude unindexed tables or unpublished calculations. The individual counts are mathematical enumerations, not experimentally measured channel error probabilities.
