# Verification scope and replay

Execute `python3 verify.py` in the directory containing `ORBIT_TABLE.csv`. The program requires only the Python standard library. Its `VERIFY_OK` line is issued after verifying all codewords, all syndromes, all error subsets up to the covering radius, group-generation order, invariant leader-multiplicity distributions, and all twenty-two stored orbit rows.

The finite enumeration is complete because the syndrome space has exactly \(2^{13}=8192\) states and the BFS confirms that every syndrome is covered by an error of weight at most \(5\). The codeword test covers all \(8192\) information vectors; the direct error-subset test is exhaustive for the reported covering radius. Every orbit is generated by explicitly verified coordinate-induced permutations and the orbit union exhausts the syndrome space.

No external, independently performed audit or validation is claimed. The cited literature supplies the pre-existing uniqueness and full-group identification, not an external verification of this new coset census. The calculation does not address other lengths, general binary self-dual codes, or priority completeness.
