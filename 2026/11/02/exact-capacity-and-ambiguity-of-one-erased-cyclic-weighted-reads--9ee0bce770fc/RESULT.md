# Exact capacity and ambiguity of one-erased cyclic weighted reads

## Finding

For integers \(n\ge3\), \(q\ge2\), and \(2\le\ell<n\), consider length-\(n\) sequences over the alphabet \(\{0,1,\ldots,q-1\}\), with fixed cyclic indexing, and a readout reporting the ordinary integer sum of each consecutive length-\(\ell\) window. Suppose one readout coordinate is erased and its position is known. By cyclic relabeling, take the missing coordinate to be zero, and let \(F_{q,n,\ell}\) denote the remaining \(n-1\) coordinates.

Set \(g=\gcd(n,\ell)\). If \(g>1\), the missing numeric sum is a linear combination of the remaining sums: **the entire inverse-fiber partition is unchanged**. If \(g=1\), choose the unique \(r\in\{1,\ldots,\ell-1\}\) satisfying \(nr\equiv1\pmod\ell\), and put \(m=(nr-1)/\ell\). Then

\[
\boxed{|\operatorname{im}F_{q,n,\ell}|=q^n-[q-r]_+^{n-m}[q-(\ell-r)]_+^m,}\qquad [u]_+=\max(u,0).
\]

The image size is exactly the largest zero-error code size for this deterministic observation channel. Every nonempty inverse fiber is a consecutive integral chain, and the largest fiber has size

\[
\boxed{1+\left\lfloor\frac{q-1}{\max(r,\ell-r)}\right\rfloor.}
\]

For binary sources, if \(g=1\) and \(\ell\ge3\), the erased-read map remains injective and has exactly \(2^n\) outputs. If \(g=1\) and \(\ell=2\), then \(n\) is odd, there is precisely one two-element inverse fiber, and the exact number of outputs is \(2^n-1\). The erased coordinate is arbitrary but known.

## Assumptions and scope

All symbols are ordinary integers, not elements of a modular ring. The window sum is computed over the integers, not modulo any number. Source words are *indexed*: different rotations are distinct sources, and the surviving read coordinates retain their positions. The erasure location is supplied to the decoder. There are no other errors or erasures. The parameters satisfy \(n\ge3\), \(q\ge2\), and \(2\le\ell<n\). The main formula is for the coprime case; the noncoprime result is an exact fiber-invariance statement, not an asserted new formula for the already-studied full-read image.

Write

\[
s_i(x)=\sum_{j=0}^{\ell-1}x_{(i+j)\bmod n},\qquad F_{q,n,\ell}(x)=(s_1(x),\ldots,s_{n-1}(x)).
\]

## Proof

**1. A redundant coordinate when the gcd is nontrivial.** Suppose \(g=\gcd(n,\ell)>1\). Define coefficients \(c_i=1\) if \(i\equiv0\pmod g\), \(c_i=-1\) if \(i\equiv1\pmod g\), and \(c_i=0\) otherwise. Each source coordinate occurs in exactly \(\ell/g\) of the sum windows with starting index in each residue class modulo \(g\), because \(g\) divides both \(n\) and \(\ell\). Thus \(\sum_i c_i s_i(x)=0\) for every real or integer source \(x\). Since \(c_0=1\), the missing sum is determined by surviving coordinates. Consequently the full and erased maps have exactly the same fibers, proving the first assertion.

**2. The primitive one-hole kernel when the gcd is one.** Suppose \(g=1\). As \(n\) is invertible modulo \(\ell\), there is a unique integer \(r\) in \(\{1,\ldots,\ell-1\}\) with \(nr\equiv1\pmod\ell\). Define \(m=(nr-1)/\ell\), so \(1\le m<n\) and \(nr-m\ell=1\). Because \(\gcd(n,\ell)=1\), the residues \(\ell,2\ell,\ldots,m\ell\pmod n\) are distinct. Let \(B\) be this set, and define

\[
v_i=\begin{cases}r-\ell,&i\in B,\\ r,&i\notin B.\end{cases}
\]

There are \(m\) negative entries and \(n-m\) positive entries, and \(\sum_i v_i=nr-m\ell=1\). The defining set \(B\) is a consecutive segment in the cyclic index order given by jumps of \(\ell\); its membership changes only across the steps starting at residues zero and minus one. Hence

\[
v_{i+\ell}-v_i=\ell\bigl({\bf1}_{i\equiv-1\pmod n}-{\bf1}_{i\equiv0\pmod n}\bigr).
\]

Since \(s_{i+1}(v)-s_i(v)=v_{i+\ell}-v_i\), all window sums \(s_1(v),\ldots,s_{n-1}(v)\) are equal, and \(s_0(v)\) exceeds each by \(\ell\). Summing all window sums counts each symbol \(\ell\) times, giving \(\sum_i s_i(v)=\ell\sum_i v_i=\ell\). Consequently

\[
(s_0(v),s_1(v),\ldots,s_{n-1}(v))=(\ell,0,\ldots,0).
\]

To prove this is the entire real one-hole kernel, first observe that the full circulant window-sum operator is invertible over the reals when \(g=1\). Indeed, if all window sums of a real vector \(z\) vanish, subtracting adjacent window sums gives \(z_{i+\ell}=z_i\) for all indices. Coprimality makes \(z\) constant, and the vanishing sum makes that constant zero. Therefore the \(n-1\) surviving rows are independent, and their kernel is exactly the real line spanned by \(v\).

The two possible coordinate values of \(v\) have gcd \(\gcd(r,\ell-r)=\gcd(r,\ell)=1\). Both occur. Hence whenever an **integer** vector lies on the real line generated by \(v\), its scalar parameter is an integer, by an integer Bézout combination of any two coordinates with these values. Thus every inverse fiber has the form

\[
\{x+t v:t\in\mathbb Z,\ 0\le x_i+t v_i\le q-1\text{ for every }i\},
\]

for any one member \(x\), and the admissible values of \(t\) constitute an interval of consecutive integers.

**3. Count the chains, not merely the source words.** Regard each source word as a vertex and link \(x\) to \(x+v\) whenever both are legal. By the primitive-kernel argument, these links form disjoint finite paths, one per distinct erased read vector; there are no cycles. The number of components is therefore the total number \(q^n\) of vertices minus the number of links.

At each of the \(n-m\) coordinates where \(v_i=r>0\), the condition that \(x_i\) and \(x_i+r\) lie in the alphabet allows precisely \([q-r]_+\) choices. At each of the \(m\) coordinates where \(v_i=r-\ell<0\), there are \([q-(\ell-r)]_+\) choices. These choices are independent. The number of links is the product \([q-r]_+^{n-m}[q-(\ell-r)]_+^m\). Subtraction establishes the exact image formula.

**4. Sharp inverse-list maximum.** If a fiber has \(k+1\) members, its extreme members differ by \(k v\), and each source coordinate lies between zero and \(q-1\). Since both coordinate values \(r\) and \(-(\ell-r)\) occur, this forces \(k\max(r,\ell-r)\le q-1\). Conversely, take a source with zero at each positive-\(v\) coordinate and \(q-1\) at each negative-\(v\) coordinate. Adding \(t v\) is valid for every integer \(t\) from zero through \(\lfloor(q-1)/\max(r,\ell-r)\rfloor\), attaining the claimed maximum.

**5. Binary consequences.** When \(q=2\), a link can occur only if both \(r=1\) and \(\ell-r=1\), equivalent to \(\ell=2\). Coprimality then makes \(n\) odd. The two choices counts each equal one, so there is exactly one link and the image size is \(2^n-1\). For \(\ell\ge3\) there are no links and every source is uniquely reconstructed from the surviving sums. This concludes the proof.

## Verification

The independent standalone script `verify.py` computes the forward window sums directly and groups source words by their observed surviving sums. For all eligible widths, it exhaustively checks the counts, largest inverse-fiber sizes, and—when \(g>1\)—preservation of every fiber size, for \(q=2\) through \(n=15\), \(q=3\) through \(n=10\), \(q=4\) through \(n=8\), and \(q=5\) through \(n=7\). Across all cases this covers 163 triples of parameters and 2,409,791 forward source instances. The same script independently checks the explicit kernel relation for all coprime parameter pairs with \(3\le n\le250\). All checks passed. These finite checks corroborate but do not replace the all-parameter proof.

For example, with \(q=3\), \(n=7\), and \(\ell=3\), the parameters are \(r=1\) and \(m=2\). The number of distinct outputs is \(3^7-2^5=2155\), and the maximum list size is two. With binary alphabet and \(n=7\), the respective output counts for \(\ell=2\) and \(\ell=3\) are \(127\) and \(128\).

## Relationship to prior work

Yerushalmi, Etzion and Yaakobi [1] introduced and analyzed capacity for a weighted-read channel with shifted windows, including exact asymptotic regimes. Its observation vectors are linear rather than cyclic, and the inspected results do not give an all-blocklength known-position erasure formula. Banerjee, Yehezkeally, Wachter-Zeh and Yaakobi [2] consider a nanopore weighted-read output with a deletion of unknown location and a noncyclic boundary convention; that channel is not the present coordinate-erasure model. The broader error-correction formulation of related weighted-read models appears in [3]. The complete *unpunctured* cyclic observation model provides only a full-output fiber enumeration; a single-coordinate projection can in general merge such fibers, and the present result determines precisely when and how that happens. In particular, the proof for the coprime case classifies integer trajectories and counts every resulting merged class.

## Limitations

This is a noiseless, **known-erasure-location**, full-overlap cyclic weighted-sum model. It does not cover unknown deletion positions, compositions rather than scalar sums, modular arithmetic, multiple erased positions, or noncyclic boundary models. In the noncoprime regime the result is exact preservation of prior full-read fibers, not a stand-alone formula for their count. The literature comparison cannot exclude all unindexed results under circulant-matrix or integer-tomography terminology. An independent expert audit has not been performed.
