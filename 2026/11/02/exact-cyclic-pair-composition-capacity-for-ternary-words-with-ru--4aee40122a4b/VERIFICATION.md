# Verification

Run `python3 verify.py` using Python 3 and the standard library. A successful run reports direct word enumeration through length ten; independent dynamic profile construction through length eighteen; exhaustive graph-realizability comparisons on sizes two to five; all coefficients from the positive parameterization through length forty-five; and two thousand explicit Eulerian source witnesses. The verifier checks identities and constructed objects but does not replace the infinite mathematical proof. In particular, exhausting bounded-length sources does not establish the theorem at unbounded lengths, and unsuccessful bibliographic searches do not prove novelty.
