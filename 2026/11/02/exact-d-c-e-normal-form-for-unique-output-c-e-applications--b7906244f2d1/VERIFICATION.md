# Verification

The normal-form proof uses enumeration of the first output and later detection of a conflicting output. These are computably enumerable positive events. The converse construction emits the computable output and one distinct output on the enumerated erasure set. For composition, the candidate erased set is c.e. after waiting for the composite computation and the relevant erasure witness. The sharpness example uses a fixed noncomputable c.e. set and its even/odd coding.

Execute the included standalone `checker.py` with Python 3. It exhausts all \(512\) relations on a three-element carrier and \(262144\) ordered pairs for composition. It reports `ALL_CHECKS_OK relations=512 composition_pairs=262144` on successful completion. This test verifies finite identities only; no experiment establishes effective index statements for arbitrary infinite c.e. enumerations. The cited literature was used for comparison, not as a computational certificate. Historical-priority risk persists.
