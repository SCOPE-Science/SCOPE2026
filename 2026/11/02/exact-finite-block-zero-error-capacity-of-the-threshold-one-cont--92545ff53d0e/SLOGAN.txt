For the deterministic contextual deletion map that removes the first symbol of each noninitial run, the exact maximum \(q\)-ary zero-error code size has generating function \(qz/((1-z)(1-z-(q-1)z^2))\) for every \(q\ge2\). Its capacity is \(\log_2((1+\sqrt{4q-3})/2)\) bits per input symbol, and every output has a unique shortest preimage obtained by extending each noninitial run by one symbol.
