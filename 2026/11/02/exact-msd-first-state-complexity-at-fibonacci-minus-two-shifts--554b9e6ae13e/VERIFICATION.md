# Reproduction and limits

Run `python verification/check_integer.py` to verify all distinguishing-prefix signatures, the terminal-deviation formula, and the single-Fibonacci rotation-classification table for \(5\le k\le100\) using integer greedy Zeckendorf digits. Run `python verification/check_rotation.py` for an independent standard-library 150-digit decimal-rotation evaluation for \(5\le k\le70\). The captured output files were generated by executing the included scripts.

The upper bound uses the published interval-consistency construction of arXiv:2603.18858v1; Appendix B of that work gives the nonstandard justification for the intervals. The lower bound is the all-parameter proof in `RESULT.md`. Numeric checks are finite corroboration only; they neither establish new-parameter truth nor independent review. Inputs with consecutive ones are outside the model, and the theorem makes no claim for arbitrary shifts.
