In the four-row rook graph \(K_4\square K_n\), mutual visibility is equivalent to avoiding an all-selected Cartesian rectangle, yielding an explicit polynomial counting every visible set for \(n\ge2\). For \(n\ge6\), every inclusion-maximal visible set has one of exactly four sizes \(n+3,n+4,n+5,n+6\), with all four multiplicities determined in closed form; a uniformly sampled maximal set has maximum size with probability \(1-64/n^2+O(n^{-3})\).
