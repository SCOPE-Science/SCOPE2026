For every number of rows and columns, the exact binary sum-channel one-edit code size is \(2^{\ell(n-1)}A_2(\ell,3)\), where \(A_2(\ell,3)\) is the classical binary distance-three packing number. The exact converse comes from fixing all but one data column, and every optimal code has maximum distance-three sections; in particular eight rows admit a 25% larger code than the shortened-Hamming instance.
