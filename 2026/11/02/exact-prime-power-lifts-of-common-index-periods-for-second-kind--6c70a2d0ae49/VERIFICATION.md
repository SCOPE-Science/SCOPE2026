# Reproducible arithmetic checks

The standalone `verify.py` uses Python 3 standard library only, with no network requirement. It enumerates every unit parameter and every residue argument in the finite collection of rings specified in its source; tests the displayed common matrix period; excludes every proper prime-divisor quotient by an actual witness; cross-checks sample polynomial recurrence indices independently; and verifies the critical derivative identity at nonsquare finite-field points.

Run `python3 verify.py`. The printed `VERIFY_OK` counts are generated by the code at execution, not asserted from a theoretical bound. The unbounded theorem requires the written field, Jordan, derivative and prime-power lifting proof. In particular, experiments cannot certify the assertions for every prime or every exponent.

This is not independent mathematical auditing. No proof assistant or external certification is claimed.
