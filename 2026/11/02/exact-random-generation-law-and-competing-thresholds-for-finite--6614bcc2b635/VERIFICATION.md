Use Python 3 with the standard library. Extract `checker.py` from the same package and run `python checker.py`. The expected final line is `ALL_CHECKS_OK`. Exhaustive checks span all nontrivial products with up to three factors and every ordered generator tuple of lengths \(0\), \(1\), \(2\). For these domains the checker recomputes subalgebra closure under \(\neg\), \(\oplus\), and \(0\), and compares it with the proved profile criterion and exact formula. A numerical test checks three critical-window instances at \(d=32\). None of the finite checks alone proves the general symbolic theorem or its Poisson convergence. The proof in RESULT.md handles arbitrary \(d,k,\ell\) and the full limit.
