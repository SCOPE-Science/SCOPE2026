For triangular graphs \(T_n=L(K_n)\), unrestricted-depth first-order logic with \(p\) variables sees the root size exactly up to \(2p-1\) and collapses every larger size into one class; remarkably, ordinary quantifier rank \(p\) yields precisely the same partition. All classes and the sharp \(2p\)-root-point cutoff are witnessed by finite path forests.
