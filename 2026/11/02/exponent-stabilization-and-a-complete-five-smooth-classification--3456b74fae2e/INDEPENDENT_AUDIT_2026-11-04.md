# Independent mathematical audit

## correctness

PASS

Reconstructed finite abelian unit-group Frattini lifting: for odd p, reduction modulo p² from p^e (e>=3) has kernel in the p-th-power component, hence in Phi; for p=2 reduction modulo 8 from 2^e (e>=4) has kernel in the square subgroup. Cartesian products preserve the Frattini kernel inclusion. As n and kappa(n) have the same prime support, the same admissible initial generators appear, proving G(n)=G(kappa(n)) for all n, with G(1)=G(2)=1. Independently recomputed all 36 reduced {2,3,5} moduli using direct modular subgroup breadth-first closure and verified each claimed B generates, B-1 does not. This proves the four-by-four table and maximum 17 for every exponent triple, not merely a finite-range conjecture. Edge examples G(4)=3, G(8)=5, G(42)=11, G(126)=13 independently checked.

## originality

PASS

Basic Frattini lifting is classical, and individual small G(n) values are present in OEIS A232928; those steps/entries are not independently new. Bellotti addresses analytic bounds for the same invariant, not the stated complete exponent-clipped 2-3-5 table in the accessible description. Best-of-knowledge novelty remains the combined universal stabilization and infinite exact fixed-support classification, with possible equivalence in Bach–Huelsbergen or older computational modular-generator literature.

## value

PASS

G(n) is a natural recognized unit-group generation threshold, not an arbitrary constructed sequence. Reducing all prime-power exponents uniformly provides a reusable classification method for fixed prime support; the complete all-exponent {2,3,5} table and its sharp maximum 17 answer a precise nontrivial arithmetic question beyond average bounds, even though its group-theoretic lifting ingredient is elementary.
