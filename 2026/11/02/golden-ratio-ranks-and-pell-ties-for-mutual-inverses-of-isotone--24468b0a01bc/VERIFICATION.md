# Reproducible mathematical checks

Run `python3 verify_direct.py` and `python3 verify_asymptotic.py` using Python 3 with its standard library. Both end in `VERIFY_OK` when all assertions hold. The first performs exhaustive semigroup composition for every ordered pair in \(\mathcal O_n\), \(1\le n\le6\), and checks the inverse relation directly. The second independently counts kernel-transversal incidences through \(n=11\), checks modes through \(n=150\), including the first Pell tie at \(n=72\), and measures convergence of the exact global count to its proved asymptotic at \(n=50,100,200,400\). The two output files were generated by running the exact included code.

The finite checks are not proofs for all \(n\). The all-dimensional claims depend on the crossed kernel-transversal equivalence, the integer-composition generating function, the factorial ratio, the complete Pell parametrization, uniform Stirling estimates, and the discrete Laplace argument in RESULT.md. No external certificate or independent audit is represented by these scripts.
