# Reproduction and evidence

Run `python3 verify.py` with Python 3 and the standard library. The program constructs the graph directly from clique fibers and adjacent base cliques. It computes all shortest paths with BFS predecessors and tests the mutual-visibility condition directly for each subset. It separately constructs predicted polynomials from connected base subtrees and their boundary-neighborhood conditions. It tests all one-vertex additions for maximality and compares full coefficient maps.

Observed output: `VERIFY_OK graph_instances=214 candidate_subsets=185798 maximum_order=12`. The direct comparisons include general trees generated by Prüfer sequences, variable fiber widths, and uniform clique paths. A deterministic seed fixes variable-width choices. The output does not count a mathematical proof of all parameter values: unrestricted correctness is established by the structural argument in RESULT.md.
