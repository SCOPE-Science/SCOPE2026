# Order-twenty-four rowmotion on complete-bipartite incidence posets

## Finding

For each integer \(n\ge1\), let \(P_n=P(K_{2,n})\) be the vertex–edge incidence poset of the complete bipartite graph with two vertices on one side and \(n\) on the other. Classical rowmotion \(\rho_n\) permutes its order ideals with exact order \(24\). Only the cycle lengths \(2,3,4,6,8,24\) occur. If \(c_d(n)\) denotes the number of distinct cycles of length \(d\), then

\[
\begin{aligned}
c_2(n)&=2^{n-1},\\
c_3(n)&=3^{n-1}-2^n+2,\\
c_4(n)&=2^n-2,\\
c_6(n)&=\frac{5^n-7\cdot3^n+11\cdot2^n-6}{6},\\
c_8(n)&=3\cdot2^{n-1}-2,\\
c_{24}(n)&=3^{n-1}-2^n+1.
\end{aligned}
\]

For \(n\ge3\) all six types actually occur; for \(n=1\), only lengths \(2,3,8\) occur, and for \(n=2\) only lengths \(2,3,4,8\) occur. In particular, a primitive \(24\)-cycle exists exactly when \(n\ge3\); for smaller \(n\) the permutation still has order \(24\) as the least common multiple of occurring lengths. The number of ideals is

\[
|J(P_n)|=5^n+2\cdot3^n+2^n.
\]

## Assumptions and scope

The graph \(K_{2,n}\) has bipartition \(\{a,b\}\sqcup\{v_1,\ldots,v_n\}\). The poset has minimal elements \(a,b,v_1,\ldots,v_n\) and maximal elements \(e_{a,j},e_{b,j}\) for each \(1\le j\le n\), with the only strict order relations \(a<e_{a,j}\), \(v_j<e_{a,j}\), \(b<e_{b,j}\), and \(v_j<e_{b,j}\). An order ideal is a downward-closed subset. Rowmotion sends an ideal \(I\) to the ideal generated by the minimal elements of \(P_n\setminus I\). All elements and right-side vertices are labelled; cycles are cycles of this permutation, not orbits modulo automorphisms. This is classical order-ideal rowmotion, not birational or piecewise-linear rowmotion.

## Proof

**1. A five-letter column alphabet.** Encode whether \(a,b\) belong to an ideal by Boolean bits \(A,B\). For every \(j\), encode the inclusion of \(v_j,e_{a,j},e_{b,j}\) by bits \(r_j,\alpha_j,\beta_j\), with constraints \(\alpha_j\le A r_j\) and \(\beta_j\le B r_j\). Write the column code \(x_j=r_j+2\alpha_j+4\beta_j\). If \(L=A+2B\), the admissible codes are precisely

| \(L\) | Allowed codes |
| --- | --- |
| 0 | 0, 1 |
| 1 | 0, 1, 3 |
| 2 | 0, 1, 5 |
| 3 | 0, 1, 3, 5, 7 |

Consequently, independently choosing a column from the admissible alphabet gives the displayed ideal count \(2^n+2\cdot3^n+5^n\).

**2. Exact local recurrence.** The minimal complement consists of every missing minimal vertex, together with any missing maximal edge element both of whose endpoints are included. Set \(u_j=A r_j(1-\alpha_j)\) and \(w_j=B r_j(1-\beta_j)\). Applying the definition of rowmotion gives

\[
\begin{aligned}
A'&=(1-A)\lor\bigvee_{j=1}^n u_j,&
B'&=(1-B)\lor\bigvee_{j=1}^n w_j,\\
r'_j&=(1-r_j)\lor u_j\lor w_j,&
\alpha'_j&=u_j,\qquad\beta'_j=w_j.
\end{aligned}
\]

Here multiplication is Boolean conjunction, \(\lor\) is Boolean disjunction, and \(1-z\) negates a bit. This recurrence is not an approximation: it is a direct restatement of the minimal-complement definition for every admissible ideal.

**3. Reduction to \(48\) support classes.** For a fixed pair \((A,B)\), let \(T\) be the nonempty set of distinct codes occurring among the \(n\) labelled columns. The update of the two left bits depends only on the *presence* of each code in \(T\), and each column's update depends only on its current code and those left bits. Therefore an orbit's exact period depends only on \((L,T)\), never on the positive multiplicities of the codes. To compute it, realize each code in \(T\) exactly once, with \(|T|\) individually labelled right vertices; then iterate rowmotion directly on the resulting ideal of \(P(K_{2,|T|})\). All possible pairs \((L,T)\) number \((2^2-1)+2(2^3-1)+(2^5-1)=48\).

A finite exhaustive calculation, using the definition of minimal complement rather than the column recurrence, gives the following **complete** table. Each entry counts initial pairs \((L,T)\) with the indicated period and support size \(k=|T|\):

| Period \(d\) | \(k=1\) | \(k=2\) | \(k=3\) | \(k=4\) | \(k=5\) |
| ---: | ---: | ---: | ---: | ---: | ---: |
| 2 | 2 | 1 | 0 | 0 | 0 |
| 3 | 3 | 0 | 1 | 0 | 0 |
| 4 | 0 | 4 | 0 | 0 | 0 |
| 6 | 0 | 0 | 3 | 5 | 1 |
| 8 | 8 | 12 | 0 | 0 | 0 |
| 24 | 0 | 0 | 8 | 0 | 0 |
| Total | 13 | 17 | 12 | 5 | 1 |

The complete source of this constant-size certificate is `verify_support.py`. It considers all allowed left bit pairs, enumerates every nonempty support by combinations, creates its labelled incidence poset, computes the ideal of the minimal complement directly, and tests the first exact return. It asserts all \(48\) values and the entire table. No extrapolation from \(n\le5\) is used: the proven recurrence shows that this finite table governs every \(n\).

**4. Counting labelled cycles.** Put

\[
S_k(n)=\sum_{i=0}^k(-1)^i\binom{k}{i}(k-i)^n.
\]

This is the number of surjections from the set of \(n\) labelled columns onto a prescribed \(k\)-element set of codes. Thus an entry \(m\) in the table at \((d,k)\) contributes exactly \(m S_k(n)/d\) different length-\(d\) cycles. Reading each row gives

\[
\begin{aligned}
c_2&=(2S_1+S_2)/2, & c_3&=(3S_1+S_3)/3,\\
c_4&=S_2, & c_6&=(3S_3+5S_4+S_5)/6,\\
c_8&=S_1+3S_2/2, & c_{24}&=S_3/3.
\end{aligned}
\]

In these expressions every \(S_k\) is evaluated at \(n\). Expanding inclusion–exclusion yields precisely the six formulas in the Finding. The total of cycle lengths times counts is \(5^n+2\cdot3^n+2^n\), so every ideal is accounted for.

**5. Sharp order.** The table shows that all periods divide \(24\), hence \(\rho_n^{24}\) is the identity for every \(n\ge1\). For every \(n\), the \(k=1\) support rows exhibit periods \(3\) and \(8\); their least common multiple is \(24\), so no smaller positive permutation order is possible. For \(n\ge3\), the \(k=3\), \(d=24\) supports additionally yield genuine length-\(24\) cycles.

## Verification

Running `python3 verify_support.py` from a directory containing that file verifies the entire \(48\)-case support-period table via direct poset rowmotion and prints `SUPPORT_PERIOD_CERTIFICATE_OK supports=48`. Running `python3 verify_direct.py` independently generates *all* ideals and their cycle decompositions for \(1\le n\le6\), checking against the symbolic formulas; it prints six `FULL_CENSUS_OK` lines and `FULL_REPLAY_OK`.

For \(n=3\), the direct cycle counts (in order of lengths \(2,3,4,6,8,24\)) are \((4,3,6,3,10,2)\), accounting for all \(187\) ideals. For \(n=6\), they are \((32,181,62,1870,94,180)\), accounting for all \(17{,}147\) ideals. The infinite conclusion follows from the support lemma and complete \(48\)-state table, not from these six finite tests.

## Relationship to prior work

Striker and Williams, *Promotion and Rowmotion* (first public version August 4, 2011, arXiv:1108.1172), define the same classical operator and develop equivariant bijections for products of chains, root posets, and related classes. Their statements do not yield the exact labelled cycle census above. Grinberg and Roby's *Iterative properties of birational rowmotion* (first public version February 25, 2014, arXiv:1402.6178) includes a classical-rowmotion analysis of skeletal posets. The incidence posets studied here are not a connected ordinal sum of two antichains, as a connected height-two skeletal poset must be, and that analysis supplies neither these cycles nor the asserted count formulas.

Neither these broader dynamical frameworks nor the known enumeration of ideals alone implies the \(24\)-period phenomenon or the six cycle formulas. This comparison is bounded by the inspected literature; no claim is made that every unindexed theorem or database entry has been examined.

## Limitations

The theorem concerns only classical rowmotion on the stated labelled posets for \(n\ge1\). It does not assert the same order for birational rowmotion, for arbitrary \(K_{m,n}\), or for general graph-incidence posets. The proof's nontrivial finite case distinction is supplied as executable source with all \(48\) cases; third-party mathematical review and exhaustive global literature priority checks have not been performed.
