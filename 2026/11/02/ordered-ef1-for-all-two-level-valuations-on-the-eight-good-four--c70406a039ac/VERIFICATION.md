# Verification of the finite two-level key-matroid theorem

The complete binary domain is \(2^{32}\) labeled preference profiles: four independently chosen eight-bit binary valuation masks. Each of the 36 feasible unordered pair partitions is generated by choosing the smallest unpaired good and matching it only across categories; the four ordered agent assignments of pairs yield 864 labeled allocations in total. For each triple of later-agent masks, the C++ checker constructs the exact set of first-agent masks with at least one simultaneously ordered-no-envy and EF1 allocation; it verifies that all 256 first-agent masks are covered.

The exhaustive `verify_exhaustive.cpp` is a finite enumerator, not random sampling. The recorded output is:

```text
allocations=864 checked triples=16777216 binary preference profiles=4294967296 failed triples=0 min_used=4
```

The independently implemented Python checker uses direct agent utility sums and checks each candidate good removal in the EF1 definition, with 3,200 deterministic pseudorandom and 65,536 structured profiles. Its recorded result is:

```text
PASS: independent direct verification, 36 matchings, 864 assignments, 3,200 random and 65,536 structured binary valuation profiles.
```

Reproduction commands are given in RESULT.md. No external proof assistant or independent scientific audit was used. The finite C++ enumerator proves only the eight-good binary specialization; the extension to general nonnegative bi-valued values is the separate analytic affine argument in RESULT.md. No larger-instance or arbitrary-additive completeness is asserted.
