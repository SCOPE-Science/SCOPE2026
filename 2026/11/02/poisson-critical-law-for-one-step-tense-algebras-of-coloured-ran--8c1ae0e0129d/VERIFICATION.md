# Reproducibility and limits

Run `python3 checker.py` with Python 3 and no third-party dependencies.

The code exhaustively enumerates all \(4{,}164\) pairs consisting of a two-colour vertex assignment and a directed graph with independent-loop convention for \(1\le n\le3\). It compares the Boolean algebra generated by modal membership signatures with an independent atom-union construction, checks first-stage closure against direct preservation of the underlying Boolean subalgebra, and verifies exact finite conditional hole-count expectations using rational arithmetic. For each fixed colour assignment, the expected number of outgoing or incoming deficiencies from colour \(a\) into colour \(b\) at edge probability \(1/2\) equals \(N_a2^{-N_b}\). The program reports `EXHAUSTIVE_CASES 4164` followed by `ALL_CHECKS_OK`.

No finite test is cited as proof of the limiting theorem. The infinite mathematical proof is the multivariate factorial-moment argument, the signature-fibre identity and the concentration/conditional-binomial estimates given in RESULT.md. Tests do not prove originality or establish independent validation.
