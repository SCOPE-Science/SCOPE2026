# Reproducibility and scope of checking

Execute `python3 check.py` with Python 3.9+ from the directory containing the standalone `check.py`; it uses the Python standard library only. It exhaustively enumerates every history generated by degree-proportional vertex attachment from one edge through nine vertices, with exact rational probabilities. It recomputes all degrees and leaf-neighbor counts from the parent arrays, then checks conditional formulas for the degree-square sum, degree-weighted leaf count, number of unordered sibling-leaf pairs, and degree-cube sum. It independently verifies all finite-size expectation identities and the two size-four martingale branches.

The archived `verification_output.txt` contains the following actually observed result:

```
PASS: 184947 exact checks, attachment histories through 9 vertices.
Exact means n=9: 1522/35, 796/35, 691/140
First nontrivial martingale variance: 1/9 at four vertices.
Finite enumeration does not certify the infinite almost-sure limit.
```

The infinite almost-sure and \(L^2\) conclusions are analytically justified by the displayed cubic-moment growth, summable martingale quadratic variations, and transfer recurrences in `RESULT.md`. Finite enumeration is not exhaustive for infinitely many sizes, and a successful checker run is not an independent audit of the proof. The limiting martingale law is not identified beyond centering, square integrability and nondegeneracy.
