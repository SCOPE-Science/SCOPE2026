# Independent mathematical audit

## correctness

PASS

For stationary unidirectional n>=2 Markov ring, each full-cycle return is renewal with hypoexponential waiting transform phi(omega)=R/P(iomega), P(s)=product(s+rho_j), R=product(rho_j). F=(|P|^2-R^2)/|P-R|^2. F-1=2R(Re P-R)/|P-R|^2; write H(s)=(P(s)-R)/s. Since |P(s)|>R for every Re(s)>=0 except s=0, H is strictly Hurwitz. With real H(0)>0, the continuous phase arg H(iomega) increases strictly from 0 to (n-1)pi/2, so F-1 has exactly floor(n/2)-1 finite positive simple sign-alternating zeros. n=2,3 have none and n=1 (Poisson) is intentionally excluded. Independently generated exact elementary-symmetric crossing polynomials with SymPy for 70 heterogeneous positive-rate lists across n=2..11; all roots and counts agree. Finite checks are independent diagnostics of the all-n analytic Hurwitz-phase proof.
