# Seven cyclic classes of minimum words in the binary length-273 BCH code

## Finding

The binary narrow-sense BCH code \(C=\mathcal C_{(2,273,5,1)}\) has exactly \(1{,}911\) codewords of Hamming weight \(5\), partitioned into exactly **seven cyclic orbits**, each with \(273\) words. For the explicit root normalization below, the supports of one representative from each orbit, displayed as integer positions between \(0\) and \(272\), are

\[
\begin{gathered}
(0,1,64,97,202),\quad (0,2,128,131,194),\\
(0,4,115,256,262),\quad (0,8,230,239,251),\\
(0,13,78,104,234),\quad(0,16,187,205,229),\\
(0,32,101,137,185).
\end{gathered}
\]

Exactly one orbit is induced from the length-\(21\) coordinate subgroup: in every support in this orbit, all five coordinates lie in a single residue class modulo \(13\). The other six orbits are exchanged transitively by the Frobenius position multiplier \(j\mapsto2j\pmod{273}\); the induced orbit is fixed. Thus there are exactly two classes under the group generated by cyclic shifts and the multiplier \(2\), of sizes \(273\) and \(1{,}638\).

## Assumptions and scope

Represent the finite field \(F\) as the degree-\(12\) extension \(\mathbb F_2[t]/(f(t))\), where
\[
f(t)=t^{12}+t^7+t^6+t^5+t^4+t^3+t^2+t+1.
\]
Represent field elements by bit masks for their degree-at-most-\(11\) polynomial coefficients. Put \(\alpha=t^3+t+1\), corresponding to the integer mask \(11\), and \(\beta=\alpha^{15}\), corresponding to the integer mask \(2766\). The exact finite-field checks below verify that \(f\) is irreducible, \(\alpha\) has multiplicative order \(4095\), and \(\beta\) has order \(273\). Define
\[
C=\{(c_0,\ldots,c_{272})\in\mathbb F_2^{273}:\sum_{j=0}^{272}c_j\beta^j=\sum_{j=0}^{272}c_j\beta^{3j}=0\}.
\]
The characteristic-two Frobenius identities imply that these checks impose zeros \(\beta,\beta^2,\beta^3,\beta^4\), so this is precisely the indicated BCH code. The previously established parameters are \([273,249,5]\); the asserted contribution is its complete minimum-weight support enumeration, not these parameters.

## Proof

**Reduction to four nonzero exponents.** Each support \(S\) of a weight-\(5\) word can be shifted so one coordinate is \(0\), because multiplying both root-sum checks by nonzero powers of \(\beta\) preserves their vanishing. Write \(S=\{0,i,j,k,\ell\}\) with four distinct indices in \(\{1,\ldots,272\}\). Its two check equations are exactly
\[
(\beta^i+\beta^j,\beta^{3i}+\beta^{3j})
=(1+\beta^k+\beta^\ell,1+\beta^{3k}+\beta^{3\ell}).
\]
Construct the complete table of unordered pairs \(1\le i<j\le272\) indexed by their two-component field syndrome. There are exactly \(\binom{272}{2}=36{,}856\) pairs; the exact deterministic checks below find all distinct syndrome keys and exactly \(210\) ordered matches under complementing each component by \(1\). All \(210\) matches have four distinct indices, and for every match the two root sums vanish.

For each fixed five-point support containing \(0\), its four other points admit three unordered partitions into two pairs, and either orientation of these pairs occurs as an ordered match. Thus the number \(210\) is precisely six times the number of distinct normalized supports: there are \(35\) five-subsets containing \(0\), all explicitly reconstructed by the algorithm. Conversely any weight-\(5\) support containing \(0\) must occur in this table, so this enumeration is exhaustive.

**Orbit completeness.** A nonidentity shift of the cyclic group of order \(273\) cannot stabilize a five-element subset: its order would have to divide both \(273\) and \(5\), which are coprime. Therefore each support has orbit size \(273\), and each orbit contributes exactly five supports containing position \(0\). Thus the total number of cyclic orbits is \(35/5=7\), and the total number of minimum-weight supports is \(35\cdot273/5=1{,}911\). Binary supports determine binary codewords uniquely. Canonicalizing the \(35\) supports by the lexicographically smallest sorted cyclic translate yields exactly the seven representatives in the Finding.

**Two semilinear types.** Doubling all indices is a code automorphism because squaring either vanishing field sum preserves zero. Its action on the seven ordered representatives has zero-based index permutation \((1,2,3,5,4,6,0)\): one fixed point and one cycle of length six. The fixed representative \((0,13,78,104,234)\) has all its coordinates divisible by \(13\), and its translates lie in single modulo-\(13\) classes. Every other representative has coordinates not all congruent modulo \(13\); this property is shift-invariant. Since multiples of \(13\) form the subgroup of order \(21\) inside the cyclic coordinate group, the single fixed class is exactly the inherited minimum-word class, with the other six genuinely outside this subgroup construction.

## Verification

The complete certificate is finite and exact, without numerical approximations. The standalone `bch273_exact.cpp` independently constructs the syndrome-pair table and checks \(36{,}856\) pair entries, \(210\) matching oriented pairs, \(35\) normalized solutions, seven canonical cyclic representatives, and \(1{,}911\) distinct supports generated by their shifts. The separately written `bch273_independent.py` constructs the field using integer-polynomial arithmetic, enumerates the pairs through a different dictionary traversal, and checks every representative, each of its shifts, and the Frobenius action. Reproduce with `g++ -std=c++17 -O2 bch273_exact.cpp -o bch273_check && ./bch273_check` and `python3 bch273_independent.py`. Recorded outputs are in `verification_output.txt`.

Irreducibility of \(f\) follows from the standard finite-field polynomial test: squaring the residue class of \(t\) twelve times returns \(t\), while the polynomial gcd with \(f\) is \(1\) for each of \(t^{2^4}-t\) and \(t^{2^6}-t\). The multiplicative generator tests use the prime divisors \(3,5,7,13\) of \(4095\). All field operations in the programs are exact bitwise polynomial operations.

## Relationship to prior work

Chen, Xie and Ding (2025) introduced the family of BCH codes of length \(2^{2s}+2^s+1\), including the relevant dimension and distance problem. Wang, He, Yi and Zheng (2026), Example 18, established that the code at \(s=4\) has parameters \([273,249,5]\). These sources do not give a complete weight-\(5\) enumerator or seven-orbit classification. A survey by Ding and Li (2024) supplies relevant general BCH background; no covering statement for these specific minimum supports was located in its inspected general treatment. The distance statement and source-root syndrome criterion are established prior work, not new claims.

## Limitations

This is an exact result for one specified binary cyclic code; it neither evaluates the full weight enumerator nor gives a formula for all \(s\). Numerical source labels depend on the displayed choice of primitive root; the orbit count and two-type classification are intrinsic under the corresponding coordinate relabeling. Exhaustive finite enumeration here is a complete proof for this fixed finite code, but gives no automatic infinite-family theorem. Equivalent coverage in less directly indexed code enumerator literature remains a priority risk. Independent mathematical validation has not been performed.
