# Sharp primitive-period maxima through fourteen vertices for sequential bi-threshold dynamics on trees

## Finding

For each \(1\le n\le14\), let \(M(n)\) be the maximum least period of a periodic configuration of the permutation-sequential closed-neighborhood Boolean bi-threshold rule \((k_\uparrow,k_\downarrow)=(1,3)\), over all simple trees on \(n\) vertices and all one-sweep vertex orders. The exact maxima, in order, are
\[
(M(1),\ldots,M(14))=(1,1,1,1,2,3,6,10,14,22,42,58,86,106).
\]
The maximum is attained by exactly one unlabelled tree of order \(14\), and that representative has exactly one primitive \(106\)-orbit. Hence the minimum order of a tree supporting primitive period \(106\) is \(14\). The same sharp minimum-order consequences follow for periods \(10,42,58,86\): respectively \(8,11,12,13\) vertices.

## Assumptions and scope

Graphs are finite, simple, connected, acyclic and unlabelled for the purpose of optimization; labels are used only for computational representatives. For each vertex \(v\), an update examines its **closed** neighborhood, including the current bit of \(v\), with already updated values for preceding vertices in a sweep. A zero bit changes to one if the closed-neighborhood sum is at least \(1\). A one bit remains one if the same sum is at least \(3\), and otherwise changes to zero. Every vertex is updated once in a fixed permutation each sweep; a sweep is one discrete time step. A primitive period \(p\) is an orbit with exactly \(p\) distinct configurations before returning to its initial configuration. Only \(1\le n\le14\) is claimed.

For a reproducible representative of the unique order-\(14\) maximizer, use vertices \(0,1,\ldots,13\) and edge list
```
(0,1) (0,2) (0,3) (0,4) (1,5) (1,6) (2,7) (2,8)
(3,9) (3,10) (5,11) (6,12) (11,13)
```
with sweep order \(0,1,\ldots,13\) and initial state having exactly vertex \(2\) active (binary mask \(4\)). The orbit visits exactly \(106\) distinct masks and returns to mask \(4\) at sweep \(106\).

## Proof

**1. Order independence of the period multiset.** The cycle-equivalence theorem for sequential graph dynamical systems identifies the periodic-orbit structure of two permutation orders related by a source-to-sink click of their induced acyclic orientations [1]. On a tree, every pair of orientations are click-equivalent: repeatedly correct source orientations along the uniquely oriented edges; equivalently, the orientation graph has only one click-equivalence class because the underlying graph has no cycles. Since the same local bi-threshold maps are applied in every order, this theorem makes the multiset of primitive cycle lengths independent of the chosen sweep order. Thus it is sufficient to check the order \(0,1,\ldots,n-1\) for each tree representative. This step uses the published cycle-equivalence theorem, not a claim that pointwise updates commute.

**2. Exhaustive tree representations.** Every tree with \(n+1\ge2\) vertices has a leaf whose deletion yields an \(n\)-vertex tree. Starting from the one-vertex tree and adjoining one new leaf to every vertex of each preceding tree therefore generates every unlabelled tree by induction. Rooting each candidate at its one or two centers and sorting the parenthesized codes of rooted branches gives the canonical Aho--Hopcroft--Ullman isomorphism code. Deduplication by this code retains one representative per isomorphism class. The number of generated representatives is checked at every order against the displayed sequence; in addition, the order-\(14\) canonical code set was independently compared to the \(3159\) tree isomorphism classes generated by a separate canonical tree generator, with exact equality. No random sampling is used.

**3. Exhaustive state cycles for each representative.** A tree with \(n\) vertices has exactly \(2^n\) binary states. For each generated representative and each state, the code computes the deterministic sequential-sweep successor by scanning vertices in ascending order. Every component of this finite functional graph consists of one directed cycle and possibly incoming transient states. The `scan_cpp.cpp` search traverses every state, recording its first visit index in the current traversal and recording the length of the resulting cycle; all traversed states are permanently marked. Each periodic orbit is therefore counted once, and the maximal recorded length for a representative is its exact maximal least period. Taking the maximum over all representatives gives the displayed \(M(n)\) and the count of extremal tree classes. A second implementation, `verify.py`, independently identifies periodic vertices by repeatedly stripping indegree-zero vertices and follows each remaining orbit; its results coincide through order \(12\). The larger-order results are additionally supported by the explicit witness replay and the complete C++ functional-graph certificate. These finite exhaustive calculations establish the stated bounded-order theorem; they are not extrapolated to larger orders.

**4. Sharp realization.** The `witness14.py` direct updater checks all \(106\) configurations in the exhibited orbit are distinct and that the next sweep returns to its initial mask. Hence \(M(14)\ge106\). The exhaustive search gives the matching upper bound and finds precisely one maximizing unlabelled tree. Because \(M(n)<106\) for every smaller order, no tree with fewer than \(14\) vertices can have period \(106\). The identical comparison with the table proves the stated minimum-order consequences for periods \(10,42,58,86\).

## Verification

The embedded files `verify.py`, `gen_trees.py`, `tree_catalog.txt`, `scan_cpp.cpp`, `cpp_certificate.txt`, `witness14.py`, and `witness14_trace.txt` form a standalone reproduction bundle. Using Python \(\ge3.10\) and a compiler supporting C++17, run in their common directory:
```
python3 gen_trees.py
g++ -std=c++17 -O3 scan_cpp.cpp -o scan_cpp
./scan_cpp
python3 witness14.py
```
The generator prints `CATALOG_OK`, and the executable prints `CPP_VERIFY_OK: 5447 unlabelled trees n=1..14` after checking all \(2^n\) states for each of the \(5447\) representatives. The direct witness check prints `WITNESS14_OK`. The `cpp_certificate.txt` file gives one maximizer witness and class counts at each order; the `witness14_trace.txt` file lists every mask in the \(106\)-orbit. The optional pure-standard-library `verify.py` is a separate proof-checking implementation; its completed earlier certificate covers orders through \(12\), while the executable checks the full range through \(14\).

## Relationship to prior work

Macauley and Mortveit [1] establish the cycle-equivalence theorem for sequential graph systems; this supplies the essential reduction of arbitrary vertex orders to one order on trees. Kuhlman, Mortveit, Murrugarra and Kumar [2] introduce and analyze sequential bi-threshold systems with long cycles on special trees. Their explicit \(3p-2\)-vertex Y-type construction realizes specified period \(p\) but does not give the smallest possible tree for that period, nor the global maxima over all trees of bounded order. The exhibited period-\(106\) tree here has \(14\) rather than \(316\) vertices in that particular general construction; this is a comparison to their construction, not a claim that it was previously the best known construction. Subsequent computational work [3] focuses on selected X-, Y-, and H-family examples, whereas the present census exhausts **all** unlabelled trees through fourteen vertices. These cited results do not entail the numerical global maxima in the table.

## Limitations

This is a finite sharp classification, not a closed formula or asymptotic statement for \(M(n)\) beyond \(n=14\). Completeness relies on inspectable source code, exhaustive finite-state execution and the correctness of the standard AHU tree-code method; the witness itself has an independent direct replay. The table uses the uniform closed-neighborhood hysteretic thresholds \((1,3)\), not simultaneous updating, open-neighborhood counting, different thresholds or arbitrary time-varying scan orders. The originality comparison covers the identified primary works and indexed research records but does not rule out equivalent results in unindexed historical literature.
