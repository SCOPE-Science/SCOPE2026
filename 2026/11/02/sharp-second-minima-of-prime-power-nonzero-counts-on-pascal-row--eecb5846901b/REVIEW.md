# Scientific review

**Correctness — PASS.** Kummer's borrow characterization gives digitwise monotonicity and reduces all possible second extremizers to elementary row perturbations. The explicit digit-transfer matrix yields closed borrow-distribution polynomials for every candidate. Coefficient truncation and three exhaustive index regimes give all sharp minima and equality cases; independent finite tests check the closed formulas on entire intervals. The result is about infinite parameter families; enumeration is corroborative only.

**Originality — PASS (with stated risk).** Rowland 2010, Everett 2007, and Spiegelhofer–Wallner 2016 count binomial-coefficient valuations **at a fixed row**; those formulae in principle supply all numerical data for this extremal problem, so the theorem does not claim a new digit-count identity. The inspected writings do not supply the optimal second distinct value and full equality set simultaneously for all primes, prime-power exponents, and digit lengths. A search for equivalent second-minimum, next-to-extremal and digital-pattern formulations found no decisive earlier theorem. An uncatalogued consequence of earlier pointwise work remains a substantive originality risk.

**Mathematical value — PASS.** The uniform second-order extremum is a natural quantitative-stability question for a classical arithmetic counting function. The classification identifies a precise transition between perturbing a low digit and the leading digit, including exceptional ties; it is not merely an isolated computed row or an arbitrary restricted slice. The exact description of all equality cases matters to future extremal/stability analysis of Pascal-triangle residue counts.

Closest literature and limitations: Rowland, arXiv:1001.1783 (complete main text inspected); Everett, arXiv:0710.1468 (pointwise formula inspected); Spiegelhofer–Wallner, arXiv:1604.07089 (main article inspected); Davis–Webb on the modulus four. This is not a higher-minima theorem and does not establish a new valuation formula for individual rows. Unlocated implicit extremal lemmas remain possible.
