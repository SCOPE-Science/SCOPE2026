# Scientific review

**Correctness — PASS.** The theorem's subject is the explicit conservative correction interval in Barsukow's 2026 Theorem 4, with every parameter and bound stated. The proof verifies denominator positivity, the inactive case, two equivalent endpoint comparisons, exact quadratic root selection, and sharpness via finite slope-ratio witnesses. An extracted standalone exact-rational checker provides 34,400 supplementary comparisons. This is an algebraic all-parameter proof; the finite tests are not treated as proof of a continuum claim.

**Originality — PASS with residual priority risk.** The exact interval (118) is already published and is expressly credited. The source proves only the sufficient universal bound \((\sqrt{97}-7)/4\) and remarks that its CFL estimate could improve; it does not state the exact contrast-dependent ceiling, the \(r=1/6\) branch transition, or the complete finite-slope admissibility law. The 2020/2021 nonlinear Active Flux source describes monotone reconstruction rather than this later flux-feasibility classification. The main residual risk is that the sharp optimization is algebraically accessible from the source's own displayed inequality or may already have been obtained in unindexed material. This is a focused strengthening of an existing bound, not a newly invented TVD method.

**Value — PASS.** The explicit interval is used to select a feasible corrected point update without solving inequalities involving unknown actual stage speeds. The sharp guarantee permits a Courant parameter from \((\sqrt{73}-7)/2\) in the extreme-contrast limit to \(6/7\) for ratios at least \(1/6\), rather than the published approximately \(0.712\) bound; this is a substantive rise in the certified step budget without changing the limiter formula. The local slope-ratio frontier additionally identifies precisely which cells can use larger steps. The gain is a guarantee for this interval alone, and does not establish a universal method stability bound.

**Closest literature and limitations.** Barsukow (2026), arXiv:2610.05920v1, Theorem 4 and equations (118), (127), (130)--(134), is directly related and supplies the mathematical starting point. Barsukow (2021), DOI 10.1007/s10915-020-01381-z, provides the earlier nonlinear reconstruction framework. Other Active Flux/CFL papers use different schemes or dimensions. The result presumes positive speed bounds and monotone data, does not cover extrema or systems, and is not independently validated.
