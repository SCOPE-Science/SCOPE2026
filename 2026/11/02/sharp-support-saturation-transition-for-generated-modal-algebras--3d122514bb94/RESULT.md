# Sharp support-saturation transition for generated modal algebras of random clustered chains

## Finding
Fix \(k\ge 1\), put \(q=2^k\), and fix a positive integer \(r\). Consider \(m\) consecutive, equally sized clusters, each containing \(r\) worlds, ordered by a reflexive transitive total preorder (a world sees all worlds in its cluster and all later clusters). Give each world one of the \(q\) Boolean \(k\)-variable color vectors, independently and uniformly. Let \(A_{m}\) be the Boolean modal subalgebra of the powerset algebra generated by the \(k\) proposition sets, and let \(Z_m\) be its number of Boolean atoms, so \(|A_m|=2^{Z_m}\).

**Exact support reduction.** Write \(C_i\subseteq[q]\) for the nonempty set of colors appearing in cluster \(i\). Scan \(C_m,C_{m-1},\ldots,C_1\) from the terminal cluster to the initial cluster. Retain the first support, then retain support \(D\) exactly when \(D\) is not a subset of the last retained support \(C\). The exact number of Boolean atoms is the sum of cardinalities of the retained supports. In particular, this number depends only on the ordered support sets and not on color multiplicities inside clusters.

**Sharp stochastic transition.** With \(k,r\) fixed and \(m\to\infty\), if \(r\ge q\), the sequence \(Z_m\) admits a monotone-suffix coupling in which it stabilizes almost surely to a finite value with an exponential tail. If \(r<q\), then \(Z_m/m\to\mu_{q,r}>0\) almost surely under the same coupling; \(\mu_{q,r}\) has an exact rational expression below. Hence a bounded number of modal atoms versus linearly many modal atoms has the sharp threshold \(r=q=2^k\).

**Finite distribution and an explicit case.** Let \(p_j=j!S(r,j)/q^r\) be the probability of a fixed \(j\)-element support (where \(S(r,j)\) is a Stirling number of the second kind). With states given by all nonempty supports \(C\subseteq[q]\) of size at most \(r\), define the multivariate polynomial recursion
\[
F_1(C;z)=p_{|C|}z^{|C|},\qquad
F_{m+1}(C;z)=\left(\frac{|C|}{q}\right)^r F_m(C;z)
+p_{|C|}z^{|C|}\sum_{A:\,C\not\subseteq A}F_m(A;z).
\]
Then \(\mathbb E[z^{Z_m}]=\sum_CF_m(C;z)\).
When \(r<q\), let \(\pi_j\) be the stationary probability of each *specified* \(j\)-element support. It is determined, descending from \(j=r\) to \(1\), by
\[
\pi_j=\frac{p_j\left(1-\sum_{\ell=j+1}^r\binom{q-j}{\ell-j}\pi_\ell\right)}{1-(j/q)^r+p_j}.
\]
The almost-sure linear growth rate equals
\[
\mu_{q,r}=\sum_{j=1}^{r}\binom qj\pi_j\left[q\left(1-\left(\frac{q-1}{q}\right)^r\right)
-j\left(\left(\frac jq\right)^r-\left(\frac{j-1}q\right)^r\right)\right].
\]
For \(k=2\) (thus \(q=4\)) and \(r=2\), these formulas give \(\pi_1=1/28\), \(\pi_2=1/7\), and \(\mu_{4,2}=159/112\).

## Assumptions and scope
All frames are finite, nonempty, reflexive, transitive total preorders with **exactly** \(m\) linearly ordered equivalence classes of the common size \(r\). Every ordered vertex pair in one or more forward classes is accessible; there are no additional edges. All color vectors are independent and uniform over \([q]\), with \(q=2^k\). The modal operator is \(\Diamond X=\{w: \exists v\ (wRv\land v\in X)\}\); the Boolean signature contains complement, intersection, and union. \(Z_m\) counts atoms of the generated *Boolean* algebra, not generators or atoms of the ambient powerset. The limiting assertions keep \(q,r\) fixed as \(m\) grows.

## Proof
**1. Modal types equal atoms.** For any finite Kripke frame and fixed coloring, define two worlds equivalent if they satisfy the same formulas over the \(k\) named propositional variables and \(\Diamond\). Finite modal depth-partition refinement begins with the color partition and repeatedly refines a world by its color and its set of successor classes. It stabilizes after finitely many steps, and the stable partition is the modal-equivalence (bisimulation) quotient: every two distinct classes are separated by a finite-depth modal formula, by induction on the refinement step. Thus the formula-definable subsets are precisely unions of final classes and each class is a Boolean atom of the generated algebra.

**2. Support reduction.** Process the clusters from right to left, at each stage keeping the pointed modal types of all worlds already processed. In the current rightmost processed cluster, its distinct color values \(A\) yield \(|A|\) types. If a preceding cluster has color support \(D\subseteq A\), every new world has exactly the same color and accessible pointed types as the corresponding top-cluster world, so the added cluster contributes zero new modal types. Conversely, if \(D\not\subseteq A\), pick a color \(d\in D\setminus A\). The new \(d\)-world accesses each top-cluster type and itself, whereas no world of the old suffix with color \(d\) can access any point of that top cluster. Its modal type is therefore new; for each color \(c\in D\), the new \(c\)-world accesses the new \(d\)-type, while no old world can access a new world. Thus each of the \(|D|\) new color types is new. The current top support becomes \(D\). Finite modal-type distinguishability in step 1 makes these comparisons valid at finite modal depth. Induction proves the greedy rule.

**3. Exact distribution.** There are \(j!S(r,j)\) assignments to a specified \(j\)-color support, hence its probability is \(p_j\). Given current active support \(C\), the next independently sampled support lies inside \(C\) with probability \((|C|/q)^r\), causing no addition. Otherwise a new support \(D\not\subseteq C\) is retained and contributes \(|D|\) new atoms. Conditioning yields the polynomial recursion.

**4. The saturated regime.** If \(r\ge q\), the probability of sampling full support \([q]\) in a cluster is \(\alpha=q!\left\{\begin{smallmatrix}r\q\end{smallmatrix}\right\}/q^r>0\). After that first full support is encountered from the right, every more-left support is included in the active full support; no further atoms appear. Under an infinite right-to-left iid coupling, the first full-support waiting time is geometric with parameter \(\alpha\). As a result \(Z_m\le qG\) for that geometric random variable \(G\), and the process stabilizes almost surely; the tail is exponentially bounded.

**5. The unsaturated regime.** Suppose \(r<q\). The retained-support process is a finite Markov chain on nonempty subsets of size at most \(r\), moving from \(A\) to \(D\) with probability \(p_{|D|}\) when \(D\not\subseteq A\), while all supports contained in \(A\) produce a holding transition. It is irreducible: if \(D\subseteq A\), first move to a singleton support outside \(A\) and then to \(D\); all these transitions have positive probability. It is aperiodic because each state has a positive holding probability. Its unique stationary distribution is invariant under color relabeling. For any fixed \(j\)-support \(D\), stationarity gives \(\pi_j[1-(j/q)^r]=p_j[1-\sum_{A\supseteq D}\pi(A)]\); isolating the term \(A=D\) and grouping larger supports yields the descending recurrence. A newly sampled color-support \(D\) contributes \(|D|\mathbf1_{D\not\subseteq A}\). Its conditional expectation at a state \(A\) of size \(j\) equals \(\sum_D|D|p(D)-\sum_{D\subseteq A}|D|p(D)\). The first term is the expected number of occupied colors among \(r\) iid samples from \(q\) colors, namely \(q[1-((q-1)/q)^r]\). The second counts the expected occupied colors only when the sample is wholly in \(A\), namely \(j[(j/q)^r-((j-1)/q)^r]\). Averaging with the stationary probabilities and applying the finite-state Markov ergodic theorem gives the stated almost-sure rate. It is strictly positive since every state has positive probability of meeting an incomparable or nonincluded independently sampled support. The stated rational specialization follows by substitution.

## Verification
The accompanying standalone `checker.py` uses only Python's standard library. It checks the support-reduction rule against an independently implemented stable modal-bisimulation refinement in 13,012 exhaustive labeled models; checks the exact polynomial recursion against full independent word enumeration for three configurations; checks the stationary recurrence on twenty-one parameter pairs; and verifies the \(159/112\) rate exactly using rational arithmetic. Execute `python checker.py`. Its expected output begins `ALL_CHECKS_OK`. These finite tests do not prove the infinite asymptotic result, which follows from the irreducibility and ergodic arguments above.

## Relationship to prior work
Agnew's 2026 treatment of locally finite transitive modal algebras gives broad algebraic criteria, not the exact random finite-cluster modal-type count, polynomial distribution, or sharp fixed-cluster-size saturation transition proved here. Classical finite-state bisimulation and stuttering arguments underlie the support reduction and are not claimed as new. Merz discusses ordinary repetition-based stuttering in temporal reasoning; the present distinct-color support inclusion is coarser than repetition of identical single letters and is tied to finite Boolean-modal generators. Other published results concerning finite weak-order retracts, Gödel fuzzy frame regradings, and S4-like chain-frame counts use different objects and do not imply this stochastic generated-algebra threshold.

## Limitations
No claim is made for nonuniform correlated colors, unequal cluster sizes, two-way modalities, or frames that are not total preorders. The exact local bisimulation/stuttering mechanism is elementary and may have appeared in prior modal logic or automata literature under another name; an absolute priority guarantee is not asserted. The threshold is about the random finite-window number of generated Boolean-modal atoms, not about local finiteness of arbitrary infinite modal frames. No independent external validation was conducted.
