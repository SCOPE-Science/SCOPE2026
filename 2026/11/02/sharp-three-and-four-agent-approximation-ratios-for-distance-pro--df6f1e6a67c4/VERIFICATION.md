# Verification

The all-metric claim is established by the analytical inequalities in `RESULT.md`.
The standalone Python 3 program `check_pairwise_finite.py` checks exact integer equivalents:

- All 65 valid labeled three-report pseudometrics with pair distances in \(\{0,1,2,3,4\}\), of which 52 have positive best-pair cost.
- All 2371 valid labeled four-report pseudometrics with those integer distances, of which 2342 have positive best-pair cost.
- All 59049 five-point graph shortest-path metrics generated by independently assigning each edge of \(K_5\) a weight in \(\{1,2,3\}\); four reports are fixed and the fifth point is allowed as a comparison-facility site.
- Six values for the three-agent sharp family and five values for the four-agent sharp family, checked as exact integer identities.

Run `python3 check_pairwise_finite.py` with Python 3 standard library only. The observed output was:

`VERIFY_OK three_report_metrics=(65, 52) four_report_metrics=(2371, 2342) five_location_graph_metrics=(59049, 59049) sharp_families=verified`

The test for the five-point metrics checks against the optimal pair among all five candidate sites; this supplements, rather than replaces, the proof against arbitrary centres in arbitrary metric spaces. Finite tests cannot certify an infinite domain. Independent audit has not been performed.
