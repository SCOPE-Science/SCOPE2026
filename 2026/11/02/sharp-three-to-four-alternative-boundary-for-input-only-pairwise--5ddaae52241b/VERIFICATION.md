# Reproducibility and evidence limits

Run `python3 ranking_quota_verifier.py` using Python 3's standard library. The computation builds ranking incidence matrices from permutations, verifies every nonempty square minor of the six-column three-alternative matrix and every row-subset signing, and then independently checks all sample-size quotas on every three-alternative anonymous profile through nine voters. It exhaustively evaluates all 17,550 four-voter, four-alternative ranking multisets directly, then independently uses the necessary-and-sufficient tied-comparison characterization for all 10,626 distinct-ranking profiles. It checks all six choices for the displayed witness, its impossibility even with repeated source rankings, its feasibility with synthetic output, all 15 four-candidate restrictions of the comparison paper's six-alternative witness, and 30 candidate-relabeling classes.

Expected terminal summary:

```

ALL CHECKS PASSED
```

All these results were generated by executing the included code. Exhaustive finite computations are used only for the finite census and to inspect elementary certificates; the arbitrary-electorate theorem follows from the mathematical integrality proof in RESULT.md. The larger-alternative, larger-electorate census and unrestricted synthetic-output questions are not established. Independent audit has not been performed.
