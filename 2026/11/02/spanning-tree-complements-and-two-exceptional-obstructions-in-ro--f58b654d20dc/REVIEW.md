# Scientific review

## Correctness

PASS. The four Kronecker-sum eigenspaces and PBH test give the sharp lower bound and a cycle-space characterization of every minimum candidate. The row/column-mode argument establishes sufficiency for unequal dimensions. For square dimensions, the nullspace of a two-row component-count matrix classifies the only additional obstructions. An extremal edge count proves that they are exactly a double star or a cross-plus-one tree. The count follows from the complete-bipartite spanning-tree formula. The zero-forcing gap has an explicit forcing construction. All hypotheses and cardinality boundaries include \(m,n\ge3\). The standalone verifier passed exhaustive finite modal tests and direct modular Kalman comparisons; these are supplementary, not a claim of infinite machine certification.

The zero-forcing count and eigenvalue-multiplicity principle are treated as context, not as new claims. The related earlier triangular-graph actuation classification addresses a different line graph with different eigenspace constraints and does not directly imply this result.

## Value

PASS. The question is a concrete, natural actuator-selection problem on an important dense product network. The answer classifies and counts *all* smallest dedicated input configurations, including a sharp square-versus-rectangle phenomenon and two precise failure mechanisms invisible from multiplicity alone. This can replace full Kalman computations by bipartite tree tests and yields an explicit fixed-weight advantage over stronger zero-forcing guarantees. It is not an arbitrary parameter slice or a repetition of the generic PBH test.
