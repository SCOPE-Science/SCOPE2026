For \(K_{n,n}\), the minimum number of rich edges in a rich-neighbor colouring using the optimal palette is exactly \(n\) for every \(n\ge4\), but four for \(n=2,3\). An explicit two-star construction achieves the palette optimum \(2n-1\) while using exactly \(n\) local witnesses, refining the previously known balanced-biclique colouring construction.
