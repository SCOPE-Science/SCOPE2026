# Verified single-transposition Gray paths for even alternating permutations through length ten

## Finding
For \(n\in\{4,6,8,10\}\), all alternating permutations of \(\{1,\ldots,n\}\), in the sense \(p_1<p_2>p_3<\cdots\), can be ordered so that every successive pair differs by exchanging exactly two entries. The respective order lengths are \(5,61,1385,50521\). Thus the one-transposition flip graph of alternating permutations has a Hamilton path for every even \(n\le10\) with \(n\ge4\). The conclusion is finite; it does **not** assert a Gray path for all even sizes.

## Assumptions and scope
A permutation is a tuple containing each element of \(\{1,\ldots,n\}\) once. It is alternating when the strict inequalities in the preceding paragraph hold at every index. Two *distinct* alternating permutations are adjacent if and only if their entries at exactly two positions are interchanged. For an alternating permutation, swapping adjacent positions cannot preserve alternation, so all legal moves interchange positions at distance at least two. A *Gray path* means a listing of every admissible permutation exactly once, with each consecutive pair adjacent; there is no requirement that its last and first elements be adjacent.

For reproducibility, programs and certificate index permutations use symbols \(0,\ldots,n-1\), obtained simply by subtracting one from the mathematical labels. Let \(L_n\) be the list of alternating permutations of these symbols in lexicographic order. The standalone certificate `gray_paths_u16le.bin` contains four consecutive blocks, for \(n=4,6,8,10\) respectively, of \(5,61,1385,50521\) unsigned 16-bit little-endian integers. Each integer is a zero-based index into the corresponding \(L_n\). The entire certificate is \(103944\) bytes long; each block is a path encoded without omitted entries or implicit search state. In particular the length-ten block contains \(50521\) indices and \(50520\) transitions.

## Proof
For each of the four indicated values of \(n\), construct \(L_n\) by enumerating all permutations and retaining precisely those obeying the alternating inequalities. The supplied `verify_primary.py` does so by filtering the full permutation list; the independent `verify_alternative.cpp` instead constructs only admissible permutations by a recursive prefix extension subject to the alternating inequalities.

Both programs read the same supplied certificate exactly as specified above. For each block they prove three finite assertions by exhaustive checks: (i) the generated admissible-state list has respectively \(5,61,1385,50521\) elements; (ii) every index in the corresponding range occurs *exactly once* in that block; and (iii) each of the consecutive indexed permutations differs only by transposing two nonadjacent positions. Assertion (i) and the exhaustive enumerators prove that there are no omitted admissible permutations; assertion (ii) proves there are no repetitions; and assertion (iii) proves every prescribed move is legal. Their conjunction is the claimed Hamilton-path theorem. No statistical sampling or unproved extension to additional sizes is involved.

For comparison, each of the four transposition graphs is bipartite under permutation sign. The certified state counts are odd, so no Hamilton *cycle* is possible for those sizes; the positive statement is about paths rather than cycles. The two end permutations for \(n=10\), written with one-based values, are \((5,7,2,6,3,9,4,10,1,8)\) and \((2,10,4,6,1,8,3,7,5,9)\).

## Verification
Run `python3 verify_primary.py gray_paths_u16le.bin` using Python 3. The complete check reports `PRIMARY_PASS` for all four lengths and `ALL_PATHS_VERIFIED`. Independently compile using `c++ -std=c++17 -O2 verify_alternative.cpp -o verify_alt` and run `./verify_alt gray_paths_u16le.bin`; this reports `ALTERNATIVE_PASS` for each size and `ALTERNATIVE_ALL_PASS`. Both test the entire embedded certificate, check complete state coverage, and compare each actual step rather than merely checking a hash of a claimed output.

The observed even/odd permutation-sign counts are \(3/2\), \(31/30\), \(693/692\), and \(25261/25260\) respectively. These are supplementary finite checks, not the reason the certificate is a Hamilton path.

## Relationship to prior work
Ruskey, *Transposition generation of alternating permutations* (1989), established a transposition Gray code for **odd** lengths. Mütze's published 2023 survey explicitly records the even-length question as open (section 5.1, page 41 of that version) and notes the distinct, more general fence-poset formulation in section 7.2. Pruesse and Ruskey's 1991 results deal with certain classes of linear extensions, and general two-swap or prism constructions do not imply the existence of a single-transposition path in these even-length induced subgraphs. The contribution here is only the explicit verified positive **finite** range through length ten. The enumeration of alternating permutations (the Euler zigzag numbers) is classical and is not claimed as new.

## Limitations
A Hamilton path was certified only for the four even lengths stated. The general problem for every even length is not settled, nor is a uniformly efficient generation algorithm proved. The path orderings are explicit computational certificates, with completeness independently reproduced by executable finite proofs; they are not a closed-form recurrence. The original Ruskey article was not available for full-text inspection through the available channels. Although a later comprehensive survey states the even-length problem as unresolved and targeted searches uncovered no equivalent length-ten certificate, an unpublished or unindexed small-size path may exist. The earliest cited date with day-level verified online-publication evidence is 2006-08-08 for Pruesse--Ruskey's archival paper; Ruskey's original 1989 print bibliographic year is earlier but no day-precision original-publication date was independently verified. This is a date-evidence limitation, not a claim that the subject originated in 2006.
