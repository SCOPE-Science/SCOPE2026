Strict convexity modulo constants forces maximizers to vertices; on a connected bipartite graph, tight spanning connectivity forces every remaining edge difference to be exactly one. This reduces the three relevant base cases to the exhaustive height enumeration whose code is embedded. The independent enumeration of all integer Lipschitz profiles agrees on every optimum and all equality vectors. Sharp spread is a natural Lipschitz-to-centered-Hilbert embedding constant that controls extremal variance and enters product-space concentration questions. The theorem locates an exact resilience boundary: a single edge fault changes the constant in dimensions two and three, but no longer in any dimension four or higher, while retaining all and only the original maximizers above the boundary. This is an infinite classification, not merely a finite arithmetic exercise or a routine restatement of Cartesian tensorization: its decisive nonproduct base comparison is nontrivial.
