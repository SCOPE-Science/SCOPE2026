# A run-pair formula for two-letter complement scattered factors

## Finding

Let \(\Sigma\) be any finite alphabet, let \(a,b\in\Sigma\) be distinct letters, and let \(w\in\Sigma^*\) be arbitrary. For the complement scattered-factor set \(C(w,ab)\), which consists of distinct remainders after deleting an \(a\) and a later \(b\), define the maximal constant-letter run decomposition
\[
w=c_1^{r_1}c_2^{r_2}\cdots c_h^{r_h},\qquad r_i\ge1,\quad c_i\ne c_{i+1}.
\]
Let \(M_{ab}(w)\) count ordered pairs of run indices \((i,j)\) with \(i<j\), \(c_i=a\), and \(c_j=b\). Let \(N_{abab}(w)\) count occurrences (overlaps allowed) of the **contiguous** factor \(abab\) in \(w\). Then
\[
\boxed{|C(w,ab)|=M_{ab}(w)-N_{abab}(w).}
\]
The formula applies with zero runs and absent embeddings, using zero for both counts. It can be evaluated by a single left-to-right scan in \(O(|w|)\) time with \(O(1)\) extra memory.

Furthermore, every fiber of the map from ordered run pairs to remainders is a path of local transformations, and there are no other identifications. For an independent uniformly distributed \(q\)-letter word of length \(n\ge2\) with fixed distinct \(a,b\), the expected value is exactly
\[
\mathbb E|C(w,ab)|=\frac1{q^2}+\frac{2(n-2)(q-1)}{q^3}
+\frac{(n-2)(n-3)(q-1)^2}{2q^4}
-\frac{\max(0,n-3)}{q^4}.
\]
For \(n<2\), this expectation is zero.

## Assumptions and scope

An embedding of \(ab\) is a pair of positions \(p<q\) with \(w[p]=a\) and \(w[q]=b\). Its complement is the length-\(|w|-2\) word remaining after deleting these two positions and preserving all other letters. Different embeddings that leave the same remainder count once. The letters \(a\) and \(b\) must be distinct; there is no restriction on the other letters of \(\Sigma\). Empty words and words without a scattered \(ab\) are allowed, with \(C(w,ab)=\varnothing\).

## Proof

**Run-pair representation.** Deleting any \(a\) from a fixed \(a\)-run and any \(b\) from a later fixed \(b\)-run gives the same remainder, because positions within a constant run are indistinguishable after deletion. Conversely, each \(ab\) embedding determines one such ordered run pair. Thus \(C(w,ab)\) is the image of a map \(f\) on exactly \(M_{ab}(w)\) run pairs. For the rest of the proof choose the rightmost letter in each run as canonical deletion positions.

**A local equality.** Whenever four consecutive runs have the form \(a^r b a b^s\), with \(r,s\ge1\), the two run pairs consisting of the first two and last two runs have the same remainder. Both deletions produce \(a^r b^s\) in place of that four-run block: in the first pair delete the rightmost \(a\) in \(a^r\) and the singleton \(b\); in the second pair delete the singleton \(a\) and one \(b\) from \(b^s\). Context outside the block is unchanged. This transformation corresponds to one occurrence of consecutive \(abab\), starting with the final \(a\) of the first run. Every consecutive \(abab\) occurs in precisely this way; the middle two runs must be singletons.

**No other equalities.** Let two eligible run pairs \((i,j)\) and \((i',j')\) yield the same remainder. If \(i=i'\) and \(j\ne j'\), use identical canonical \(a\) deletion positions and suppose \(j<j'\). At the rightmost \(b\) of run \(j\), the second remainder retains \(b\) while the first uses the next surviving letter, which is not \(b\) because that position ends its run; hence the remainders differ, a contradiction.

Now suppose \(i<i'\). Let \(p\) be the rightmost \(a\) of run \(i\), and \(q\) the rightmost \(b\) of run \(j\). Both remainders share the prefix before \(p\). The second run-pair deletion has not yet begun and therefore retains \(a\) at \(p\). Since \(p\) ends an \(a\)-run, the next input letter is not \(a\). Equality forces the first pair to delete that next letter as its \(b\), so \(q=p+1\), and forces the next undeleted input letter \(w[p+2]\) to equal \(a\). Comparing the following output letter forces \(w[p+3]=b\), since the second pair still retains the \(b\) at \(p+1\). In particular, these positions exist and the intervening \(b\)- and \(a\)-runs are both singletons, so the word locally has \(a^r b a b^s\), and the first pair is \((i,i+1)\). By the local equality, it can be replaced by \((i+2,i+3)\) without changing the remainder. The replacement has a strictly later first run and cannot pass \(i'\), because its \(a\)-run begins before or at the second pair's first deleted \(a\). Repeating the argument finitely many times reaches the same first \(a\)-run as the second pair, at which point the previous paragraph forces identical second \(b\)-runs. Thus every equality is generated by the described local moves.

**Counting fibers.** Form a graph whose vertices are eligible ordered run pairs and whose edges are the described local moves. Every edge goes from \((i,i+1)\) to \((i+2,i+3)\). The graph is a disjoint union of paths because its edges strictly increase the first index by two, and every vertex has at most one predecessor and one successor. Its connected components are exactly the fibers of \(f\). There is exactly one edge for each occurrence of consecutive \(abab\), hence exactly \(N_{abab}(w)\) edges. The components of a forest number \(M_{ab}(w)-N_{abab}(w)\), proving the formula.

**Expected count.** For uniformly independent \(q\)-ary letters, the expected number of ordered \(a\)-run/\(b\)-run start pairs is obtained by separating the first start at position one, adjacent run starts, and two disjoint start events. These contribute respectively \(q^{-2}\), \(2(n-2)(q-1)q^{-3}\), and \((n-2)(n-3)(q-1)^2/(2q^4)\). Each of the \(\max(0,n-3)\) possible four-letter windows equals \(abab\) with probability \(q^{-4}\). Subtraction proves the expectation formula. No independence between overlapping \(abab\) windows is needed, only linearity of expectation.

## Verification

The standalone `verify.py` independently constructs the complement-output set from all ordered letter-position deletions and compares it to both the quadratic run-pair formula and the linear streaming formula. It also reconstructs every collision fiber and checks that its members form precisely the permitted local-move path. It covers all \(269{,}880\) tested words, including every ternary word of length at most \(11\), plus randomized words of lengths \(12\) through \(60\) over alphabet sizes \(2\)–\(5\). Exact rational expectations were checked by enumeration for alphabet sizes \(2,3\) through length \(7\). Run `python3 verify.py` in the directory containing that file. The symbolic argument above, not finite enumeration, proves the unrestricted theorem.

## Relationship to prior work

Adamson, Fleischmann and Huch introduced complement scattered-factor sets and supplied general algorithms for constructing \(C(w,u)\), along with special structural results. Their March 2026 preprint's conclusion explicitly leaves closed counting formulas, even in special cases, as a direction for further work. The present statement restricts the deleted pattern to the two **distinct** letters \(ab\) but allows every input word and alphabet. It replaces explicit set construction by one exact run/contiguous-factor expression and identifies every source of collision. It does not improve the published algorithm for arbitrary deleted patterns.

A previous exact formula for deleting alternating words from alternating inputs concerns a restricted family of source words and deleted patterns. Its special cases do not imply the arbitrary-input identity here. General unrestricted two-deletion output counts and reconstruction-graph formulas are also different statistics; they do not distinguish the prescribed deletion order and letter labels in this result.

## Limitations

The theorem requires a prescribed deleted pattern of length two with different letters. It does not classify deleted patterns with repeated letters or length at least three. The expected-value corollary assumes independent uniform source letters. Exhaustive tests cover only bounded lengths. An equivalent identity may exist under older deletion-channel or shuffle terminology that was not located; historical priority is not independently certified.
