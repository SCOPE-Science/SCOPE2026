The proof's main nonstandard reduction is an independent first exponential alarm for the added edge, coupled to pure bipartite adsorption. Conditional uniformity of unmatched vertices and independent pure-process holding times produce the exact rational formula. The analytical asymptotic proof separates a possible terminal surviving pair from the nonterminal sum, controls the Laplace factors and uses Riemann sums on macroscopic states.

Reproducibility: run `python3 verify_defect.py` and `python3 verify_asymptotic.py` from the folder containing these files. `verify_defect.py` uses exact fractions and a graph-state dynamic program whose transitions enumerate every currently available edge, rather than using the theorem's one-dimensional derivation. It verifies 120 cases with \(2\le a\le6\), \(1\le b\le6\), and rates \(1/3,1,5/2,4\), totaling 13,564 memoized states. `verify_asymptotic.py` checks representative finite regimes through size 16,000. Both use Python 3 standard-library modules only.

Finite enumeration and numerical convergence do not certify infinite identities. The all-size formula and asymptotic statements are proved mathematically in `RESULT.md`.
