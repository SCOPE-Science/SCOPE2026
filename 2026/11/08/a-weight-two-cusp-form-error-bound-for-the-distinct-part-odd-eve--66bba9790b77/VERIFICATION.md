# Exact verification and scope

Run `python3 verify.py` using the embedded standalone program. It uses only Python's standard library. The output in `VERIFICATION_OUTPUT.txt` was generated by running that source.

The program performs three distinct tasks: a combinatorial signed-weight dynamic program for distinct-part partitions, an unrelated logarithmic-derivative computation of the Euler-quotient correction coefficients, and exact rational computations of the 24 cusp orders together with the two eta-quotient congruences. The two coefficient calculations agree at every index from 0 to 1100. The cusp calculations confirm the symbolic classification of the two possible gcd ratios.

The infinite weight-two cusp-form membership follows from the explicitly proved eta-quotient criterion assumptions, not from computation. The asymptotic uses classical Ramanujan--Petersson for cusp-form coefficients and the classical distinct-part partition asymptotic. None of the finite tests establishes the infinite theorem, proves historical novelty, or constitutes independent audit.
