For \(W=(0^a1^b)^k\) with positive run lengths and \(k\ge2\), every smallest string attractor has two positions and an explicit complete classification. If both runs have length at least two there are exactly \(2k(k-1)\) optimal pairs; if either run is a singleton there are exactly \((k-1)(k\max(a,b)+1)\), and for these words every two-position attractor for length-at-most-two factors is a full attractor.
