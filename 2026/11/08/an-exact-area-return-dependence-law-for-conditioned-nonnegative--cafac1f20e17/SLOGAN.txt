For a uniformly sampled nonnegative simple random-walk bridge of length \(2n\), the integrated height has strictly negative covariance with the positive-time return count for every \(n\ge2\), with exact value \((6\cdot4^n/C_n-4n^2-14n-6)/(n+2)\) and asymptotic \(-4n+6\sqrt{\pi n}+O(1)\). Among paths with exactly one return versus exactly two, the expected integrated height differs by exactly \(n\).
