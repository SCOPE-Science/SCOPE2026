The mathematical argument uses exact payoff differences, finite-state class reduction, Kolmogorov's cycle criterion, and an explicit positive stationary weight recursion. The distributed Python checker, using only the standard library, independently recomputes 16,320 recurrent-state stationary equations over 1,008 binary environments on rings of sizes four through nine. It separately checks the upper-threshold counterexample and the ternary cycle affinity. Those finite tests are not a proof for arbitrary ring size or every multiplier: the proof in RESULT.md supplies the general quantifiers. Independent external audit has not been performed.
