## Correctness — PASS
The displayed absent factors have occurring proper prefixes and suffixes. Conversely, avoiding the three stated families forces every adjacent run-label transition to follow the directed cycle, every run length to be bounded by its prescribed value, and every complete interior run to have its full prescribed length. Such words are exactly the factors of the periodic run cycle. Disjoint family counting gives the cardinality and length polynomial. The independent finite checker matched exact sets in 485 parameter profiles, but infinite correctness rests on the proof.

## Originality — PASS, with bibliographic qualification
Fici, Restivo and Rizzo (arXiv:1707.04450, Section 3) provide the general circular-word framework, finite-word reduction and upper bounds, and explicitly cover the permutation-word specialization where every run length is one; these are not claimed as new. Akagi et al. (arXiv:2202.13591) treat algorithms and classification types for finite RLE input strings rather than this exact all-parameter circular cycle family. Searches of published result summaries and targeted literature searches did not locate the exact three-family list or the polynomial. A general method for computing the invariant on individual inputs is acknowledged, and unindexed equivalent formulas are a residual risk.

## Mathematical value — PASS
An antidictionary is the complete finite local obstruction set determining a factorial language, important in word automata and compression. This natural family allows arbitrary run lengths, yet has a particularly rigid, explicitly computable obstruction set of size linear in the total period length. The nontrivial classification explains why no forbidden factor can involve more than three runs, supplies an exact multivariate length profile, and extends the established all-singleton-runs case beyond the scope of a fixed numerical table.

## Limits
The theorem requires each run label to appear exactly once in the circular run sequence. A different alphabet or repeated cyclic run labels can change the answer. The result is not a classification of general RLE input. No independent priority check or independent proof audit has been carried out.
