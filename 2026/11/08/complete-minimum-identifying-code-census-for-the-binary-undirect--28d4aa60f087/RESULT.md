# Complete minimum identifying-code census for the binary undirected de Bruijn graph of word length five

## Finding

Let \(G\) be the undirected binary de Bruijn graph whose vertices are the \(32\) labeled binary words of length five. Exactly **58** subsets of \(V(G)\) are minimum-radius-one identifying codes; every one has **12** vertices. Under the explicitly specified four-element group generated by global bit complementation and word reversal, these 58 codes form **16** orbits: thirteen of size four and three of size two. Exactly six codes are fixed by global complementation, and none by reversal or reversal-complementation.

The following eight vertices appear in **no** minimum code: `00000`, `00100`, `01010`, `01110`, `10001`, `10101`, `11011`, `11111`. Every other vertex appears in at least one minimum code. The full 58 labeled codebooks and sixteen orbit representatives are supplied in `optima_58.txt` and `orbits_16.tsv`.

## Assumptions and scope

The vertex set is \(\{0,1\}^5\), with all words distinct and labeled by their five bits. Two different vertices \(u\) and \(v\) are adjacent when either the final four bits of \(u\) equal the first four bits of \(v\), or conversely. Loops are irrelevant; identifying codes use the **closed** neighborhood \(B(u)=\{u\}\cup N(u)\) in this simple undirected graph. A subset \(S\) is identifying when all 32 sets \(B(u)\cap S\) are nonempty and pairwise distinct. Reversing all word coordinates and complementing all bits are graph automorphisms. No cyclic rotation of the individual words is identified.

Each bit mask in `optima_58.txt` encodes a codebook: bit \(i\) is set precisely when the five-bit word giving integer \(i\) in binary lies in the codebook (\(0\le i<32\)). The smallest representative in `orbits_16.tsv` is chosen numerically within its orbit; the reported group is only the subgroup explicitly generated by the two stated involutions.

## Proof

For a fixed vertex \(u\), the nonemptiness requirement is \(S\cap B(u)\ne\varnothing\). For two different vertices \(u,v\), their identifying signatures differ exactly when
\[
S\cap\bigl(B(u)\triangle B(v)\bigr)\ne\varnothing.
\]
Thus identifying codes are exactly the hitting sets for the family consisting of the 32 closed neighborhoods and the 496 symmetric differences of two distinct closed neighborhoods. A constraint \(D\) can be discarded if another constraint \(C\) satisfies \(C\subseteq D\): hitting \(C\) necessarily hits \(D\). Removing such redundant sets and exact duplicates leaves **161** inclusion-minimal nonempty constraints, computed directly from the graph by `count_cpp.cpp`. The same identification criterion is separately reconstructed from string-overlap equalities in `independent_verify.py`.

The finite exhaustive proof uses the following recursion for a target cardinality \(k\). Start at \(S=\varnothing\). At a partially chosen \(S\), choose any constraint \(C\) disjoint from \(S\), and branch on \(S\cup\{x\}\) for every \(x\in C\); memoize identical chosen subsets. Prune when \(|S|>k\), or when any greedily chosen family of mutually disjoint unmet constraints has size greater than \(k-|S|\). Stop at an identifying set or when no further element can be chosen. This is exhaustive: if a valid target set \(T\) contains the currently selected \(S\), then any unmet \(C\) has some \(x\in C\cap T\), and the corresponding branch remains contained in \(T\). Distinct unmet disjoint constraints demand distinct additional elements, justifying the pruning rule.

The C++ implementation finds no identifying set of cardinality at most eleven, and exactly 58 identifying sets of cardinality twelve. These sets are explicitly enumerated in `optima_58.txt`, giving both the lower bound and its attainment. This proves the minimum is twelve and the list complete. A second implementation independently branches on **include versus exclude** decisions for a vertex, using the unreduced 528 neighborhood/symmetric-difference clauses, and reconstructs exactly the same 58 sets, with none of size at most eleven. Thus the completeness check is not based on trusting a saved result list.

Applying the four graph automorphisms to each of the 58 masks gives exactly thirteen four-element and three two-element orbits. Comparing all 58 masks against each word's incidence gives precisely the eight never-selected words listed above. These are exact finite assertions about this one 32-vertex graph; no finite search is extrapolated to arbitrary word lengths.

An example minimum code (one orbit representative), written as its twelve labeled words, is
`00010`, `00011`, `00101`, `00111`, `01011`, `01101`, `01111`, `10000`, `10100`, `11000`, `11010`, `11100`.

## Verification

In a directory containing all four artifact files, run:

```sh
g++ -std=c++17 -O2 count_cpp.cpp -o count_cpp
./count_cpp > enumerated_masks.txt
python3 independent_verify.py
diff -u optima_58.txt enumerated_masks.txt
```

The C++ run reconstructs the 161 inclusion-minimal constraints and reports `CXX_SIZE_11=0`, `CXX_SIZE_12=58`, and symmetry classes with sizes `2:3` and `4:13`. The Python run independently constructs graph neighborhoods from literal word overlaps, checks the minimum-size obstruction, exactly matches the saved 58 masks, checks all 32 nonempty pairwise-distinct observation signatures of each code, validates `orbits_16.tsv`, and prints `INDEPENDENT_COMPLETE_OK`. The supplied data contain 58 decimal 32-bit masks and 16 canonical representatives. Both programs are complete finite enumerations; no random sampling or external mathematical software is needed for replay.

## Relationship to prior work

Boutin, Horan Goliber, and Pelto (publicly posted December 18, 2014) explicitly report the minimum cardinality **12** for the undirected \(\mathcal B(2,5)\), based on earlier computation, in the future-work discussion of their directed de Bruijn paper [1]. **The minimum cardinality is not presented as new here.** Horan (publicly posted August 3, 2015) establishes radius-one identifiability for undirected binary de Bruijn graphs at all lengths at least three, but does not enumerate all minimum length-five identifying sets [2]. The finding here is instead the full 58-codebook classification, exact symmetry-orbit sizes, and exact forbidden-vertex incidence profile. Generic identifying-code bounds and results on different graph families do not imply that census. No matching published census was located in the checked sources, but that search is not an independent priority certificate.

## Limitations

The theorem concerns closed, unoriented radius-one graph neighborhoods in the **specific** undirected binary graph of word length five. Directed-graph identifying codes, larger alphabets, longer words, larger radii, fault-tolerant variants, and quotients by any larger graph-automorphism group are outside the claim. The computational search is exhaustive only because its complete branch logic and input graph are supplied. An independent scientific and historical-priority audit has not been performed.
