# Reproducibility and limits

Execute `python3 verify.py` from the directory containing the standalone program, using standard Python 3.10 or later. The expected complete output is stored in `verification_output.txt`.

The verifier generates all weakly connected functional digraphs through twelve vertices as cyclic necklaces of unlabeled rooted trees. Rooted trees are generated by attaching one new leaf to every possible vertex of each smaller rooted tree; sorting the child encodings gives a canonical tree, and minimum cyclic rotation gives a canonical connected mapping. This generation has no isomorphism testing heuristic or probabilistic hashing. The resulting exact type counts agree with OEIS A002861, ending in \(16949\) types at order \(12\).

A globally shared color palette is refined simultaneously across all structures of each order. At each vertex, the update records its previous color, its unique successor's color, and the multiset of incoming predecessor colors. The verifier reports an injective signature on the connected isomorphism classes for every order through \(12\). This refinement is definable in \(\mathrm C^2\). It also directly enumerates automorphisms for all connected maps through seven vertices and verifies that their orbits coincide with the stable colors. Finally, it checks a six-cycle and two disjoint directed triangles, which have identical full two-variable relation profiles and stable uniform refinement.

These finite checks are not a proof of arbitrary order. The unrestricted statements follow from the cycle-peeling and rooted-tree reconstruction argument in `RESULT.md`. No external or independent mathematical audit has been carried out.
