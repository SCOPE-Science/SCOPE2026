# Equal occurrence frequencies for every palindrome in the Rudin–Shapiro word

## Finding

Let \(r:\mathbb N_0\to\{0,1\}\) be the parity of the number of (overlapping) adjacent `11` pairs in the ordinary binary expansion of its argument. A factor is a consecutive finite block, and a palindrome equals its reversal. For any factor \(u\), write
\[
\delta(u)=\lim_{N\to\infty}\frac1N\#\{0\le i<N:r(i)\cdots r(i+|u|-1)=u\}.
\]
Every palindromic factor has a natural starting-position density, and **all palindromic factors of the same length have exactly the same density**. The complete list is:

| Length \(n\) | Number of distinct palindromes | Density of each palindrome |
| --- | ---: | ---: |
| 1 | 2 | \(1/2\) |
| 2 | 2 | \(1/4\) |
| 3 | 4 | \(1/8\) |
| 4 | 4 | \(1/32\) |
| 5 | 4 | \(1/16\) |
| 6 | 4 | \(1/32\) |
| 7, 8, 10 | 4 at each length | \(1/64\) |
| 12, 14 | 2 at each length | \(1/128\) |
| all other positive lengths | 0 | — |

Thus the infinite word has exactly \(36\) distinct nonempty palindromic factors. More strongly, the exact starting positions of every palindrome can be generated by a finite eight-state rule, with explicit residue/state descriptions for all palindromes of length at least seven below.

## Assumptions and scope

All indices are zero-based integers and all densities are natural asymptotic densities of **starting positions**, not the probability conditional on a random factor being palindromic. A binary palindrome of length \(n\) is counted once per distinct word, independently of its number of occurrences. The statement concerns this precise classical binary Rudin–Shapiro word, not arbitrary generalized Rudin–Shapiro sequences or other codings.

Let \(a(q)=r(q)\), \(b(q)=r(q+1)\), \(e(q)=q\bmod 2\), and put \(S(q)=(a(q),b(q),e(q))\). Identify each state with its three-bit string. Define \(R(t)=r(t)\) for \(0\le t<16\); its finite table is given exactly by the definition of \(r\), and can be independently recomputed from binary expansions.

## Proof

**1. Two-digit recurrence and primitive state system.** Counting the adjacent binary `11` pairs gives, for all \(q\ge0\),
\[
r(2q)=r(q),\qquad r(2q+1)=r(q)\oplus(q\bmod2),
\]
where \(\oplus\) denotes bitwise addition modulo two. Hence the state word \(S(0)S(1)\cdots\) is fixed under a length-two substitution whose child-state maps are
\[
T_0(a,b,e)=(a,a\oplus e,0),\qquad T_1(a,b,e)=(a\oplus e,b,1),
\]
so \(S(2q)=T_0(S(q))\) and \(S(2q+1)=T_1(S(q))\). Its initial state is \((0,0,0)\). Direct calculation on its eight possible states shows every state can reach every state after exactly four transitions, and every state has exactly two incoming transitions, counting input digits. These are finite assertions exhaustively checked in `verify.py` by enumerating all eight sources and all sixteen four-digit paths. In particular, the substitution is primitive and its incidence matrix is twice-stochastic after normalization. The unique limiting letter-frequency vector of a primitive constant-length substitution is therefore uniform:
\[
\lim_{N\to\infty}N^{-1}\#\{0\le q<N:S(q)=s\}=\frac18\quad\text{for every }s\in\{0,1\}^3.
\]
The assertion includes all eight states, which are reachable from the initial state.

**2. Exact finite block reduction.** For \(0\le t<16\), concatenating binary digits and accounting for the single cross-boundary pair gives
\[
r(16q+t)=r(q)\oplus R(t)\oplus\bigl((q\bmod2)\,\mathbf1_{t\ge8}\bigr).
\]
Here multiplication inside the final bit is ordinary Boolean multiplication. For a factor of length \(1\le n\le16\) beginning at \(i=16q+h\) with \(0\le h<16\), write its \(j\)-th index as \(16q+h+j\). If \(h+j<16\), its symbol is
\[
a(q)\oplus R(h+j)\oplus\bigl(e(q)\,\mathbf1_{h+j\ge8}\bigr).
\]
If \(16\le h+j<32\), set \(t=h+j-16\); the symbol is
\[
b(q)\oplus R(t)\oplus\bigl((1\oplus e(q))\,\mathbf1_{t\ge8}\bigr).
\]
These formulas determine every such factor from the **exactly \(8\cdot16=128\)** possible pairs \((S(q),h)\). Because each state has frequency \(1/8\) and each residue \(h\) occurs once per block, each pair has starting-position density \(1/128\). Thus the density of any length-\(n\) factor is its number of pairs in this finite table divided by \(128\).

**3. Exhaustive exact finite comparison.** Enumerating the 128 pairs for every \(1\le n\le16\), and retaining a factor exactly when it equals its reversal, gives the following complete certificate. Each entry is \(u:m\), meaning the indicated word occurs for exactly \(m\) state/residue pairs. (This computation uses integer and string operations only; `verify.py` independently constructs every pair from the two displayed block formulas and checks the entire table.)

| \(n\) | Complete palindrome-and-multiplicity list |
| --- | --- |
| 1 | `0`:64, `1`:64 |
| 2 | `00`:32, `11`:32 |
| 3 | `000`:16, `010`:16, `101`:16, `111`:16 |
| 4 | `0000`:4, `0110`:4, `1001`:4, `1111`:4 |
| 5 | `00100`:8, `01110`:8, `10001`:8, `11011`:8 |
| 6 | `010010`:4, `011110`:4, `100001`:4, `101101`:4 |
| 7 | `0001000`:2, `0100010`:2, `1011101`:2, `1110111`:2 |
| 8 | `00100100`:2, `01000010`:2, `10111101`:2, `11011011`:2 |
| 9 | none |
| 10 | `0001001000`:2, `0010000100`:2, `1101111011`:2, `1110110111`:2 |
| 11 | none |
| 12 | `000010010000`:1, `111101101111`:1 |
| 13 | none |
| 14 | `01111011011110`:1, `10000100100001`:1 |
| 15, 16 | none |

For length \(n\ge17\), an odd palindrome contains a central length-15 palindromic factor, and an even palindrome contains a central length-16 palindromic factor. The last certificate row excludes both; hence no longer palindromes exist. Summing the number of words in the finite table gives exactly \(36\), and dividing the multiplicities by \(128\) proves the frequency table.

**4. Exact starting positions, not just densities.** For all listed factors of lengths \(1\) through \(6\), the occurrence set is precisely the set of indices \(16q+h\) such that the block formula in step 2, using \(S(q)\), returns the given factor. The same gives a concise explicit description of all longer palindromes. In the following table, a word \(u\) occurs at exactly the positions \(16q+h\) with \(S(q)\) in the indicated set; no other positions occur.

| --- | ---: | --- |
| `0001000` | 11 | `001`, `100` |
| `0100010` | 14 | `000`, `101` |
| `1011101` | 14 | `011`, `110` |
| `1110111` | 11 | `010`, `111` |
| `00100100` | 1 | `000`, `010` |
| `01000010` | 13 | `001`, `100` |
| `10111101` | 13 | `010`, `111` |
| `11011011` | 1 | `100`, `110` |
| `0001001000` | 0 | `000`, `010` |
| `0010000100` | 12 | `001`, `100` |

The exact starting-position rule follows directly from the 128-case calculation and the state recurrence. The last two tables are complete, not a bounded experimental sample. This concludes the proof.

## Verification

Run `python3 verify.py` with standard Python 3. The script recomputes the eight-state substitution, verifies its reachability, two incoming transitions and four-step primitivity, exhaustively constructs the \(16\times128\) candidate factors, checks the entire palindrome-and-multiplicity table, and checks every long-palindrome start set. A separate diagnostic compares its exact finite-state predictions against direct binary-expansion factors at 2,097,152 starts and checks 80,000 high-index block symbols. The recorded successful output was:

`VERIFY_OK exact_cases=2048 primitive_state_power=4 direct_windows=2097152 long_position_checks=80000`

The **infinite** density and exclusion claims depend on the proved block reduction and primitive frequency law; the large finite diagnostics alone would not prove them.

## Relationship to prior work

The absence of long palindromes is known: Allouche–Baake–Cassaigne–Damanik, *Palindrome complexity*, studies palindromes in generalized Rudin–Shapiro words and proves a cutoff at length 15. Schaeffer–Shallit, *Closed, Palindromic, Rich, Privileged, Trapezoidal, and Balanced Words in Automatic Sequences*, derives automatic descriptions of palindromic factor-length properties and describes maximal Rudin–Shapiro palindromes. Frid–Laborde–Peltomäki, *On prefix palindromic length of automatic words*, studies the quite different statistic of the smallest number of palindromic blocks in a prefix and its difference sequence for Rudin–Shapiro.

The present assertion is **not** novelty for the cutoff or the abstract ability to construct an automaton. It is the explicit per-factor *starting-position density*, its surprising equality across all palindromes of each length, and the complete exact occurrence rule. Neither knowing that a palindrome occurs nor knowing the number of distinct palindromes implies its natural density. The inspected primary articles did not present this frequency table or the all-palindrome equidistribution assertion.

## Limitations

The argument is for the binary parity-of-overlapping-`11` Rudin–Shapiro convention only. It makes no claim about all factor frequencies being equal; non-palindromic factors may have different frequencies. It does not provide independent review, and an unindexed equivalent literature statement remains possible. Earlier work already establishes the finite palindrome-length cutoff; that fact is used here rather than claimed as new. A related 1997 original is available as an abstract, but its historical PostScript full text was not accessible in the consulted format.
