# Verification

Run `python3 verify.py` in a directory containing the standalone `verify.py` file. It uses only the Python standard library. The checked examples cover complete graphs and complete multipartite graphs with part sizes up to three, thresholds from two to six, and groups generated by vertex swaps, part swaps, transitive cycles and mixed permutations. It independently enumerates forbidden cliques of every original invariant union, checks projections of vertex orbits to complete part orbits, verifies every stated dominated-vertex removal, and computes reduced simplicial homology over the field with two elements.

The recorded run `verify_output.txt` ended with `ALL_QUOTA_FIXED_CHECKS_OK parameter_cases= 50 fixed_orbit_faces= 807 quota_faces= 483 dominated_deletions= 28`. All cases matched the quota-predicted Betti ranks, including the mixed-degree and disconnected examples.

The code is finite corroboration. No finite enumeration proves the arbitrary-order integral statement; the explicit affine deformation and integral CW wedge argument are the mathematical proof. Since only mod-two homology is calculated by code, torsionfreeness is justified by the integral wedge construction instead.
