The standalone `checker.py` enumerates each set partition in restricted-growth-string form for \(N=1,\ldots,6\). Every ordered pair of partitions defines two equivalence relations on the same labelled worlds. For each pair, the program computes all relations generated by the two by explicit Boolean relational composition, including identity. It separately computes the side-specific graph distances by breadth-first search and the claimed count. It asserts equality across all \(44{,}168\) cases and prints a size distribution and the maximum. The program checks its own enumeration counts, and the sharp maxima obtained are \(1,2,6,7,10,11\).

Execute `python3 checker.py` using Python 3 and the standard library. The finite check provides direct computational corroboration but does not independently prove the general theorem.
