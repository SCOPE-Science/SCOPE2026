# Verification

Execute `python3 verify_spider.py` with Python 3 and no third-party packages. The script constructs each tree from its arm lengths, runs simultaneous refinement from a single initial color, and checks by an independent equivalence-of-partitions comparison that every round equals the claimed capped-distance partition. It computes the stabilization round directly and checks the full orbit partition, with 4,998 parameter instances in total.

An actual run produced the stdout embedded in `verification_output.txt` and ended with `VERIFY_OK cases=4998`. The file can be regenerated by running the script; equality of log text is only a reproducibility check, not a proof of the infinite theorem.

The symbolic induction in RESULT.md handles every integer arm length and every number of arms at least three. Boundary cases include length-one arms, all equal arms, a unique longest arm, and repeated second-longest distinct lengths. The checker does not verify historical originality or independent mathematical review.
