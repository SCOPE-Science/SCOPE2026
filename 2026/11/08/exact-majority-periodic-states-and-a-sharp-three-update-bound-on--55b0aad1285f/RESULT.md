# Exact majority-periodic states and a sharp three-update bound on complete split graphs

## Finding
For integers \(c,s\ge1\), let \(S_{c,s}=K_c\vee\overline{K_s}\), the join of a clique \(C\) of order \(c\) and an independent set \(I\) of order \(s\). At every integer time, each vertex adopts the strict majority binary opinion among its *open* neighbors; in a tie it retains its own opinion. A configuration is *fixed* if one update leaves it unchanged and is *primitive two-periodic* if its second update equals itself but its first does not. Let \(C_2(c,s)\) count distinct primitive two-cycle orbits (not configurations).

There are exactly two fixed configurations, the unanimous zero and unanimous one states. Every orbit has first periodic-entry time at most three. The complete primitive two-cycle orbit count is
\[
\boxed{\displaystyle C_2(c,s)=\mathbf1_{s\ge c}+\mathbf1_{c>s,\,c\equiv s\ (\mathrm{mod}\ 2)}\binom c{(c-s)/2}+\mathbf1_{2\mid c,\,2\mid s}\frac12\binom c{c/2}\binom s{s/2}.}
\]
Each term is a disjoint, explicitly classified type. For \(c>s\ge3\) with \(c\equiv s\pmod 2\), the three-update bound is attained, so it is a sharp bound uniform over all complete split graphs. No initial configuration has eventual period greater than two.

The three primitive two-cycle families are as follows: (A) if \(s\ge c\), the two opposite monochromatic-part states \((C=0,I=1)\leftrightarrow(C=1,I=0)\); (B) if \(c>s\) and \(c-s\) is even, for each \((c-s)/2\)-subset \(U\subset C\), the state with ones precisely \(U\cup I\) alternates with the state with ones precisely \(C\setminus U\); and (C) if \(c,s\) are both even, every state with exactly half the clique and half the independent-set vertices in opinion one alternates with the state obtained by complementing all clique opinions and leaving independent-set opinions unchanged. In type (C) all independent vertices are stationary while all clique vertices flip.

## Assumptions and scope
The graph is simple, finite, undirected and labelled. The partition \(C\sqcup I\) is specified; \(c,s\) are positive integers. At each synchronous update, neighbors are counted without counting the vertex itself, and ties preserve the old bit. All counts are of labelled binary configurations or of two-element orbits under time evolution, as indicated. A *first periodic-entry time* of an initial configuration \(x\) is \(\tau(x)=\min\{t\ge0:T^{t+2}x=T^tx\}\). All quantifiers cover every \(c,s\ge1\) and every initial binary state; the sharpness statement applies to the stated infinite subfamily.

## Proof
**Exact local update.** Write \(k\) for the number of ones in \(C\), \(j\) for the number of ones in \(I\), and \(H=k+j\). Every clique vertex has degree \(c+s-1\) and sees all other vertices. Consequently the new clique is uniformly zero when \(2H<c+s\), uniformly one when \(2H>c+s\), and is the bitwise complement of the old clique when \(2H=c+s\). Indeed, in the equality case the clique degree is odd, and a clique zero sees one more one than zero whereas a clique one sees one more zero than one. Every independent vertex sees precisely the clique, so the new independent set is uniformly zero if \(2k<c\), uniformly one if \(2k>c\), and unchanged if \(2k=c\). These formulas include the boundary cases \(c=1\) and \(s=1\).

**Fixed states.** A mixed clique cannot be fixed: its next state is uniform or its bitwise complement. If the clique is uniformly zero (respectively one), all independent vertices update to zero (respectively one); hence a fixed state must be globally unanimous. Both unanimous states are fixed.

**Periodic classification.** In a two-periodic configuration with initially mixed clique, the first update must complement it, for otherwise no second update could restore a mixed clique. Therefore \(2H=c+s\). If \(k=c/2\), necessarily both \(c\) and \(s\) are even and \(j=s/2\). The independent set does not change, while the half-filled clique complements itself on every update: precisely type (C).

If \(k<c/2\), the first independent-set update sends all its vertices to zero, while the first clique update replaces \(k\) ones by \(c-k\). Since the original clique is mixed, the second update can restore it only if its first-update state also satisfies the equality \(2H'=c+s\); otherwise the second clique would be monochromatic. Thus \(c-k=(c+s)/2\), so \(k=(c-s)/2\) and the initial equality forces \(j=s\). Such a mixed clique has \(0<k<c/2\), implying \(c>s\) and same parity. The next clique has more than half ones, so its independent set resets to one, and the second clique update complements back: type (B). The case \(k>c/2\) is obtained by interchanging zero and one. These are all mixed-clique cycles.

For a two-periodic state with initially unanimous clique, its independent set becomes unanimous after the first update. Because it must return to its initial state after the second update, the independent set was initially unanimous as well. The only nonfixed candidates are the two opposite monochromatic-part states. When the independent part opposes the clique, all independent vertices flip. The clique flips precisely when \(s\ge c\): if \(s>c\) there is a strict opposite majority, and if \(s=c\) there is the complementing equality case. This gives type (A) and exhausts all possibilities.

Types (A), (B) and (C) are disjoint. Type (A) gives one orbit; type (B) gives \(\binom c{(c-s)/2}\) orbits, because each subset specifies one unordered pair and the partner's independent bits are the opposite; type (C) gives \(\frac12\binom c{c/2}\binom s{s/2}\) orbits, because the complementing clique involution has no fixed point. The displayed count follows.

**Universal transient bound.** If initially \(2H\ne c+s\), the clique is unanimous after one update and the independent set is unanimous after a second update. Both parts are therefore unanimous by time two. Their state is either a consensus (fixed), or an opposing-part state, which is already a two-cycle if \(s\ge c\), and moves to consensus at the next update if \(s<c\). Thus \(\tau\le3\).

If initially \(2H=c+s\), the clique complements once. If \(2k=c\), this is exactly type (C). Otherwise the independent set becomes unanimous at time one. If the total at time one again equals \((c+s)/2\), the preceding periodic-classification argument shows a type (A) or (B) two-cycle (the former when the clique is unanimous). If it does not, the clique becomes unanimous at time two, while the independent set is also unanimous at time two: its time-one clique has \(c-k\) ones, which is unequal to \(c/2\) when \(k\ne c/2\). As before the system is periodic by time three. Hence \(\tau(x)\le3\) for every initial state.

**Sharpness.** Suppose \(c>s\ge3\), \(c\equiv s\pmod2\). Choose initially \(k=(c-s)/2+1\) clique ones and \(j=s-1\) independent-set ones (in any labelled positions). Then \(2H=c+s\) and \(k<c/2\). At the first update, the clique complements and the independent set becomes all zero; the new clique has \(c-k=(c+s)/2-1\) ones. At the second update, the clique becomes all zero and the independent set all one. Since \(c>s\), at the third update this opposing state becomes all zero, a fixed point. Neither the initial, first nor second configuration is two-periodic, so \(\tau=3\).

## Verification
The proof above is for all positive integer parameters, independently of finite computations. To reproduce finite cross-checks from the accompanying files, run `python3 code/direct_enumeration.py` and `python3 code/weighted_profiles.py` from this package's root. The first program constructs neighbor lists and checks every labelled configuration for 36 parameter pairs \(1\le c,s\le6\), totalling 15,876 states. The second checks all permutation-orbit representatives, weighted by their exact binomial orbit sizes, for 900 pairs \(1\le c,s\le30\) and separately checks 2,304 explicit three-update witnesses. Both programs compare to the theorem's closed formula; their captured standard outputs are in `evidence/direct_enumeration.txt` and `evidence/weighted_profiles.txt`. These computations are reproducibility checks, not an infinite proof.

## Relationship to prior work
Goles and Olivos established eventual period at most two for symmetric binary threshold dynamics. Benjamini, Chan, O'Donnell, Tamuz and Tan (arXiv:1405.2486v1, first posted 11 May 2014) discuss majority dynamics and cite that theorem, but their main results concern infinite and random graphs. Kaaser, Mallmann-Trenn and Natale (arXiv:1508.03519v1, first posted 14 August 2015) study the voting time of deterministic majority updates and obtain bounds through graph modules, including cliques and independent modules; the inspected theorem and symmetry section do not give the exact fixed/primitive-two-cycle enumeration on complete split graphs. The present classification is not an implication of the general period-two bound, nor of a convergence-time upper bound alone. Related equal-size complete-multipartite periodic-state formulas concern different part-size constraints and do not cover singleton-part plus one large-part split graphs in general.

## Limitations
The theorem concerns synchronous deterministic strict open-neighbor binary majority with tie retention and the specified complete split graph family. It does not address other split graphs, asynchronous updates, random initial-condition basin distributions, or minimal first-entry times for each parameter pair. The exact three-update upper bound is sharp over the family and on the specified infinite parameter subfamily; it is not asserted that every parameter pair attains three. The literature search does not establish global historical priority. Older threshold-dynamics articles may contain relevant special cases that were not fully available for inspection.
