In finite-memory Pólya threshold graphs, the non-loop edge count has a process-level Gaussian limit with exact covariance \(\rho(1-\rho)\mathcal D_M\min(s,t)^3/3\), where \(\mathcal D_M=1+2M\delta+M(M-1)\delta^2/(1+\delta)\). Finite reinforcement memory forces a deterministic limiting edge density, whereas unbounded Pólya memory retains a random Beta limit; the Gaussian variance inflation grows quadratically with fixed memory length.
