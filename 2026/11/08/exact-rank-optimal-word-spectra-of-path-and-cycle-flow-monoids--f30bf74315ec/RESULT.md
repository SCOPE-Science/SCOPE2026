# Exact rank-optimal word spectra of path and cycle flow monoids

## Finding

Let \(G\) be the labeled undirected path \(P_n\), \(n\ge1\), or the labeled simple cycle \(C_n\), \(n\ge3\). Its flow transformation monoid is generated by the distinct directed edge-collapse maps \(\tau_{ab}\) for every orientation of each edge: \(\tau_{ab}(a)=b\) and \(\tau_{ab}(x)=x\) for \(x\ne a\). Compose maps from left to right, as transformations acting on the right. For integers \(0\le m\le n-1\), let \(W_G(n,m)\) be the number of **words of exactly \(m\) labeled generators** whose transformation has image size \(n-m\). These are the geodesic rank-loss words: each letter reduces the current image size by one. Repeated words representing the same transformation are counted separately.

The entire rank-optimal word spectra are

\[
W_{P_n}(n,m)=2^m(n-m)^m\qquad(0\le m\le n-1),
\]

and

\[
W_{C_n}(n,0)=1,\qquad
W_{C_n}(n,m)=2^m n(n-m)^{m-1}\qquad(1\le m\le n-1).
\]

For \(n\ge3\) and \(1\le m\le n-1\), their exact ratio is
\[
\frac{W_{C_n}(n,m)}{W_{P_n}(n,m)}=\frac{n}{n-m}.
\]

In particular, there are \(2^{n-1}\) shortest reset words for \(P_n\) and \(n2^{n-1}\) for \(C_n\). For any specified reset state \(r\in\{1,\ldots,n\}\), a path has exactly \(\binom{n-1}{r-1}\) shortest reset words with that state as image, whereas a cycle has exactly \(2^{n-1}\) such words at each vertex.

## Assumptions and scope

Paths are simple labeled graphs, with vertices \(1,\ldots,n\) in order. Cycles have the same vertex labels cyclically and require \(n\ge3\). Each oriented edge is a distinct alphabet letter. The empty word for \(m=0\) is counted once. The claim counts words, not distinct monoid elements, and does not count words longer than the minimum possible length at the specified rank. A path of one vertex has only the empty word, so its claimed value is one. The characteristic of a field is irrelevant: these are set transformations.

## Proof

**Rank reduction and forests.** Suppose a word has transformed the full vertex set into current image \(S\). Appending the letter \(\tau_{ab}\) changes the image to \(\tau_{ab}(S)\); its cardinality drops by exactly one if and only if \(a\) and \(b\) both lie in \(S\). Otherwise it stays constant. Since each elementary collapse decreases rank by at most one, length \(m\) yields rank \(n-m\) exactly when this strict-drop condition holds at all \(m\) steps.

In such a word every source \(a\) is used at most once, because immediately after its letter it is absent from all subsequent images. Draw a directed arrow \(a\to b\) for every letter \(\tau_{ab}\). Each source has outdegree one and each other vertex outdegree zero. Because \(b\) is still present when \(a\) is removed, an arrow \(a\to b\) can point to another removed vertex only if \(b\) is removed strictly later. Thus no directed cycle is possible. The arrows form a directed rooted forest with \(m\) edges and \(k=n-m\) rooted components, each edge belonging to the underlying graph. Conversely, given such a forest, execute its edge letters in any total order in which children precede parents. Every chosen target is still present; each letter causes one strict rank drop. Hence the correspondence between geodesic words and rooted spanning forests equipped with linear extensions of the descendant-before-ancestor partial order is bijective.

**A connected path component.** A component with \(\ell\) consecutive vertices has a unique choice of edge set, and its root can be any vertex in position \(j=1,\ldots,\ell\). The arrows point toward that root. The descendant-before-ancestor order is a shuffle of the two linear chains of lengths \(j-1\) and \(\ell-j\), so it has \(\binom{\ell-1}{j-1}\) linear extensions. Summing over the possible roots gives \(\sum_j\binom{\ell-1}{j-1}=2^{\ell-1}\). If a spanning forest has path components of orders \(\ell_1,\ldots,\ell_k\), put \(a_i=\ell_i-1\), so \(\sum_i a_i=m\). Each rooted component contributes \(2^{a_i}\) possible internal letter orders, and the component orders interleave in \(\binom{m}{a_1,\ldots,a_k}\) ways. Thus the total word count for that fixed edge forest is
\[
2^m\frac{m!}{a_1!\cdots a_k!}.
\]

**Paths.** Choosing \(m\) of the \(n-1\) path edges uniquely yields an ordered list of the \(k\) positive component lengths \(\ell_1,\ldots,\ell_k\), or equivalently a nonnegative \(k\)-tuple \((a_1,\ldots,a_k)\) with sum \(m\). Hence the multinomial theorem yields
\[
W_{P_n}(n,m)=2^m\sum_{a_1+\cdots+a_k=m}\frac{m!}{a_1!\cdots a_k!}=2^m k^m.
\]
This also covers \(m=0\), with all components singletons.

**Cycles.** For \(m\ge1\), a spanning forest with \(m<n\) edges is a union of \(k=n-m\) nonempty path components separated by \(k\) omitted cycle edges. Distinguish one omitted edge as a starting cut. There are \(n\) choices for this edge, followed by a cyclically ordered composition of \(n\) into \(k\) positive lengths, equivalently a nonnegative \(k\)-tuple of the \(a_i\) with sum \(m\). Every unmarked forest has exactly \(k\) possible distinguished cuts. Therefore
\[
W_{C_n}(n,m)=\frac nk\,2^m\sum_{a_1+\cdots+a_k=m}\frac{m!}{a_1!\cdots a_k!} = \frac nk\,2^mk^m=2^m n k^{m-1}.
\]
For \(m=0\), the only word is empty. Division by the path formula proves the ratio.

**Specified reset states.** At full compression \(m=n-1\), a path has a single spanning tree. If its root is at position \(r\), the two directed chains can be shuffled in \(\binom{n-1}{r-1}\) orders. Cyclic symmetry makes the number of shortest reset words per cycle vertex constant; the total \(n2^{n-1}\) divided by \(n\) gives \(2^{n-1}\).

## Verification

`verify.py` is a standalone Python 3 standard-library checker. It uses two independent finite models: first, it actually enumerates words and their transformations at every rank for paths on one through six vertices and cycles on three through six vertices; second, a subset-image dynamic program enumerates only the rank-reducing directed edge choices for paths up to 12 vertices and cycles up to 12 vertices. It checks every predicted count and 65 exact ratio equalities. The recorded output `verification_output.txt` ends with `VERIFY_OK direct_cases=10 subset_cases=22 ratio_checks=65`. This checks examples and boundaries; the preceding forest-and-multinomial proof covers all permitted sizes.

## Relationship to prior work

Assem, Derets and Nehaniv (arXiv:2608.24239, first made public 2026-08-25) define the same edge-collapse flow monoid and explicitly note that a connected graph on \(n\) vertices has shortest reset length \(n-1\). Cameron, Castillo-Ramirez, Gadouleau and Mitchell (DOI 10.1007/s10801-016-0703-9, first online 2016) investigate the lengths of **individual elements** of arc-generated transformation semigroups; they also provide underlying rank-loss results. East, Gadouleau and Mitchell (DOI 10.5802/alco.56, 2019) investigate semigroup structure. These works supply the definitions and reset-length context, not an all-rank **word-multiplicity** formula for labeled paths and cycles. Counting shortest reset **words** is strictly different from counting image transformations or proving the existence of a shortest reset word. Searches and implication comparisons did not identify an equivalent complete formula; that does not establish absolute historical priority.

## Limitations

The word spectra are for edge-collapse generating alphabets of simple paths and cycles only. No statement is made for arbitrary trees, all graphs, distinct induced transformations, or non-geodesic words. The exact counts are mathematically proved here but have only self-review; no independent mathematical audit has been performed. Earlier semigroup or automata enumerations under other terminology could affect historical priority.
