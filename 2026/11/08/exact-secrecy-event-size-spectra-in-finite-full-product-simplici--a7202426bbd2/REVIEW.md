# Review of exact secrecy-event size spectra

## Correctness — PASS

The argument starts from the full source frame condition (SN) and ordinary knowledge, not an unverified reformulation. Every facet of the fixed owner star must be in the truth event. A missing facet outside that star must witness every non-owner coordinate value, so the false-facet set has surjective projections. This is necessary and sufficient: choose the atom valuation equal to the event and a singleton owner secrecy neighborhood, leaving all others empty. Inclusion-exclusion over absent coordinate labels proves every generating-polynomial coefficient. A largest non-owner coordinate supplies the lower bound on false-facet count; surjective assignments attain it, with a bijective anchor preventing overcounting. The one-owner-state boundary is addressed separately. The included independent brute-force semantic checker matches the formula on 108 small parameter vectors and checks the extremum and examples.

## Mathematical value — PASS

The event-size spectrum is a natural parameter for the central new notion in the motivating logic: how large a proposition's truth set can be while the owner knows it and every other agent retains a possible counterexample. The result answers existence, maximal secret-event size, exact number of extremizers and all intermediate size multiplicities for every finite complete-information-product dimension. This is a complete natural invariant, rather than an arbitrary small sample or an isolated illustrative counterexample. Although the proof employs classical inclusion-exclusion, the owner-local interpretation and sharp resource bound are an exact structural description of those semantics.
