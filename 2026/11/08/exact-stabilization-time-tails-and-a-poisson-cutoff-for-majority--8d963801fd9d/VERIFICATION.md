# Reproducibility

Run `python3 verify_rule232.py` using Python 3 standard-library only. The provided `verify_rule232.log` is the actual output. The checker exhausts every labelled binary state for each ring order from three through fourteen, determines the first periodic-entry time by iterating the synchronous majority map, compares the predicted local alternating-window flip criterion, and checks the exact cumulative counts from two independent signed matrix powers for each observation time zero through five.

The code verifies finitely many cases, not the infinite family or the distributional limit; those conclusions require the graph-theoretic and factorial-moment arguments in `RESULT.md`. No independent validation or external audit has been performed.
