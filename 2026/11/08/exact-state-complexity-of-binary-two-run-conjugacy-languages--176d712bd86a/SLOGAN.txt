For every positive run pair \(a,b\), the minimal complete DFA for all cyclic shifts of \(0^a1^b\) has exactly \(2ab+3\) states. The sharper Myhill–Nerode profile has \(2\min\{j,a,b,a+b-j\}\) distinct nonempty states at each intermediate prefix depth \(j\), showing that balanced runs maximize this complexity at fixed length.
