Over every binary extension field, the complete fixed-subalgebra dimension distributions of unital endomorphisms and automorphisms of \(\mathbb F_q[x,y]/(x^2,y^2)\) have explicit formulas and a single isomorphism type in each dimension. An automorphism fixes only the scalars if and only if \(q>2\); the automorphism action has exactly \(3q\) element orbits.
