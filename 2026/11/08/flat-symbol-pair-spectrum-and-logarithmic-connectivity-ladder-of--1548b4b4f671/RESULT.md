# Flat symbol-pair spectrum and logarithmic connectivity ladder of \(\mathrm{RM}(1,m)\)

## Finding

Let \(m\geq2\), \(n=2^m\), and order the points of \(\mathbb F_2^m\) by the ordinary binary numerical order \(0,1,\ldots,n-1\), with coordinate \(0\) the least significant bit. Let \(C_m\) be the binary first-order Reed–Muller code evaluated in precisely this order. For a cyclic binary word \(u\), let its symbol-pair weight be
\[
 w_p(u)=\#\{t\in\mathbb Z/n\mathbb Z:(u_t,u_{t+1})\ne(0,0)\}.
\]
Then its complete symbol-pair weight enumerator is
\[
 \boxed{W_{C_m}^{p}(z)=1+4\sum_{r=1}^{n/2-1}z^{n/2+r}+3z^n.}
\]
Thus **every integer pair weight strictly between \(n/2\) and \(n\) occurs exactly four times**, and exactly three nonzero codewords have pair weight \(n\). In particular the minimum pair distance is \(n/2+1\).

For each integer \(\alpha\geq0\), write
\[
 S_\alpha=\{u\in C_m:0<w_p(u)\leq\alpha\},\qquad
 \gamma_m(\alpha)=\dim_{\mathbb F_2}\langle S_\alpha\rangle.
\]
The entire generation profile is
\[
 \boxed{\gamma_m(\alpha)=
 \begin{cases}
 0,&\alpha\leq n/2,\\
 \min\{m+1,\,3+\lfloor\log_2(\alpha-n/2)\rfloor\},&\alpha\geq n/2+1.
 \end{cases}}
\]
Consequently, the graph on \(C_m\) joining codeword pairs at symbol-pair distance at most \(\alpha\) has exactly \(2^{m+1-\gamma_m(\alpha)}\) connected components; it becomes connected exactly at \(\alpha=3n/4\). Its disconnection threshold, in the convention of Singh–Singh, is \(3n/4-1\). At \(m=2\) the minimum-distance layer already generates the code; for \(m\geq3\) the strict interval is nonempty.

## Assumptions and scope

The alphabet is \(\mathbb F_2\); the code is the \((m+1)\)-dimensional space of evaluations of all affine forms \(f(t)=c\oplus\sum_{j=0}^{m-1}a_jt_j\), with \(a_j,c\in\mathbb F_2\). Evaluation is in **binary numerical order**, not an unspecified ordering of the same code's coordinates. The symbol-pair metric uses a cyclic wrap-around pair from the last to the first coordinate. The theorem holds for all integers \(m\geq2\), and no claim is made about arbitrary coordinate permutations, higher-order Reed–Muller codes, or nonbinary fields.

## Proof

**1. Transition identity.** Fix a nonconstant affine word \(u_t=f(t)\), so its Hamming weight is \(n/2\). Let \(T\) be its number of cyclic bit transitions. Every cyclic run of \(L\) ones touches exactly \(L+1\) adjacent pairs (the \(L-1\) internal pairs and the two boundary pairs), giving
\[
 w_p(u)=\frac n2+\frac T2.
\]
(The equality is equivalently the standard identity \(w_p=w_H+\text{number of cyclic one-runs}\).) Constants are handled separately.

Set \(s_j=a_0\oplus\cdots\oplus a_j\), for \(0\leq j\leq m-1\). The map \(a\mapsto s\) is invertible over \(\mathbb F_2\). For \(0\leq t<n-1\), the binary change from \(t\) to \(t+1\) toggles exactly bits \(0,\ldots,j\) when \(j=v_2(t+1)\). There are \(2^{m-j-1}\) such steps, and the function changes value exactly if \(s_j=1\). The wrap from \(n-1\) to \(0\) toggles all bits, contributing \(s_{m-1}\). Therefore
\[
 T=\sum_{j=0}^{m-1}2^{m-j-1}s_j+s_{m-1}
  =2\left(\sum_{j=0}^{m-2}2^{m-j-2}s_j+s_{m-1}\right).
\]
Define \(r(s)=\sum_{j=0}^{m-2}2^{m-j-2}s_j+s_{m-1}\); every nonzero \(a\) corresponds to exactly one nonzero \(s\), and both choices of \(c\) yield \(w_p(u)=n/2+r(s)\).

**2. Exact weight spectrum.** The generating polynomial of the integer \(r(s)\) for all \(s\in\mathbb F_2^m\) is
\[
 \begin{aligned}
 P_m(z)&=(1+z)^2\prod_{j=1}^{m-2}(1+z^{2^j})\\
 &=(1+z)(1+z+\cdots+z^{2^{m-1}-1})\\
 &=1+2\sum_{r=1}^{n/2-1}z^r+z^{n/2}.
 \end{aligned}
\]
The product over an empty index range is \(1\), covering \(m=2\). Its constant term comes only from \(a=0\), not from a balanced word. For \(a=0\), the choices \(c=0,1\) produce the zero and all-one words, of pair weights \(0,n\). Every nonzero \(s\) produces exactly two codewords of the stated pair weight. Consequently \(W^p=1+z^n+2z^{n/2}(P_m(z)-1)\), which simplifies to the displayed spectrum. This also checks that all multiplicities sum to \(2^{m+1}=2n\).

**3. Exact generated subspace.** Let \(\alpha=n/2+r\), where \(r\geq1\) is an integer. The nonconstant words in \(S_\alpha\) are precisely those with \(0<r(s)\leq r\), together with both possible values of \(c\). Since at least one such \(s\) exists, their sum includes the all-one codeword. The additional rank is the dimension of the span of the corresponding \(s\)-vectors. The function \(r(s)\) is a sum of **nonnegative coordinate weights**: \(1,1,2,4,\ldots,2^{m-2}\). If a coordinate has weight greater than \(r\), no eligible \(s\) uses it. Conversely, every unit vector of coordinate weight at most \(r\) is eligible. Hence the span is exactly the coordinate subspace generated by these unit vectors. For \(1\leq r<2^{m-2}=n/4\), the number is \(2+\lfloor\log_2 r\rfloor\), and at \(r\geq n/4\) it is \(m\). Adding the all-one direction gives the claimed rank formula. Below \(n/2+1\) there is no nonzero eligible word.

**4. Connectivity.** Translation invariance makes the pair-distance graph the Cayley graph of the additive code \(C_m\) with connection set \(S_\alpha\). A path starting at the zero codeword reaches exactly \(\langle S_\alpha\rangle\); the other components are its cosets. There are therefore \(2^{(m+1)-\gamma_m(\alpha)}\) components. The largest required coordinate weight in \(r(s)\) is \(n/4\), so full generation occurs first at \(\alpha=n/2+n/4=3n/4\), and one integer earlier is the last disconnected level. The proof holds for arbitrarily large \(m\); the finite tests below are corroboration, not a substitute for these identities.

## Verification

The complete, standalone Python 3 program `check_rm_pair.py` directly enumerates every affine evaluation word for \(m=2,\ldots,8\), computes cyclic symbol-pair weights from adjacent bits (without using the transition formula), calculates the entire enumerator, and independently recomputes generated-subspace ranks using binary elimination at every integer threshold. Run `python3 check_rm_pair.py` in the directory containing the file. It must finish with `CERTIFICATE_OK`. The observed checks cover \(\sum_{m=2}^8 2^{m+1}=1016\) affine words. No numerical extrapolation is used in the all-length proof.

## Relationship to prior work

Singh and Singh (2026, arXiv:2609.10989) introduce the general symbol-pair generation profile, disconnection threshold, and coset-based function-protection criterion. The present result evaluates those invariants exactly for the natural binary numerical ordering of the full first-order Reed–Muller family and adds its flat, full symbol-pair weight distribution. The general Cayley/coset principle is credited to that work and is also independently justified in Step 4. Xia, Liu, and Chen (arXiv:2312.16271) develop function-correcting symbol-pair codes without this particular Reed–Muller computation. Jurrius (arXiv:1104.0172) treats generalized **Hamming** weight enumeration of first-order Reed–Muller codes, not cyclic pair-weight data; Carlet and Solé (arXiv:2301.13497) likewise study Hamming spectra of different Reed–Muller orders. An accessible record of a cyclic Hamming-code generation-profile result addresses a different code family and does not imply the binary numerical-order Reed–Muller profile.

## Limitations

This is an exact code-invariant theorem for a specified coordinate ordering, not a classification under all coordinate orderings or a new bound on optimal redundancy. The connection to protectable function partitions is mediated by existing general results; the theorem itself proves only the explicitly stated spectrum, ranks, and graph connectivity. Mathematical priority remains subject to wider literature and independent review. A code presented as a systematic encoder may require a coordinate choice, which can alter the pair metric; no systematic realisation without such checking is asserted.
