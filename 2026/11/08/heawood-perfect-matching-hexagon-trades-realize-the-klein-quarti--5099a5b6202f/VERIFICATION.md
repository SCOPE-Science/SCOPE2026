# Executable finite verification

The two complete scripts `verify_matchings.py` and `verify_fano.py` use only the Python standard library. Invoke them from the same extracted directory using:

```text
python3 verify_matchings.py
python3 verify_fano.py
```

The first verifies all \(3^7\) point-to-incident-line choices; the second checks all \(7!\) assignments independently using arithmetic in \(\mathbb F_2^3\). Both recover 24 valid perfect matchings and 28 Heawood hexagons, the 84-edge seven-regular matching flip graph, and all root/neighbor-distance counts giving the intersection array \(\{7,4,1;1,2,7\}\). They separately construct the Coxeter disjointness graph, exhibit 24 induced heptagons, and compare the common-two-edge-path criterion with every legal matching flip. The torus faces are generated by local dart rotations in the first implementation and explicit translation orbits in the second. Both give exactly three isolated vertices and three facial-reconfiguration seven-cycles.

These finite exhaustive computations depend on neither sampling nor a fixed precomputed data file. The identification with the *named* Klein graph uses published uniqueness of the corresponding distance-regular intersection array. No independent external scholarly audit, nonfinite generalization, or exhaustive historical priority determination is asserted.
