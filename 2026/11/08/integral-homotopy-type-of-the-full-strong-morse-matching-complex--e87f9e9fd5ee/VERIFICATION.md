# Reproduction and verification

Run `python3 verify_c9.py` with Python 3 and the standard library from this directory. The script rebuilds every full strong Morse matching generated by an injective ordering of the nine graph vertices; it does not read a precomputed face table or external file. All 362,880 permutations are examined. There are 510 different resulting matching masks and 2,634 nonempty faces; the nonempty face vector is `(18, 126, 438, 810, 792, 378, 72)`.

Using the explicitly supplied incidence-toggle order, the script reconstructs all 1,314 matched covering pairs and exactly six critical faces (one zero-cell, five four-cells). It checks every covering incidence and performs a full topological sort of the reversed Hasse directed graph (2,634 vertices, 11,538 directed covering edges). It also independently calculates ranks over \(\mathbb F_2\) of the unmodified simplicial boundary matrices, obtaining only reduced degree-four Betti rank five. It recomputes the pure subcomplex and finds exactly 36 additional nonempty simplices in the full complex (18 of dimension three, 18 of dimension four).

Expected final line: `ALL_VERIFY_OK`. Acyclicity and critical-cell counts, together with the standard finite discrete-Morse CW theorem, prove the integral homotopy type. Mod-two ranks alone do **not** prove an integral or homotopy classification. No independent mathematical audit has been performed, and no assertion is made about other cycle lengths.
