# Reproducible finite verification

Execute `python3 verify_morse.py` in the same directory. The verifier uses the Python 3 standard library only. Its actual expected stdout is stored in `verification_output.txt`. Every face of the octagonal-prism ordinary matching complex is generated by the disjoint-edge rule, independently of any topological guess.

The complete augmented face poset contains 11,396 simplices, including the empty simplex. The face-toggle matching contains 5,692 distinct pairs, leaving four critical four-simplices and eight critical five-simplices. A complete orientation test of all 55,296 cover incidences produces an acyclic directed graph. A signed gradient-path substitution computes the integral Morse boundary; the nonzero rows are unit multiples of the primitive vector \((0,1,-1,-1)\). The Smith factors are therefore \((1,0,0,0)\). An independent direct mod-two simplicial boundary calculation checks reduced Betti numbers three in dimension four and seven in dimension five.

The homotopy conclusion also uses the ordinary mathematical fact that the four-skeleton of this Morse CW model is a wedge of four four-spheres and that its fourth homotopy group equals its fourth integral homology, so the integral degree matrix controls all five-cell attachments. The code does not certify novelty, arbitrary other prism sizes, or an independent review.
