# Maximal EF1 on complete multipartite conflicts: existence, exact counts, and a parity bottleneck

## Finding

**Theorem (constructive existence and exact bipartite law).** Fix an integer \(n\geq 1\) of labeled agents, indivisible unit-value goods, and the identical additive valuation \(v_i(S)=|S|\). An allocation may leave goods unassigned; every agent's bundle must be an independent set of an undirected conflict graph. *Maximal* means no unassigned good can be added to any bundle without violating independence. *EF1* means that for any pair of agents, removing at most one good from the second bundle removes the first agent's envy. All statements below use these definitions.

1. Every finite complete multipartite conflict graph \(K_{a_1,\ldots,a_s}\), with positive part sizes, admits a maximal EF1 allocation for **every** \(n\). An explicit algorithm sorts the parts by size and constructs such an allocation using \(O(m+s\log s+n)\) elementary operations, where \(m=\sum_i a_i\).
2. For \(K_{a,b}\) with \(a,b\geq1\), the exact number of maximal EF1 allocations with labeled agents and individually labeled goods is \(M_n(a,b)=F_n(a,b)+D_n(a)+D_n(b)\), with the closed formulas below. In particular, the largest possible number of allocated goods is \(a+b\) when \(F_n(a,b)>0\), and \(\max(a,b)\) otherwise.
3. For each odd integer \(t\geq3\), on \(K_{t,t}\) with \(n=t\), **every** maximal EF1 allocation leaves exactly half the goods unassigned, and there are exactly \(2t!\) such allocations. If instead all maximal feasible allocations (without the EF1 requirement) are sampled uniformly, their exact number is
   \[
   T_t=2t!+\sum_{\substack{i,j\geq1\\i+j\leq t}}\frac{t!}{(t-i-j)!}\,\left\{\begin{matrix}t\\i\end{matrix}\right\}\left\{\begin{matrix}t\\j\end{matrix}\right\},
   \]
   where the braced quantities are Stirling numbers of the second kind. Consequently, the exact fraction satisfying EF1 is \(2t!/T_t\), which decays at least as fast as \(\exp(-t\log t+O(t))\) along odd \(t\).

For the formula in (2), set \(m=a+b\). If \(n>m\), put \(F_n(a,b)=n!/(n-m)!\). Otherwise write \(m=nh+r\), \(h\geq1\), \(0\leq r<n\), and use
\[
F_n(a,b)=\frac{a!b!}{(h!)^{n-r}((h+1)!)^r}
\sum_{j=0}^{n}\ \sum_{u=0}^{r}
\mathbf1_{\{a=jh+u\}}\binom{n}{j}\binom{j}{u}\binom{n-j}{r-u}.
\]
For any positive integer \(x\), define
\[
D_n(x)=\begin{cases}
0,&x<n,\\
\displaystyle\binom{n}{e}\frac{x!}{(d!)^{n-e}((d+1)!)^e},&x=nd+e,\ d\geq1,\ 0\leq e<n.
\end{cases}
\]
A binomial coefficient with invalid lower index is interpreted as zero. The formula also applies at \(n=1\), and the \(n>m\) case allows empty agent bundles.

## Assumptions and scope

The graph has one vertex per good, and two goods conflict exactly when their vertices lie in different multipartite parts. Goods and agents are labeled; agents have the same nonnegative unit-additive valuation; no per-agent capacity constraints are imposed. The number of parts, all part sizes, and the number of agents are arbitrary positive integers. The probability in (3) is uniform **over maximal feasible allocations** of labeled goods to labeled agents, allowing unassigned goods; it is not a distribution generated by an online mechanism.

For identical unit values, EF1 is equivalent to \(\max_i|A_i|-\min_i|A_i|\leq1\). This equivalence includes empty bundles, because removing one good from an envied nonempty bundle decreases its value by exactly one.

## Proof

**Structural lemma.** In a complete multipartite graph, each nonempty independent set lies in exactly one part. If a part contains an unassigned good, it contains no assigned good at all: otherwise the unassigned good could be added to the agent holding an assigned good from that part. If some part is unassigned, all \(n\) agents must hold a nonempty bundle, since an empty agent could receive an unassigned good. Conversely, any allocation that fully distributes each selected part among disjoint agent bundles, uses every agent whenever it leaves any part unassigned, and does not mix different parts in a bundle, is maximal. Indeed each unassigned good is adjacent to a good in every agent's bundle.

**Constructive existence.** Let the part sizes in nonincreasing order be \(a_1\geq\cdots\geq a_s\). If \(m\leq n\), give each good to a distinct agent and leave the other agents empty. This is complete, feasible, and EF1. If \(m>n\) and \(a_1\geq n\), distribute all \(a_1\) goods of the first part among all \(n\) agents in sizes \(\lfloor a_1/n\rfloor\) and \(\lceil a_1/n\rceil\), leaving the other parts entirely unassigned. Every bundle is nonempty, and the structural lemma implies maximality.

It remains to assume \(m>n\) and \(a_1<n\). Select the smallest prefix of parts with total \(S\geq n\), and let \(c\) be the size of its final part. The preceding total is less than \(n\), so \(n\leq S\leq n+c-1<2n\). Split the selected goods into \(S-n\) disjoint **within-part pairs** and \(2n-S\) singletons; make these \(n\) pieces the agents' bundles. Such pairs exist: their maximum available number is \(\sum_{i\text{ selected}}\lfloor a_i/2\rfloor\), at least \(\lfloor a_1/2\rfloor+\lfloor c/2\rfloor\geq c-1\geq S-n\). Select any \(S-n\) pairs and make all other goods singleton pieces. All bundles have size one or two, so they satisfy EF1. No good of a selected part remains unassigned, every agent has a nonempty bundle, and every unselected part is wholly unassigned. The structural lemma gives maximality. Sorting plus these operations has the claimed complexity.

**Exact bipartite enumeration.** The structural lemma reduces any maximal EF1 allocation of \(K_{a,b}\) to three mutually exclusive situations: (I) all goods allocated, (II) all \(a\) goods in the first part allocated and the second part wholly unallocated, or (III) the reverse. In (I), if \(n\leq m\), exactly \(r\) agent bundles have size \(h+1\) and the other \(n-r\) have size \(h\). Let \(j\) agents be assigned to the first part, of whom \(u\) have size \(h+1\). The first part can contain exactly \(a=jh+u\) goods. Choose the \(j\) agents, the \(u\) larger first-part bundles, and the \(r-u\) larger second-part bundles in \(\binom nj\binom ju\binom{n-j}{r-u}\) ways, and assign labeled goods to these prescribed nonempty sizes in \(a!b!/((h!)^{n-r}((h+1)!)^r)\) ways. Summing yields \(F_n(a,b)\). If \(n>m\), EF1 requires each allocated bundle to be a singleton, so the full count is the number of injections of \(m\) labeled goods into \(n\) agents: \(n!/(n-m)!\). In (II), maximality requires all agents nonempty. If \(a<n\), this is impossible; otherwise the balanced sizes of a surjective assignment number \(D_n(a)\). Similarly, (III) gives \(D_n(b)\). This proves the formula. Since any nonfull maximal allocation discards one entire part, the maximal possible number of assigned goods has the stated dichotomy. Existence already proved ensures at least one nonfull option when \(F_n=0\).

**Odd balanced bipartite bottleneck.** Put \(a=b=n=t\), with \(t\geq3\) odd. If all \(2t\) goods were assigned in EF1 bundles, each of the \(t\) bundles would have exactly two goods. No bundle could mix the sides, but an odd-sized side cannot be partitioned into pairs. Therefore \(F_t(t,t)=0\). A nonfull maximal EF1 allocation must assign one entire side among all \(t\) agents with singleton bundles; each side has \(t!\) bijections. Hence there are exactly \(2t!\) fair maximal allocations, each assigning precisely \(t\) goods.

To count all maximal feasible allocations without requiring EF1, the nonfull ones are still exactly the \(2t!\) side-bijections, because maximality forces all agents nonempty when one entire side is unassigned. In a full allocation, suppose exactly \(i\geq1\) agent labels occur on the first side and \(j\geq1\) on the second, with \(i+j\leq t\). Choose the disjoint label sets, and surject each side's \(t\) labeled goods onto its selected labels. This gives
\[
\binom ti\binom{t-i}{j}\,i!\left\{\begin{matrix}t\\i\end{matrix}\right\}\,j!\left\{\begin{matrix}t\\j\end{matrix}\right\}
=\frac{t!}{(t-i-j)!}\left\{\begin{matrix}t\\i\end{matrix}\right\}\left\{\begin{matrix}t\\j\end{matrix}\right\}.
\]
Summing proves \(T_t\). Write \(t=2z+1\). Keeping only the summand \(i=z\), \(j=z+1\), we have
\[
\frac{2t!}{T_t}\leq \frac{2}{\left\{\begin{matrix}t\\z\end{matrix}\right\}\left\{\begin{matrix}t\\z+1\end{matrix}\right\}}
\leq \frac{6\,4^z z!(z-1)!}{((2z+1)!)^2}.
\]
The second inequality counts, respectively, partitions with one triple and \(z-1\) pairs, and partitions with one singleton and \(z\) pairs. Stirling's factorial estimates imply the claimed \(\exp(-t\log t+O(t))\) upper bound. The probability claim is about maximal allocations, not arbitrary proper allocations.

## Relationship to prior work

Equbal et al. (2026) study maximal EF1 under conflict constraints, prove the two-agent monotone-valuation result on arbitrary graphs, prove a unit-valuation existence result for trees for any number of agents, and explicitly identify minimizing unallocated items as a research direction. Their results motivate the present complete-multipartite restriction, but the cited full text does not state the construction, exact labeled bipartite counts, or odd-family scarcity law above.

Yan and Wang (2012), and Nakprasit and Nakprasit (2015), establish equitable **complete** coloring theory for complete multipartite graphs. In particular, the impossibility of complete equitable coloring in certain odd complete bipartite cases is already known and is **not** claimed here as a new standalone fact. The additional assertions here concern allocation-level maximality with unassigned goods, constructive existence for arbitrary agent numbers, exact counts, optimal retention when complete EF1 is impossible, and the probability among all maximal feasible allocations. Earlier equitable-coloring theory supplies context and does not, by itself, enumerate these maximal partial assignments.

## Limitations

Only identical unit-additive nonnegative valuations and complete multipartite conflict graphs are covered; the result does not establish maximal EF1 for all graphs, even for unit values. The welfare objective counts assigned goods, rather than summing heterogeneous values. The probability law assumes the uniform distribution on all maximal feasible allocations and makes no assertion about a particular allocation mechanism. Some complete-coloring feasibility phenomena used in the boundary example were previously known. The count formula treats agents and goods as labeled. A separate independent scientific validation has not been conducted.
