The general proof is the four-weight-band majority transition analysis in RESULT.md. No numerical test is used to infer a universal case. The C++ program directly updates vertices and tests all binary initial configurations for each graph parameter from 3 through 10; the Python program instead uses matched-pair permutation classes for parameters 3 through 26, with exact integer class multiplicities. Both independently reconstruct the same joint first-entry/population formulas. Their outputs appear in `exhaustive.out` and `pair_classes.out`. The independent implementations and logs were replayed against the final local package, but these constitute computational checks, not independent scientific auditing.

The source comparison inspected the full text of arXiv:1508.03519v1 and the full accessible article by Agur--Fraenkel--Klein; the 1980 Goles--Olivos paper was not available in full text. The first verified day-specific public methodological source is the August 14, 2015 original arXiv version; the 1980 and 1988 publications have earlier year-level bibliographic evidence and are cited as such, without inventing a first-posted day. Omitted parameter regimes include asynchronous, probabilistic, and altered-neighborhood rules.
