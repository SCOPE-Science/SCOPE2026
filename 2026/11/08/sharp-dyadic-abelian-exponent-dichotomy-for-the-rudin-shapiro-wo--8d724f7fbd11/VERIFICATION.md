# Reproducibility and verification

Run `python3 verify.py` in the same directory as `CERTIFICATE.json` to reproduce the word-language closure, all exact rational obstructions, direct finite checks, and explicit witnesses. The script uses only the Python standard library; no network, solver library, or hidden file is needed.

The certificate is for the entire infinite word: the four-letter factor set comes from seven substitutions and is shown exactly closed under the six-factor substitution operation. For any later substitution stage, every six-letter factor lies within the image of a six-letter factor at the previous stage. This justifies replacing infinitely many positions by 36 sign patterns.

The analytical dyadic decomposition reduces the two required absence statements to 288 integer-affine one-variable systems. Each candidate solution is checked using exact fractions. In the four groups of 72 cases, every system has an explicit nonzero constant equation or incompatible exact roots. Those category counts are listed in `CERTIFICATE.json` and regenerated by the checker.

The direct comparison of 495,567 finite windows at periods \(1,2,4,\ldots,512\) is additional testing only. It does not establish absence at unbounded positions or scales. No claims are made for non-dyadic periods or independently validated provenance.
