# Reproducible finite checks and proof boundary

Run `python3 verify.py` with Python 3 standard library. The program builds two graph representations (the full admissible overlap graph and its claimed retained-edge subgraph), checks exact cardinalities and degree balances against Fibonacci numbers, tests reachability in both directions, explicitly extracts Euler circuits, and checks the cyclic substrings generated by those circuits. These tests run for orders \(3\) through \(16\). It separately enumerates circular binary words for orders \(4\) and \(5\), checking every word with the no-triple property and pairwise distinct windows against the claimed capacity and common optimum window set.

The proof for all orders is the degree-imbalance lower bound on deleted edges, followed by a forced balanced deletion, explicit connectivity via alternating extensions, and equality-rigidity. Finite checking is diagnostic, not a substitute for those arguments. No independent mathematical audit has been performed.
