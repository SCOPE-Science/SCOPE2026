# Scientific comparison and self-review

## Correctness: PASS
The exact full-domain enumeration over all \(256\) binary tensors produces rank shells of sizes \(1,27,162,66\), independently agreeing with Bremner–Stavrou (2011), Table 3. The nontrivial Walsh table is reconstructed by both direct integer character sums and an independent fast Hadamard transform; the script replays successfully. All five analytic spectral expressions are checked for all positive real exponents by monotonicity and strict concavity, with the sharp second-row root \(2^\alpha+3^\alpha=5/2\). The endpoint Gram rank is \(201\). The enumeration is exhaustive for the specified finite domain, not an unbounded experiment.

Searches of published mathematical records found no direct matching claim, although incomplete indexing cannot establish novelty. The 2026 paper's broader rank-one theorem is a substantive antecedent and creates residual risk that an unlocated application already derives the powered-distance result.

## Mathematical value: PASS
The tensor-rank metric on the smallest non-matrix trilinear tensor space is a canonical test case for metric negative type beyond distance-regular matrix-rank graphs. Its exact allowable exponent and the unexpectedly smaller endpoint Euclidean dimension are natural metric invariants, not arbitrarily chosen parameter slices. The result directly determines when the powered distance is a valid squared Euclidean metric. It does not assert a theorem for larger tensor formats.
