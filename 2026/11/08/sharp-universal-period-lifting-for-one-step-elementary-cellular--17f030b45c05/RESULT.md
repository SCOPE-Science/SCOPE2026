# Sharp universal period lifting for one-step elementary cellular automata

## Finding

Let \(r\in\{0,\ldots,255\}\) denote a Wolfram elementary binary radius-one cellular automaton, and let \(F_r\) be its one-step map on bi-infinite binary configurations. For an integer \(n\ge1\), call \(y\in\{0,1\}^n\) *admissible periodic output* when the bi-infinite repetition \(y^{\mathbb Z}\) belongs to \(F_r(\{0,1\}^{\mathbb Z})\). Define \(m(r)\) as the least positive integer \(m\) such that, for every \(n\ge1\) and every admissible periodic output \(y\) of length \(n\), an input periodic with period dividing \(mn\) maps to \(y^{\mathbb Z}\).

The exact distribution for all 256 rules is

\[
\#\{r:m(r)=1\}=156,\quad\#\{r:m(r)=2\}=82,\quad
\#\{r:m(r)=4\}=6,\quad\#\{r:m(r)=6\}=12.
\]

No other values occur. The six rules with \(m(r)=4\) are \(90,94,122,133,161,165\). The twelve with \(m(r)=6\) are \(22,30,86,104,106,120,135,149,151,169,225,233\). The complete rule-by-rule assignment is in `classification.json`.

Consequently, **12 is the smallest single multiplier** \(M\) such that, for every elementary rule, every \(n\), and every admissible periodic length-\(n\) output, there exists an input of period dividing \(Mn\) producing that output. Rule 90 forces \(4\mid M\), and Rule 30 forces \(6\mid M\).

## Assumptions and scope

The alphabet is \(\{0,1\}\); configurations are indexed by \(\mathbb Z\). For a neighborhood \((a,b,c)\), the rule output is the bit of \(r\) at index \(4a+2b+c\). One simultaneous update, not iteration, is considered. A word of length \(n\) need not have least period \(n\); saying its input has period dividing \(mn\) is therefore intentional. The assertion concerns *attainable* bi-infinite periodic outputs, not arbitrary periodic words for nonsurjective rules.

For each bit \(b\), put a directed edge labeled \(b\) from vertex \((a,c)\) to \((c,d)\) when the rule sends the three-bit neighborhood \((a,c,d)\) to \(b\). The four vertices are \(00,01,10,11\). Let \(R_b\) be the Boolean adjacency relation of the edges labeled \(b\), and for \(w=b_1\cdots b_n\), let \(R_w=R_{b_1}\cdots R_{b_n}\), using Boolean relation composition.

## Proof

**Periodic-output lemma.** For every \(w\in\{0,1\}^n\), the point \(w^{\mathbb Z}\) is in the image of \(F_r\) if and only if the four-vertex graph of \(R_w\) has a directed cycle. Moreover, a preimage of period dividing \(mn\) exists precisely when \(R_w^m\) has a nonzero diagonal entry. Indeed, a path labeled \(w\) records a consistent length-\(n+2\) predecessor block. Repeating this path according to a closed walk in \(R_w\) yields a periodic predecessor. Conversely, a bi-infinite predecessor of \(w^{\mathbb Z}\) yields a bi-infinite walk in the finite relation graph; its bi-infinite walk contains a directed cycle. A period-\(mn\) predecessor yields a closed path of exactly \(m\) copies of \(w\), and the converse follows by concatenation.

**Universal bound.** Every directed cycle in a four-vertex directed graph contains a simple cycle of length \(\ell\in\{1,2,3,4\}\). Since each possible \(\ell\) divides \(12\), the relation \(R_w^{12}\) has a diagonal entry for every admissible periodic \(w\). Thus \(m(r)\le12\) for all \(r\).

**Sharpness across rules.** Three explicit relations, with ordered vertices \(00,01,10,11\), suffice. For Rule 90 and \(w=1\), the only relation edges are \(00\to01\), \(01\to11\), \(11\to10\), \(10\to00\): a single four-cycle. Every common multiplier must therefore be divisible by \(4\). For Rule 30 and \(w=1\), the edges are \(00\to01\), \(01\to10\), \(01\to11\), \(10\to00\); its only directed cycle has length three. For Rule 30 and \(w=011\), the edges are \(00\to10\), \(00\to11\), \(10\to00\), \(11\to01\); its sole directed cycle has length two. A common multiplier must be divisible by both \(2\) and \(3\), hence by \(6\). Together with Rule 90 this forces a multiple of \(12\), proving optimality of the universal bound.

**Exact per-rule classification.** For fixed \(r\), define \(\mathcal R_r\) to be the finite monoid of Boolean relations generated by \(R_0,R_1\), including the identity. Each relation is a four-by-four zero-one matrix, so \(|\mathcal R_r|\le 2^{16}\). Breadth-first search from the identity, repeatedly multiplying on the right by \(R_0,R_1\), exhausts \(\mathcal R_r\). For each \(T\in\mathcal R_r\) containing a directed cycle and each \(m=1,\ldots,12\), the test \(\operatorname{diag}(T^m)\ne0\) is an exact integer Boolean computation. The least \(m\) passing this test for every such \(T\) is \(m(r)\) by the periodic-output lemma. Running this finite exhaustive procedure for every \(r=0,\ldots,255\) gives exactly the four class sizes above and the complete assignment in `classification.json`. Two independently implemented, self-contained procedures `verify.py` (matrix tuples) and `verify_bits.py` (bit-packed Boolean relations) reproduce the classification. Their loops terminate because new relations can be added only from a finite \(2^{16}\)-element universe. No bound on output period \(n\) is imposed; each possible \(R_w\) is visited regardless of word length.

## Verification

Run `python3 verify.py` and `python3 verify_bits.py` from this directory using the Python standard library. Both scripts independently enumerate all 256 relation monoids, test exact Boolean powers, and check the class counts and exceptional-rule lists. The first script additionally directly enumerates all finite input rings of sizes \(n,2n,3n,4n\) for \(n=1,2,3\), cross-checking the graph criterion for all rules and outputs. It writes `classification.json` deterministically, which should match the packaged table. Re-run from extracted copies of the files, not a different working directory or another version.

The direct finite ring checks are auxiliary. The infinite quantifier over \(n\) is handled by the exhaustive finite relation-monoid argument, not by extrapolation from short periods.

## Relationship to prior work

Wolfram (1983) introduced and extensively analyzed the 256 elementary rules. Mariot and Leporati (2015) study spatial periods of preimages for linear/bipermutive cellular automata and give a \(q^{2r}\) period-multiplier bound for a chosen periodic output in the bipermutive case. Mariot, Leporati, Dennunzio and Formenti (2017) introduce the labeled de Bruijn closure graph and compute preimage-period multiplicities for chosen periodic outputs of surjective cellular automata. Salo (2018) investigates periodic-preimage obstructions in regularity questions for elementary rules. The present claim is a **single minimal common multiplier for every admissible periodic output of each rule**, calculated simultaneously for all 256 rules, including nonsurjective cases, and an exact optimal global common multiplier. It does not claim the de Bruijn closure-graph technique as new.

## Limitations

This is a computer-assisted finite classification with a fully supplied exhaustive deterministic verification program. It is not an independent audit or a classification of *all* preimage periods of each individual output. The rule-by-rule classification is tied to binary radius-one cellular automata; the universal four-state argument yields a bound for this neighborhood, not for higher radii. Earlier specialized or unindexed equivalence tables might contain the same global multiplier distribution. All output claims refer to one step and bi-infinite spatial periodicity.
