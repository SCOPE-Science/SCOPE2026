# Reproducibility and actual checks

Extract `verify.py` and `verify_output.txt` from the same complete package. Run `python3 verify.py` using Python 3.10+ and the standard library only. The provided output was generated by executing that script and ends in `ALL_VERIFY_OK`.

The code constructs nonempty face posets of the tetrahedron and its boundary, enumerates each Hasse incidence and all disjoint acyclic incidence matchings, constructs the pure downward closures of the 256 maximum matchings in each case, and asserts all four known full and pure face vectors. For all 24 tetrahedral vertex permutations and all 24 compositions with the boundary ghost involution, it computes exact simplicial-chain Lefschetz traces with orientation signs. Each nonidentity representative is cross-checked against an independently structured enumeration of invariant incidence-orbit unions. It verifies the ghost's commuting involution property, the character values on all ten classes, the \(45/36\) split and irreducible character inner products.

The calculation proves the finite signed trace sums. Conversion to homology characters requires the independently identified published theorem that the reduced homology of both pure complexes is concentrated in degree three with rank 81 (Scoville, arXiv:2604.18172, Theorem 22). The code is not a proof of that published infinite-dimensional statement; the present claim concerns only the two finite tetrahedral complexes. No third-party data or packages are needed to reproduce these trace values, and no outside audit has been completed.
