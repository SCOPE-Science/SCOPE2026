# Scientific review

**Correctness — PASS.** The closed-neighborhood identities give an exhaustive disjoint classification by the number of empty columns and the presence of double columns. For ordinary location, at most one empty column is permissible; for solid location, the exact incomparability obstruction excludes only two singleton profiles and permits one special near-full profile; for self location, exactly two codewords per clique suffice and are necessary. Weight enumeration and single-deletion minimality arguments establish all six polynomials for every integer \(n\ge4\). Direct exhaustive verification using the literal definitions covered \(87{,}296\) labelled subsets for \(4\le n\le8\). The unbounded result relies on the written proof rather than finite testing.

A previously available crown-graph open-location enumeration concerns the complementary graph with a different nonemptiness condition and does not directly imply these formulas.
