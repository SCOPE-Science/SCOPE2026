For the complete prisms \(K_2\square K_n\) with \(n\ge4\), explicit polynomials count every ordinary, solid and self-locating-dominating code and every inclusion-minimal code of each type. In particular, solid-locating-dominating codes have exactly \(n\) inclusion-minimal configurations of size \(2n-2\), while every inclusion-minimal self-locating-dominating code has size \(n\).
