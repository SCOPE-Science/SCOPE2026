The finite checker requires Python 3 and the standard library. Run `python3 checker.py`. The script checks the rank-two atomic-pair-type signatures for all component-size partitions through thirty points; separately enumerates all 49,023 labelled idempotent unary functions on sizes one through eight; and verifies both the total labelled-component formula and all twelve classwise exponential generating functions through twelve points. The mathematical proof uses two-round back-and-forth for all finite and infinite models, so no finite computation is offered as a proof of the infinite assertion.
