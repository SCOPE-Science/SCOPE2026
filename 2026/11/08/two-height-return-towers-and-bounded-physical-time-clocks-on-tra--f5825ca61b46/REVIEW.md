# Scientific review: two-height translated-cone return towers

## Correctness — PASS

The theorem is stated for the explicit half-open four-interval exchange with \(n\ge1\) and strictly positive \(L,\eta\), and separately identifies the regular embedded-cap interpretation. The long corridor visits exactly \(4n\) outside indices before returning because \(\gcd(2n-1,4n)=1\). The short corridor returns in two steps. These algebraic facts yield the exact two-height roof and the full-measure tower partition. The return map is rotation by \(L\pmod{L+\eta}\); counting its wraps gives the exact cumulative-time coboundary identity and the strict uniform deviation bound. Uniform base sampling makes the wrap count Bernoulli at each fixed horizon, producing the claimed mean and variance with no independence assumption between excursions. Rational rotations give the least original-time period because every original-map return to the same base point must complete an integer number of induced returns. Parameters realizing each reduced rational ratio are explicit. An exact-arithmetic independent-map checker passed 54 parameter cases, 3,456 sampled first-return points, 700 least-period tests, and 180 two-atom moment checks; only the analytic proof establishes infinitely many cases.

## Originality — PASS within checked sources

The originating full-text preprint (arXiv:2312.17412v1, Section 3.2) establishes the four-interval exchange and its induced two-IET, and classifies rational versus irrational orbit types; these are expressly attributed, not represented as new. The additional claim is the **complete roof-height partition in the original clock**, its exact finite-horizon two-atom timing distribution, the bounded physical-clock variance for all real parameters and all horizons, and the full realizable original-time least-period spectrum. The source describes no such complete quantitative clock statement. Classical balanced Sturmian rotation coding and general inducing theorems imply the abstract balance *once the cap-specific roof is independently determined*, and are credited. This is a narrow explicit dynamical invariant rather than a claim to invent a new method. Published-record searches for translated-cone roof laws, cap periods, rational rotation return towers, and clock discrepancy found no equivalent. The closest searchable records involve either a distinct rotated-odometer model or an unrelated IET induction problem. Residual risk: these formulas are elementary consequences of the previously explicit interval exchange and could be implicit in unindexed literature or in an alternative tower formulation; independent publication-priority assessment is not completed.

## Mathematical value — PASS

The source's rational/irrational dichotomy does not tell how many **original planar-map iterates** a cap orbit requires to return, nor how accurately induced return time tracks physical time. The theorem determines every return duration, all possible least periods across a natural geometric family, and an exact distribution at every return horizon. Its bounded variance, independent of the number of excursions, is a substantive quantitative rigidity statement separating the cap suspension from a renewal model with independent two-valued return times (whose variance would grow linearly). These are natural observables needed to compare geometric orbit periods and physical-time statistics across caps, not arbitrary parameter slices. The result is self-contained but does not claim extension to nonembedded planar points or degenerate parameters.
