# Complete fifth-order Fourier rank incidence on the twelve-cycle
## Finding
Let \(F_{12}=(\zeta^{rc})_{r,c\in\mathbb Z_{12}}\) with \(\zeta=e^{2\pi i/12}\), and independently select any five distinct rows \(R\) and five distinct columns \(C\). The rank distribution of the resulting \(5\times5\) submatrix is exactly
\[
\begin{array}{c|rrr}
\operatorname{rank}F_{12}[R,C]&3&4&5\\\hline
\#(R,C)&3888&109008&514368.
\end{array}
\]
No restriction has rank below three. In particular, exactly \(3888\) masks lose **two** independent Fourier-coordinate directions, rather than only one. Under independent translations of row and column index sets, the complete \(66\times66\) incidence array has rank counts \(27,757,3572\), and its values are supplied in `census12.json`. Exactly \(24\) five-element row index sets yield full-spark five-row frames.

## Assumptions and scope
All index sets are *unordered* subsets of \(\mathbb Z_{12}\) of cardinality five. We count an ordered pair \((R,C)\) once: the row/column roles are distinguished, but reordering the same set does not create a new pair. Ranks are over \(\mathbb C\), and multiplying the complete matrix by \(12^{-1/2}\) does not change them. This is a finite order-twelve statement, not a formula for other Fourier orders. The attached rank array orders the translation representatives lexicographically.

## Proof
**Orbit reduction.** For \(a,b\in\mathbb Z_{12}\), translating the row set by \(a\) multiplies each selected column by a nonzero power of \(\zeta\), and translating the column set by \(b\) multiplies each selected row by a nonzero power. Neither changes rank. The stabilizer of a five-element subset under cyclic translations has cardinality dividing both \(5\) and \(12\): its orbits inside the subset are all of its own cardinality. Hence the stabilizer is trivial, so there are exactly \(\binom{12}{5}/12=66\) representatives. Every row-column representative pair stands for exactly \(12^2=144\) distinct pairs.

**Exact cyclotomic criterion.** The primitive twelfth root \(\zeta\) has minimal polynomial \(\Phi_{12}(z)=z^4-z^2+1\). For any equally sized index sets \(I,J\) of size \(k\le5\), expand the determinant symbolically:
\[
D_{I,J}(z)=\sum_{\pi\in S_k}\operatorname{sgn}(\pi)
 z^{\sum_{h=1}^k i_hj_{\pi(h)}}.
\]
Reduce each exponent modulo twelve and each resulting monomial using \(z^4=z^2-1\). The computed four integer coefficients of the unique reduced representative in \(\mathbb Z[z]/(\Phi_{12})\) all vanish if and only if \(D_{I,J}(\zeta)=0\). This is exact: the kernel of substitution \(\mathbb Q[z]\to\mathbb Q(\zeta)\) is generated by the irreducible polynomial \(\Phi_{12}\).

**Rank test.** For each of the \(66^2\) pairs, first inspect its exact fifth-order determinant. If zero, inspect every fourth-order minor; if all are zero, inspect third-order minors, and so on. By the standard rank-minor criterion, this procedure determines its complex rank without numerical approximation. The attached `verify_census12.py` enumerates representatives and computes every required determinant directly from the displayed alternating-sum formula. It obtains \(27\) rank-three pairs, \(757\) rank-four pairs, and \(3572\) rank-five pairs. Multiplying by \(144\) proves the asserted \(3888,109008,514368\) counts and the absence of smaller ranks. The file `census12.json` is the complete reproducible array of representatives and ranks. The same certificate finds precisely two five-row translation classes with all \(66\) fifth-order minors nonzero; these give \(2\cdot12=24\) full-spark row sets.

**An explicit two-dimensional defect.** For example, let \(R=\{0,1,2,6,7\}\) and \(C=\{0,2,4,6,8\}\). Since every column index is even, the rows indexed by \(0,6\) agree, as do the rows indexed by \(1,7\). The three distinct rows at indices \(0,1,2\) are independent as evaluations of powers of a primitive sixth root at five distinct sixth roots. Thus this restriction has rank three, illustrating the double defect counted by the census.

## Verification
Run `python verify_census12.py` in the directory containing the companion file `census12.json`. The verifier recomputes the complete \(66\times66\) table using exact integer coefficients in \(\mathbb Z[z]/(z^4-z^2+1)\), checks all reported rank counts, and checks symmetry of the incidence array. As a separate corroboration, it computes each representative rank using Gaussian elimination at a primitive twelfth root modulo the prime \(1009\); the two computations agree on all \(4356\) pairs. **Only the cyclotomic calculation certifies the complex ranks**; finite-field agreement alone would not do so. The program regenerates the attached JSON and prints its SHA-256 digest, permitting a byte-for-byte artifact comparison. On the packaged run the script completed without assertion failure.

## Relationship to prior work
The possibility of singular Fourier minors at composite orders is classical. Delvaux and Van Barel develop low-rank submatrix constructions and extremal Fourier-support bounds, not this fifth-order incidence matrix. Cabrelli, Molter and Negreira (arXiv:2404.02229) characterize recovery via principal minors and discuss Fourier matrices, while Caragea and Lee (arXiv:2409.09793) establish existence results for singular principal minors at non-square-free orders. Those statements do not determine the rank distribution over *all independent row/column pairs* at order twelve.

A previously published order-twelve full-spark classification identifies which row sets have at least one singular maximal minor; the present table refines this to **every** five-row/five-column pair and distinguishes rank-three from rank-four failures. An exact-support uncertainty profile at order twelve records possible support cardinalities, not the positional rank-incidence array. An accessible general-audience Fourier-minor census tabulates aggregate zero minors across all sizes at order twelve, not the complete fifth-order rank classes. Its aggregate vanishing statement is credited rather than represented as new.

## Limitations
This is an exhaustive finite classification, not a general formula at arbitrary group order or a lower bound for noisy singular values. The symbolic certificate is the proof of the finite incidence counts, and therefore requires running the supplied ordinary Python program; the printed table alone is not a proof. Source searches cannot exclude unpublished, unindexed, or differently encoded earlier exact rank tables. In particular, the underlying data behind earlier aggregate zero-minor counts could contain additional unreported refinements. No independent mathematical audit is claimed.
