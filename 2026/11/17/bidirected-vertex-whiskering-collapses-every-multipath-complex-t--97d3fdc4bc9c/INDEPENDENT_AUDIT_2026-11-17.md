# Independent mathematical audit

## correctness

PASS

For any finite loopless digraph D on n>=1 vertices (antiparallel arcs allowed), each legal nonempty core arrow set R is a union of directed vertex-simple paths and so has an endpoint p incident to exactly one core arrow. Exactly one compatible pendant orientation at p can be toggled; the other is forbidden by occupied in/out slot. The toggle preserves indegree/outdegree<=1 and acyclicity because it attaches a distinct leaf. Fibers processed in decreasing number of core arrows and decreasing face size make each lower member a genuine free face with unique remaining upper coface; after all nonempty core fibers disappear, precisely the join of n disjoint S^0 pendant pairs remains. Includes n=1 and edgeless cores. Homology sign follows from the invariant inclusion of the surviving join: swapping two S^0 factors acts by -1 on top reduced homology, even though chosen elementary collapses are not equivariant. Separate independent brute enumeration and free-face tests cover four small cores, not the infinite result.

## originality

PASS

The all-core, all-directions vertex whiskering collapse with natural vertex-permutation character is not entailed by the inspected specialized subdivided-forest and path/polygon theorems. The proof is a new local free-endpoint argument over arbitrary directed core paths and cycles. Best-of-knowledge, not a declaration of global priority.

## value

PASS

A uniform explicit simple-homotopy stabilization valid for arbitrary directed core graphs, independent of branching, directed cycles, and bidirected edges, is a useful structural operation; it additionally determines integral homology and a nontrivial natural symmetry character rather than an isolated computation.
