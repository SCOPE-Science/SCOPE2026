# Reproducibility
Run `python verify.py` using Python 3.10 or later. This standalone program uses only the Python standard library. It independently enumerates all fifteen axis-pair dot products, checks first-contact multiplicities and width identities, and checks the local spherical-lens coefficient by decreasing deficits. The exact analytic argument is provided in `RESULT.md`; these finite computations are supplementary and cannot certify all real heights or the infinite-dimensional historical novelty question.
