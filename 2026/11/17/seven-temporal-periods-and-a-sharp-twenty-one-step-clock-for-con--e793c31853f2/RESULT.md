# Seven temporal periods and a sharp twenty-one-step clock for Conway Life on the four-by-five torus

## Finding

For standard synchronous Conway Life (B3/S23) on the labelled periodic grid \(\mathbb Z/4\mathbb Z\times\mathbb Z/5\mathbb Z\), all \(2^{20}=1,048,576\) binary states have exactly \(461\) temporal attractor orbits. The set of attainable least temporal periods is exactly \(\{1,2,4,5,6,8,10}\). The first periodic-entry time is at most \(21\) synchronous updates, and this bound is sharp: precisely \(80\) initial states require all \(21\) updates. Under all \(80\) coordinate translations and independent horizontal and vertical reflections, the \(461\) temporal orbits form exactly \(23\) geometric classes.

The complete period and attraction-basin census is:

|---:|---:|---:|---:|
| 1 | 313 | 313 | 975232 |
| 2 | 32 | 64 | 46564 |
| 4 | 20 | 80 | 160 |
| 5 | 8 | 40 | 40 |
| 6 | 60 | 360 | 10000 |
| 8 | 20 | 160 | 7240 |
| 10 | 8 | 80 | 9340 |
| **Total** | **461** | **1,097** | **1,048,576** |

A pronounced distinction between the short odd clock and its doubled clock is exact: the \(8\) period-five attractors are isolated (their total basin is their \(40\) periodic states), whereas the \(8\) period-ten attractors have basins totalling \(9,340\) initial states. The all-dead equilibrium alone attracts \(884,500\) configurations.

## Assumptions and scope

A state is a binary function \(x:\mathbb Z/4\mathbb Z\times\mathbb Z/5\mathbb Z\longrightarrow\{0,1}\). Coordinates are ordered with the four-site coordinate first. The synchronous update \(F\) sets a dead cell to one if exactly three of its eight Moore neighbors are live, retains a live cell if it has two or three live neighbors, and sets the cell to zero otherwise. The eight offsets \(\{-1,0,1}^2\setminus\{(0,0)}\) determine eight *distinct* neighbors on this torus; no neighbor is counted twice. Every state is labelled: rotations, translations and reflections are not identified when counting temporal orbits or basins.

A temporal orbit is a directed cycle of the finite function \(F\), with its least period the number of distinct phases; one orbit is counted once irrespective of its number of phases. The first-entry time \(e(x)\) is the smallest nonnegative integer \(t\) for which \(F^t(x)\) is already periodic. An attraction basin contains every state whose eventual orbit is the given orbit, including its phases. Geometric classes refer *only* to equivalence of temporal orbits under the group generated by translations in each coordinate and independent coordinate reversals, of order \(4\cdot5\cdot2\cdot2=80\); there is no color-complement identification.

## Proof

The claim is a complete finite-state theorem with a self-contained exhaustive certificate, not an inference from sampled trajectories. Enumerate the state set by bit integers from \(0\) to \(2^{20}-1\), using bit \(5r+c\) for cell \((r,c)\). Both attached programs compute the full next-state function, once for **every** possible input integer, directly from the displayed B3/S23 definition.

The first program, `verify_paths.cpp`, performs deterministic forward-chain tracing from each as-yet-unclassified state. On encountering an element already on the current chain it records precisely one new simple cycle and its period; on reaching a classified state it connects the current chain to the known cycle. Reverse traversal of each chain gives each state's first-entry time and eventual orbit label. Thus all \(1,048,576\) states are assigned exactly once. Counting the disjoint cycles yields the seven period populations shown above; summing states by final cycle proves the basin populations.

The second program, `verify_topological.cpp`, *independently constructs* the next-state function using the explicit eight coordinate offsets, then uses incoming-degree pruning. Each repeatedly removed vertex is transient, and every remaining vertex lies on a directed cycle, since each vertex has one outgoing edge and all remaining indegrees are positive. It enumerates the residual simple cycles, assigns removed vertices in reverse pruning order, and independently recomputes every period, first-entry depth and basin population. Both programs agree exactly on all those quantities. In particular, the second checker records \(1,097\) cyclic states and \(1,047,479\) noncyclic states, summing to the complete state space.

For geometric classification, every transformation \((r,c)\mapsto(\epsilon r+a,\eta c+b)\) with \(\epsilon,\eta\in\{-1,1}\), \(a\in\mathbb Z/4\mathbb Z\), \(b\in\mathbb Z/5\mathbb Z\), preserves the Moore neighborhood and hence commutes with \(F\). The first checker groups temporal orbits by their images under all eighty transformations. The second checker calculates each orbit's temporal-orbit stabilizer and applies orbit-stabilizer and Burnside's lemma to check the resulting groups independently. Concrete witnesses provide additional direct local checks. The decimal state `7559`, whose four rows are `OOO.. / ..OO. / OOO.. / .....`, has least period five. The state `270732`, with rows `..OO. / ..OO. / ...O. / ...O.`, has least period ten. The state `38194`, with rows `.O..O / O..O. / O.O.. / O....`, has first periodic-entry time \(21\), ultimately entering a fixed state. Here `O` denotes one and `.` denotes zero; spaces and slashes separate rows only. These explicit configurations are not used to infer the universal counts: the exhaustive state-space decomposition supplies that proof.

## Verification

Compile separately with `g++ -std=c++17 -O2 verify_paths.cpp -o verify_paths` and `g++ -std=c++17 -O2 verify_topological.cpp -o verify_topological`, then run each executable. Their captured output files are supplied. The two programs have different next-state constructions, cycle-finding algorithms and geometric-class counting methods, while agreeing on every reported census. The total of all entry-time bins and the total of all basin populations separately equal \(2^{20}\). The output and source files are included in this package as complete reproducible data.

## Relationship to prior work

Wuensche's thesis develops exact finite-state attractor-basin methods and explicitly reports \(345\) basins for a different, \(4\times4\), toroidal Life system (Chapter 2, Figures 2.2--2.4); it does not give these \(4\times5\) populations. Reia and Kinouchi describe the same outer-totalistic B3/S23 local update and analyze large-lattice mean-field versus extinction behavior, not this complete finite rectangular configuration graph. The topological distinctions between toroidal and other finite boundaries are described by LifeWiki. Earlier exact transfer descriptions of fixed points on height-four tori imply the \(313\) fixed-point component here; that one component is not asserted as a new standalone result. The new scope is the **complete** temporal-period, transient-entry, basin and geometric classification, particularly the sharp \(21\)-step clock and isolated five-period waves versus attractive ten-period waves.

## Limitations

This theorem concerns the labelled \(4\times5\) torus only. It makes no asymptotic statement for other dimensions, no classification of arbitrary Life patterns on the infinite plane, and no claim of independent external validation. Although two different exact enumerators agree, undetected shared assumptions in the boundary convention are possible; the eight distinct Moore offsets are therefore specified explicitly. Complete historical priority against undocumented databases or unpublished configurations is not established. The reported geometric classification identifies only the specified eighty spatial automorphisms, never temporal phase rotations as extra group generators.
