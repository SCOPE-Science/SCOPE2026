A fixed barycentric point has constant weights on each rotation orbit of undirected edges, so rescaling orbit weights yields a PL identification with the distance-set simplicial complex. A triangle of selected edge-orbits occurs exactly when signed distances x,y,z in the symmetric step set obey x+y=z modulo n (repeated step values allowed), proving the sum-free equivalence. The assigned verifier enumerates all distance subsets for every integer n=3..21, constructs signed integer boundary matrices and computes exact Smith forms. An independent implementation separately rebuilt all these complexes, confirmed unit nonzero Smith factors for n<=20 and at n=21 factors 1^8 for boundary1 and 1^17,2 for boundary2. The n=21 9-vertex,27-edge,18-facet complex is connected; every edge appears twice and each vertex link is a connected six-cycle. Euler characteristic zero plus the orientation contradiction in the original verifier identifies a nonorientable closed surface, hence the Klein bottle. Torsion computation independently supports the orientation result. The sharpness claim is ONLY the exhausted finite interval, not all larger n.
