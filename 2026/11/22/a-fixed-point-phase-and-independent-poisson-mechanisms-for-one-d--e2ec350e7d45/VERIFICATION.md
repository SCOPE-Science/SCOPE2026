# Verification

Run `python3 verify.py` using Python 3 with only standard-library modules. Its independently constructed standardized-deletion sets test the statement \(L=A+B+2(C^++C^-+E)\), and per-fixed-point strata test the exact expectation using rational arithmetic, through all involutions of lengths one to eleven. Expected final output: `VERIFY_OK`. See `verification_output.txt` for the actual rerun and per-length counts.

The finite tests are not evidence of a limit theorem on their own. The proof additionally requires fixed-site/matching chord probabilities, vanishing overlapping connected clusters in each finite mixed factorial moment, moment determination of independent Poisson variables, and concentration of unrestricted involution fixed points. The verification script does not certify those analytic steps or independent peer review.
