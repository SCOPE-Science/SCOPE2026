# Reproducibility and limits

Run `python3 verify_stars.py` (standard library only) to check the numerical semigroup quotient criterion, explicit edge orientations, the sharp nonrepresentation obstruction, and independent finite-case existence by complete column-mask dynamic programming. Successful completion prints `VERIFY_OK`.

The proof for all integer parameters is in `RESULT.md`. No finite numerical experiment implies the unrestricted theorem; infinite sufficiency uses Gale--Ryser, and sharpness uses the Frobenius gap of the semigroup generated by \(k\) and \(k+1\). The construction and its test use explicit outgoing-edge groups of these two sizes. Independent mathematical validation has not been performed.
