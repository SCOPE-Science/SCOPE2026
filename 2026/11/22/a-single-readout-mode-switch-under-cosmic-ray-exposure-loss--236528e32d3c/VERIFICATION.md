# Reproduction and evidence limits

Run `python3 check.py` with the Python standard library. The program performs monotone bisection of each stationary equation, reconstructs the illustrative mode transition, checks the required mode ordering on both sides, and samples parameter pairs for diagnostic tests. On the provided package it reports 29,265 passed finite assertions and the example switch near \(1.0988848516722565\), with optimal durations near \(1.35858714882211\) and \(0.954820016525673\).

The complete theorem is an analytic statement for every positive real value satisfying the assumptions. Neither randomized parameter probes nor bisection output is an exhaustive proof. The proof is in `RESULT.md`; the code implements supplementary numerical checks. The independence of a future reviewer, historical priority, telescope-specific calibration, and clinical or field applicability have **not** been established. Full statistical modeling of cosmic-ray particle-track salvage and saturated detector wells is outside the claim.
