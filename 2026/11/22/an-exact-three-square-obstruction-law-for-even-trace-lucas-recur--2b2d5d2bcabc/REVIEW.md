# Scientific review

## Correctness — PASS

The all-index proof is self-contained once the classical Legendre three-square criterion and standard Lucas polynomial identities are stated. The polynomial expansion controls all odd indices exactly modulo eight. Companion doubling proves \(\nu_2(U_{2^s u})=\nu_2(P)+s-1\) and the odd-part unit \(a c_su\pmod8\), including the boundary \(s=1\). The density computation sums disjoint dyadic cylinders and proves an absolute \(O(\log(N+2))\) discrepancy. The checkable recurrence code provides independent finite corroboration; it is not the proof.

## Originality — PASS on inspected evidence

The closest source is Sobolewski (first public arXiv version 20 February 2022), Theorem 5.4 and Example 5.1. The theorem gives a general *shape* for obstruction indices, whereas Example 5.1 solves \((P,B)=(2,1)\). Here all positive even \(P\) and odd \(B\) are classified by explicit necessary-and-sufficient index congruences and exact densities. Latushkin–Ushakov (2012) addresses the standard Fibonacci and Lucas recurrences. Publicly indexed related results on Lucas-family Dold congruences do not entail this Legendre obstruction classification. Unindexed equivalent work, implicit coverage in broader identities, and partially read older primary sources remain material priority risks. This is a same-model, not independent, originality assessment.

## Mathematical value — PASS

The object is a classical two-parameter Lucas family, and deciding three-square representation of its values is a naturally motivated Diophantine question. The result replaces a general algorithmic description with complete uniform residue formulas and a phase diagram of five exact densities. It exhibits genuine changes as the two-adic order of the trace and the odd companion's residue vary, while controlling the counting discrepancy across the full infinite family.

## Limitations and prior work

The result does not count representations or cover odd traces/even companions. Its logarithmic discrepancy bound is not asserted to be optimal. Relevant literature: Sobolewski, arXiv:2202.09922 and DOI: 10.1007/s11139-023-00710-8; Latushkin–Ushakov, DOI: 10.1134/S0001434612050070. Full priority assessment is not independently validated.
