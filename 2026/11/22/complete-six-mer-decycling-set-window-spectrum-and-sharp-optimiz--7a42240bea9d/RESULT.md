# Complete six-mer decycling-set window spectrum and sharp optimizer symmetry

## Finding

Let \(D_6\) be the directed binary de Bruijn graph on the \(64\) length-six binary words. For each minimum decycling set \(M\subseteq V(D_6)\), let \(L(M)\) be the maximum number of vertices in a directed path of \(D_6\setminus M\). There are exactly \(68,288\) such labeled minimum sets, each of cardinality \(14\), and their complete distribution is:

| Remaining path (vertices) | Number of minimum decycling sets |
|---:|---:|
| 13 | 408 |
| 14 | 3,728 |
| 15 | 6,624 |
| 16 | 6,292 |
| 17 | 11,380 |
| 18 | 14,052 |
| 19 | 9,468 |
| 20 | 7,744 |

| 26 | 48 |
| **Total** | **68,288** |

Exactly \(408\) of these sets attain the sharp optimum \(L(M)=13\), while \(48\) attain \(L(M)=26\). Thus only \(408/68,288\) (approximately \(0.5975\%\)) of minimum-size binary six-mer selectors achieve the smallest possible worst-case uncovered run. Under the order-four action generated by bit complement and word reversal, the \(408\) optimal sets form exactly \(103\) classes: \(101\) four-element classes and \(2\) two-element classes. The two smaller classes are fixed by the combined reverse-complement operation, but not by reversal or complement individually.

## Assumptions and scope

- The alphabet is the *labeled* binary alphabet \(\{0,1\}\). The order is fixed at \(k=6\); no extrapolation to other orders or alphabet sizes is claimed.
- Vertices are the \(64\) six-bit strings, encoded as integers \(u\in\{0,\ldots,63\}\). The two outgoing edges from \(u\) go to \(2u\bmod64\) and \((2u\bmod64)+1\), respectively.
- A decycling set \(M\) deletes vertices, not edges; the residual graph is required to be acyclic. Its path length \(L(M)\) counts *vertices*, not edges. Identical sets are counted once; distinct bit labels are not identified under symmetry in the \(68,288\) total.
- For the final symmetry classification only, complementation takes every six-bit word to its bitwise complement and reversal reverses the order of its six bits. These operations act on sets of labels, not on a cyclic indexing of a long word.

## Proof

**Lower bound and exhaustive domain.** Left-cyclic rotation of any six-bit word is a directed edge of \(D_6\): shift the leading bit to the end. Its orbits are pairwise disjoint directed cycles, with sizes \(1,6,6,6,6,3,6,6,6,2,6,3,6,1\), accounting for all \(64\) vertices in exactly \(14\) orbits. Every decycling set meets each orbit; hence it has at least \(14\) members. Any decycling set of size \(14\) consists of exactly one chosen member per orbit. The witness below passes the explicit residual-DAG test, proving the bound is attained, so these transversals are *all* possible minimum decycling sets.

**Complete computation as a finite proof.** Enumerate the \(14\) rotation orbits, and choose one deleted vertex from each. The raw search comprises precisely \(181,398,528\) transversals (the product of the orbit sizes). In the supplied fast exact enumerator `verify_fast.cpp`, process orbits in descending size and maintain the induced directed graph on surviving vertices from the orbits already processed. If this partial induced graph contains a directed cycle, every extension also contains it, so that branch cannot be decycling and is pruned. Conversely, no pruned branch can contain a valid final decycling set. At every remaining leaf, topologically sort the full induced graph and evaluate longest-path lengths by dynamic programming on this DAG. This is an exhaustive classification of *all* transversals, not sampling and not a numerical extrapolation. It finds exactly \(68,288\) acyclic choices, with the histogram above. The witness of shortest surviving path, displayed with fixed-width binary codes, is

`000000 000100 001010 001100 001101 001110 010110 011110 011111 100100 101010 101110 110110 111111`.

Deleting these \(14\) vertices yields an acyclic graph with \(L=13\), as verified by the second checker. Both the sharp minimum \(13\) and maximum \(26\), as well as the previously reported count \(68,288\), agree with the published bounds and total in Marçais–DeBlasio–Kingsford, but the entire frequency distribution is a new object computed here.

**Symmetry computation.** Word complementation preserves directed edges, while word reversal maps each directed edge to an edge with opposite orientation. Thus both preserve decycling, the longest directed path length and minimum cardinality. Their commuting involutions give a group of order \(4\). The independent checker enumerates all \(408\) optimum masks and their four transforms and deduplicates these transforms into classes. It returns \(101\) classes of size \(4\) and exactly two of size \(2\). The two size-two orbit representatives, with the selected six-bit vertices encoded as bit positions \(0\) through \(63\), have hexadecimal membership masks `0x83f0001003300011` and `0x80c00cd000000cd1`. Each is fixed by reverse-complement and not by either generator separately. These are compact witnesses for the two exceptional symmetry types.

## Verification

The `verify_fast.cpp` program (C++17; compile with `g++ -std=c++17 -O3 verify_fast.cpp -o check_fast`) implements the orbit-by-orbit exhaustive search with Kahn topological sorting and longest-path dynamic programming; run `./check_fast`. The independent `verify_independent.py` uses recursive DFS for cycle detection and longest paths, and visits same-size rotation orbits in a different order; run `python3 verify_independent.py`. Both reproduce all \(14\) histogram entries and \(68,288\) total minimum decycling sets. The independent script also reproduces the \(408\) optimizers and \(101+2\) orbit partition. The machine-readable table is `SPECTRUM.tsv`; no external data files are required.

Exhaustivity follows from the necklace-cycle lower bound and complete one-choice-per-orbit recursion. Agreement with published totals and extrema is an additional consistency check, not substituted for the explicit search proof. The claim is finite at fixed order six; it does not purport to prove a uniform theorem for all orders.

## Relationship to prior work

Marçais, DeBlasio and Kingsford (first made public on arXiv on November 6, 2023; subsequently published in 2024) study minimum de Bruijn decycling sets and their use as context-free sequence-sketching selectors. Their Table 1 reports \(68,288\) binary six-mer minimum sets, while their Table 2 reports the exact minimum and maximum residual path lengths \(13\) and \(26\). Their Section 5.3 compares per-component *extrema*, not the full multiplicity of each path length over labeled sets or the symmetry classes of all global minimizers. The source software provides generic enumeration and longest-path tools; its documented `sketch_histo` command counts gaps between selected k-mers in input sequences, a different statistic. The new content here is the complete \(14\)-bin distribution and the count/symmetry classification of sharp minimizers, not the previously published population total, extrema, or generic algorithms.

## Limitations

This is an exact finite classification only at length six. The 2023 preprint and 2024 article have already enumerated the total number of optimum-cardinality sets and the range of window guarantees, so no originality is claimed for those two inputs. Their generic code can in principle be used to compute further statistics. A historical-priority risk remains if an unindexed supplement or archived dataset explicitly contains the same histogram or optimizer orbit classification. No efficiency improvement or biological performance gain of a particular selector is established here. Independent external mathematical audit has not been performed.
