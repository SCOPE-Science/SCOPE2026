Every minimum ordinary zero-forcing set of the binary hypercube \(Q_d\), for \(d\ge2\), selects exactly \(2^{d-2}\) vertices of each Hamming parity. As every cube edge changes parity, no optimal set can move even one token along an edge and remain optimal: the minimum token-sliding graph is completely frozen in every dimension \(d\ge2\), including the four-cube whose unrestricted exchange graph is known to be connected.
