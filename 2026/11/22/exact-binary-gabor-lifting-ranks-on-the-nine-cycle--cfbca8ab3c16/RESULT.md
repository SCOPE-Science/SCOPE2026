# Exact binary Gabor lifting ranks on the nine-cycle

## Finding
Let \(g=(g_0,\ldots,g_8)\in\{+1,-1\}^9\) and consider its complete \(81\)-vector cyclic Gabor system. Form the corresponding \(81\) rank-one projectors and let \(R(g)\) be the **complex-linear dimension of their span in \(M_9(\mathbb C)\)**. After identifying \(g\) and \(-g\), the exact distribution over all \(256\) binary windows is

| \(R(g)\) | Number of normalized binary windows |
|---:|---:|
| 73 | 117 |
| 69 | 81 |
| 65 | 54 |
| 21 | 3 |
| 9 | 1 |

These are the only possible ranks. In particular, the optimal rank among all binary phase-only windows is \(73=9^2-9+1\), attained by exactly \(117\) of the \(256\) windows, and the next attainable rank is \(69\), not \(72\), \(71\), or \(70\). The unique rank-nine window modulo global sign is constant. The three rank-\(21\) windows are exactly the nonconstant three-periodic windows modulo global sign. No rank statements here assert nonlinear phase retrieval of arbitrary complex signals.

The rank census is governed by an explicit four-event rule. For each \(x\in\{1,2,3,4\}\), put
\[
 S_r(x)=\sum_{j=0}^2g_{r+3j}g_{r+3j+x},\qquad r=0,1,2,
\]
with all subscripts modulo \(9\), and define \(E_x(g)\) by \(S_0(x)=S_1(x)=S_2(x)\). For a non-three-periodic window, \(R(g)=73-4e(g)\), where \(e(g)\) is the number of true events among \(E_1,E_2,E_3,E_4\). Moreover, \(e(g)\) can only equal \(0,1,2\), and its counts are \(117,81,54\), respectively. The count \(81\) consists exactly of the windows for which \(E_3\) holds alone; every window with \(e(g)=2\) has one of the six event pairs, each pair realized by exactly nine windows.

## Assumptions and scope
Indices lie in \(\mathbb Z/9\mathbb Z\). For \(t,k\in\mathbb Z/9\mathbb Z\), define \((T_tg)(j)=g(j-t)\) and \((M_kg)(j)=\exp(2\pi i kj/9)g(j)\). Write \(\pi(t,k)=M_kT_t\), \(P_{t,k}=\pi(t,k)gg^*\pi(t,k)^*\), and
\[
 \mathcal L_g:X\longmapsto\bigl(\operatorname{tr}(XP_{t,k})\bigr)_{t,k\in\mathbb Z/9\mathbb Z}.
\]
Then \(R(g)=\operatorname{rank}_{\mathbb C}\mathcal L_g\). The projector normalization \(g/3\) has the same rank. Global multiplication by \(-1\) does not change any projector, so we impose \(g_0=1\). This leaves \(2^8=256\) normalized windows. The result is about the **linear matrix-lifting map**, not the rank of the original \(9\)-by-\(81\) Gabor synthesis matrix, and not nonlinear phaseless uniqueness or numerical conditioning.

## Proof
**1. Weyl diagonalization.** The \(81\) Weyl operators \(M_bT_a\) form an orthogonal basis of \(M_9(\mathbb C)\). Expanding \(gg^*\) in this basis, conjugation by \(M_kT_t\) multiplies each coefficient by a distinct two-dimensional character. The two-dimensional character matrix is invertible. Hence the orbit of \(gg^*\) spans exactly those Weyl directions where its coefficient is nonzero, so
\[
 R(g)=\#\{(a,b)\in(\mathbb Z/9\mathbb Z)^2:A_g(a,b)\ne0\},\quad
 A_g(a,b)=\sum_{j=0}^8g_jg_{j+a}\zeta_9^{bj},
\]
where \(\zeta_9=\exp(2\pi i/9)\). This diagonalization is a classical ingredient; the exact binary nine-cycle evaluation below is the claim.

**2. Exact cyclotomic zero test.** For \(a=0\), \(A_g(0,b)=9\) at \(b=0\) and \(0\) at every nonzero \(b\), giving eight unavoidable zero Weyl directions. For \(a\ne0\), the coefficient sequence \(h_a(j)=g_jg_{j+a}\) contains nine signs, so its sum \(A_g(a,0)\) is an odd, nonzero integer.

When \(b\in\{3,6\}\), the primitive cubic-root relation \(1+z+z^2=0\) shows that \(A_g(a,b)=0\) if and only if
\[
 S_0(a)=S_1(a)=S_2(a).
\]
Both modulations vanish together. When \(b\in\{1,2,4,5,7,8\}\), the minimal polynomial of \(\zeta_9^b\) is \(1+z^3+z^6\), so \(A_g(a,b)=0\) if and only if \(h_a(j+3)=h_a(j)\) for every \(j\); all six primitive modulations then vanish together.

That latter condition holds for \(a\ne0\) **if and only if \(g\) is three-periodic**. Indeed put \(u(j)=g(j+3)/g(j)\in\{\pm1\}\). The three-periodicity of \(h_a\) says \(u(j+a)=u(j)\). If \(3\nmid a\), this forces \(u\) to be constant, and its product around any three-step orbit is \(u^3=1\); hence \(u=1\). If \(3\mid a\), then \(u\) is constant separately on each three-step orbit; again each orbit has product one, so \(u=1\). The converse is immediate.

The event condition for \(a\) is unchanged when \(a\) is replaced by \(-a\), since \(h_{-a}(j)=h_a(j-a)\), which only permutes the three residue-class sums. Thus the eight nonzero displacements come in four pairs indexed by \(a=1,2,3,4\).

**3. Count the order-three cancellation events.** For any unit \(a\pmod9\), set \(h(j)=g_jg_{j+a}\). Along the single nine-cycle generated by \(a\), the map from \(g_0=1\) to \(h\) is bijective onto binary words with product \(1\). The event \(E_a\) means that the three residue classes modulo three have equal numbers of negative entries. Since their common negative count \(m\) satisfies \((-1)^{3m}=1\), it is \(m=0\) or \(m=2\). Case \(m=0\) gives the constant window. In case \(m=2\), exactly one positive edge occurs in each residue class, giving \(3^3=27\) nonconstant windows. Hence each unit event \(E_1,E_2,E_4\) holds on exactly \(28\) normalized windows.

For \(a=3\), each of the three residue columns \((g_r,g_{r+3},g_{r+6})\) has cyclic binary autocorrelation sum \(3\) if constant and \(-1\) otherwise. Consequently \(E_3\) holds precisely when all three columns are constant or all three are nonconstant. The former gives \(1\cdot2\cdot2=4\) normalized windows (one constant and three nonconstant three-periodic); the latter gives \(3\cdot6\cdot6=108\) non-three-periodic windows.

**4. Exact intersections and exhaustiveness.** For \(E_1\) in the nonconstant case, the positive positions of \(h(j)=g_jg_{j+1}\) consist of one position from each residue class. All \(27\) possibilities split into three distinct cyclic-shift orbits of nine, represented by
\[
 \{0,1,2\},\qquad\{0,1,5\},\qquad\{0,2,4\}.
\]
Their respective numbers of cyclicly adjacent positive pairs are \(2,1,0\), proving the orbits distinct; each has nine members because none is invariant under a nontrivial cyclic shift. There are \(27\) positions in all, so this is exhaustive. Recovering \(g\) from \(h\) by \(g_0=1\) and \(g_{j+1}=g_jh(j)\), direct multiplication gives the sets of true events for these representatives:
\[
 \begin{array}{c|c}
 \text{Positive positions of }h&\text{True events}\\\hline
 \{0,1,2\}&E_1,E_3\\
 \{0,1,5\}&E_1,E_4\\
 \{0,2,4\}&E_1,E_2
 \end{array}
\]
Translations of \(g\) preserve these events. Multiplying the index by a unit modulo nine permutes \(E_1,E_2,E_4\) transitively and fixes \(E_3\). Therefore every pair among the four events occurs on exactly nine **nonconstant non-three-periodic** windows; three-event intersections are empty in that class. All six event pairs account for \(6\cdot9=54\) distinct normalized windows, and every nonconstant window with a unit event belongs to one of them.

Of the \(108\) non-three-periodic windows satisfying \(E_3\), precisely \(3\cdot9=27\) also satisfy a unit event, leaving \(81\) with \(E_3\) alone. There are exactly \(4\) three-periodic normalized windows, one constant and three nonconstant. The remaining \(256-54-81-4=117\) windows have no event.

**5. Read off the ranks.** If \(g\) is not three-periodic, no primitive-order Fourier zero occurs at a nonzero displacement, and each true event removes exactly four Weyl directions (two shifts, two cubic-order modulations). Thus \(R(g)=73-4e(g)\), producing the \(117,81,54\) counts at ranks \(73,69,65\). A nonconstant three-periodic window has 48 additional primitive-order zeros and four cubic-order zeros at displacements \(3,6\); including the eight zero-displacement zeros gives \(R(g)=81-8-48-4=21\). A constant window has every nonzero modulation vanishing at every displacement, leaving exactly nine surviving Weyl directions, so \(R(g)=9\). These cases exhaust all normalized binary windows.

## Verification
The bundled `check_cyclotomic.py` independently evaluates the integer cyclotomic zero conditions on all \(256\) windows and verifies the three nine-member positive-edge orbits. The separate `check_finitefield.py` computes all \(81\) ambiguity coefficients for every window directly in the finite field with prime modulus \(531613\), using the element \(45273\) of exact order nine. The second check is **exact**, not a heuristic reduction: if a nonzero ninth-root integer combination of nine signed terms vanished modulo that prime, its nonzero algebraic norm would be divisible by \(531613\), but all six complex conjugates have modulus at most nine, so its integer norm has absolute value at most \(9^6=531441\), a contradiction. Both programs reproduce the rank counts \(\{9:1,21:3,65:54,69:81,73:117\}\). Run each with Python 3 without third-party dependencies. The written orbit and cyclotomic proof, rather than extrapolation from finite examples, establishes the complete finite statement.

## Relationship to prior work
Bojarovska and Flinth (2015, Theorems 2.2–2.3 and Proposition 2.3) give the Weyl/ambiguity approach to finite Gabor measurements and identify phaseless noninjectivity mechanisms; these foundational results are prior, not claimed here. Goldberger, Kang and Okoudjou (2021) study ranks and symmetries of incomplete Gabor POVMs, but their inspected classification does not give a binary-nine-window occurrence table. An earlier prime-power digit-fiber Gabor-rank theorem for **nonnegative rational** windows provides a close cyclotomic framework; its primitive-root argument also applies to signed rational coefficients, but its published conclusions do not enumerate the five binary nine-point rank classes. Another exact cyclotomic phase-mask theorem treats proper supports in prime cyclic groups, not full-support binary windows at composite order. The contribution here is the exact binary nine-cycle rank spectrum, sharp multiplicities, and three-orbit event proof—not the classical Weyl rank formula or cyclotomic minimal polynomials.

## Limitations
The classification is exactly for binary full-support windows in dimension nine; no phase-alphabet or dimension-uniform rank histogram is asserted. The maximal matrix-lifting rank \(73\) is smaller than \(81\): every constant-modulus window loses the eight zero-displacement modulations. In fact, these windows do not give general complex phase retrieval; rank of linear measurement operators is not the same as injectivity on rank-one Hermitian signals. The classification is exact but is not an estimate for numerical conditioning. Historical priority against unindexed binary-sequence or finite Gabor tables has not been independently established.
