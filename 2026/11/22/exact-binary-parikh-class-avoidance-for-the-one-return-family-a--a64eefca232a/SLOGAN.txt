The scattered family \(a^r b a b\), for every \(r\ge2\), has an exact binary Parikh-class avoidance polynomial obtained by forcing all positive Ferrers rows from the \(r\)-th onward to have equal length. Every class immediately below the maximum \(ab\)-pair count universally contains the pattern when \(A\ge r+1\) and \(B\ge2\), while the maximal class avoids it.
