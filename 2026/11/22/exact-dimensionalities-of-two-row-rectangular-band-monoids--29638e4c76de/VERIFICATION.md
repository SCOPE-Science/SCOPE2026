# Reproducibility and verification

The definitions, complete classification, all-\(n\) proof and exact counting formulas are in `RESULT.md`. The standalone file `verification/verify.py` uses only the Python 3 standard library. Execute from the document directory:

```bash
python3 verification/verify.py
```

The checker enumerates all \(B_{2n}\) set partitions of the \(2n\) rectangular-band elements for \(1\le n\le5\). It tests product rectangles directly for the union-of-blocks condition; separately it tests the asserted structural classification. It then enumerates every subgroup-orbit partition generated by automorphisms of the labelled grid, using joins of individual permutation cycle partitions, and compares the independently recovered total with the closed formula. The expected exact lines are:

```
n=1 D=2 O=2 nonorbit=0 congruences=2
n=2 D=5 O=5 nonorbit=0 congruences=4
n=3 D=16 O=13 nonorbit=3 congruences=10
n=4 D=64 O=48 nonorbit=16 congruences=30
n=5 D=309 O=184 nonorbit=125 congruences=104
RECTANGULAR_BAND_DIMENSIONALITIES_OK
```

The program also validates the seven-element non-orbit example and the \(n=5\) count \(309\) from an independent Stirling-number recurrence, alongside full enumeration. No finite check is claimed to prove the infinite result, and the script does not enumerate partitions above \(n=5\). The automorphism calculations do not classify abstract quotient relational monoids up to isomorphism. Independent verification has not been performed.
