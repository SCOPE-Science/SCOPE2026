In a periodized-Gaussian vegetation model with local Allee activation, the uniform positive state can alternate between linear instability and renewed stability as habitat circumference grows, with an **exact** number of stable return windows \(\max\{0,\lceil k_-/(k_+-k_-)\rceil-1\}\). This count diverges at the sharp \((D_c-D)^{-1/2}\) scale as diffusion approaches the Gaussian Turing threshold, and an explicit biologically admissible parameter choice has exactly two return windows.
