# Scientific review

## Correctness (C): PASS
The profile-difference proof is finite and exhaustive by construction: every insertion is either at an endpoint or between a unique adjacent source pair. For interior insertion of the same letter as a neighbor, the difference is a positive loop basis vector; otherwise it has exactly one negative ordered-digram coordinate, so the existing digram and inserted symbol can be recovered from the signed difference. Endpoint vectors form two coordinate stars with one possible nonloop intersection. These disjoint classes rigorously yield the all-word formula. With \(q\ge3\) all coefficients of the three support counts are positive, so equality is exactly full two-gram support and equal endpoints. The length threshold is an edge count, and the complete directed graph supplies Eulerian witnesses. The standard BEST and directed matrix-tree count gives the number of shortest witnesses. The probability bound is a direct union bound on disjoint independent two-letter blocks. Literal exhaustive tests across \(73{,}079\) source words and a ternary census of all shortest optimizers corroborate the proof. No infinite assertion relies on finite enumeration.

## Originality (O): PASS against inspected evidence
The earliest relevant contemporary motivation is the September 2026 paper on linear hashing of substring counts, in which all-alphabet local edits are used for asymptotic coding bounds, not enumerated as exact one-insertion two-gram profile balls. The 2015–2016 DNA-profile source establishes the measurement model but does not supply the nonbinary insertion-shadow theorem. The closest published binary insertion result proves the four-coordinate case and a binary Fibonacci–Lucas distribution: its entire scope is the binary alphabet. The new term recording different nonloop ordered digrams is identically zero in that binary case. The separately inspected binary deletion-profile distribution concerns a different channel. The classical de Bruijn count is explicitly recognized as prior knowledge; neither its renaming nor a new proof of that classical count is claimed. The contribution is the nonbinary all-word profile law and its exact sharp consequences.

## Mathematical value (V): PASS
Counting observable profiles rather than insertion words is a natural uncertainty invariant for ordered short-read histogram channels. The nonbinary change-vector classes do not exist in binary, so extrapolating from the known six-profile binary law does not yield the answer. The result gives an exact test for every source word, a sharp extremal count for each alphabet, the first length where full profile ambiguity becomes possible, a complete characterization and exact number of those earliest maximizers, and an exponential convergence law for random sources. The de Bruijn correspondence turns an information-channel saturation question into a universal-cycle characterization. These are structurally motivated, all-alphabet results, not an arbitrary finite numerical slice or a routine parameter change.

## Closest literature and limitations
The 2026 substring-count-hashing paper and the 2015 profile-channel model cover related objects but do not state the same local invariant. The binary insertion result already covers \(q=2\); the binary deletion result cannot be transported to the insertion operation. Classical de Bruijn counting is used as a lemma, not claimed as new. Residual risk: an unindexed exact multiletter insertion-profile analysis could imply this theorem, and independent review is outstanding. The result does not cover two or more edits, longer substring profiles or optimal code size.
