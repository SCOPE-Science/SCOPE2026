# Review of exact modular periods and preperiods

**Correctness: PASS.** The object and normalization agree with the source definition. The proof separates the coprime component, where the unique reset-ratio position forces all periods to be multiples of the memory length, from the nonunit 2- and 3-adic components, whose last nonzero indices are found by exact valuation inequalities. It separately handles \(k=2\) and the initial-transient thresholds for \(k=3\). Exact-integer direct recurrence checks pass for 2235 pairs, but do not replace the infinite proof.

**Originality: PASS, with residual priority risk.** The most relevant primary source, arXiv:2609.12569v1, was read through its initial conditions, period collapse, closed forms, valuation statements and concluding open questions. It does not explicitly determine least eventual periods and sharp least preperiods modulo every integer. The indexed finite-intersection result for rotating-memory Fibonacci sequences concerns intersections across different parameter values and does not imply this modular classification. Earlier general recurrence-period work concerns different settings. The present result is deduced from the original authors' known block formula, and an unindexed equivalent short corollary remains possible.

**Mathematical value: PASS.** The source explicitly identifies modular periodicity as a natural number-theoretic question. The result gives the complete sharp answer for every modulus and memory length \(k\ge2\), distinguishing the persistent even-modulus tail for \(k=2\), the disappearing ramified components for \(k\ge3\), and the exact first index of periodicity. This is a natural exact invariant and a full classification, not a single isolated congruence. It does not resolve modular periods for general nonconsecutive memory patterns.

**Sources and limits.** Abdelaidoum–Mehiri–Belbachir, arXiv:2609.12569v1, is the load-bearing prior paper. Brent, arXiv:1004.5439, is a related but different periodic linear-recurrence setting.
