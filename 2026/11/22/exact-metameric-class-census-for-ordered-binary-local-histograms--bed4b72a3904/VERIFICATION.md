The included `verify.py` enumerates all binary words for \(1\le h\le n\le15\), forms the complete positional read vector, and compares full inverse-fiber multiplicity histograms with the direct subset expression in the theorem. It additionally compares distinct-profile, singleton-profile, non-singleton-class and maximum-fiber formulas, checks total source mass, and tests five larger parameter pairs using exact integer identities. Run `python3 verify.py` from the directory containing the script.

The code does not assume a result from a previous execution. Finite checks corroborate but do not replace the all-parameter proof. No independent mathematical audit has been performed.
