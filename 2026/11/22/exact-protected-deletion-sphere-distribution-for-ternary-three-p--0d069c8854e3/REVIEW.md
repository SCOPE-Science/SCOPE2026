# Scientific review

## Correctness — PASS

The source and receiver are both ternary length-three-palindrome-avoiding linear words. Removing one member of a maximal equal-symbol run produces the same read, so run-start representatives are exactly the distinct candidates. A source-valid word can acquire an invalid factor only across the deletion junction, giving two explicit local tests. A six-state equality-pattern transfer calculates the complete bivariate count; exact symbolic elimination proves the displayed rational function. Its polynomial recurrence and six initial cases give the sharp maximum and all optimizer multiplicities by induction. The independent direct-deletion enumerator agrees through length 13, and the symbolic identity is checked exactly. Finite tests are supporting evidence rather than the infinite proof.

## Originality — PASS (best-knowledge, qualified)

Shen et al. (arXiv:2407.16449, 2024) define this forbidden-palindrome language and count allowed source words, but their one-variable sequence enumerator does not measure deletion readouts surviving the same constraint. Bar-Lev et al. (arXiv:2304.01317, 2023) address encoder constructions, while Bar-Lev, Etzion and Yaakobi (arXiv:2206.07995, 2022) consider unrestricted edit spheres. The closest indexed restricted deletion result for run-two words has a weaker forbidden condition. These sources neither imply the exact receiver-constrained polynomial nor its extreme-degree law. Relevant aliases and candidate stronger coverage were searched and compared; an unindexed equivalent may still exist.

## Value — PASS

The protected single-deletion sphere distribution records how many distinct one-deletion outputs remain inside a natural finite-type coding constraint. Knowing the exact distribution and sharp maximum for every length gives a reproducible benchmark for constrained synchronization coding, beyond the raw number of admissible words. No optimal code size or channel-capacity bound is claimed.
