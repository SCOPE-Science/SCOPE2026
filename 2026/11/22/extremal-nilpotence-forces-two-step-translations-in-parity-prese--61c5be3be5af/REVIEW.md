# Independent mathematical audit

## correctness

PASS

The index of a nilpotent partial injection is the number of vertices in its longest path, and in this monoid a path is strictly monotone and stays in one parity class. Thus its index is at most ceil(n/2), attained by a full parity path. Equality forces that path to exhaust a largest parity class and hence to step +2 or −2. In the +2 case, an additional source bracketed by two mandatory sources has just the translated image available. An additional source adjacent to an end of the mandatory source list must map to an adjacent image on the correct side. For the only extra point beyond both the last mandatory source and its immediate successor (the last point n for an even chain with an odd maximal orbit), the only possible image above the final path image is n, a forbidden fixed point. The terminal orbit point itself cannot be a source. Taking inverses gives the −2 case. Restrictions of either translation satisfy both directions of fence preservation. With 2m+1 points the optional sources number m−1 for each of two directions; with 2m points there are four cubes of m−1 optional choices and the two cubes in each direction intersect only at the full translation, of rank 2m−2. This gives both enumerators and their evaluations at one, including n=3 and n=4. For n=1,2 all parity-preserving maps are partial identities, so only the empty one is nilpotent. Independent enumeration n=3–10 gave extremizer totals 2,6,4,14,8,30,16,62, matching all rank coefficients and verifying translation membership in each finite size.

Work already assuming isometry covers the smaller setting, not the assertion that extremizers in the fence monoid must be isometries. The bounded comparisons do not establish historical priority.
