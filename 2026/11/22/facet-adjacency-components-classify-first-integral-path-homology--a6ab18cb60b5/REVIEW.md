# Review: facet-adjacency and first integral cyclic-Hasse path homology

## Correctness — PASS

The full proof normalizes arbitrary coefficient-group-valued degree-one cocycles, not just field ranks: two-path relations reduce to differences of paths sharing ordered endpoints; fixing one reference facet yields constant weights on incident vertex-edge arcs, constant weights on each facet's global return arcs, and facet parameters identified precisely across common edges. Gauge uniqueness gives \(H^1(G;A)\cong A^{c(K)}\) for every abelian group \(A\). Integral universal coefficients and \(H_0\cong\mathbb Z\) prove \(H_1\cong\mathbb Z^{c(K)}\) without torsion. The checker independently reproduces 171 modular finite cases, without being used as infinite proof.

## Originality — PASS, with uncertainty

Ivanov–Zhang (arXiv:2611.19813v1) treat closed oriented manifolds and posets with Poincaré-duality ideal pairs; the present purely two-dimensional nonmanifold case, including vertex-glued filled triangles with unbounded first path rank, is not implied by those conditions. Chaplin's first-path-homology relations provide general groundwork but no facet-adjacency classification. Related indexed bidirected-triangle multipath calculations concern different complexes. Equivalent unpublished or unindexed formulations may exist; originality is a self-review, not a publication certification.

## Mathematical value — PASS

This gives a natural exact structural invariant across all finite connected pure two-complexes, plus a sharp qualitative separation: contractible complexes can produce arbitrarily large first cyclic-Hasse path homology. It delineates a meaningful limit of manifold-oriented cohomological classification, rather than merely recomputing one example.

## Boundaries

Requires pure dimension two, connected one-skeleton and **all** return arrows from facets to vertices. Higher path homology and multiplication are unclassified. Finite checks do not prove the infinite result; the all-coefficient cocycle proof does. Independent mathematical validation is outstanding.
