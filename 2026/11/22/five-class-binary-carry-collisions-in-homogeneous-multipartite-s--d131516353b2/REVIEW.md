# Review of five-class binary-carry profile collisions

## Correctness — PASS

The generic equivalence-enriched multipartite graph admits arbitrary cross-class one-point edge diagrams, giving exactly \(\sum_i 2^{n-a_i}\) nonalgebraic types. The proof explicitly fixes the total number of named parameters before comparing exponent sums. The binary-splitting classification covers all popcounts one through five and identifies the sole genuine five-summand resonance \(A+C=2B-1\). Converting exponents back to positive class sizes yields the complete \((t,d)\) classification and disjoint two-element fibers. The proof does not infer an infinite statement from finite enumeration. A dependency-free checker corroborates every fixed-size profile at orders through eighty, the sixteen-point uniqueness threshold by an independently generated census, the five-summand carry condition for 20,349 exponent multisets, and explicit small-base type diagrams. The separate cross-size example confirms the necessity of the fixed-cardinality hypothesis.

## Originality — PASS (best available comparison)

Previously established finite-base type formulas for an infinitely many-class analogue already imply the one-point power-sum representation, with an extra new-class term; that formula is not claimed to be original here. The new assertion is a complete fixed-size, fixed-five-class inverse classification. Lockett and Truss (2014, arXiv:1406.6517) classify homogeneous coloured multipartite graphs; the relevant primary text establishes the generic multipartite setting, not an inverse classification of fixed-base singleton-type counts. Earlier classification by Jenkinson, Truss and Seidel (2012) concerns the structures, not this binary-carry fiber theorem. A published result on finite equivalence-structure induced-substructure profiles studies parameter-free tuple counts in a language without graph adjacency. A published result on random bipartite reducts addresses two named sides and switching-group orbit counts. A published metric-graph result also has a five-part collision threshold but compares continuous distance histograms and part-size power sums, not finite-base logical singleton-type counts. Their statements do not imply this theorem. Searches for binary equal-power-sum/equal-exponent-sum identities and multipartite one-point reconstruction did not identify a prior full classification. Historical priority remains provisional, especially for arithmetic descriptions of equisum equilog binary partitions.

## Mathematical value — PASS

The theorem identifies the exact first information loss in a natural logical type-count invariant under an intrinsic restriction (fixed base cardinality). It provides an all-size classification of every five-class collision, exact two-element fiber counts for every parameter size, a sharp four-versus-five class boundary, a unique minimal witness, and a graded invariant that restores profile reconstruction. It also distinguishes this coarser inverse problem from reconstruction of the full old edge matrix, which the type count never sees. The result is structurally motivated by the indistinguishability of cross-class adjacency patterns in generic multipartite homogeneity, not by selecting an arbitrary finite coefficient.

## Limits and sources

The proof assumes every equivalence class is represented in the named base and both profiles have the same number of parameters. Different base sizes may have the same scalar count, already in three classes: \((1,4,4)\) and \((3,3,4)\) both give \(320\). No six-or-more-class collision classification or graph-edge-matrix reconstruction is claimed.
