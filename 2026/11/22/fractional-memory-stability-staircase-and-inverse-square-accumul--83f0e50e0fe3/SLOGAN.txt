The commensurate fractional sine–cubic map has an exact staircase of linearly stable equilibria: their number grows as \(D_\alpha/(\pi\sqrt{c-1})\) near the degenerate parameter \(c=1\), with successive spectral boundaries accumulating at inverse-square rate. Every genuine fractional order has \(D_\alpha>1=D_1\), so fractional memory preserves a symmetric stable branch in a parameter interval where the integer-order map has none; nonlinear attraction is not asserted.
