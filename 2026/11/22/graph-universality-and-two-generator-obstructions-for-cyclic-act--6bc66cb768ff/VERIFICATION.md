# Verification and reproducibility

Run `python3 verify/packet_graph_verify.py` from the package root. The checker uses only the Python standard library. The expected exact output is included in `verify/expected_output.txt`.

The script checks all \(1099\) labelled simple graphs on one to five vertices, computes chromatic numbers by explicit coloring search, and independently computes gcd-packet minima by subset dynamic programming. It tests pairwise prime-support edges, uniqueness and divisibility of the orbit indices, and Sylow prime multiplicities for each graph. It enumerates the subgroup generated by two explicit elements of \(C_6\times C_{10}\times C_{15}\) and verifies that all \(900\) elements occur. Complete-graph examples through eight vertices confirm the growing packet gap at actual generator rank two.

The logical proof for **all** graphs, the finite-abelian rank formula, and the NP-completeness reduction are in `RESULT.md`. No finite run certifies an infinite mathematical claim or an entire complexity class. No external audit has been performed.
