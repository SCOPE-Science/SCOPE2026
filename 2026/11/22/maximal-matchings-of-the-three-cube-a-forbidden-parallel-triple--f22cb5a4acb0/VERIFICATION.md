# Reproduction and boundaries

Run from this directory with Python 3 standard library:

```sh
python3 verify.py
```

Run independently with a C++17 compiler:

```sh
g++ -std=c++17 -O2 -Wall -Wextra verify.cpp -o verify_cpp
./verify_cpp
```

Compare console output, byte-for-byte, with `verification_python.txt` and `verification_cpp.txt`. Both check all 4,096 edge subsets and every support's shattering criterion. Python also checks all 48 cube isometries, rational rank 25 of the signed boundary matrix, and exact determinant \(+1\) of the specified rank-25 minor; C++ checks mod-two rank 25 independently. The proof of integral torsion-freeness uses the primitive image certified by the unimodular minor, not the mod-two rank alone. The path names are relative and all required data are generated by the source files.

Finite enumeration is exhaustive for \(Q_3\) but is not a proof for higher dimensions. This reproduces the mathematical certificate and does not constitute independent mathematical validation. Historical priority requires separate investigation beyond the stated comparisons.
