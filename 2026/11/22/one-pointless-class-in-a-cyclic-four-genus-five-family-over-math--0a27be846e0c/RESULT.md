# One pointless class in a cyclic-four genus-five family over \(\mathbb F_{17}\)

## Finding

Consider the coefficient-marked hyperelliptic curves
\[
C_{a,b,c}:\quad y^2=a x^{12}+b x^4+c,
\qquad a,c\in\mathbb F_{17}^{\times},\ b\in\mathbb F_{17},
\]
with smooth projective models. Among the \(4352\) such marked equations, exactly \(4096\) are geometrically smooth of genus five, and **exactly \(32\)** have no \(\mathbb F_{17}\)-rational point. Moreover, all \(32\) pointless curves are related by diagonal changes \(x\mapsto u x\), \(y\mapsto v y\) over \(\mathbb F_{17}\), and hence represent **exactly one abstract \(\mathbb F_{17}\)-isomorphism class within this family**. A representative is
\[
\boxed{y^2=5x^{12}+3x^4+3.}
\]
Every smooth member has an order-four automorphism \((x,y)\mapsto(4x,y)\) and a genus-one quotient \(y^2=a t^3+b t+c\) under \(t=x^4\).

## Assumptions and scope

The parameter space consists of all triples \((a,b,c)\in\mathbb F_{17}^{\times}\times\mathbb F_{17}\times\mathbb F_{17}^{\times}\); distinct triples are counted as distinct equations even if isomorphic. A curve is called pointless if its smooth projective model has no rational points, including points above infinity. The one-class assertion concerns the family, not all genus-five curves. The quotient map and its cyclic order-four symmetry are defined over the given ground field because \(4\in\mathbb F_{17}\) has multiplicative order four.

## Proof

**Smoothness and genus.** Put \(t=x^4\) and \(F(t)=at^3+bt+c\). Since \(a,c\ne0\), the polynomial \(F(x^4)\) is squarefree over the algebraic closure exactly when the cubic \(F(t)\) is separable: its roots are nonzero and the map \(x\mapsto x^4\) is separable away from zero. The cubic has nonzero discriminant precisely when
\[
\Delta=-4ab^3-27a^2c^2\ne0\pmod {17}.
\]
Thus \(C_{a,b,c}\) is geometrically smooth of genus \((12-2)/2=5\) if and only if \(\Delta\ne0\). For each fixed nonzero \(a,c\), the equation \(\Delta=0\) is equivalent to \(b^3=-(27/4)ac^2\). Since cubing is a bijection of \(\mathbb F_{17}^{\times}\) (its order is sixteen), exactly one of the seventeen possible \(b\) is singular. Therefore precisely \(16\cdot16\cdot16=4096\) triples are smooth, out of \(16\cdot17\cdot16=4352\). The accompanying standalone checker independently confirms this count.

**Pointlessness criterion.** The nonzero squares in \(\mathbb F_{17}\) are \(\{1,2,4,8,9,13,15,16\}\), and the nonzero nonsquares are \(\mathcal N=\{3,5,6,7,10,11,12,14\}\). The nonzero fourth powers are \(H=\{1,4,13,16\}\). A rational point above \(x=0\) exists exactly when \(c\) is square, and one above infinity exists exactly when \(a\) is square. For \(x\ne0\), a rational point exists exactly when \(at^3+bt+c\) is square (including zero) for some \(t\in H\). Thus, among the smooth members, pointlessness is equivalent to
\[
a,c\in\mathcal N,\qquad at^3+bt+c\in\mathcal N\quad\text{for all }t\in H.
\]

**Exact finite classification.** Scaling the equation by a nonzero square using \(y\mapsto v y\) allows every nonsquare constant \(c\) to be normalized uniquely to \(c=3\) at the coefficient level. For each of the eight nonsquare \(a\), testing all \(17\) values of \(b\) against the four explicit fourth powers gives the *complete* table

| \(a\) | Admissible \(b\) when \(c=3\) |
|---|---|
| \(3\) | \(5\) |
| \(5\) | \(3\) |
| \(6\) | none |
| \(7\) | none |
| \(10\) | none |
| \(11\) | none |
| \(12\) | \(14\) |
| \(14\) | \(12\) |

Each of the four admissible pairs \((a,b)=(3,5),(5,3),(12,14),(14,12)\) has \(\Delta\ne0\), as checked by substitution. The finite table is exhaustive because the criterion tests all possible \(a,b\). Each of the eight nonsquare constants corresponds bijectively to these four pairs by a square scaling, so there are exactly \(8\cdot4=32\) smooth pointless triples.

**One isomorphism class.** With constant \(c=3\), replacing \(x\) by \(u x\) transforms the coefficient pair as
\[
(a,b)\longmapsto (au^{12},bu^4).
\]
Since \(u^4\) ranges over \(H\), the orbit of \((5,3)\) is exactly the four displayed pairs. Hence all normalized pointless curves, and therefore all \(32\) original ones, are diagonally isomorphic. Their existence proves that this family contains exactly one abstract isomorphism class of pointless curves.

**Elliptic quotient.** The map \((x,y)\mapsto (x^4,y)\) has degree four with cyclic deck group generated by \(x\mapsto 4x\). The cubic \(at^3+bt+c\) is separable exactly on the smooth locus above, so its smooth completion has genus one; since a rational point at infinity exists on the odd-degree cubic, it is an elliptic curve. This identifies the classification as an arithmetic statement about a natural cyclic-four pullback family, rather than an arbitrary sparse-polynomial census.

## Verification

The standalone file `verify_cyclic4_F17.py` uses Python standard-library arithmetic only. Running `python3 verify_cyclic4_F17.py` exhaustively checks all \(4352\) marked coefficient triples, the discriminant criterion, all rational fourth-power values, the four normalized candidates and their diagonal orbit. Its expected output is `CYCLIC4_POINTLESS_F17_VERIFIED smooth=4096 pointless=32 normalized=4 diagonal_orbits=1`. The proof above gives the complete finite criterion and group action; the code is an independent reproducibility route for the finite table.

## Relationship to prior work

Becker and Glass, *Pointless Hyperelliptic Curves* (2012, arXiv:1209.2984), develop general pointless-curve constructions; Howe, Lauter and Top (2004, arXiv:math/0403178) produce relevant lower-genus examples, and their results combined with Becker–Glass's genus-raising construction can yield genus-five pointlessness over \(\mathbb F_{17}\). **Neither the existence of a pointless genus-five curve nor the universal closed-point threshold is claimed as new.** The present result instead gives the exact arithmetic count and isomorphism rigidity of the *entire distinguished cyclic-four elliptic-pullback family* at this field. Aubry, Herbaut and Monaldi (2023, arXiv:2310.11218v1) provide context concerning closed points and their universal thresholds, but not this parameter classification. Related searches for cyclic-order-four pullbacks, pointless genus-five hyperelliptic families and characteristic-seventeen enumerations found no statement covering the four normalized coefficients or the single diagonal orbit.

## Limitations

The classification is coefficient-marked, apart from the explicitly proved diagonal equivalence. It does not classify all genus-five curves, all cyclic-four covers of elliptic curves, or the full geometric automorphism group. The finite calculation is exact but does not establish historical priority; an unindexed or uninspected earlier classification of the same family is a residual risk. Independent mathematical audit has not been performed.
