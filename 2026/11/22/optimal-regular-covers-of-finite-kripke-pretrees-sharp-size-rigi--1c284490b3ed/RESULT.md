# Optimal regular covers of finite Kripke pretrees: sharp size, rigidity, and multiplicity

## Finding
Let \(F\) be a nonempty finite rooted preorder whose quotient \(T=F/{\sim}\) by mutual accessibility is a rooted tree. Denote its clusters by \(C_t\), their sizes by \(c_t\), its internal quotient vertices by \(I(T)\), and its maximum quotient branching degree by \(\Delta(T)\) (zero for a singleton). Fix integers \(k,m\geq1\). A *regular source of type \((k,m)\)* is a finite rooted pretree all of whose clusters have \(m\) elements and whose quotient tree has exactly \(k\) children at every nonleaf.

**Sharp cover and rigidity theorem.** A root-preserving surjective bounded morphism from some type-\((k,m)\) source onto \(F\) exists exactly when
\[
 k\geq\Delta(T),\qquad m\geq\max_{t\in T}c_t.
\]
Under these conditions its smallest possible source cardinality is
\[
 \boxed{\ m\bigl(k|I(T)|+1\bigr).\ }
\]
Moreover, **every minimum source has the same unlabelled quotient-tree shape**: retain the rooted tree induced by the internal vertices of \(T\), then give each such vertex \(t\) exactly \(k-u_t\) new leaf children, where \(u_t\) is its number of internal children. When \(T\) has a single vertex the optimal source consists of one \(m\)-element cluster. Thus the optimal quotient shape is canonical even though optimal maps need not be unique.

There is also an exact **weighted count of optimal morphisms**. For \(a\geq b\geq1\) put \(s(a,b)=\sum_{j=0}^{b}(-1)^j\binom bj(b-j)^a\), the number of surjections from an \(a\)-element set onto a \(b\)-element set. For each quotient leaf \(v\), put \(w_v=s(m,c_v)\). For each internal \(t\), let \(B_t\) be its set of immediate leaf children, \(L_t\) its set of all descendant leaves, and \(q_t=k-u_t\). Define
\[
 W_t=\sum_{J\subseteq B_t}(-1)^{|J|}
 \left(\sum_{v\in L_t\setminus J}w_v\right)^{q_t}.
\]
For a **fixed source** with the canonical quotient shape and with individually distinguishable worlds, the number of surjective bounded morphisms to the fixed concrete target (without fixing which root-cluster element is the image of a specified source root element) is, for \(I(T)\ne\varnothing\),
\[
 \boxed{\mathcal N_{k,m}(F)=|\operatorname{Aut}(T^\circ)|
  \prod_{t\in I(T)}s(m,c_t)\,W_t,}
\]
where \(T^\circ\) is the rooted tree induced by \(I(T)\). When \(T\) is a singleton, the count is \(s(m,c_r)\). If instead a particular world of the source root cluster must map to a prescribed world of the target root cluster, the count is \(\mathcal N_{k,m}(F)/c_r\). In the purely tree case \(m=c_t=1\), \(W_t=\sum_{j=0}^{|B_t|}(-1)^j\binom{|B_t|}{j}(|L_t|-j)^{q_t}\).

## Assumptions and scope
A finite pretree here means a **rooted preorder** with equivalence classes for \(x\sim y\iff(x\leq y\wedge y\leq x)\), whose quotient is a finite rooted tree under reflexive ancestor order. This is different from the interval-function notion of a pretree. A bounded morphism \(f:S\to F\) satisfies the forward and back conditions, equivalently \(f(\uparrow x)=\uparrow f(x)\) for each source world \(x\). Roots are least clusters, and “root-preserving” means a chosen source-root world maps to a chosen target-root world. In the unpointed count, only the root *cluster* is preserved. The quotient tree is nonempty, unordered, and has no bound on height. Source worlds and target worlds are distinct even inside a cluster. No inverse-back, immediate-successor, valuation-preservation, or infinitary condition is imposed.

The minimum and the canonical shape are about the source **preorder**, not about a specific embedding of a smaller tree into a larger one. Different designated root worlds within the unique minimum source are isomorphic. All integer powers in the weighted formula use \(0^0=1\) when the exponent is zero, as prescribed by the empty-product convention.

## Proof
**1. Passing to quotient trees.** Mutual accessibility is preserved by every order-preserving map, so a bounded morphism induces a map \(\bar f\) from source quotient clusters to target quotient clusters. The back condition for any source-world representative shows \(\bar f(\uparrow s)=\uparrow\bar f(s)\). As the source root cluster maps to the target root cluster, both the original map and the quotient map are onto.

**2. Necessary thresholds.** Fix a target cluster \(C_t\), and choose a source quotient vertex \(s\) *maximal in the source ancestry order* among those mapping to \(t\); it exists by finiteness and surjectivity. No strict descendant of \(s\) maps to target cluster \(t\). For any chosen source world \(x\in C_s\), every world of \(C_t\) is accessible from \(f(x)\), so the back condition demands preimages in \(\uparrow x\). These preimages must lie in \(C_s\). Hence \(m\geq c_t\).

If \(t\) has \(d_t\) immediate quotient children, the back condition at \(x\) gives a descendant of \(s\) mapping to each one. Along the path to that descendant, the first source-quotient child of \(s\) must map to that immediate target child: no strict source descendant maps to \(t\), and there is no target vertex strictly between \(t\) and its child. Different target children require different source children. Thus \(d_t\leq k\), proving the two necessary conditions.

**3. Sharp lower bound.** For every internal target quotient vertex \(t\), surjectivity supplies a source quotient vertex \(s\) mapping to \(t\). It must be nonleaf: a source leaf cluster cannot have an accessible image equal to the nontrivial cone above \(t\). As different target vertices cannot share one preimage vertex, the source has at least \(|I(T)|\) internal quotient vertices. Every finite rooted full \(k\)-ary tree with \(j\) internal vertices has exactly \(kj+1\) vertices (count its \(kj\) edges). Each source quotient vertex contributes exactly \(m\) worlds, yielding the claimed cardinality lower bound.

**4. Construction attaining the bound.** If \(T\) is a singleton, take one \(m\)-element source cluster. Otherwise keep all internal vertices of \(T\), preserving their parent-child relation, and attach \(k-u_t\) leaf children to each internal vertex \(t\). Since \(k\geq d_t=u_t+|B_t|\), there are enough new leaf children to map one onto each immediate target leaf child in \(B_t\). Map each remaining source leaf child to any target quotient leaf below \(t\); there is always one. Map each source internal vertex to its corresponding target internal vertex. Every source leaf then maps to a target leaf. At each source internal vertex \(t\), its cone image consists of \(t\) plus the complete images of all internal target-child subtrees, plus all immediate target leaf children, hence equals the entire target cone. Choose independently a surjection from each source \(m\)-element cluster onto the target cluster to which it is assigned; possible by \(m\geq\max c_t\). The resulting map satisfies the bounded-morphism equation pointwise, is onto, and can be chosen to send the designated source-root world to the designated target-root world. Its quotient has exactly \(|I(T)|\) internal vertices, proving equality.

**5. Rigidity of every optimal source.** At equality, each internal target quotient vertex has **exactly one** source internal preimage, and no source internal vertex maps to a target leaf. Denote the unique source internal preimage of \(t\) by \(s_t\). For any internal \(u\) above \(t\), the back condition at \(s_t\) gives an internal descendant mapping to \(u\), which must be \(s_u\). Thus \(t\mapsto s_t\) preserves strict ancestry. Conversely, the forward condition and injectivity imply that ancestry between source internal vertices reflects target ancestry. This is an isomorphism between the source internal skeleton and \(T^\circ\). Full \(k\)-branching then forces exactly \(k-u_t\) terminal children at every corresponding internal vertex. Therefore every minimum source has the same quotient shape, irrespective of the morphism.

**6. Counting all optimal maps.** The internal quotient skeleton may be mapped isomorphically onto \(T^\circ\) in exactly \(|\operatorname{Aut}(T^\circ)|\) ways. For a fixed choice, there are \(s(m,c_t)\) maps from each internal source cluster onto its target cluster; necessity of surjectivity follows from the uniqueness of its preimage cluster (no descendant maps to the same target cluster). Each of the \(q_t=k-u_t\) leaf children of the source cluster corresponding to \(t\) must choose a target quotient leaf in \(L_t\), with at least one such child choosing each of the immediately adjacent target leaves in \(B_t\). Choosing target leaf \(v\) carries weight \(w_v=s(m,c_v)\), the number of surjections from that source leaf cluster onto \(C_v\). Inclusion-exclusion on the compulsory leaves \(B_t\) counts the weighted assignments as \(W_t\). Choices at distinct internal vertices are independent; multiplying gives \(\mathcal N_{k,m}(F)\). Any permutation of the elements of the target root cluster is a preorder automorphism, transitive on its points, so exactly \(1/c_r\) of these maps send a prescribed source-root world to a prescribed target-root world. The singleton target is the usual surjection count. ∎

## Verification
The standalone standard-library program `check_regular_pretrees.py` constructs regular covers, tests the complete cone-image equality, and compares the weighted factorization with direct function enumeration in small cases. Its successful output is

```text
VERIFY_OK shapes 57 brute_tree_counts 24 cluster_brute 4 shape_rigidity 375 branch_obstruction 259
```

The 57 construction cases include every unlabelled rooted target tree of order at most six and several regular degrees. The 24 direct-count cases enumerate all concrete tree maps for small shapes; four additional cases enumerate cluster-to-cluster maps, including nontrivial clusters. The 375 comparisons check all candidate full regular source-tree shapes at and just below the purported minimum in the tested range, and 259 further comparisons check branching infeasibility. These finite checks are supplementary and do not certify any infinite quantifier in the theorem; the proof above provides the unbounded argument. Run `python3 check_regular_pretrees.py` with Python 3.10 or later.

As small boundary examples, for a three-vertex two-leaf star with \(k=2,m=1\), the minimum source has three vertices and exactly two maps. For a three-vertex chain with \(k=2,m=1\), the minimum source has five vertices and exactly one map. For the five-vertex tree whose root has one leaf child and one internal child with two leaf children, \(k=3,m=1\) gives a seven-vertex minimum source and exactly thirty maps. A long unary tail below one child of a binary split illustrates the value of the optimization: the straightforward same-child replication in the known regularization construction may grow exponentially in tail length, whereas the sharp minimum is linear in the number of target nonleaf clusters.

## Relationship to prior work
Wołoszyn (arXiv:2605.14182v1, May 13, 2026), §3, Lemma 3.7, proves that every finite pretree is a bounded-morphic image of a regular pretree, using a uniform branching parameter and a uniform cluster size. The construction repeats target children to fill extra source branches; it does not optimize source order, identify the unique optimum shape, or count optimal maps. The present theorem strengthens that particular finite regularization problem quantitatively without altering the modal semantics.

The published published-finding corpus finding *Finite rooted Kripke p-morphism images are rooted topological minors* establishes a general existence characterization between two already specified **tree** frames using least-common-ancestor-preserving embeddings, and a decision algorithm. That broader existence criterion is compatible with the present lower bound in the cluster-free case, but does not specify the optimization over all regular source frames, the rigid minimum shape, or counts with nontrivial clusters. Another published published-finding corpus finding, *Exact bounded-morphism counting between arbitrary finite rooted tree frames*, gives a general subtree inclusion-exclusion recurrence for the number of maps between two specified cluster-free trees. That recurrence subsumes the unoptimized number-of-maps question, but not the stated optimum source size, uniqueness theorem, or uniform-cluster weighted factorization. The three-level-target and starlike-frame bounded-morphism censuses address other source-target restrictions. No novelty is attributed to the classical Kripke bounded-morphism semantics, full-ary edge count, inclusion-exclusion, or surjection numbers.

## Limitations
The result concerns finite rooted preorders with **tree quotient** and a single reflexive ancestor-style accessibility relation, and regular sources with a common cluster size. It does not treat inverse accessibility simultaneously, arbitrary finite preorders, nonuniform source clusters, or infinite trees. The multiplicity formula counts maps from one *fixed* minimum source with its worlds distinguishable; it does not count source labelings, isomorphism classes of maps, or all larger regular covers. An exact count for prescribed source and target **trees** is already available in the cited published-finding corpus work; the novelty is the optimized-cover characterization and its explicit optimal multiplicity. Searches and full-text comparisons reduce but cannot eliminate specialized historical-priority risk. Independent verification has not been performed.
