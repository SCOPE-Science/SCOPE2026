# Scientific assessment: principal finite rank thresholds for strict weak orders

## Correctness — PASS
The ambient hereditary class, induced embeddings, exact one-point-extension quantifiers and special empty cases are defined in RESULT.md. The all-size proof classifies every prime-extension type (joining an existing selected antichain or creating a class in one of its ordered gaps), inductively factors the relative game rank into unused-class capacities and split-gap ranks, derives the complete max–min recurrence, and converts it by induction into a unique canonical induced-witness pattern for each threshold. The minimum-size formula and unique equality type follow because every rank-\(t\) host must contain the whole canonical witness. The checker independently enumerated all extension types and all host replies for 627,231 marked states from every positive weak-order word through eleven elements. It also tested 1,200 additional random words. These tests support the proof but are not an infinite certificate.

## Originality — PASS within inspected evidence
The 2026 primary paper establishes the rank definition and finite linear-order thresholds in the different hereditary class of linear orders; equal-rank classes in weak orders can also accept additional vertices into existing incomparable levels, so the linear-order theorem cannot imply this result. The 2024 manuscript provides general finite-witness-list existence, but not a single principal threshold witness for each finite rank or the present exponential-minus-linear sharp size law. The publicly available weak-order finite-variable-theory result characterizes \(\mathrm{FO}^k\) equivalence by capped level sizes, an invariant different from one-point-extension game rank. The previously available equivalence-relation finding forgets the order between incomparability classes: equal class-size multisets need not have equal weak-order rank. Targeted database and web searches did not reveal a covering theorem, but search incompleteness leaves historical priority provisional.

## Value — PASS
The core research problem is to make the recently studied Fraïssé one-point-extension rank explicit in natural amalgamation classes lacking free amalgamation. Finite weak orders combine the gap choices of linear orders and same-class choices of equivalence relations; neither previous single-resource formula determines the combined game. The theorem supplies a complete relative-rank characterization, a principal induced-substructure obstruction for *every* finite rank threshold, the sharp minimum host size and unique minimizer, and a constructive polynomial-time decision procedure. This is a structural classification of a whole hereditary class, not a parameter substitution or a finite table entry.
