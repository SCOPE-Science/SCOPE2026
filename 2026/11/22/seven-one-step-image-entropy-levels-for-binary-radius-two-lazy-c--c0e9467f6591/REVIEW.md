# Scientific review: seven lazy-automaton image-entropy levels

## Correctness — PASS
The object is the full set of 32 binary radius-two cellular automata with precisely one active five-bit neighborhood, not 32 independently chosen Boolean constraints. Sixteen rules switch a center zero to one at one designated surrounding four-bit pattern. The remaining sixteen are their bit-complement conjugates. A sixteen-vertex de Bruijn input graph determines output words. Determinization produces between eleven and fourteen reachable nonempty subset states for each of the sixteen first cases; all such states are accepting. For each output length the word count equals the row-vector/matrix-power/ones-column expression, and its exponential growth rate equals the Perron root of the finite transition matrix. Exact integer characteristic polynomials, divisibility by the claimed seven class factors, and Sturm root counts on explicit rational intervals verify the seven classes and their strict ordering. Every map's two-step versus one-step value is checked on the entire nine-bit determining neighborhood; the twelve non-idempotent maps are identified, and their single-forbidden-word fixed-shift characteristic polynomials share the same Perron factor. Exact root separation proves the two positive image-minus-fixed entropy gaps. An independent C99 exhaustive finite-word enumerator and a Python/SymPy verifier both passed. Numerical tests do not substitute for the all-length matrix argument.

## Value — PASS
The precise gap is a basic natural classification for the smallest radius beyond the 256 elementary rules: which spatial information rates can persist after one application of an automaton that changes exactly one possible neighborhood? The exact all-rule spectrum has only seven algebraic values. Importantly, twelve non-idempotent maps increase image-word entropy strictly over their fixed-point subshifts, and do so at only two exact rates; this separates single-update information retention from eventual fixed-state constraints. It is not merely a restatement of idempotence or a single arbitrary code sample, and the full finite census and reproducible sharp comparisons have potential use in related radius-two image and limit-set work. No claims are made about limit-set entropy or long-term orbit statistics.
