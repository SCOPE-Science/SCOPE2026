# Minimum order for a prescribed neighborhood trace count in cographs

## Finding

Let \(G\) be a finite simple cograph, \(A\subseteq V(G)\) a set of \(m\ge1\) marked vertices, and \(t\) the number of distinct traces \(N_G(v)\cap A\), counting witnesses at all vertices, including those in \(A\). For every \(1\le t\le2m\), the least graph order that realizes \(t\) is
\[
N_{\min}(m,t)=\max\{m,t\}.
\]
Equivalently, with exactly \(N\ge m\) vertices the spectrum is \(1,2,\ldots,\min(N,2m)\). Both statements also hold for closed-neighborhood traces. Distinctness here refers only to adjacency traces on \(A\), not to equality literals or quantified types.

## Proof

For the upper bound \(t\le2m\), use the augmented trace inequality \(|\mathcal T(G,A)\cup\{\varnothing,A\}|\le2m\); this is already in the companion *A sharp two-per-parameter bound for one-point adjacency types of finite cographs* (Resultary, record `911f048f6a8a`, Finding and inequality (1)). Its argument is to induct on union and join. At a union with both child parameter sets nonempty, the child augmented families overlap only at the empty set and the full set is added. At a join the translated families overlap only at the full set and the empty set is added. An unmarked child can add only the corresponding extreme. This proves the bound, starting with the single marked vertex. The same companion result gives order \(3m\) for attaining \(2m\) **external** traces; it does not assert the minimum when witnesses may be marked.

The lower bound \(N\ge\max(m,t)\) holds for any graph with m marked vertices, since each vertex contributes at most one trace. To meet it, first suppose \(t\le m\) and mark every vertex of an \(m\)-vertex graph. An edgeless graph gives \(t=1\); a star gives \(t=2\) if \(m\ge2\), including the edge when \(m=2\). For \(3\le t\le m\), use a clique of size \(t-1\) with \(m-t+1\) isolated vertices. The clique contributes \(t-1\) distinct nonempty traces and the isolates contribute just the empty trace. All these graphs are cographs.

For \(m\ge2\) and \(m\le t\le2m\), mark all \(m\) vertices \(a_1,\ldots,a_m\) of a clique. Choose any \(t-m\) distinct lengths from \(0,1,\ldots,m-2,m\), and add one independent unmarked witness for each chosen prefix of the ordered clique. The graph is a cograph: it can be built by placing the witness of length \(m\) first as an isolated vertex if chosen, adding clique vertices in descending index as dominating vertices, and placing each shorter-prefix witness as an isolated vertex just before adding the first clique vertex of its prefix in this descending order (length 0 is placed last). The clique contributes the \(m\) distinct sets \(A\setminus\{a_i\}\) of size \(m-1\). All added prefixes are distinct and no prefix of length \(m-1\) was selected. There are thus exactly \(t\) vertices and exactly \(t\) traces. For \(m=1\) the single marked vertex gives one trace, and an edge with one endpoint marked gives two.

To enlarge any witness to an arbitrary order \(N\ge\max(m,t)\), replace any vertex by an independent set of false twins, retaining the original marking at just one member if the vertex was marked and leaving all new copies unmarked. This substitutes a disjoint union of single vertices for a leaf in the cograph union/join construction. The old traces are preserved and every new vertex gives the same open trace as the chosen vertex; in particular the original vertex is not adjacent to any added copy. Thus every larger order is possible. Finally, \(N_G[v]\cap A=A\setminus(N_{\overline G}(v)\cap A)\) and complementation preserves order and the cograph class, giving the closed-trace result without any identification of the open and closed systems in a single graph.

## Scope, prior work, and verification

The order parameter is important when a graph has few potential witnesses. In particular, the sharp \(2m\) upper bound says nothing about whether all traces can be realized simultaneously with exactly one vertex per trace or about how much they can reuse marked vertices. Here the minimum is exact for each trace count under the all-vertex convention, as distinct from the external-only minimum. The upper bound is credited to the [matching companion statement](https://github.com/Resultary/2026/tree/main/2026/11/22/SCOPE-a-sharp-two-per-parameter-bound-for-one-point-adjacency-types-of--911f048f6a8a), without claiming priority from equal publication dates. Bonnet, Foucaud, Lehtilä and Parreau [Theorem 1](https://arxiv.org/abs/2301.04217) give \(4m\) at twin-width zero; the preceding credited upper bound is sharper. The resulting VC-dimension two follows already from that bound and its sharpness at \(m=2\), and is not a separate novelty claim.

The retained `verify.py` checks an exhaustive small-graph range and gives constructions for the trace spectrum up to \(m=11\). The witness, false-twin extension and complement proofs establish the order-bounded assertion for all sizes; finite checks are supplementary. The statement does not require domination of vertices or a nonempty trace for each vertex.
