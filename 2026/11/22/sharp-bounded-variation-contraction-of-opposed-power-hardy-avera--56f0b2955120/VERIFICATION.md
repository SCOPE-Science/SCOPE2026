# Verification
The proof in `RESULT.md` applies to all positive parameters and all real interval BV inputs; the standard-library checker `verify_hardy.py` runs representative analytic and numerical consistency tests.

Run `python verify_hardy.py` in a directory containing this file. The tests exercise six parameter pairs, two closed-form slices, an exact rational order-asymmetry certificate and deterministic signed finite-jump examples. They are not exhaustive for arbitrary real parameters or infinite-dimensional BV; those conclusions use the stated analytical measure decomposition and monotonicity proof.

The decimal value for the noncommuting example is approximate and generated by bisection and Simpson quadrature. The strict inequality is proved separately with a positive rational lower bound for \(\log3\).
