# Scientific review

## Correctness — PASS

The quantifier order in the finite relative rank is checked directly: for rank \(k+1\), every allowed extension type must have some realized witness of rank \(k\), with no requirement for all witnesses to work. Every one-point type of a two-sorted bipartite marked pair has been listed. Same-shore pairs require all four opposite-shore profiles and a spare same-shore vertex; mixed pairs require both opposite bit values available on each relevant shore. Singleton rank two and empty rank three are expansions of that recursion. Rank three therefore forces at least four vertices on each shore. The four required incidences of a rank-one same-shore pair, together with the necessity of the opposite-shore rank-one pair, rule out four edges at any size.

Finite enumeration visits every integer mask from 0 through \(2^{16}-1\). Direct recursive verification independently reconstructs all one-point types for every mask. Canonical side-preserving orbit enumeration and an independent Burnside computation agree on 29 classes; the weight-adjusted fixed-point sum is 16,704. The minimum edge stratum contains precisely 576 labelled matrices in one orbit. Reproducibility scripts and their actual outputs are included. Finite verification is not substituted for the all-order lower bounds.
