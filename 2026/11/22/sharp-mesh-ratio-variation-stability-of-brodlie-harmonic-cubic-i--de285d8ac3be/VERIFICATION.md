The mathematical proof in RESULT.md establishes the exact coefficient on every admissible fixed bi-infinite grid; the computational script checks only finite examples. Reproduce the finite-cell tests with `python3 verify_pchip.py` (standard-library Python). The tests include absolute integration of each derivative quadratic, seeded random positive meshes and arbitrary signed secant data, individual-data variation conservation, a two-input bound, and near-flat sharpness witnesses. A passing run is corroborative and is not an independent proof of the infinite-dimensional theorem.
