# Scientific review

## Correctness

PASS. The exact structural identity \(q(T,A)=m+b+s+\varepsilon\) follows by partitioning the marked set according to the components left by deleting each candidate vertex and then identifying the precise duplicate signatures on pendant compressed segments. The degree-sum argument proves \(b\le l-2\), yielding the sharp \(3m-4\) upper bound. Explicit contractions, edge subdivisions and an external leaf realize every host order. At equality, the complete-bipartite signatures are exactly the leaf-labelled tree splits, giving reconstruction and the \((2m-5)!!\) count. The packaged checker independently recomputes path truth vectors, compares all 89,629 tested finite instances against the structural formula, and enumerates binary extremal signatures for \(m\le7\). This testing supports but does not replace the all-size proof.

PASS within investigated evidence; historical priority is not independently established. The closest structural papers are Courcelle (arXiv:2004.10127) on axiomatization of tree betweenness; Bradley-Williams and Truss (arXiv:2108.12904) on tree-of-B-sets one-point extensions; and Hellmuth, Lindeberg and Moulton (arXiv:2606.16963) on LCA comparisons of leaf pairs. Queries to the published mathematical-record index included pair-incidence, betweenness types, phylogenetic reconstruction, equivalence and broad one-point growth formulations; relevant near hits use different query families (geodesic halfspaces, strict ancestor, clade shattering). The remaining priority risk is an unindexed classical combinatorial-geodesy formulation of the same  \(3m-4\) fact.

## Value

PASS. The primitive two-parameter path-membership formula yields only linearly many one-point behaviours, with an exact sharp coefficient/additive term, not just an asymptotic VC-density estimate. The theorem determines the optimal growth simultaneously as a function of host size and number of parameters, gives an exact invariant of every marked host tree, characterizes extremality, and makes maximal logical truth-pattern families topology-faithful. This is useful when choosing a finite set of path queries for tree identification and comparing graph-theoretic versus logical encodings; it is not an arbitrary finite table.
