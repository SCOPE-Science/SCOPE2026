# Verification

With Python 3 and SymPy installed, run `python verify.py`. It checks the Bilal mixed-Poisson identity, the rational threshold and factor-crossing equations symbolically. With built-in exact rational arithmetic, it also checks the logarithmic power-sum recurrence for four scales at inflation, unmodified and critical deflation parameters, and produces negative even coefficients beyond the cutoff. This finite suite is supplementary: the all-index weak-majorization, root-modulus and dominant-root arguments in RESULT.md constitute the proof. The code does not claim that any finite experiment certifies an infinite number of coefficients.
