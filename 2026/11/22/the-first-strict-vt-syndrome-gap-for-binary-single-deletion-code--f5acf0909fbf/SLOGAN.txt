For binary words having no run of three equal bits, the exact one-deletion-correcting capacities through length nine are \((1,2,2,3,3,6,6,10,13)\). Length nine is the first blocklength where a code with \(13\) words strictly exceeds all standard VT-syndrome intersections, whose largest has only \(12\) words; a standalone exhaustive clique certificate proves optimality.
