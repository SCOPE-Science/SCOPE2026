## 1. Setup and bounds from scratch
An [[n,k,d]] binary stabilizer code has n-k independent commuting Pauli generators on n qubits,
stabilizer group S size 2^{n-k}, normalizer N(S) size 2^{n+k}, distance d=min{wt(E):E in N\S}.
Binary symplectic form: Pauli (x|z) in GF(2)^{2n}, weight #{i:(x_i,z_i)!=(0,0)},
symplectic product <a,b>=a_x.b_z+a_z.b_x (mod 2). Commutation iff product 0.

Here n=12,k=2,n-k=10,|S|=1024,|N|=16384,K=2^k=4,|C|=2^{n-k}=1024 (additive GF(4) size).

**Singleton (quantum):** n-k>=2d-2. Proof sketch: standard (Knill-Laflamme shortening).
Here 10>=2d-2 => d<=6. d=7 needs 12>=10 false. So d in {<=6}.

**Hamming (quantum, degenerate-free bound, hence necessary for existence):**
sum_{j=0}^{floor((d-1)/2)} 3^j C(12,j)<=1024.
Computed from scratch: t=1:1+36=37<=1024; t=2:1+36+9*66=631<=1024; t=3:+27*220=6571>1024.
So d=4 (t=1),d=5,6 (t=2) allowed; d=7 (t=3) excluded. Hence Singleton+Hamming give d<=6.
Neither excludes d=5. The LP/shadow below does.

CSS definition used: stabilizer row space S subset GF(2)^{24} is CSS iff it is generated by
X-only and Z-only vectors, equivalently dim(S_X)+dim(S_Z)=n-k where
S_X=S cap (GF2^12 x 0), S_Z=S cap (0 x GF2^12). We show dx=dz=0, so strongly non-CSS.

## 3. Nonexistence of [[12,2,5]]: MacWilliams + shadow LP
We use standard necessary conditions for any (pure or impure/degenerate) stabilizer code,
via GF(4)-additive correspondence (Calderbank et al. quant-ph/9608006) and Rains shadow
(Rains, IEEE Trans. Inf. Theory 1998). We do not re-prove the shadow theorem; it is an
explicit dependency (see Limitations).

Let A_i=#stabilizer weight i, B_i=#normalizer weight i. Then A_0=B_0=1,
sum A=1024, sum B=16384, A_i,B_i>=0 reals (integers dropped for LP),
B=(1/1024)K A with quaternary Krawtchouk
K_j(i)=sum_s (-1)^s 3^{j-s} C(i,s)C(12-i,j-s),
B_j-A_j>=0 all j, =0 for 1<=j<d (no logical weight <d; stabilizer low weights allowed
only if matched in normalizer, i.e. degenerate case included).
Shadow: with Ks_{j,i}=coeff of x^{12-j}y^j in (x+3y)^{12-i}(y-x)^i =(−1)^i K_j(i),
S_j=(1/1024)sum_i A_i Ks_{j,i}>=0 all j (Rains).
Eliminate A_0=1, vars a_i=A_i (i=1..12). All constraints linear with integer coefficients.

Feasibility check (float simplex, cross-checked): d=4 feasible (as must be, witness exists);
d=5 feasible without shadow but **infeasible with shadow**; d=6 infeasible even without shadow.
Hence shadow is essential for d=5. Monotonicity: d=6 feasibility implies d=5 feasibility
(drop one equality), so d=5 infeasibility implies no d>=5.

**Exact Farkas certificate for [[12,2,5]] with shadow (integers, scale 21504):**
Constraint order Aub: [0..11]:-A_i<=0 (i=1..12); [12..24]:B_j>=0 (j=0..12);
[25..32]:B_j-A_j>=0 (j=5..12); [33..45]:S_j>=0 (j=0..12).
Aeq: row0 sum=1023; rows1-4 B_j-A_j=0 (j=1..4).
Nonzero duals (scaled by 21504):
y0=21504 (-A1), y1=11264 (-A2), y2=9216 (-A3), y3=3072 (-A4), y4=2048 (-A5),
y33=24 (S0), y34=4 (S1), y35=4 (S2); all other y=0;
z (equalities sum,j1..j4) = [39,19,9,3,1] (all zp, zm=0).
Unscaled rationals: y=[1,11/21,3/7,1/7,2/21,0..,1/896,1/5376,1/5376],
z=[13/7168,19/21504,3/7168,1/7168,1/21504].
