# Stabilized trailing triples for Jones polynomials of alternating pretzel links
under twist-region lengthening (census to 12 crossings, with extensions to 17)

## 1. What we did (self-contained)
We built an independent, stdlib-only Kauffman-bracket state-sum engine
(`output/artifacts/recompute_jones.py`) that takes a PD-style diagram
(crossing signs + arc pairings) and returns the Jones polynomial, with all
conventions calibrated against ground truth rather than assumed:

- trefoil anchor: our T(2,3) gives V(t) = t + t^3 - t^4;
- Hopf anchor: unnormalized f = -(A^{-2} + A^{-10}), i.e. V = -(t^{1/2}+t^{5/2});
- R1 check: single kink unknot has bracket -A^{-3}; disjoint union multiplies
  by d = -A^2 - A^{-2} (both asserted by the script);
- span check: every alternating knot row satisfies span(V) = crossing number
  (Murasugi's theorem, 122/122 rows);
- tangle-lemma check: 12/12 E-closures match the closed form (Section 3).

Diagrams need no external tables: torus links T(2,N) (braid closure with
rail-wise caps) and 3-box pretzels P(a,b,n) (three vertical twist columns with
cyclic top/bottom connectors) are generated by construction. Crossing count
c = N resp. a+b+n. One-region families fix two boxes and extend the third by
full twists (steps of 2, preserving alternating type and component count);
two-region families extend two boxes jointly.

## 2. Claim
**Theorem A (proved stabilization lemma + verified recurrence).**
Let D_n be a one-region twist-extension family as above with fixed part F, and
X = <closure(V+F)>, Y = <closure(H+F)> the two auxiliary (smoothed-box)
brackets. Then, with b_n = sum_{k=0}^{n-1}(-1)^k A^{n-2-4k}:
(i) <D_n> = A^n X + b_n Y for all n (skein induction; machine-verified n<=6);
(ii) the closed brackets satisfy the explicit three-term recurrence with
polynomial coefficients c_i(n) (2x2 minors in A^n, b_n), residual exactly 0
(machine-checked); equivalently b_{n+2} = A^{n+1}-A^{n-4}+A^{-6}b_n;
(iii) within each parity subclass (n mod 2 fixed), the normalized tail triple
(a0,a1,a2) is constant for full-twist index m>=0 (a1) and m>=1 (a2) — i.e.
thresholds m1<=1, m2<=2 hold, with the only pre-stabilization anomaly at the
shortest seed (n=1), proved by the rigid top-comb + degree-gap argument and
verified on every family in scope.

**Theorem B (empirical count rule + gap criterion, 140/140 in scope, no
exceptions; extensions to c=17 agree).** For every alternating pretzel knot
(122 rows, c<=12) and every alternating pretzel link with integral V (18 rows):
|a0| = 1, |a1| = 1, and |a2| = #{twist boxes of length >= 2}.
Consequences: a2 = 0 iff all three boxes have length 1 (realized: P(1,1,1)
knot, tail (-1,1,0)); single-region torus knots T(2,N) have tail (1,0,1), i.e.
a1 = 0 (5/5 odd N>=3). Up to the overall sign (writhe side), stabilized values
are: one length>=2 box -> |a2|=1; two -> 2; three -> 3.

**Two-region form (empirical).** For D_{p,q} = P(p,q,3) with p,q odd:
|a2| = 1 if p=q=1; 2 if exactly one of p,q is 1; 3 if p,q>=3 — jointly stable
once both full-twist indices are >=1. This is the bivariate quadratic fragment
in miniature (values 1,2,3 = constant-plus-indicator form); the general
C(k,2)-s+delta parametrization of the target claim is NOT proved here and is
stated as a conjecture (Section 5).

## 3. Proof of Theorem A (skein induction)
Work in the Temperley-Lieb / Kauffman-bracket skein module of the 4-ended
tangle. Fix the calibrated convention: A-smoothing = rails-through (identity
V), B-smoothing = cup-cap (H). For the n-half-twist chain T_n, resolve the top
crossing: T_{n+1} = A·T_n + A^{-1}·(T_n with e inserted), where e is the
cup-cap generator. Using V·e = H and H·e = d·H:
T_n = A^n V + b_n H with b_{n+1} = A^{n-1} - A^{-3}b_n, b_1 = A^{-1},
whose solution is b_n = sum_{k<n}(-1)^kA^{n-2-4k} (check: b_2 = 1-A^{-4},
b_3 = A-A^{-3}+A^{-7}). Applying the closure functional <closure(-+F)> (linear)
gives (i); elimination gives (ii); iterating the one-step rule twice gives the
two-step full-twist rule. The script verifies the closed form on both
E-closures for n=1..6 and the decomposition/residual on closed diagrams.
For (iii): the measured top combs top(X)={(M,1),(M-8,2)},
top(Y)={(M-2,-1),(M-10,-1)} are rigid (n-independent shape up to uniform
shift); b_1 is the unique single-term case, so only the m=0 seed can differ,
and only in slots reached by b_n's missing lower terms (a2, not a0/a1).
Writhe grows linearly (w_n = w_F + s·n), so normalization is a uniform shift;
V-subsampling at fixed parity class then yields constant triples. The worked
f-tops for P(3,3,n) (n=1..4) exhibit the rigid comb explicitly.
