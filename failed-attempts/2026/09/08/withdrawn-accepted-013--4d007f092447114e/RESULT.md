# Sharp conic-plus stop at q+8 in PG(2,9): a (17,3)-arc and [17,3,14] NMDS code over F9

## Context
Dimension-3 NMDS codes over F_q are equivalent to (n,3)-arcs in PG(2,q)
(point sets with at most 3 points on any line, and at least one line
meeting the set in exactly 3 points). Recent work builds infinite
conic-plus families: [q+5,3,q+2] from maximal arcs (Xu/Fan/Han), and
[q+6,3,q+3] for all odd q plus [q+7,3,q+4] for odd q >= 11 from conics
(Donmez/Akpinar/Pelen, arXiv:2608.18192). The latter states that
admissible [q+7] parameters exist for no q <= 9 *within its parametric
family* (sixth point on a distinguished external line), leaving the q=9
conic-plus length open beyond that parametrization.

## Definitions
- PG(2,9): projective plane over F_9 = F_3[t]/(t^2+1), with 91 points,
  91 lines, 10 points per line. Points are normalized so the first
  nonzero coordinate is 1 (lexicographic enumeration 0..90).
- C: the nondegenerate conic {(1:t:t^2) : t in F_9} union {(0:0:1)},
  indices [0,10,20,29,39,52,58,66,76,88] (10 points, at most 2 per line).
- An (n,3)-arc: n points with at most 3 on any line.
- A conic-plus set is C union S with S disjoint from C.
- The code of a point set A is generated by the 3x|A| matrix whose
  columns are homogeneous coordinates of A; its weight is the number of
  nonzero positions. NMDS means d = n-k-1 and dual distance n-k^perp-1
  with k = 3.

## Result
The largest S subset of PG(2,9) \ C with C union S an (n,3)-arc has
|S| = 7. In particular:
1. There EXISTS a conic-plus (16,3)-arc in PG(2,9), i.e. a [16,3,13]
   NMDS code over F_9 (any 6 of the 7 extension points below).
2. The conic-plus route stops sharply at n = 17 = q+8: with
   S = [11,27,53,62,72,79,90], A = C union S is a (17,3)-arc, i.e. a
   [17,3,14] NMDS code over F_9, and no 8th off-conic point can be added
   to C (hence to any nondegenerate conic, by PGL(3,9) transitivity).
Coordinates (x,y,z): C = (0,0,1),(1,0,0),(1,1,1),(1,2,1),(1,3,2),
(1,4,6),(1,5,3),(1,6,2),(1,7,3),(1,8,6);
S = (1,0,1),(1,1,8),(1,4,7),(1,5,7),(1,6,8),(1,7,6),(1,8,8).
Line-occupancy spectrum of A over all 91 lines:
{#0-secants: 19, #1: 12, #2: 22, #3: 38} (sums to 91; max 3).
Raw weight distribution (728 = 9^3-1 nonzero codewords):
14:304, 15:176, 16:96, 17:152
(projective: 14:38, 15:22, 16:12, 17:19), so d = 14 = n-k+1-1.
Dual distance is 3 (38 trisecants exist). Trisecants through added
points: 11:8, 27:8, 53:7, 62:6, 72:7, 79:7, 90:7.
Setwise stabilizer in PGL(3,9) is trivial (order 1; 8 GL(3,9) matrices
differing by F_9* scalars). Puncturing one point of S gives
[16,3,13] NMDS codes (e.g. drop 90: 13:248, 14:216, 15:104, 16:160;
drop 11: 13:240, 14:240, 15:80, 16:168).

## Proof / Evidence (machine-checked exhaustive search)
For a line L with c = |L cap C| and s = |L cap S|, validity is
c+s <= 3: c=2 (45 bisecants) forces s<=1 (1260 forbidden pairs among 81
off-conic points); c=1 (10 unisecants) forces s<=2 (840 forbidden
triples); c=0 (36 exterior lines) forces s<=3 (quadruple constraints).
`maxcap_search.py` branch-and-bounds all 81 off-conic points under
exactly these constraints: optimum 7 (17424 nodes, ~0.5 s).
`verify_all.py`, an independently written verifier (different order,
forward checking, direct 9^3 weight recount), confirms the witness
table, the enumerator, and the global optimum 7 (24389 nodes).
The audit independently re-proved the optimum with a third
implementation (capacity counters, include/exclude search: optimum 7,
243711 nodes, 0.29 s, distinct witness [1,2,14,23,54,64,87]) and
re-enumerated the stabilizer by frame transport over all 1848 ordered
non-collinear 4-frames of A (8 GL matrices, PGL order 1). All scripts
rebuild PG(2,9) from scratch with stdlib only and agree.

## Limitations
- Decision covers the conic-plus prescription only; general
  non-conic-containing (16,3)/(17,3)-arcs in PG(2,9) are not classified.
- Fixing one conic is without loss by PGL(3,9) transitivity on
  nondegenerate conics (cited standard theorem, not recomputed).
- No computed monomial-equivalence comparison against the
  Fan/Wang/Xu or Donmez codewords (their matrices were unavailable);
  distinguishing data supplied are the trivial projective stabilizer,
  the trisecant spectrum/profile, and the enumerator.
- LRC locality-2 optimality is not separately proved.

## Reproducibility
Run (stdlib only, < 1 s each on one core):
`python3 output/artifacts/witness_analysis.py` (needs
`output/artifacts/maxcap_result.json`; rebuilds PG(2,9), checks the
17-point line table, recounts the enumerator by direct 9^3 enumeration,
prints spectrum, weights, trisecant profile);
`python3 output/artifacts/verify_all.py` (independent replay of witness
plus global optimum 7); `python3 output/artifacts/maxcap_search.py`
(primary optimum search); `python3 output/artifacts/stabilizer.py`
(frame-transport stabilizer count; needs both JSON files).
