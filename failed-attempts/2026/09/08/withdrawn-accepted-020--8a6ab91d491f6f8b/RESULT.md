# Exact covering-radius census fragment for binary linear codes, lengths 20–24

## Context

The covering radius of a binary linear code is the maximum Hamming distance
from any vector in F_2^n to the code (the packing-side dual is the minimum
distance). The least covering radius R\*(n,k), the minimum covering radius
over all binary linear [n,k] codes, is a recognized benchmark tracked by
covering-code tables and a dedicated least-covering-radius literature
(small lengths; dimension 6) plus general sphere-covering / Delsarte /
redundancy bound theory, with downstream uses in quantization, covering-code
shortening/lengthening constructions, and syndrome-decoding benchmarks.
Published covering tables list numeric bounds without parity-check witnesses
or coset-leader replay in the length 20–24 window.

## Definitions

- Let H be an r × n binary matrix with r = n − k, rank(H) = r, no zero
  column. It is the parity check matrix of a binary linear [n,k] code
  C = {x : Hx^T = 0}.
- Write the n columns of H as vectors in F_2^r. For a syndrome s in F_2^r,
  its coset-leader weight is min{w : s = XOR of w columns of H}.
- The covering radius rho(H) = max over all 2^r syndromes of the
  coset-leader weight (equivalently, max distance of any vector to C).
- The least covering radius R\*(n,k) = min rho over binary linear [n,k] codes.
- The coset weight distribution (cwd) is the vector (A_0,...,A_rho) where
  A_w = number of syndromes of coset-leader weight exactly w; hence
  sum A_w = 2^r, A_0 = 1.
- The sphere-covering lower bound: any [n,k] code with covering radius rho
  satisfies sum_{i=0}^{rho} C(n,i) ≥ 2^{n-k}; the least such rho is the
  sphere bound LB(n,k) ≤ R\*(n,k). Hence rho(H) = LB implies R\*(n,k) = rho(H).

## Proof / evidence

For each committed H:
1. Shape/binary check, GF(2) rank check (rank = n−k), no-zero-column check.
2. Exact covering radius by exhaustive breadth-first layering of the Cayley
   graph of F_2^r generated by the n columns: distance 0 at syndrome 0,
   each layer = XOR-shifts of the frontier by all columns; visits every one
   of the 2^r syndromes. Max layer = rho; layer sizes = cwd. Finite
   exhaustive enumeration, not heuristic. (Search that found H — random
   systematic sampling + Golay/BCH-shorten seeds + hill-climbing on the
   coverage-at-(rho−1) objective — is heuristic; verification of the stored
   H is exact.)
3. cwd summation check (sums to 2^r), sphere-bound recomputation
   sum_{i≤rho} C(n,i) ≥ 2^r with minimality flag.
4. Optimality inference only where rho equals the sphere lower bound:
   LB ≤ R\* ≤ rho = LB forces R\* = rho.

Audit replay: `verify.py` reports 35/35 OK with 9 sphere-optimal pins;
independent stdlib (non-numpy) deque-BFS on five cells and independent
bit-integer GF(2) rank checks confirm the results; sphere-LB values,
gap flags, and redundancy bound rho ≤ n−k rechecked for all 35.

## Limitations

- Least-ness proved only at the 9 sphere-bound-meeting cells; the other 26
  rho values are certified upper bounds, possibly improvable.
- The (23,12) and (24,12) pins are classical Golay facts; novelty is the
  replayed witness, not the value.
- The k=6 column falls under the dimension-6 classification; draft values
  there are upper bounds only.
- The (20,8) and (21,7) rho values coincide with known small-length optima
  but are claimed only as upper bounds here.
- No Delsarte/supercode lower-bound strengthening attempted.
- Matrices are machine-found; inequivalence/canonicity not addressed.
- No live-table-beating claim is made.
