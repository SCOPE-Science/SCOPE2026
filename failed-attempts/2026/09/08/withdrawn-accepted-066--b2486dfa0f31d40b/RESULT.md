# Hochster-replay Betti census of edge ideals over all connected graphs on 5–7 vertices: exact reg − indmatch gap maximum

## Context and motivation

For a finite simple graph $G$, the edge ideal $I(G) \subset S = k[x_v : v \in V(G)]$
is generated by the quadrics $x_u x_v$ for edges $uv \in E(G)$.
Two guiding programs relate homological invariants of $S/I(G)$ — projective
dimension $\mathrm{pd}$ and Castelnuovo–Mumford regularity $\mathrm{reg}$ — to
combinatorial matching numbers: the induced-matching number $\mathrm{im}(G)$
and the minimum-cardinality maximal-matching number $\mathrm{min\text{-}match}(G)$.
Hibi–Higashitani–Kimura–Tsuchiya prove
$\mathrm{im}(G) \le \mathrm{reg}(S/I(G)) \le \mathrm{min\text{-}match}(G)$;
Nguyen–Vu classify linearity defect $\le 1$ via weakly chordal graphs with
$\mathrm{im} \le 2$; Matsuda–Yoshida determine realizable
$(\mathrm{ind\text{-}match}, \mathrm{min\text{-}match}, \mathrm{match}, n)$ and
$(\mathrm{reg}, \mathrm{min\text{-}match}, \mathrm{match}, n)$ tuples.
None publishes a uniform per-graph Betti census with gap certificates over all
connected $5$–$7$-vertex graphs. This record supplies it.

## Definitions

- Scope: one representative per isomorphism type of connected simple graph with
  $n \in \{5,6,7\}$: $21 + 112 + 853 = 986$ types (OEIS A001349).
- $S = k[x_0,\dots,x_{n-1}]$ over the fixed declared field $k = \mathbb{F}_{32003}$;
  $I(G) = (x_u x_v : uv \in E(G))$.
- Graded Betti numbers $\beta_{i,j}(S/I(G))$ via the Hochster formula for the
  independence complex $\Delta(G)$:
  $\beta_{i,j} = \sum_{|W|=j} \dim \tilde{H}_{j-i-1}(\Delta_W)$.
- $\mathrm{pd}(G) = \max\{i : \beta_{i,j} \ne 0\}$,
  $\mathrm{reg}(G) = \max\{j-i : \beta_{i,j} \ne 0\}$,
  $\mathrm{im}(G)$ = induced-matching number,
  $g(G) = \mathrm{reg}(G) - \mathrm{im}(G)$,
  $d_{\max} = \max_G g(G)$.

## Result (computed, replay-certified)

Over all $986$ connected graphs on $5$–$7$ vertices (field $\mathbb{F}_{32003}$):

- Regularity distribution:
  $n=5$: $17 \times \mathrm{reg}\,1$, $4 \times \mathrm{reg}\,2$;
  $n=6$: $67 \times \mathrm{reg}\,1$, $45 \times \mathrm{reg}\,2$;
  $n=7$: $299 \times \mathrm{reg}\,1$, $550 \times \mathrm{reg}\,2$, $4 \times \mathrm{reg}\,3$.
- Distinct graded Betti tables: $286$ total ($15$ on $5$ vertices, $55$ on $6$,
  $269$ on $7$; strata overlap, union $286$).
- **$d_{\max} = \max(\mathrm{reg} - \mathrm{im}) = 1$**, attained by exactly
  $48$ types ($1$ on $5$ vertices, $5$ on $6$, $42$ on $7$);
  every attainer has $(\mathrm{reg}, \mathrm{im}) = (2,1)$.
- The sandwich $\mathrm{im}(G) \le \mathrm{reg}(G) \le \mathrm{min\text{-}match}(G)$
  holds on all $986$ rows.

## Proof / evidence (reproducible computation)

1. One representative per isomorphism type generated by canonical augmentation
   (every connected $(n+1)$-graph has a non-cut vertex whose deletion is
   connected), canonicalized by lex-min adjacency bitstring; counts verified
   $21/112/853$ against OEIS A001349; every output connectivity-checked.
   Auditor brute-force re-enumeration of all labeled $5$-vertex graphs gives
   $21$ connected types, confirming the pipeline on that stratum.
2. Each graded Betti number regenerated from the Hochster formula with exact
   modular boundary ranks over $\mathbb{F}_{32003}$; per-row checks
   $\beta_{1,2} = m$ and Euler sum $= 0$; engine self-tests pass
   ($C_5$: $\beta_{2,3} = 5$, $\beta_{3,5} = 1$, pd $3$/reg $2$;
   $K_5$: reg $1$/pd $4$; $C_7$: reg $2$).
3. $\mathrm{im}$ by exhaustive edge-subset search with witness;
   $\mathrm{min\text{-}match}$ by exhaustive maximal-matching search; gap table
   derived; $d_{\max}$ read off.
4. Independent audit (separate code path): $G^*$ recomputed with exact
   $\mathbb{Q}$ (Fractions) ranks — identical table (consistent with Katzman
   field-independence for $n \le 10$); random $40$-graph sample (seed $223$)
   $\mathbb{F}_p$ == $\mathbb{Q}$ == table row, with pd/reg/im rechecks;
   auditor re-ran $8$ further random rows $\mathbb{F}_p$ == $\mathbb{Q}$ ==
   census row plus witness adjacency-level checks (empty unjoined-pair list,
   covering min-match witness, cancellation closure).

## Limitations

- Numbers are certified over the declared field $\mathbb{F}_{32003}$;
  $\mathbb{Q}$ agreement is recomputed on $G^*$ plus samples (with Katzman
  theory), not all $986$ rows — a full-$\mathbb{Q}$ rerun is seconds-scale
  future work.
- "New" means: no prior publishes this uniform $986$-row replay table with gap
  enclosures (bounds/family formulas/realizability ranges exist: Hibi et al.,
  Nguyen–Vu, Matsuda–Yoshida); the computation itself uses standard formulas.
- Per-row `taylor` fields in the full census file are $\binom{m}{i}$ dimension
  placeholders; the genuine consecutive-cancellation certificate is logged for
  $G^*$ in `witness_audit.json`.
