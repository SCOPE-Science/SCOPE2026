# FAILED ATTEMPT — NOT A VALIDATED FINDING

This package contains a reproducible 325-case census of 13-element subsets of
`Z/157Z` fixed by multiplication by 13. The census is computationally correct, but
it is not an original exclusion of a cyclic `(157,13,1)` difference set.

The classical multiplier theorem is stronger: for a planar abelian difference set
with `n=k-lambda=12`, the divisor 2 is a numerical multiplier. After translation,
the difference set may be taken to be fixed by multiplication by 2. Since
`ord_157(2)=52`, the action of multiplication by 2 on `Z/157Z` has orbit sizes
`1,52,52,52`, so no fixed set can have size 13. Thus the entire cyclic case is
excluded without the 325-case search.

The original record also overstates a code-transfer argument: the binary rank of
the circulant code generated by translates of one subset does not, by itself,
exclude that subset from appearing as a block of an arbitrary noncyclic symmetric
`2-(157,13,1)` design.

The computation is preserved for reproducibility and historical value only.
