# Disproof of small-time local exact controllability for the two-input Schrödinger system on S²

## Context

The admitted target asks whether the bilinear Schrödinger system on the two-sphere S² with two real scalar controls,

i ∂_t ψ(t,ω) = −Δ_{S²} ψ(t,ω) + u_1(t) cos θ ψ(t,ω) + u_2(t) sin θ cos φ ψ(t,ω),

with state in the unit sphere S of L²(S²,C) and controls in L^∞((0,T),R), is small-time locally exactly controllable around the constant ground-state orbit ψ_0(t) = (4π)^{−1/2}. Precisely, the target requires either constructing T* > 0, C > 0, q ≥ 0, δ > 0 such that every H³ target within δ of ψ_0(T) is exactly reachable in time T ≤ T* with cost bounded by C T^{−q} via a two-input return-method trajectory, or rigorously proving that no such quadruple exists through a two-input drift, selection-rule, or cost blow-up obstruction valid for all bounded small-time control pairs.

## Definitions

Write (x,y,z) for Cartesian coordinates on S² and (θ,φ) for spherical coordinates, so that V_1 = z = cos θ and V_2 = x = sin θ cos φ. Let r(x,y,z) = (x,−y,z), i.e. φ ↦ −φ, and define the pullback (Rψ)(θ,φ) = ψ(θ,−φ). Let E = {ψ : Rψ = ψ} be the closed R-even subspace of L². Let φ_0 = (4π)^{−1/2}, η = √(3/4π) y = √(3/4π) sin θ sin φ, N = √(1+ε²), and ψ_{f,ε} = (φ_0 + εη)/N.

## Result

For every T > 0 and every u_1,u_2 ∈ L^∞((0,T),R), the mild solution of the system from ψ(0) = φ_0 satisfies Rψ(t) = ψ(t) for all t. Consequently the system is not locally exactly controllable around φ_0 in H³ ∩ S in any time T > 0 with any controls, and a fortiori not small-time locally exactly controllable with any polynomial cost bound C T^{−q}. In particular no quadruple (T*,C,q,δ) as in the target claim exists. The mixed quadratic bracket of V_1,V_2 breaks continuous L_z rotation invariance but not this Z_2 reflection.

## Proof / evidence

R is linear unitary on L², bounded on every H^s, satisfies R² = I, R* = R, and Rφ_0 = φ_0. Both potentials are R-even: V_1 is φ-independent and cos(−φ) = cos φ, so V_k ∘ r = V_k and RM_{V_k} = M_{V_k}R as multiplication operators. Since r is an S² isometry, R preserves each degree-ℓ spherical-harmonic eigenspace H_ℓ and commutes with −Δ_{S²} on H² and with the free group U_0(t) = exp(itΔ). In Duhamel form ψ(t) = U_0(t)ψ(0) − i∫_0^t U_0(t−s)[u_1(s)V_1+u_2(s)V_2]ψ(s) ds in C([0,T];L²), boundedness of V_k gives at most one mild solution by Gronwall. Setting ψ̃(t) = Rψ(t) and using the commutation relations shows ψ̃ solves the same integral equation with the same data whenever Rψ(0) = ψ(0); uniqueness gives ψ̃ ≡ ψ. Hence every reachable state from φ_0 lies in E for every T and every bounded or unbounded, real or complex control pair, and the Lie algebra generated by iΔ and iV_k preserves E.

The witness η is smooth, unit-normalized (∫x² = ∫y² = ∫z² = 4π/3), orthogonal to φ_0, satisfies −Δη = 2η, and Rη = −η. Each ψ_{f,ε} is smooth hence in H³, unit-normalized, and in H³ ∩ S. In the spectral H³ norm ∥f∥² = Σ_ℓ(1+ℓ(ℓ+1))³∥P_ℓf∥², ∥ψ_{f,ε} − φ_0∥² = (1/N−1)² + 27(ε/N)² → 0 as ε → 0, so every H³ ball about φ_0 contains such targets for small nonzero ε. By r-invariant change of variables, ⟨η,f⟩ = 0 for all f ∈ E, whence for any reachable ψ(T) ∈ E, ∥ψ(T) − ψ_{f,ε}∥_{L²} ≥ |⟨η,ψ(T) − ψ_{f,ε}⟩| = |ε|/N > 0. Exact equality in H³ implies equality in L², so ψ_{f,ε} is unreachable. Given any candidate (T*,C,q,δ), choosing ε with H³ distance below δ and any T ∈ (0,T*] negates the claim uniformly in controls and cost.

Numerical corroboration re-executed: pointwise evenness of x,z and oddness of y; ∥φ_0∥ = ∥η∥ = 1; ⟨φ_0,η⟩ ∼ 10^{−17}; exact spectral H³ distances and L² odd lower bounds for ε ∈ {0.5, 0.1, 0.01}. All checks passed.

## Limitations

The disproof exploits the exact evenness of the admitted pair (z,x) under y ↦ −y. It does not characterize the reachable set inside E, does not address triple-input or generic symmetry-breaking potentials, and uses standard mild-solution uniqueness for bounded multiplicative potentials rather than re-proving global well-posedness.

## Reproducibility

Definitions, commutation identities, Gronwall uniqueness, change-of-variables orthogonality, and Cauchy–Schwarz bound above suffice to replay the proof. The quadrature script output/artifacts/verify_selection_rule.py reproduces all analytic identities numerically with Gauss–Legendre × uniform-φ quadrature.
