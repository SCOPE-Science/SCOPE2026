# Quasiconvex genus-4 surface subgroup in G1 = <a,b,c | ([a,b]c^2)^2>

## Context
A question attributed to Gromov asks whether every one-ended hyperbolic group contains a subgroup isomorphic to the fundamental group of a closed hyperbolic surface. For one-relator groups with torsion, which are hyperbolic by Newman's spelling theorem, recent work (Wilton; Ng) establishes quasiconvex surface subgroups for sufficiently large torsion exponents via Dehn-filling machinery, leaving small exponents open. The admitted target asks for a complete two-sided answer for the specific group G1 = <a,b,c | w1^2 = 1> with w1 = aba^{-1}b^{-1}cc = [a,b]c^2: either exhibit an explicit finitely generated quasiconvex closed-hyperbolic-surface subgroup, or prove none exists.

## Definitions
Let F = F(a,b,c), w1 = aba^{-1}b^{-1}cc, r = w1^2, G1 = <a,b,c | r = 1>. Let phi: F -> Z/4 send a|->0, b|->0, c|->1. Since phi(w1) = 2, phi(r) = 0, phi descends to phi: G1 -> Z/4. Let H = ker(phi), of index 4, with Schreier transversal T = {1, c, c^2, c^3}. Write a_i = c^i a c^{-i}, b_i = c^i b c^{-i} for i = 0,...,3 and z = c^4. A closed orientable surface group of genus g >= 2 is the group <x1,y1,...,xg,yg | [x1,y1]...[xg,yg] = 1>; it is a closed hyperbolic surface group. A subgroup of a hyperbolic group is quasiconvex if geodesics between its points fellow-travel it up to a uniform constant; finite-index subgroups are quasiconvex.

## Result
H = ker(phi: G1 -> Z/4) is an index-4 subgroup of G1 isomorphic to the fundamental group of the closed orientable surface of genus 4. It is explicitly generated by the eight elements c^i a c^{-i}, c^i b c^{-i} (i = 0,...,3). Since G1 is hyperbolic, H is quasiconvex in G1. This affirmatively resolves the admitted target.

## Proof / Evidence
G1 is a one-relator group with torsion: w1 is cyclically reduced (first letter a, last letter c), involves all generators, has abelianization (0,0,2) hence is non-primitive, and is not a proper power (a cyclically reduced square root would have length 3, but the first three letters a,b,a^{-1} differ from the last three b^{-1},c,c). By Newman, G1 is Gromov hyperbolic. Every nontrivial torsion element is conjugate to w1 (Fischer-Karrass-Solitar); since phi(w1) = 2 != 0, H is torsion-free.

Reidemeister-Schreier with transversal T gives generators a_i, b_i, z and four relators obtained by tracing r from each coset:
R0 = [a0,b0][a2,b2]z, R1 = [a1,b1][a3,b3]z, R2 = [a2,b2]z[a0,b0], R3 = [a3,b3]z[a1,b1].
The c^2 block shifts the coset by 2 before the second commutator, which explains the index-2 offset; the final two c-steps contribute z exactly once. All four rewrites are machine-verified and hand-traceable.

Put U = [a0,b0][a2,b2], V = [a1,b1][a3,b3], so R0 = Uz, R1 = Vz. Eliminating z = U^{-1} via R0 makes R2 freely trivial; equivalently R3 is conjugate to R1' = V U^{-1} (checked by free reduction). The surviving presentation is L = <a0..a3,b0..b3 | [a0,b0][a2,b2] = [a1,b1][a3,b3]>, i.e. single relator S = [a0,b0][a2,b2][a3,b3]^{-1}[a1,b1]^{-1}. Setting x1=a0,y1=b0,x2=a2,y2=b2,x3=b3,y3=a3,x4=b1,y4=a1 gives S = [x1,y1][x2,y2][x3,y3][x4,y4] = 1, the standard genus-4 presentation. Each of the 8 generators occurs exactly twice with exponent-sum 0; Euler characteristic chi = 1-8+1 = -6 = 2-2g gives g = 4, hence a closed hyperbolic surface group. Since z = U^{-1} is a word in the a_i, b_i, H is generated by the eight stated conjugates. Finite index (coset representatives 1,c,c^2,c^3 of lengths 0,1,2,3, coarse density constant 3) implies H is quasiconvex in G1.

## Limitations
Quasiconvexity uses the general finite-index-in-hyperbolic fact rather than an optimized constant. Hyperbolicity uses Newman's spelling theorem and torsion-freeness uses the standard one-relator-torsion classification as cited facts. No other limitations affect the existence claim.
