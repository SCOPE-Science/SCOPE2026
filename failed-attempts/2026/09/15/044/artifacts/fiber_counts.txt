# Fiber-multiplicity counts for X1=[0,1]∨[0,1]^2 vs X2=X1∨[0,1]

Stratum: points of X^N with exactly j square-coordinates (loc.dim N+j),
minus the wedge-point singular set (any coordinate = *).
Each interval coordinate minus {*} contributes 1 punctured branch in X1
vs 2 punctured branches in X2; each square coordinate minus {*} is connected.

N j C(N,j) X1_components=C(N,j) X2_components=C(N,j)*2^(N-j) r_inf_value=gamma*(1+j/N)
