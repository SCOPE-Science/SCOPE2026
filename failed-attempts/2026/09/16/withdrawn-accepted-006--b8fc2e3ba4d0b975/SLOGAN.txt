Dot-product set A_n in F_2^n x F_2^n x F_2 at density >=1/2 has x-fibres exactly kernels ker(chi_y) with trivial total intersection. Any fixed Bohr set covering fraction c of these fibres needs rank >= n+log2(c), so fibrewise Sanders plus pigeonholing cannot reach delta-only bounds; trilinear proofs need genuinely varying frequencies M_k(y,z).
