# A resonance at m = 2p - 1 controls second-order tails in weighted porous-medium self-similarity

## Statement

Consider the self-similar profile equation

\[
(f^m)''+\frac{N-1}{\xi}(f^m)'+\alpha f-\beta\xi f'-\xi^\sigma f^p=0,
\]

with

\[
1<p<m,\qquad \sigma>0,\qquad N\ge 1,
\]
\[
\alpha=\frac{\sigma+2}{\sigma(m-1)+2(p-1)},\qquad
\beta=\frac{m-p}{\sigma(m-1)+2(p-1)}.
\]

Iagar--Munteanu prove that every bounded self-similar profile has the common leading tail

\[
f(\xi)\sim c_*\xi^{-q},\qquad
q=\frac{\sigma}{p-1},\qquad
c_*=\left(\frac1{p-1}\right)^{1/(p-1)}.
\]

Define

\[
D=\sigma(m-1)+2(p-1),\qquad
r=\frac{D}{p-1}=2+(m-1)q,
\]
\[
h=\frac1\beta=\frac{D}{m-p},\qquad
s=mq=\frac{m\sigma}{p-1},
\]

and write the relative tail error as

\[
f(\xi)=c_*\xi^{-q}(1+\varepsilon(\xi)).
\]

Then the first correction to the universal tail changes character exactly at
\(m=2p-1\).

### (i) Diffusion-forced regime: m < 2p - 1

Here \(r<h\), and every bounded profile satisfies

\[
\boxed{
\varepsilon(\xi)=A_{\rm dif}\,\xi^{-r}+o(\xi^{-r})
}
\]

with the universal coefficient

\[
\boxed{
A_{\rm dif}
=\frac{(p-1)c_*^{m-1}s(s-N+2)}{2p-1-m}.
}
\]

Thus the first relative correction is independent of which bounded self-similar profile is selected.

### (ii) Resonant regime: m = 2p - 1

Here \(r=h\). If

\[
A_0:=c_*^{m-1}s(s-N+2)\ne0,
\]

then every bounded profile satisfies

\[
\boxed{
\varepsilon(\xi)
=\frac{A_0}{\beta}\,\xi^{-r}\log\xi+O(\xi^{-r}).
}
\]

The logarithm is generated by resonance between the diffusion-forced tail mode and the homogeneous stable mode.

### (iii) Homogeneous-mode regime: m > 2p - 1

Here \(h<r\). For every bounded profile there is a constant \(K_f\in\mathbb R\), depending on the selected profile, such that

\[
\boxed{
\varepsilon(\xi)=K_f\,\xi^{-h}+o(\xi^{-h}).
}
\]

Thus, generically, the first correction is no longer universal: it retains information about the global profile. If \(K_f=0\), the profile decays faster than \(\xi^{-h}\); no universal next term is asserted in that exceptional case because nonlinear harmonics can precede the diffusion-forced mode.

There is a separate geometric cancellation when

\[
\boxed{s=N-2,\quad\text{i.e.}\quad \frac{m\sigma}{p-1}=N-2.}
\]

Then \(A_0=0\), so the leading diffusion forcing vanishes. This can occur only for \(N\ge3\). In regime (i) the conclusion sharpens to \(\varepsilon=o(\xi^{-r})\); at resonance only \(\varepsilon=O(\xi^{-r})\) is asserted without a logarithmic leading term.

## Derivation

Set \(t=\log\xi\) and

\[
F(t)=f(e^t)=c_*e^{-qt}(1+\varepsilon(t)),\qquad
G(t)=(1+\varepsilon(t))^m.
\]

For a radial function \(g(e^t)\),

\[
g''(\xi)+\frac{N-1}{\xi}g'(\xi)
=e^{-2t}\left(g_{tt}+(N-2)g_t\right).
\]

Since \(c_*^{p-1}=1/(p-1)\) and

\[
\alpha+\beta q=\frac1{p-1},
\]

the profile equation becomes the exact relative-error equation

\[
\boxed{
\beta\varepsilon_t
+\frac{(1+\varepsilon)^p-(1+\varepsilon)}{p-1}
=c_*^{m-1}e^{-rt}
\Big[G_{tt}+(N-2-2s)G_t+s(s-N+2)G\Big].
}
\]

The leading-tail analysis in arXiv:2609.20397v1 is obtained from a three-dimensional autonomous system whose relevant orbit approaches the point corresponding to the above universal tail on a stable center manifold. In the logarithmic radial variable, the two linear decay rates relevant to this approach are precisely

\[
r=\frac{D}{p-1},\qquad h=\frac{D}{m-p}=\frac1\beta.
\]

The same center-manifold description supplies the decay and derivative control needed to expand the exact equation. Since \(\varepsilon\to0\), it yields

\[
\beta\varepsilon_t+\varepsilon
=A_0e^{-rt}+o(e^{-rt})+O(\varepsilon^2),
\qquad
A_0=c_*^{m-1}s(s-N+2).
\]

The two exponents cross when

\[
r=h
\iff
\frac{D}{p-1}=\frac{D}{m-p}
\iff
m=2p-1.
\]

For \(r\ne h\), variation of constants gives a forced term

\[
\frac{A_0}{1-\beta r}e^{-rt},
\qquad
1-\beta r=\frac{2p-1-m}{p-1},
\]

plus the homogeneous term \(K_fe^{-ht}\). Whichever exponent is smaller controls the first correction. This gives (i) and (iii). At \(r=h\), the forcing has the same exponential rate as the homogeneous solution and variation of constants instead produces

\[
\frac{A_0}{\beta}\,t e^{-rt},
\]

which is exactly the logarithmic correction in (ii).

The factor \(s(s-N+2)\) has a direct geometric origin:

\[
\Delta_{\rm rad}\,\xi^{-s}
=s(s-N+2)\xi^{-s-2}.
\]

Hence the additional cancellation \(s=N-2\) is the vanishing of the radial diffusion curvature of the leading power \(f^m\).

## Interpretation

The source theorem shows that all bounded self-similar profiles share the same leading tail. The refinement above reveals that this universality has a sharp second-order boundary:

- for \(m<2p-1\), diffusion fixes the first correction and its coefficient;
- at \(m=2p-1\), the two stable tail rates resonate and force a logarithm;
- for \(m>2p-1\), the slower homogeneous mode generically carries profile-specific information.

This distinction is relevant when the self-similar profiles are used as asymptotic patterns: two profiles that are indistinguishable at leading order can either remain locked through the first correction or separate already at the first subleading scale, depending only on the position of \(m\) relative to \(2p-1\).

## Limitations

The result concerns bounded radial self-similar profiles of the weighted porous-medium equation in the range \(1<p<m\), using the tail manifold established in arXiv:2609.20397v1. It does not determine which global profiles in the supercritical regime have \(K_f=0\), nor does it classify the next term after such an exceptional cancellation. When \(s=N-2\), a higher-order expansion is required to identify the first nonzero diffusion contribution. No claim is made here about convergence rates of general PDE solutions toward these profiles; that is a separate large-time problem.
