# Independent mathematical audit

## correctness

PASS

Surjective self-maps are permutations and, on a finite poset, order automorphisms; order-theoretic height/coheight preserves each two-point level, giving exactly 2^{n+1} homeomorphisms. For a proper image, if every occupied target level were full, incomparable preimages force levelwise paired images and the intervening-level order constraints propagate occupation across all levels, contradicting nonsurjectivity; hence some occupied target level is a singleton. Removing occupied levels toward that singleton by beat points contracts the image, so every nonhomeomorphism factors through a contractible finite subspace and is null-homotopic. Stong rigidity for a minimal finite space makes every homeomorphism a singleton homotopy class. The packaged enumeration for n=1,2,3 checks map counts, proper-image contractions and automorphism isolation but is not used for the universal quantifier.
