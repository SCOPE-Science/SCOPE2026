Reproduction instructions: run `python3 code/reproduce.py` from this directory. Dependencies: Python 3, SymPy and a C++17 compiler. The script compiles two independent C++ calculations, exhaustively enumerates all 1,048,575 nonzero cubics into 141 projective orbits, checks projective smoothness on all four charts by exact Groebner bases, computes tangent-plane Eckardt geometry by a separate symbolic method, checks 3-rational-line incidence directly, and compares regenerated outputs with data files. data/orbits_all.txt lists all nonzero cubic orbits; data/smooth_classification.json includes all smooth/singular decisions; data/independent_contacts.json records the 36 smooth-orbit contact types; data/refined_spectrum.csv is the full weighted 21-stratum table; data/smooth_orbits.csv lists all 36 smooth projective orbit representatives.
