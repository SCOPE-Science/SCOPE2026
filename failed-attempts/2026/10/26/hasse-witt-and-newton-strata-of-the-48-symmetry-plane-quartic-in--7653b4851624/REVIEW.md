# Independent mathematical audit

## correctness

PASS

The partial-derivative smoothness test works for p>=5. The standard degree-4 Cech Frobenius coefficient formula in the basis (2,1,1),(1,2,1),(1,1,2) reduces to nonnegative multinomial exponent equations, which yield supports diagonal 3 entries if p=1 mod12, an offdiagonal invertible 2×2 block if p=5, one diagonal entry if p=7, zero if p=11. These ranks are Frobenius stable; Cartier kernel has dimension 3−rank, and polarization/height constraints determine the listed Newton polygons. Independent exponent congruence script verified supports for all 27 primes 5..109. This checks arithmetic but is not itself an infinite proof.

## originality

FAIL

A decisive same-object alias was missed: over algebraic closure, put x=Y/X and y=Z/X on the X≠0 chart, so y^3=−(1+x^4). Choose ζ with ζ^4=−1 and u=ζ x; then y^3=u^4−1. The smooth projective model is thus geometrically isomorphic to the special Picard curve of Kazemifard and Tafazolian (2015), Theorem 3.6, which explicitly gives the SAME four Newton polygon classes for p=1,5,7,11 modulo 12. Their proof calculates Hasse–Witt ranks 3,2,1,0 (including Cartier matrices in the p=5 and7 cases), implying a-numbers 0,1,2,3. All claimed arithmetic invariants were covered eleven years earlier. Although direct publisher PDF access required disconnected VPN, the complete primary theorem and proof section are accessible as indexed publisher full-text HTML; no missing source ambiguity can overturn the explicit statement/implication. The original novelty claim fails and cannot pass through disclaimer.

Repeating that table in alternate plane-quartic coordinates without a further substantive invariant is known-table recomputation, not a new mathematical result.
