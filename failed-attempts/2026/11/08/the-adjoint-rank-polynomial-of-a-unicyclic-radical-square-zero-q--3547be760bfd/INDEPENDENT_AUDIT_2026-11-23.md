# Independent mathematical audit

## correctness

PASS

An edge with nonzero vertex difference supplies a row pivot in its own arrow column; the remaining nonzero rows have the rank of the incidence matrix on the edges with zero difference and nonzero arrow coefficient. Its sole possible deficiency from edge count is one, when it contains the whole cycle. Coherently signed differences on cycle edges obey one sum constraint; bridge differences are free and each permitted assignment has q lifts. For r active pairs on the cycle, the one-coordinate additive-character sum is q^2-1 for the trivial character and -1 otherwise. The full-cycle exceptional assignments contribute q(q-1)^c(z^(c-1)-z^c), independently of the bridges. Constant, linear, and top-degree assertions follow; the correction cannot affect degree zero or one since c >= 3. With all vertex labels equal, any rank below n can be achieved by using an acyclic arrow support of that size. For rank n, use a nonzero difference and its negative at two cycle edges and use all nonzero arrow coefficients; this also works in characteristic two. The centralizer dimension follows by rank-nullity. An original bounded computation of the span sizes of the basis images confirmed the full histograms on seven small quivers: e.g. triangle over F4 (4,36,792,3264), F2 triangle with a bridge (2,12,50,120,72), F2 square (2,8,60,106,80).

## originality

FAIL

The same polynomial was already published in Graphic-matroid adjoint-rank spectra in radical-square-zero quiver algebras. The change from counting distinct inner derivations to counting representing elements is multiplication by q for a connected graph, stated in the earlier record itself. Neither the cycle-length recovery nor the centralizer-dimension restatement survives as a substantive new result.
