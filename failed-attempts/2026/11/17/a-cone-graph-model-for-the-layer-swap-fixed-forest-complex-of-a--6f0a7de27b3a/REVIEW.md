Paired cross-edges on a selected base-edge set A give two covers of each tree component when A is a forest; cycles in A lift to cycles. A chosen diagonal v+v- bridges two lifted tree components; a second diagonal in the same base component creates a cycle. Thus orbit-union forest condition is exactly A acyclic and each A component has at most one selected diagonal; exactly the same condition characterizes forests of the cone G*. This is functorial with vertex permutation. Read complete verification code checking 75 labeled graphs through four vertices and seven n=5 graphs, 49,302 orbit subsets.
