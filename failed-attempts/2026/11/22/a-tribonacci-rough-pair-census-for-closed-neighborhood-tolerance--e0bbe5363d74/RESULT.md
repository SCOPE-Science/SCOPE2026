# A Tribonacci rough-pair census for closed-neighborhood tolerances on finite paths

## Finding

For the reflexive symmetric relation of a finite simple path, the number of **distinct** pairs of lower and upper rough approximations is given by

\[
\sum_{n\ge0} a_n t^n=\frac{1+t+t^3+t^4}{1-t-t^2-t^3}.
\]

The empty path is assigned the conventional value \(a_0=1\). For nonempty paths, the initial counts are \(a_1=2\), \(a_2=3\), \(a_3=7\), \(a_4=13\), followed by the exact recurrence \(a_n=a_{n-1}+a_{n-2}+a_{n-3}\) for each \(n\ge5\). This is an image-cardinality formula: repeated inputs producing the same pair are counted only once.

## Assumptions and scope

For every integer \(n\ge1\), let \(V_n=\{1,\ldots,n\}\) and let \(R_n\) consist of all ordered pairs at distance at most one on the ordinary path, including equality. Thus \(R_n\) is reflexive and symmetric, but generally not transitive. Write \(N[i]=\{j\in V_n:|j-i|\le1\}\). For each \(X\subseteq V_n\) define

\[L(X)=\{i\in V_n:N[i]\subseteq X\},\qquad U(X)=\{i\in V_n:N[i]\cap X\ne\varnothing\}.\]

Then \(a_n=|\{(L(X),U(X)):X\subseteq V_n\}|\). The theorem concerns this **single fixed closed-neighborhood tolerance**, not an equivalence partition constructed from the adjacency-information table and not the cardinality of the Boolean subalgebra generated by these pairs.

## Proof

**Step 1: a three-symbol output encoding.** Write the indicator of \(X\) as \(x_1\cdots x_n\in\{0,1\}^n\), and adopt boundary conventions \(x_0=x_1\), \(x_{n+1}=x_n\). For each position \(i\), record \(y_i=0\) if its closed neighborhood has all zeros, \(y_i=1\) if it has all ones, and \(y_i=*\) otherwise. The output symbols correspond respectively to \((\mathbf1_{L}(i),\mathbf1_{U}(i))=(0,0),(1,1),(0,1)\). Hence distinct rough pairs are in bijection with the distinct realizable output words \(y_1\cdots y_n\).

**Step 2: a finite recognizer of possible output words.** Use the four binary-pair states \(00,01,10,11\). A transition from state \((a,b)\) on an output symbol chooses \(c\in\{0,1\}\), emits \(0\) if \(a=b=c=0\), emits \(1\) if \(a=b=c=1\), and otherwise emits \(*\), moving to \((b,c)\). The allowed start states are \(00\) and \(11\) because \(x_0=x_1\); a terminal pair is admissible precisely when it is \(00\) or \(11\), because \(x_{n+1}=x_n\).

Determinize this nondeterministic recognizer by replacing each state with the set of possible binary pairs after a given output prefix. The start subset is \(\{00,11\}\); a subset accepts if it meets that start subset. The reachable-subset list has exactly twelve members:

```
{00,11}, {00}, {01,10}, {11}, {01}, {},
{00,01,10,11}, {10}, {10,11}, {00,01},
{00,01,10}, {01,10,11}.
```

Here the empty subset is a rejecting sink. The transition rule just described determines the entire subset automaton without an unverified inference from finite experimental counts.

**Step 3: complement symmetry and the seven-state transfer system.** Interchanging zeros and ones on all binary-pair states induces an involution on the twelve reachable subsets. Every two-element orbit has identical acceptance behavior, and after ignoring the rejecting sink, the orbits have names \(A,B,C,D,F,G,H\), with representatives

```
A={00,11}; B={00}; C={01,10}; D={01};
F={00,01,10,11}; G={10,11}; H={00,01,10}.
```

The representatives of \(B,D,G,H\) also stand for their complements. Their accepted-status vector, in this order, is \((1,1,0,0,1,1,1)\). The **weighted** transitions, with an integer coefficient counting distinct output letters, are exactly:

```
A -> 2B + C
B -> B + D
C -> F
D -> G
F -> 2B + F
G -> B + H
H -> B + F
```

Every missing transition leads to the rejecting sink. To verify these equations directly, apply the three possible symbols \(0,*,1\) to a representative and, if needed, replace its successor subset by the complement representative. For example, from \(A\), the symbols \(0\) and \(1\) lead to \(\{00\}\) and \(\{11\}\), both in orbit \(B\), while \(*\) leads to orbit \(C\). From \(C\), the only non-sink successor is \(F\).

**Step 4: solve the transfer equations for all lengths.** Let \(A(t),B(t),C(t),D(t),F(t),G(t),H(t)\) count accepted suffixes by length from the corresponding orbit. The terminal condition and transitions give the complete linear system

\[
\begin{aligned}
A&=1+t(2B+C),&B&=1+t(B+D),\\
C&=tF,&D&=tG,\\
F&=1+t(2B+F),&G&=1+t(B+H),\\
H&=1+t(B+F).
\end{aligned}
\]

Elimination gives \(B(t)=1/(1-t-t^2-t^3)\) and \(F(t)=(1+t)^2/(1-t-t^2-t^3)\), whence \(C(t)=tF(t)\) and

\[A(t)=\frac{1+t+t^3+t^4}{1-t-t^2-t^3}.\]

The start orbit is \(A\), so \(A(t)=\sum_{n\ge0}a_nt^n\). Coefficient extraction proves the claimed initial values and recurrence for every length, including the boundary cases. There are no extrapolations from finite enumeration.

**Step 5: growth.** The denominator has a unique smallest-modulus zero \(r=\lambda^{-1}\), where \(\lambda\approx1.839286755\) is the real root greater than one of \(\lambda^3=\lambda^2+\lambda+1\). All other roots have greater modulus, and the numerator is nonzero at \(r\). Hence \(a_n=\Theta(\lambda^n)\) and \(a_n/2^n\to0\) exponentially.

## Relationship to prior work

The 2026 work by Düntsch and Orłowska [1] motivates the lower/upper relational-operator viewpoint and its algebraic interpretation; it does not enumerate distinct pairs for closed-neighborhood tolerances on paths. Chiaselotti and collaborators [2,3] do analyze rough approximations of paths and other graphs, but form **equivalence classes from Boolean adjacency-information-table rows** and take their Pawlak approximations, which is a different relation from the reflexive, nontransitive closed-neighborhood tolerance here. Exact pair counts for a different graph family (complete multipartite tolerances) and incidence-order rough sets do not imply this path formula. Distinct appearances of a Tribonacci sequence do not establish logical implication or priority.

## Limitations

The count applies only to the reflexive distance-one tolerance on the **finite simple path**; it is not a formula for arbitrary trees, cycles, or equivalence-based Pawlak approximations. No assertion about the order-theoretic structure of the family of pairs, nor about multiplicities of preimages, follows from this census. A related path-focused work by Sanahuja [4] was available only at abstract level in the literature inspection and remains a residual priority risk.
